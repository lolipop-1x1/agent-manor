# 正式代码活动地图

Vite 构建产物由本地分析服务提供，页面通过同源 `/api/v1` 查询真实结果。页面没有示例数据，也没有原型切换器。

- 覆盖查询先取得完整仓库文件目录，再用返回的版本查询当前目录。后续文件、来源、原始证据保留相同客户端、时间、类别、目录和版本。
- 刷新任务独立轮询；完整新版本发布后切换结果，失败时保留上一版并展示失败原因。
- D3 treemap 的权重为后端提供的物理行数。零行文件可从文件列表进入；地图不会为它添加面积。活动着色使用 `activityCount`，不把可能重叠的计数相加。
- CodeMirror 6 只读显示当前内容，JavaScript／TypeScript／JSX／JSON 有语法高亮，其他文件明确按纯文本显示。精确与近似覆盖单独标记；内容过期或不可读时不应用旧范围。
- Radix Dialog、Dropdown Menu、Tooltip 实际用于对话框、仓库选择与提示。所有地图文件可通过键盘进入，也有文件列表作为窄小矩形的访问入口。
- 路径搜索仅筛选地图与文件列表，不改变后端统计分母；页面会提示这一范围。统计只由后端计算。

运行 `npm run check:web`、`npm run build:web` 和 `node --import tsx --test tests/web*.test.ts` 验证前端构建与核心展示不变量。真实仓库发现、刷新和浏览器交互需在服务集成后验收。
