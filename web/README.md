# 正式代码活动地图

Vite 构建产物由本地分析服务提供，页面通过同源 `/api/v1` 查询真实结果。页面没有示例数据，也没有原型切换器。

- 覆盖查询先取得完整仓库文件目录，再用返回的版本查询当前目录。后续文件、来源、原始证据保留相同客户端、时间、类别、目录和版本。
- 刷新任务独立轮询；完整新版本发布后切换结果，失败时保留上一版并展示失败原因。
- D3 treemap 的权重为后端提供的物理行数。零行文件可从文件列表进入；地图不会为它添加面积。活动着色使用 `activityCount`，不把可能重叠的计数相加。
- CodeMirror 6 只读显示当前内容，JavaScript／TypeScript／JSX／JSON 有语法高亮，其他文件明确按纯文本显示。精确与近似覆盖单独标记；内容过期或不可读时不应用旧范围。
- Radix Dialog、Dropdown Menu、Tooltip 实际用于对话框、仓库选择与提示。可读地图文件支持键盘聚焦，所有文件也可通过文件列表进入，作为窄小矩形的访问入口。
- 路径搜索仅筛选地图与文件列表，不改变后端统计分母；页面会提示这一范围。统计只由后端计算。
- 仓库目录默认显示顶层，箭头逐级展开或折叠，目录名称用于选择统计范围；折叠不改变当前筛选。地图与面包屑下钻会展开所选目录的祖先，切换仓库重置展开状态。
- 仓库导航与文件详情可独立收起，桌面保留窄边栏的恢复按钮，地图使用释放出的宽度并调整视野。收起保留当前选择；地图或文件列表选择文件后自动展开详情。窄屏面板上下排列，仍可收起内容。
- 拖动导航右边界或详情左边界调整宽度，收起后展开会恢复本次页面中调整后的宽度。分隔线可聚焦，用左右键微调、Shift 加速、Home／End 到达边界；地图至少保留 360 CSS 像素。窗口变窄时暂时压缩面板，恢复后沿用偏好；上下堆叠的面板不提供横向拖动。
- 地图内滚轮以鼠标位置为中心连续缩放，拖动平移；地图聚焦后可用 `+`、`-` 缩放、方向键平移、`0` 适应窗口，也有按钮入口。缩放只改变视野，不改变当前统计范围或触发分析。
- 文件面积使用浮点逻辑布局，显示时裁剪至可见区域。文件名、指标与行数按可读空间逐步出现，文字保持正常字号；超长路径可悬停或聚焦查看。选择列表中的小文件后，点击“定位所选文件”可直接进入其局部。
- 色块之间使用固定的 1 CSS 像素视觉间隔，不随缩放增粗；极小色块先保留面积，放大后再留出间隔。绘制间隔不改变逻辑文件面积或统计。
- 全屏保留目录面包屑、指标与图例，可按 Esc 或退出按钮返回。全屏、侧栏变化和指标切换保留局部；文件集合或目录改变时适应新范围。缩放能力按最小文件尺寸动态计算，并留出继续放大的余量。

运行 `npm run check:web`、`npm run build:web` 和 `node --import tsx --test tests/web*.test.ts` 验证前端构建与核心展示不变量。真实仓库发现、刷新和浏览器交互需在服务集成后验收。

安装好 `playwright-cli` 和 Chrome 后，运行 `npm run build && node scripts/e2e-workspace.mjs` 可重放目录与面板浏览器验收。脚本启动隔离后台，只创建合成仓库，将三类历史目录指向空测试目录；结束时关闭浏览器并清理临时数据。验收截图保存在忽略的 `.local/workspace-e2e/`，不进入发布包。

连续缩放的实际仓库验收使用 `node scripts/e2e-map-zoom.mjs`，运行前设置 `AGENT_MANOR_E2E_REPOSITORY` 为已登记仓库名称或路径；可通过 `AGENT_MANOR_E2E_URL` 指定服务地址，默认本机 4317。脚本只查询已发布结果，使用独立 Chrome 会话，不刷新或停止服务。真实输入和截图只留在忽略的 `.local/map-zoom-e2e/`；不要将它们加入 Git。
