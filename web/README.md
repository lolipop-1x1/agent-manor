# Web 前端

## 模块布局

- `app/`：应用导航、主题、跨页面跳转与五个页面的组装。
- `features/overview/`：默认总览、六分区独立首读与完整报告原子刷新、最多五条核心洞察、分页调查及单期仓库摘要；统计口径见 [总览看板](../docs/design/overview-dashboard.md)。
- `features/code-map/`：代码地图、仓库筛选、文件详情、覆盖与证据展示。`CodeMapPage.tsx` 的 `useCodeMapPage` 封装页面状态，向应用返回页面内容、页头操作、维护提示和地图定位入口，保持既有页面与页头布局。
- `features/sessions/`：会话列表、消息、画像、执行轨迹、搜索、速度与导出。`useContinuousReading.ts` 管理对话／全部记录的有界连续阅读与消息锚点；`SessionTurnNavigation.tsx` 统一轮次导航；`SessionTrace.tsx` 组织全宽节点表格和下方可调、可放大的正文详情。
- `features/resources/`：资源清单、使用统计、资源地图与管理操作。
- `features/usage/`：全局请求用量、估算费用、筛选地址、趋势／组成／排行／热力图、会话与请求分页，以及模型价格管理。
- `shared/ui/`、`shared/layout/`：统一控件、工作区布局及相关样式。`AppearanceMenu.tsx` 提供明暗模式、预设配色和点选自定义色盘，沿用共享偏好与主题变量。
- `shared/map/`、`shared/refresh/`：通用地图几何与相机计算、可见页面轮询。
- `shared/`：请求与错误处理、Web 国际化接入、格式化、时间筛选和主题应用。`i18n.tsx` 读写本地服务的共享语言、外观与自动刷新偏好；`theme.ts` 应用 `src/appearance.ts` 派生的颜色并同步 favicon。`shared/styles/base.css` 保留原有全局样式及级联顺序。

功能模块优先就近放置展示、模型与样式。`app` 组装功能，功能引用共享能力，`shared` 不反向引用功能；功能间的跳转通过应用层的目标参数与回调协调。共享契约、客户端定义和翻译目录继续复用仓库的 `src/`。

应用层的历史同步控制器统一管理手动检查、全局周期检查与任务轮询；自动同步在五页共享，网页隐藏时暂停新检查，恢复可见时补查，只有发布版本变化才通知页面重读。无变化自动检查不会重复读取报告、正文、画像和资源证据；当前活动页的历史相关读取通过稳定回调通知控制器暂缓下一次自动检查，读取期间到达的通知保留最新一条，完成后接续，不反复取消慢报告；全局按钮始终检查全部客户端，按钮原位显示阶段与进度，状态弹层只提供时间、处理数量、已用时间和错误重试。局部检查与完整检查保留在服务端及 CLI。完成通知由各页消费，隐藏页在激活后读取，代码地图分析与资源盘点继续独立；历史联动只更新资源使用相关数据，详情与同版本证据成功准备后一起替换，等待及失败保留旧结果。页面刷新入口复用 `shared/ui/RefreshControl.tsx`，原操作的失败重试与页面查询重试分别保留。

地图画布与文件表复用稳定输入和显示语言，历史进度轮询不重建大型结果；会话库已有内容的加载状态使用固定位置图标。最新验收见 [全局历史自动同步](../docs/validation/global-history-sync.md)。

五个页面始终挂载，通过 `hidden` 和 `active` 切换显示与请求；不要改成按当前页条件挂载，以免丢失筛选、阅读位置和地图视野。保留 `web/main.tsx`、Vite 根目录 `web` 及构建产物 `dist/web`。

外观、会话阅读和资源导航的操作入口见 [使用指南](../docs/usage.md)，呈现规范见 [设计系统](../DESIGN.md)，连续阅读与执行轨迹的数据边界见 [会话设计](../docs/design/session-history.md)。近期浏览器验收范围与重放命令见 [工作台验收](../docs/validation/workbench-refinements.md)，总览的统计、调查与性能证据见 [总览看板验收](../docs/validation/overview-dashboard.md)。

## 正式代码活动地图

Vite 构建产物由本地分析服务提供，页面通过同源 `/api/v1` 查询真实结果。页面没有示例数据，也没有原型切换器。

- 覆盖查询先取得完整仓库文件目录，再用返回的版本查询当前目录。后续文件、来源、原始证据保留相同客户端、时间、类别、目录和版本。
- 刷新任务独立轮询；完整新版本发布后切换结果，失败时保留上一版并展示失败原因。
- 登记复用项目选择器，候选来自全局会话索引，同时保留路径输入。重复登记进入已有仓库，不重复启动分析。
- 仓库菜单提供删除当前仓库及明确确认；分析中删除会撤销旧任务并清理仓库专属数据，保留全局会话与资源数据。异步旧响应及另一页面删除的状态不会继续显示失效仓库。
- D3 treemap 的权重为后端提供的物理行数。零行文件可从文件列表进入；地图不会为它添加面积。活动着色使用 `activityCount`，不把可能重叠的计数相加。
- CodeMirror 6 只读显示当前内容，JavaScript／TypeScript／JSX／JSON 有语法高亮，其他文件明确按纯文本显示。精确与近似覆盖单独标记；内容过期或不可读时不应用旧范围。
- Radix Dialog、Dropdown Menu、Tooltip 实际用于对话框、仓库选择与提示。可读地图文件支持键盘聚焦，所有文件也可通过文件列表进入，作为窄小矩形的访问入口。
- 路径搜索仅筛选地图与文件列表，不改变后端统计分母；页面会提示这一范围。统计只由后端计算。
- 仓库目录默认显示顶层，箭头逐级展开或折叠，目录名称用于选择统计范围；折叠不改变当前筛选。地图与面包屑下钻会展开所选目录的祖先，切换仓库重置展开状态。
- 仓库导航与文件详情可独立收起，桌面保留窄边栏的恢复按钮，地图使用释放出的宽度并调整视野。收起保留当前选择；地图或文件列表选择文件后自动展开详情。窄屏面板上下排列，仍可收起内容。
- 拖动导航右边界或详情左边界调整宽度，收起后展开会恢复本次页面中调整后的宽度。分隔线可聚焦，用左右键微调、Shift 加速、Home／End 到达边界；地图至少保留 360 CSS 像素。窗口变窄时暂时压缩面板，恢复后沿用偏好；上下堆叠的面板不提供横向拖动。
- 地图内滚轮以鼠标位置为中心连续缩放，拖动平移；地图聚焦后可用 `+`、`-` 缩放、方向键平移、`0` 适应窗口，也有按钮入口。缩放只改变视野，不改变当前统计范围或触发分析。
- 文件面积使用浮点逻辑布局，显示时裁剪至可见区域。文件名、指标与行数按可读空间逐步出现，文字保持正常字号；超长路径可悬停或聚焦查看。选择列表中的小文件后，点击“定位所选文件”可直接进入其局部。
- 色块之间使用固定的 1 CSS 像素视觉间隔，不随缩放增粗；极小色块先保留面积，放大后再留出间隔。绘制间隔不改变逻辑文件面积或统计。
- 全屏保留目录面包屑、指标与图例，可按 Esc 或退出按钮返回。全屏、侧栏变化和指标切换保留局部；文件集合或目录改变时适应新范围。缩放能力按最小文件尺寸动态计算，并留出继续放大的余量。

运行 `npm run check:web`、`npm run build:web` 和 `node --import tsx --test tests/web*.test.ts` 验证前端构建与核心展示不变量。真实仓库发现、刷新和浏览器交互需在服务集成后验收。

安装好 `playwright-cli` 和 Chrome 后，运行 `npm run build && node scripts/e2e-workspace.mjs` 可重放目录与面板浏览器验收。脚本启动隔离后台，只创建合成仓库，将三类历史目录指向空测试目录；结束时关闭浏览器并清理临时数据。验收截图保存在忽略的 `.local/workspace-e2e/`，不进入发布包。

连续缩放的实际仓库验收使用 `node scripts/e2e-map-zoom.mjs`，运行前设置 `AGENT_MANOR_E2E_REPOSITORY` 为已登记仓库名称或路径；可通过 `AGENT_MANOR_E2E_URL` 指定服务地址，默认本机 4317。脚本只查询已发布结果，使用独立 Chrome 会话，不刷新或停止服务。真实输入和截图只留在忽略的 `.local/map-zoom-e2e/`；不要将它们加入 Git。
