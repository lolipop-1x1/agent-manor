# CLI 响应与按需读取

CLI 默认取得完成当前操作所需的摘要，详情按稳定身份和数据版本读取。默认人类格式提供列表或结果摘要，`--json` 使用同一查询范围的稳定字段；`--full` 显式请求原有完整响应。格式与数据范围独立，不根据 stdout 是否连接终端切换契约。

## 列表与消息

会话列表、搜索和分组默认每页20条。每条会话默认仅包含 `id`、`title`、`client`、`project`、`updatedAt`，缺失的可选值不填造；产品生成的后备标题额外保留稳定翻译描述。轮次数、消息数、开始时间、模型、原生来源身份、关系、上下文快照和诊断不属于寻找会话所必需的信息，通过画像、详情或 `--full` 读取。搜索命中保留消息定位和片段，同一分组的会话信息只返回一次。分页结果保留版本和下一页信息，后续读取沿用该版本。

消息正文默认有界。`textTruncated` 表示仍有未返回正文，`textOffset`、`textLength` 和 `nextTextOffset` 提供字符范围。通过相同 `messageId`、`version`、`maxTextChars` 和后续 `textOffset` 继续读取，直到没有下一段；分页与字符偏移分别控制消息集合和单条正文。原文始终保留，片段不替代原始执行证据。

画像默认提供汇总统计。`sessions profile --section` 可选择 `summary`、`steps`、`context`、`reports`、`tools` 或 `resources`；明细使用 `--page`、`--page-size` 和 `--version`。`--full` 保留完整字段，用于明确需要完整数据的现有调用。会话导出可通过 `--output` 写入文件，终端只返回导出摘要。

## 状态、价格与管理结果

状态命令提供实例身份、就绪与数据准备状态、关键计数和必要错误；诊断通过 `sessions gaps` 分页读取。价格配置读取、设置和刷新返回配置及目录摘要，`usage pricing list` 按模型和版本分页读取价格项。汇总中的未知值保留为 `null`，估算和记录值仍使用各自字段。

写操作返回对象身份、修订或数据版本、结果状态及任务定位。知识审阅的确认摘要、授权范围和精确修订不因响应缩减而改变。耗时任务的接受、运行、暂停、完成和失败分别表达；显式暂停并等待到 `paused` 是暂停操作成功，普通任务等待仍按该任务的完成状态判断。

知识沉淀任务历史默认每页20条；任务详情默认提供事件、结果数量及当前阶段，完整事件和逐条结果通过 `--full` 读取。提交知识后通过返回的条目与修订身份读取正文，不在写入响应重复整份历史内容。

## 按 CLI 使用场景选择字段

默认字段采用白名单，领域对象后续新增字段不会自动进入 CLI。JSON 与人读模式使用同一范围；完整字段模式仍遵守分页和筛选，不等同于导出整库。

| 使用场景 | 默认保留 | 按需读取 |
| --- | --- | --- |
| 查找会话 | 会话 ID、标题、客户端、项目、更新时间、版本与分页 | 画像、模型、原生来源、上下文与诊断 |
| 查找知识 | 条目及修订 ID、标题、类型、适用范围、审阅及可用状态 | 知识正文、来源摘录和版本历史 |
| 读取单条知识 | 当前正文、适用条件、标签、状态、修订定位、来源位置与状态 | 所有历史正文、来源摘录及哈希与审计记录 |
| 查看知识历史 | 修订 ID、版本、标题、审阅状态及变更信息 | 单个指定修订正文或完整字段 |
| 提交或修改知识 | 条目 ID、最新修订 ID、版本和状态 | 通过返回身份重新读取正文 |
| 查找资源 | 资源身份、核心使用统计、收藏与保护状态、位置数量和分页 | 所有入口、定位规则、历史关联、分布与诊断 |
| 查询资源状态或修改来源 | 来源计数、更新时间，以及实际变更的来源身份 | 完整来源、项目清单与诊断 |
| 登记或删除仓库 | 仓库身份、路径、版本与新鲜度，实际任务状态 | Git 公共目录等内部管理信息 |

明确读取正文、证据或操作预览的命令保留该操作需要的内容。人工审批及可用性变更的授权绑定精确请求路径，输出选项不改写授权路径；确认前始终读取完整目标修订和已发布修订进行比较。

## HTTP 与兼容

已支持的后台接口通过 `response=summary` 提供轻量契约，CLI 默认请求该契约。未指定该参数的 Web 请求保留已有字段与统计语义。后台从查询或响应组装阶段去除无关大字段，CLI 负责命令展示；CLI 不复制 SQL、统计或证据判定。CRUD 的字段投影由后台和 CLI 复用，连接旧后台时也能限制默认输出。非法投影参数在业务处理前拒绝，避免操作成功后才返回参数错误。

CLI 默认 JSON 的大字段已移到按需读取路径；依赖旧完整形状的脚本显式使用 `--full`。列表、摘要、详情与完整响应的差别在帮助和配套 Skill 中说明。JSON 字段和枚举不随产品显示语言变化，中英文只影响帮助与人类格式。

## 回归边界

使用大量合成快照和长正文，断言默认响应体积不随隐藏明细增长；同时检查完整模式、明细分页与正文续读可以取回原值。命令测试核对退出码、stdout/stderr、状态读回及中英文。真实包外安装验收覆盖默认格式、JSON、完整模式和文件导出；原始会话与个人配置不作为管理测试夹具。
