# 全局用量与估算费用

用量页在顶部独立入口汇总本机已索引的请求，默认近 30 天，纳入主会话与子会话各自新增的用量。原始历史只读，查询使用完整发布的会话索引与固定价格版本。记录范围不足时，页面显示缺失或部分记录。

## 统计范围

- 日期沿本机时区，按每条请求已记录的发生时间归属。日期值 `YYYY-MM-DD` 包含该日全部时间；带时区的 ISO 区间开始包含、结束不包含。
- 缺少可靠时间的请求独立显示小计及其部分 Token／估价覆盖。有限日期范围不把它们加进指标与趋势；全部日期包含其小计，趋势仍不伪造日期。
- 主、子会话只累加自身新增请求，不重复累加父会话整树画像。已有明确复制身份的继承记录按现有索引规则排除；日志缺身份时不能承诺跨来源的全局去重。
- 项目取会话自身记录，子会话不继承改写父会话项目。模型取逐请求模型，模型映射不改原始名称或筛选值。
- 客户端、项目、模型支持包含和排除，排除优先；未知模型或项目保留选项。日期、主／子、会话类型、用量覆盖、定价覆盖与数值范围共同限定查询。
- Token 与费用数值范围作用于会话在当前筛选范围内的汇总。分页只改变明细行，指标、趋势、组成、排行与热力图使用同一组有效请求。

没有请求用量的会话用于检查覆盖缺口，不用消息数量补造请求数；原始内容体量估算不混入模型 Token。缺模型和缺价格的请求仍保留其已记录 Token。

## Token 与组成

索引中的总输入已经按来源格式归一化。缓存包含在总输入时不再次相加；来源把普通输入与缓存分开报告时，在归一化阶段合并为总输入。总 Token = 总输入 + 总输出。属于输出的推理 Token 不再次相加。

组成图使用普通输入、缓存读取、缓存写入和总输出这些互斥桶。只有缓存拆分明确时，普通输入 = 总输入 − 缓存读取 − 缓存写入。未知桶保持缺失，已确认零值保留为零。Codex 没有缓存写入收费桶；其他来源缺少该记录时保留未知。

输入／输出仅有一项时，已记录分项构成小计并标为部分记录。两项都缺失时没有可确认总量。总 Token 完整不代表组成完整；组成无法完整拆分时独立说明。缓存读取占输入比例使用相同可计算请求的缓存读取与总输入，直接显示对应请求覆盖数量，不解释为请求命中率。

## 价格与费用

单价使用 USD／百万 Token。估算费用按所选快照重估历史用量，不代表历史实际账单、订阅支出、余额或套餐额度。

价格优先级：

1. 用户给原始模型设置的手动价格，已识别和未识别模型都适用。
2. 用户明确映射的目标服务商与模型，目标模型的适用手动价格同样优先。
3. 精确、无歧义的自动目录条目。明确服务商前缀可定位条目；同名模型对应多个服务商时要求映射，不用客户端身份推测服务商。

自动目录来源为 `https://models.dev/api.json`。进入页面时后台检查更新，24 小时内复用已有检查，手动更新可立即重试。请求使用固定公开地址，不携带历史、项目路径、Token 或凭据。结构和价格校验成功后才保存；失败保留上一成功缓存。逐模型依次使用最新网络条目、最近成功缓存、随包快照。

网络刷新只更新自动目录，用户覆盖和映射独立保存。清除手动价格后恢复自动查询，映射需单独清除。随包快照记录来源、获取日期与内容版本，更新入口为 `node --import tsx scripts/update-usage-prices.mjs`；授权声明保留在生成文件头。

可完整拆分和匹配价格时：

```text
估算费用 =（普通输入 × 输入单价
          + 缓存读取 × 缓存读取单价
          + 缓存写入 × 缓存写入单价
          + 总输出 × 输出单价）÷ 1,000,000
```

已确认零 Token 的桶不需要单价，非零 Token 缺单价不视为免费。上下文档位使用归一化输入量选择，保留档位规则和实际适用单价。推理独立价格与总输出价格不同时，必须有推理分项才能拆分；音频有不同价格而缺少独立用量时保留估价限制。

完整可估价、部分可计算和无法估价请求分别计数。已计算金额是已知桶的小计，覆盖不足直接显示；未知模型、未知价格、缺 Token、档位依据不足与分项含义不明保留对应原因。

## 版本

`usage-pricing.json` 保存手动配置，`usage-price-cache.json` 保存成功目录与元信息，二者独立于可重建会话索引。统计绑定会话索引版本和价格内容版本。价格版本依据条目、覆盖和映射计算，不把重新抓取时间当作新的内容。

进程内保留最近八个价格视图；旧版本不可用时返回 `VERSION_NOT_FOUND`，不静默使用新价格。索引版本也沿现有保留规则校验。网络错误不清空当前结果，页面可显式加载最新结果。

## 增量计算与缓存

新会话修订完成时，在同一事务内保存结构化用量事实及明确的复制排除结果。事实只包含统计需要的模型、时间、Token 与请求身份；完整消息关联和计时证据继续保存在原请求记录中。旧索引在统计 Worker 中补齐事实，原始历史保持只读。

服务启动后自动准备统计；后台每两秒检查完整发布的分析版本、价格内容版本及本机时区。不变会话修订复用已有汇总。价格变化重估费用，时区变化重新生成当地小时与日期归属，均复用 Token 事实。

汇总以会话修订、客户端、价格版本和时区为身份，保存每个小时、模型、Token 覆盖与定价覆盖的统计，以及有限的请求预览。严格时间元数据按请求时间安排计算，近 30 天优先，随后补齐历史。全局筛选项与无用量会话需要完整事实身份；首次打开旧库须先完成这一步。有限日期报告只等待可能落入范围及缺时间记录的必要修订汇总，历史汇总可在报告返回后继续准备。

不同版本、价格和时区在事实批次与修订边界协作推进；正在补历史的任务为其他身份的前台查询让出，不要求先完成上一项全历史预热。同一身份的查询共享准备任务。

常规日期、筛选、图表与翻页复用小时基础。精确 ISO 边界、费用范围、费用指标和费用排序使用精简事实及原精确计算路径，保留结束排他与金额临界值、同金额排序的口径。费用总计按小时合并时可能有低于显示精度的浮点误差。

统计 Worker 独立执行全量读取和计算；主服务线程只检查版本、传递固定价格快照、读取当前页原请求并补全证据。相同进行中查询合并。报告与请求页缓存限制为 16 MiB／24 项，完整小时基础为 128 MiB／2 项，精简事实源为 64 MiB／1 项；超过单项体积上限的结果不驻留。缓存命中仍校验分析和价格版本可用，当前价格更新错误等状态单独读取。

`usage-rollups.sqlite` 是可重建的独立派生缓存，保留最多两个价格版本、三个时区及 256 MiB 汇总记录；SQLite 页、空闲页与 WAL 另有空间开销。已回收会话修订的缓存同步淘汰。缓存格式独立版本化，事实格式变化也使汇总失效；损坏或结构不兼容的条目从事实重建。清除派生数据不改手动价格、映射与原始会话。

## 查询接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/usage` | 同一请求集合的指标、趋势、日强度、分组及会话分页 |
| `GET /api/v1/usage/status` | 指定分析版本、价格版本和时区的后台准备状态与会话进度 |
| `GET /api/v1/usage/requests` | 某会话的请求分页与计价依据 |
| `GET /api/v1/usage/pricing` | 自动目录、配置和更新状态，触发后台检查 |
| `POST /api/v1/usage/pricing/refresh` | 手动更新目录，空 JSON 请求体 |
| `PUT /api/v1/usage/pricing` | 保存明确的 `overrides` 与 `mappings` |

统计查询使用 `version`、`priceVersion`、`timezone`，数组筛选值按 JSON 数组编码，使用返回的维度身份。缺失维度的身份为 `unknown`；真实名称 `unknown` 编为 `literal:unknown`，真实名称以 `literal:` 开头时再加一层该前缀，展示时恢复原始名称。因此缺记录与原始名称不会合并或误翻译。请求明细额外使用 `sessionId`、`requestPage`、`requestPageSize`。查询拒绝无效日期、未知条件和非法范围。

## 交互与验证

趋势可切换 Token、估算费用与请求数，以及小时／日／周／月、分组和柱状／折线。轴从零开始，鼠标、键盘和触屏可以查看具体区间与数值。隐藏图例只改变显示；区间和排行下钻产生明确筛选。热力图按当前范围展示日强度。

会话和请求明细支持完整分页、稳定排序、父子关系及消息定位；缺定位依据时保留只能打开会话的说明。筛选、指标和返回位置保存在页面状态及地址中，中英文与主题切换不改变统计含义。

合成回归覆盖公式、缺失、价格优先级、逐模型兜底、版本、时区和分页。真实浏览器复现入口为 `node scripts/e2e-usage-statistics.mjs`，先执行 `npm run build`；它使用临时索引、价格与偏好，截图和报告存入忽略的 `.local/usage-statistics-e2e/`。

加载持续一秒后才轮询准备状态；报告完成、筛选变化或页面切出时取消轮询与旧请求。已知总会话数显示实际计数，未知总量不生成百分比。准备失败保留错误和重试入口。可复现的状态验收为 `node scripts/e2e-usage-preparation.mjs`，使用合成后端及可控延迟响应验证取消、进度、重试、语言和窄屏主题。
