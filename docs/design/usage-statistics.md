# 全局用量与估算费用

有限日期范围的会话明细只纳入范围内请求及独立的缺时间请求证据。没有请求用量事实的会话无法归属该日期范围，仅在全部历史中列出，时间列显示“未记录请求用量”，不补造发生时间。

用量页在顶部独立入口汇总本机已索引的请求，默认近 30 天，纳入主会话与子会话各自新增的用量。原始历史只读，查询使用完整发布的会话索引与固定价格版本。记录范围不足时，页面保留用量缺失、用量不全或估价不全状态，具体覆盖计数按需查看。

## 统计范围

- 日期沿本机时区，按每条请求已记录的发生时间归属。日期值 `YYYY-MM-DD` 包含该日全部时间；带时区的 ISO 区间开始包含、结束不包含。
- 缺少可靠时间的请求在统计帮助中保留小计及其 Token／估价覆盖。有限日期范围不把它们加进指标与趋势；全部日期包含其小计，趋势仍不伪造日期。
- 主、子会话只累加自身新增请求，不重复累加父会话整树画像。已有明确复制身份的继承记录按现有索引规则排除；日志缺身份时不能承诺跨来源的全局去重。
- 项目取会话自身记录，子会话不继承改写父会话项目。模型取逐请求模型，模型映射不改原始名称或筛选值。
- 客户端、项目、模型支持包含和排除，排除优先；未知模型或项目保留选项。日期、主／子、会话类型、用量覆盖、定价覆盖与数值范围共同限定查询。
- Token 与费用数值范围作用于会话在当前筛选范围内的汇总。分页只改变明细行，指标、趋势、组成、排行与热力图使用同一组有效请求。

没有请求用量的会话用于检查覆盖缺口，不用消息数量补造请求数；原始内容体量估算不混入模型 Token。缺模型和缺价格的请求仍保留其已记录 Token。

## Token 与组成

索引中的总输入已经按来源格式归一化。缓存包含在总输入时不再次相加；来源把普通输入与缓存分开报告时，在归一化阶段合并为总输入。总 Token = 总输入 + 总输出。属于输出的推理 Token 不再次相加。

Codex 原生响应后的旧式用量投影按同一助手事件组及单次用量一对一关联，累计基数不同不新增请求；旧式记录先出现时还须累计进度一致才能关联后续原生响应，不同原生响应身份仍分别保留。上下文压缩请求有明确原生用量时纳入统计，随后仅报告上下文大小的零用量状态不作为请求。WorkBuddy 同一份用量投影的总量等于输入与输出之和时，确认输入包含缓存，数组形式的缓存及推理详情也保留；缺少可靠总量时继续标记未知。DSH 总量与普通输入、缓存及输出之和吻合时才将省略缓存桶核验为零。

ZCode 普通输入和缓存桶与原始请求字段核验一致时归一化为总输入；供应商补充字段缺失不否定有效原始字段，明确冲突仍保持未知。OpenCode 根据总量与输入、输出、推理及缓存的等式识别输出是否已包含推理，冲突时不猜测输出。PI 保留压缩请求的自身用量；WorkBuddy 空正文不丢弃已有用量。DSH 同身份 V3／V4 来源择一，完整且受支持的来源优先，不把副本并行累加。

组成图使用普通输入、缓存读取、缓存写入和总输出这些互斥桶。只有缓存拆分明确时，普通输入 = 总输入 − 缓存读取 − 缓存写入。未知桶保持缺失，已确认零值保留为零。Codex 没有缓存写入收费桶；其他来源缺少该记录时保留未知；CodeFlicker CLI 的完整 requestTokenBaseline 持久化格式只保存正缓存桶，有效输入/输出下缺省缓存读写按该格式恢复为零。缺格式依据或显式无效字段不补零。

输入／输出仅有一项时，已记录分项构成小计并标为部分记录。两项都缺失时没有可确认总量。总 Token 完整不代表组成完整；组成无法完整拆分时独立说明。缓存读取占输入比例使用相同可计算请求的缓存读取与总输入，在统计帮助中保留对应请求覆盖数量，不解释为请求命中率。

## 价格与费用

单价在界面中使用 `$ / 百万 Token`。估算费用依据已记录服务商、模型与请求时间计算。存在可核验的生效区间时采用对应历史价格；无适用区间时按当前价格快照估算。估算状态直接可见，具体计价依据按需展开。结果不代表实际账单、订阅支出、余额或套餐额度。

页面中的费用金额统一采用 `$` 前缀并显示两位小数，覆盖指标、小计、明细、图表坐标与提示、排行、热力图及会话画像。仅在展示时舍入；内部计算、存储、筛选和接口金额保留原精度，接口币种标识仍为 `USD`，模型单价保留必要精度。

价格优先级：

1. 用户给原始模型设置的全局手动价格，适用于所有服务商，优先级最高；其次是原始模型与已记录服务商的专属手动价格。同名模型的多个服务商覆盖可以共存。
2. 用户明确映射的目标服务商与模型，目标模型适用的手动价格同样优先。
3. 自动匹配同一模型的原厂 API 价格，优先于请求渠道、转售目录、免费及套餐单价。免费、订阅和 Token Plan 套餐内请求也采用 API 基准估算；原厂单价本身明确为零时保留零值，不按价格高低挑选服务商。
4. 原厂没有同版本条目时，采用 OpenRouter 的同版本模型公开目录条目，并标记公开目录 API 基准。仍无匹配时，保留已记录服务商或明确目录前缀的精确匹配；无服务商记录的名称仅在目录有唯一同名服务商时匹配。
5. 自动匹配从模型名称识别通用渠道前缀、大小写、点号／下划线分隔符、Claude 的版本与系列顺序，以及末尾免费标记，不维护渠道名称白名单。版本、日期及 thinking、highspeed 等功能变体必须保留；多个候选无法确定目标时保留未定价，允许用户修改映射或填写价格。

标准身份优先依据目录的 `canonical_model_id`，保留原服务商、原模型名与该身份；标准型号签名必须与原条目一致，不能把目录合并的不同版本、pro 或视觉变体带入定价。名称识别继续保留版本、日期和功能变体，不以公共前缀或编辑距离猜型号。标准身份冲突且缺少明确依据时保持未知；已记录服务商或明确目录前缀的价格仍可唯一匹配同型号。缺少标准身份时，已有系列与服务商规则作为补充。原厂有多个公开身份时采用固定的原厂身份顺序，例如 GLM 优先 zhipuai 再 zai，Kimi 优先 moonshotai 再 moonshotai-cn；用户可通过明确映射选择另一目标。自动映射不写入手动配置，不改原始服务商、模型名或筛选归属，也不能证明请求实际路由或实际账单。

确定服务商与模型后，自动价格优先选择包含请求发生时间的历史区间，其次使用当前目录。区间开始包含、结束不包含；公开日期转换为 UTC 零点，不沿显示时区重解释价格生效时间。无请求时间、无适用历史区间或未支持的日内／其它约束，均回退当前快照并显示限制。没有当前价格时保留未定价。

价格管理显示已记录原始模型名的默认匹配、自动或手动映射的计价模型，以及官方／公开目录 API 基准。请求明细按记录的服务商与时间取价，可能与模型名默认匹配不同。未匹配时直接区分身份冲突、多个服务商、缺 API 基准、未知身份与失效手动映射，提供相关候选和全部目录入口。有效目标可以预填；歧义或失效目标保持空选，不能静默选择第一项。清除手动映射后恢复自动匹配。历史区间在请求计价明细中展示。同名覆盖按服务商与模型共同保存、编辑及恢复；修改身份移除原身份，恢复仅作用于选中覆盖。空服务商明确表示全局覆盖，清除它后可继续使用已有服务商覆盖。

当前自动目录来源为 [公开模型目录](https://models.dev/api.json)，历史区间及备用当前快照来源为 [公开价格数据](https://raw.githubusercontent.com/pydantic/genai-prices/main/prices/data.json)。后者的明确日期序列作为历史依据，普通单价对象及唯一无日期条目仅作当前快照，补齐主目录缺少的精确身份；多条无日期价格、不支持的约束及仅输入计费的嵌入模型不猜选或套用。随包另保留少量已核对官方 API 的快照，保存来源与核对日期；网络同身份条目优先，不将核对日期当作历史生效日期。

进入页面后台并行检查，24 小时内复用已有检查，手动更新可立即重试；旧安装首次没有历史缓存时仍检查历史来源。两个目录独立校验、保存及保留最后成功缓存，一个来源失败不阻止另一来源更新。主目录逐模型依次使用最新网络条目、最近成功缓存和随包快照，缺少身份再由备用快照补齐；历史区间仅使用成功网络数据或其本地缓存。首次离线且无历史缓存时按随包当前价格估算。

网络请求仅使用固定公开地址，不携带历史、项目路径、Token 或凭据。价格详情保留采用的服务商、来源和历史生效区间；统计覆盖分别列出手动、历史价格和当前快照的已计算请求数。

网络刷新只更新自动目录，用户覆盖和映射独立保存。清除手动价格后恢复自动查询，映射需单独清除。随包快照记录来源、获取日期与内容版本，更新入口为 `node --import tsx scripts/update-usage-prices.mjs`；授权声明保留在生成文件头。

可完整拆分和匹配价格时：

```text
估算费用 =（普通输入 × 输入单价
          + 缓存读取 × 缓存读取单价
          + 缓存写入 × 缓存写入单价
          + 总输出 × 输出单价）÷ 1,000,000
```

已确认零 Token 的桶不需要单价，非零 Token 缺单价不视为免费。上下文档位使用归一化输入量选择，保留档位规则和实际适用单价。推理独立价格与总输出价格不同时，必须有推理分项才能拆分；音频有不同价格而缺少独立用量时保留估价限制。

完整可估价、部分可计算和无法估价请求分别计数。已计算金额是已知桶的小计，覆盖不足直接显示；未知模型、未知价格、缺 Token、档位依据不足与分项含义不明保留对应原因。

## 版本

`usage-pricing.json` 保存手动配置，`usage-price-cache.json` 保存当前目录，`usage-price-history-cache.json` 保存历史区间与备用当前快照及内容版本，三者独立于可重建会话索引。统计绑定会话索引版本和价格内容版本。价格版本依据条目、标准身份、覆盖、映射及解析规则版本计算，不把重新抓取时间当作新的内容。解析规则升级后重新生成费用汇总，复用原 Token 事实。

进程内保留最近八个价格视图；旧版本不可用时返回 `VERSION_NOT_FOUND`，不静默使用新价格。索引版本也沿现有保留规则校验。网络错误不清空当前结果，页面可显式加载最新结果。

## 增量计算与缓存

新会话修订完成时，在同一事务内保存结构化用量事实及明确的复制排除结果。事实包含统计需要的模型、明确服务商、时间、Token、请求身份与速度计算所需的精简计时；完整消息关联和计时证据继续保存在原请求记录中。旧索引在统计 Worker 中补齐事实，原始历史保持只读。

服务启动后自动准备统计；后台每两秒检查完整发布的分析版本、价格内容版本及本机时区。不变会话修订复用已有汇总。价格变化重估费用，时区变化重新生成当地小时与日期归属，均复用 Token 事实。

汇总以会话修订、客户端、价格版本和时区为身份，保存每个小时、模型、Token 覆盖与定价覆盖的统计，以及有限的请求预览。严格时间元数据按请求时间安排计算，近 30 天优先，随后补齐历史。全局筛选项与无用量会话需要完整事实身份；首次打开旧库须先完成这一步。有限日期报告只等待可能落入范围及缺时间记录的必要修订汇总，历史汇总可在报告返回后继续准备。

不同版本、价格和时区在事实批次与修订边界协作推进；正在补历史的任务为其他身份的前台查询让出，不要求先完成上一项全历史预热。同一身份的查询共享准备任务。

常规日期、筛选、图表与翻页复用小时基础。精确 ISO 边界、费用范围、费用指标和费用排序使用精简事实及原精确计算路径，保留结束排他与金额临界值、同金额排序的口径。费用总计按小时合并时可能有低于显示精度的浮点误差。

统计 Worker 独立执行全量读取和计算；主服务线程只检查版本、传递固定价格快照、读取当前页原请求并补全证据。相同进行中查询合并。报告与请求页缓存限制为 16 MiB／24 项，完整小时基础为 128 MiB／2 项，精简事实源为 64 MiB／1 项；超过单项体积上限的结果不驻留。缓存命中仍校验分析和价格版本可用，当前价格更新错误等状态单独读取。

`usage-rollups.sqlite` 是可重建的独立派生缓存，保留最多两个价格版本、三个时区及 256 MiB 汇总记录；SQLite 页、空闲页与 WAL 另有空间开销。已回收会话修订的缓存同步淘汰。缓存格式独立版本化，事实格式变化也使汇总失效；损坏或结构不兼容的条目从事实重建。清除派生数据不改手动价格、映射与原始会话。

## 查询接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/usage` | 同一请求集合的指标、趋势、日强度、分组及会话分页 |
| `GET /api/v1/usage/status` | 指定分析版本、价格版本和时区的后台准备状态与会话进度 |
| `GET /api/v1/usage/requests` | 某会话的请求分页与计价依据 |
| `GET /api/v1/sessions/:id/cost` | 当前会话自身或包含子会话的完整用量与费用小计 |
| `GET /api/v1/usage/pricing` | 自动目录、配置和更新状态，触发后台检查 |
| `POST /api/v1/usage/pricing/refresh` | 手动更新目录，空 JSON 请求体 |
| `PUT /api/v1/usage/pricing` | 保存明确的 `overrides` 与 `mappings` |

统计查询使用 `version`、`priceVersion`、`timezone`，数组筛选值按 JSON 数组编码，使用返回的维度身份。缺失维度的身份为 `unknown`；真实名称 `unknown` 编为 `literal:unknown`，真实名称以 `literal:` 开头时再加一层该前缀，展示时恢复原始名称。因此缺记录与原始名称不会合并或误翻译。请求明细额外使用 `sessionId`、`requestPage`、`requestPageSize`。查询拒绝无效日期、未知条件和非法范围。

会话费用接口使用 `version`、可选的 `priceVersion` 与 `includeChildren`。范围沿用画像的已确认关联；包含子会话时递归纳入各自新增请求，排除已确认复制用量。接口读取该范围的精简事实，在统计 Worker 中复用相同的价格解析与汇总规则，包含无时间记录，不受正文或请求明细分页影响，也不等待全历史汇总。费用缓存绑定索引版本、价格版本及范围，独立于纯画像缓存。

会话画像在概览和用量标签的请求用量区域显示带 `$` 前缀的估算费用。完整估价直接显示金额；存在部分或未定价请求时，金额标为已知费用小计并展示覆盖计数。全部无法估价时显示横线，明确的零费用仍显示零。定价失败保留独立重试入口，不阻断会话阅读。切换自身／包含子会话、重新打开侧栏或返回会话页时刷新费用，采用与用量统计页一致的单价。

## 交互与验证

趋势可切换 Token、估算费用与请求数，以及小时／日／周／月、分组和柱状／折线。轴从零开始，鼠标、键盘和触屏可以查看具体区间与数值。趋势通过单个选择入口接收方向键、Home／End，Enter／Space 保留所选区间的明细浮层，避免大量时间桶占用 Tab 顺序。隐藏图例只改变显示；排行点击产生明确筛选，日期范围通过顶部控件设置。日历热力图与趋势在同一区域切换，沿用当前查询范围，日期采用单个 Tab 入口及方向键导航。

时间主图还提供“吐字速度”局部指标，在原位置展示 tok/s 折线，不改变下方组成、归因排行和会话排序的原用量指标。速度视图使用可搜索的模型分组多选，按客户端、原始模型、响应／输出阶段、原生／历史估算及具体方法保留独立曲线；默认选择当前筛选范围内全部可用分组。菜单支持连续勾选、取消、全选或清空，“应用”整体提交，关闭或 Escape 放弃尚未应用的选择。可以只选一个，也可以清空后重新选择；返回普通指标恢复已有柱线和日历偏好。

速度按请求发生时间及相同报告时区进入小时、日、周或月桶，沿用全部用量筛选与会话数值阈值。每个日期点使用该组同一批合格请求的输出 Token 总和除以耗时总和；资格判定复用[会话速度口径](session-history.md)，不平均各请求的速率。无日期请求不进入曲线，缺少模型身份的请求仍保留用量及总体覆盖；不将不同计时分组合成总速度。

无合格样本日期保留未知并断开各自折线，单个有效点仍可见；历史估算数值逐组保留 `≈`。图例、曲线与浮层保持一致颜色，增减选择不重新分配仍存在曲线的颜色。图例和多选选项仅显示模型与客户端，不附带计时区间、来源或方法副标题。悬停、键盘与触屏明细按同一日期紧凑展示模型名称和速度，长名称截断，模型与客户端可通过名称提示查看；长列表独立滚动，日期与关闭入口固定。计时口径、算法与总体覆盖放入区域帮助。更新期间保留上一完整选择与图表并暂停旧图交互，错误保留重试入口；分页、语言和主题不改变完整趋势范围。

`includeSpeed=true` 为用量报告附加速度分组与选中组日期序列，`speedGroups` 为组身份的 JSON 数组；显式空数组表示不选组，部分身份仍在当前筛选范围时只保留有效选择，全部失效则回退当前全部可用分组。旧 `speedGroup` 单选参数继续兼容，新数组优先。响应提供 `selectedGroups` 与逐组 `series`，旧 `selectedGroup`／`buckets` 保留首条曲线视图。普通查询省略速度结果。速度事实及小时聚合随格式号重建，多选查询本身不更改持久格式或原始历史，也不在浏览器逐会话请求画像拼装曲线。

趋势按可见容器宽度展示完整日期范围，不因时间桶数量增加而横向撑宽。日期刻度随空间调整且保留区间两端，横轴、选中日期及热力图月份包含年份；小时刻度将日期与时刻分行，沿用报告时区。没有显式日期边界时，范围说明使用报告实际起止日期；自定义日期与精确时间边界使用查询值，未知时间仍独立统计。

会话和请求明细支持完整分页、稳定排序、父子关系及消息定位；缺定位依据时保留只能打开会话的说明。点击会话行、标题或查看请求入口，在当前视口打开宽对话框，保留请求时间、模型、总输入、总输出、缓存读取、缓存写入、费用、定价依据和操作九列；内容独立滚动，关闭后恢复原会话列表位置和触发入口焦点。数值旁的状态图标可以查看具体缺口，不逐行重复完整覆盖说明。筛选、指标和返回位置保存在页面状态及地址中，中英文与主题切换不改变统计含义。

价格管理默认显示已记录与已配置模型，完整价格目录通过范围筛选进入。价格、映射与新配置编辑在对话框内替换列表工作区，保持对象、返回、保存和取消入口可见；定价状态支持未匹配、自动匹配、手动映射与用户定价，并与搜索、范围组合；原始名称、计价目标和四个单价表头支持升降序，完整筛选结果排序后分页，真实零价正常排序，缺失单价始终置后。未匹配包括没有可用价格的冲突、身份未知、缺基准与失效映射；未记录的目录条目不归入自动匹配状态。取消或返回保留列表搜索、状态、排序、分页、滚动与操作焦点。保存失败保留输入及重试能力；编辑时 Escape 返回列表，列表中 Escape 关闭管理。计价来源、获取时间与通用规则收进区域帮助，单行只保留计价模型、必要状态和价格规则图标，版本标识收进诊断信息。

合成回归覆盖公式、缺失、价格优先级、逐模型兜底、版本、时区和分页。真实浏览器复现入口为 `node scripts/e2e-usage-statistics.mjs`，先执行 `npm run build`；它使用临时索引、价格与偏好，截图和报告存入忽略的 `.local/usage-statistics-e2e/`。

界面流程专项为 `node scripts/e2e-usage-interface.mjs`，使用隔离合成响应验证宽请求表、关闭后的滚动和焦点恢复、价格工作区、保存失败与重试、目录范围切换、图表键盘操作、中英文及窄屏深浅主题。真实历史页面用于核验实际标题、模型长度、日期跨度与布局，写操作使用隔离配置。

加载持续一秒后才轮询准备状态；报告完成、筛选变化或页面切出时取消轮询与旧请求。已知总会话数显示实际计数，未知总量不生成百分比。准备失败保留错误和重试入口。可复现的状态验收为 `node scripts/e2e-usage-preparation.mjs`，使用合成后端及可控延迟响应验证取消、进度、重试、语言和窄屏主题。

## 按需说明与稳定更新

用量页不常驻覆盖计数条、图表黄色状态小字或每行单价说明。完整性与定价覆盖选项提供解释图标：鼠标和触屏可点击查看，键盘聚焦选项显示解释，选项选择与说明查看相互独立。覆盖计数、缺时间小计与细分限制保留在统计及图表帮助，费用覆盖不足时字段名标为“估算费用小计”，未知值保留横线。

请求定价模型旁的信息图标打开适用单价、档位、来源与生效区间；关闭后恢复原图标焦点。目录价格规则采用同样的按需入口，避免重复第二行。

已有报告的刷新与筛选更新不卸载结果、不插入占位加载块，固定刷新图标表示进行中。等待期间保留上一完整报告的真实范围与图表指标，暂停旧结果下钻，成功后整体更新；查询失败保留旧结果并提供重试。首次读取仍显示准备状态及可核验进度。

时间区间只用于查看明细，悬停、点击及键盘选择均不修改日期筛选。每日明细使用浮层，不在图表下方插入可变高度内容；日期范围通过顶部控件设置。

专项复现入口为 `node scripts/e2e-usage-cleanup.mjs`，使用隔离合成来源及可控延迟、失败响应检查解释图标、连续切换、稳定布局、失败重试、单价详情、时间查看、中英文与窄屏。

## 指标与图表展示

默认范围为近 30 天，含今天；地址中的明确日期选择继续恢复。Token 统一使用 M（百万）单位，悬停数值查看完整记录值，计算和价格仍使用原始精度。

总输入已包含缓存，总输出已包含推理。补充指标包括日均费用、每日峰值费用及日期、项目数、原始模型数和活跃天数。日均使用有日期的已估算费用之和除以所选范围的日历天数，空白日纳入分母；没有可估价日期时显示未知，已知零费用仍显示零。峰值只比较可估价日期，同额采用最早日期。活跃天数为存在已记录请求的日期数；无时间请求不归入日期。项目和模型从最终纳入总量的完整请求集合去重，缺失名称不计为实体，明细分页和分组视图不影响计数。

时间趋势与日历明细通过有界浮层查看，鼠标悬停、键盘选择和触屏点击均不修改日期筛选。点击或 Enter 可保留浮层，Escape 或外部点击关闭；日期范围通过顶部控件设置。明细不参与页面排版，避免下方表格跳动。归因默认矩形占比，允许切换横条排行，切换只改变显示方式。矩形面积采用已确认正值，色阶按当前最大值归一到共享五级强度，同值同色、数值越大色阶越强。所有方块通过悬停或键盘焦点展示完整名称、指标与占比，Token 额外显示精确计数；微小方块的点击区域保持实际面积。其余合计可查看完整信息，但不作为独立筛选项；未知值不伪造面积。

查询期间保留已有报告与布局，在范围、指标和分组控制旁显示固定加载图标；旧报告暂时不可下钻，成功后整体替换。会话画像缓存占比与费用采用同一普通数据行样式，不单独使用强调背景。
