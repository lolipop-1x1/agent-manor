# 总览看板

总览将跨客户端活动、用量、资源、过程与已登记仓库放在同一页面。统计在本机完成；汇总及调查沿用完整历史索引与价格版本。

## 页面与范围

总览是默认进入页，筛选写入可恢复的总览地址。明确的会话、地图、资源和用量地址仍进入对应页面；独立用量页继续提供费用与请求明细。

默认近一年包含今天在内的 365 个本机日历日。日期、客户端、项目对常规区域生效；模型仅筛选用量、模型分布及相关请求分析，不改变全局六项指标、活动、资源与工具统计。七天洞察只跟随客户端与项目，始终使用不含今天的七个完整本地日期。下钻保留报告范围、统计时区及版本，返回保留页面位置。

六项概况为会话数、模型请求数、Token 总量、估算费用／小计、活跃天数及连续活跃天数。主、子与分叉会话按自身新增记录纳入；继承复制记录不重复累计。

活动依据有可靠时间的真实用户交互及 Agent 活动，不由会话开始与结束时间之间的跨度推算，不要求当天记录 Token。系统提示、上下文注入和明确复制记录排除。今天尚未活动可延续截至昨天的连续记录；历史区间严格以末日为终点。最长连续与峰值均限制在所选范围内。

未记录与零值分开。无时间事实只进入全部历史的总量，另可调查；不分配给某一天。部分 Token 和费用显示小计，估算费用不是实际账单。

## 最近7天洞察与调查

首屏以七天洞察为主，所选时段六项概况紧凑保留在其后，日期控制就近放在该区域。七天洞察替换首页重点洞察，不做前七天对比。四组固定数值为会话与压缩、单轮投入、缓存与输入、偏好与节奏；最长轮次和高 Token 轮次提供原需求及会话定位。会话阅读、画像和洞察共享一次真实用户需求及后续响应过程的轮次与投入事实。平均步骤按唯一逻辑模型请求计算，工具调用单列；平均 Token 只采用输入与输出完整的可统计回复轮次，缓存与推理子集不重复累加。缺用量关联或分项不补零。轮次按末条回复记录日纳入整轮，跨周轮次也包含窗口之前的投入；事件与偏好按发生日纳入，两个范围不要求总量相等。

真实用户会话与独立需求的分叉构成主要样本，子 Agent 投入单列；缺少自动触发身份时保留未知，不能按正文猜测。有回复轮次以同轮最后一条非空 AI 回复为观测边界，不要求原生正常结束标记，取消、部分响应或后续工具记录不排除已有回复。轮次耗时采用首条真实用户输入与最后回复记录时间之差，缺失或倒序时间不纳入；它包含等待，不证明需求成功。

末条保存回复样本的均值、中位数、P90 和最大值以 `≈` 标注，空值显示 `—`，轮次数与覆盖计数保留精确整数；样本和定义收进已有帮助与记录详情。会话、轮次、缓存与输入详情默认紧凑摘要加记录，完整统计另切；轮次记录默认“有回复”，与摘要使用同一批轮次，并保留全部、标记终答、末条回复、尚无回复筛选。Agent、模型、思考程度、项目与工具默认排行，选中对象进入固定标题。小时、星期和星期×小时分布在同一画布切换，记录另切；每图只有一个 Tab 入口，方向键及 Home/End 定位数值。详情提供均值、中位数、P90、投入集中度、排行、覆盖及原始记录入口，工具失败与压缩仅描述已记录过程。

零缓存请求、部分与完整命中、未知字段分别统计。假设缓存价差使用普通未缓存输入及适用输入／缓存读取价格，不将缓存写入混入，不宣称输入本可命中或差额可兑现。无压缩会话先按整个留存历史、压缩支持与相关缺口筛选，再取七天内请求峰值总输入并求会话平均，不复用语义混合的上下文字段。

常用 Agent 按客户端及真实用户发起轮次数排行；模型与明确思考设置按请求排行，缺失保留未知。用户提示词长度按同轮次及来源记录行合并非空白 Unicode 字符，排除已确认的注入或后台通知、客户端取消控制记录、复制记录和工具结果；无法拆分的混合正文保留采集边界。用户交互按本地星期、小时呈现，不推算真实工作时长。

以下分析通过数值、排行或具体调查进入。

| 分析 | 调查内容 |
| --- | --- |
| 用量变化 | 请求次数与每请求平均投入分别比较，区分规模和均值变化 |
| 会话集中度 | 单个及前五个会话的用量占比，保留分布与峰值请求 |
| 资源习惯 | 资源种类、频次、活跃周与项目分布 |
| 资源后续使用 | 所选历史首次观测后的 30 个完整日期；成熟、观察中、区间不足与覆盖不足分开 |
| 委派 | 有子活动的主会话、主子拆分及可记录的请求／Token |
| 缓存 | 在相同客户端和模型下比较已记录输入与缓存读取 |
| 项目与模型 | 项目月度分布、模型偏好、相邻模型切换与主子模型组合 |
| MCP 工具 | 服务器内实际工具的次数、会话与结果分布 |
| 资源组合 | 默认同一自身会话，可切换真实用户轮次；共同出现不自动解释为工作流 |
| 工具失败 | 已确认失败、已知结果覆盖及同轮次后续同工具调用，保留服务器身份 |
| 跨日活动 | 活动日期与间隔；不把跨日跨度视为实际耗时 |
| 输入走势 | 同客户端、同模型的可靠请求片段，标记缓存及压缩位置 |
| 代码热点 | 每个已登记仓库在所选范围内的读取、修改与失败摘要，按单期热点进入代码地图 |
| 覆盖变化 | 已记录采集覆盖与缺失的变化，保留未知及原诊断 |

完整次数和原记录仍可查看；已确认失败或明确峰值允许独立调查。复盘口径见[七天洞察规格](https://github.com/lolipop-1x1/agent-manor/blob/main/.scratch/overview-insights-review/spec.md)，其他按需计算沿用[查询优化规格](https://github.com/lolipop-1x1/agent-manor/blob/main/.scratch/overview-performance/spec.md)和[统计规格](https://github.com/lolipop-1x1/agent-manor/blob/main/.scratch/overview-dashboard/spec.md)。兼容完整报告中的旧规则仍保留独立样本门槛及最多五条结论，首页不再加载该分区。

## 资源与过程口径

Skill 显式调用与成功正文读取分别统计。MCP 先按服务器汇总，再进入实际工具。资源名称级汇总只用于分析，管理操作必须回到具体来源。

三十天窗口从首次观测的次日开始。窗口未结束为观察中；选择区间不足或相关采集缺失不进入成熟观察比例。首次观测仅表示所选历史中的首次记录，不表示安装时间。

失败率的分母为已知成功加已知失败，未知结果单列。调用与结果按原身份配对，歧义不强行确认。失败后续只调查同一会话、同一真实用户轮次、同名且同服务器的后续调用；保留首次失败作为证据起点，不称为重试或恢复成功。

请求计时按客户端、原始模型、响应／输出窗口、原生／历史估算及具体方法分组。只比较相同依据，响应时长和吐字速度分别解释；先提供分布与最长记录，不自动判定性能异常。轮次经过时间另行统计，不替代请求计时。思考设置仅解析来源明确字段并按请求生效，不从推理 Token 倒推；快速模式、纯执行时间与成果评价仍需后续数据支持。

## 仓库与版本

只展示已登记仓库的现有完整分析。每个仓库保留自身文件基线，不计算全局平均覆盖。摘要和热点只计算所选单期范围，可包含今天的活动；不计算两期热点变化。

仓库未准备、版本不可用或过期状态独立表达，不自动登记或启动分析。地图入口保留仓库版本、日期、客户端与热点路径；版本失效明确报错，不静默使用最新版本。

## 更新与实现边界

更新总览查询最新完整结果，不等于刷新所有历史或重新分析所有仓库。已有数据的更新保留上一完整报告及布局，固定位置显示进度；等待期间暂停旧结果下钻，成功整体替换，失败可重试。总览没有独立自动刷新设置。

常规区域先取得固定快照，再分别读取概况、用量、资源、过程与仓库，同时读取独立筛选项和当前使用分布。七天洞察使用独立查询与后台通道，不等待年度快照；顶部日期或模型更新不会暂停已经就绪的复盘。复盘自己的客户端、项目或刷新变化保留旧完整结果、暂停旧下钻，成功整体替换。首次进入时，准备完成的完整分区独立显示；失败分区可单独重试，迟到响应不能覆盖新范围。

用量趋势与组成共用轻量日期统计，不构建会话行、原请求预览、价格管理数据或每个日期的分组明细。Token、估算费用、请求数与日／周／月切换在页面复用已有日期桶。使用分布默认项目，每次只计算所选的项目、客户端或模型维度；切换维度只补取对应结果，按快照和维度复用缓存。工具分布继续复用过程统计。完整排行只计算当前维度，服务端分页不改变统计范围。

趋势按实际容器宽度绘制全部日期，每日点间距不足 4px 时采用折线，其余每日及周、月采用柱形。纵轴从零开始，使用整齐刻度，请求数刻度保持整数；零值不补造最小柱高，缺失日期断开折线，部分记录在详情中保留小计名称。日期刻度随宽度稀疏显示，跨年时分行显示年份。一个键盘入口支持方向键及首尾日期选择，鼠标点击或 Enter 打开对应区间的请求记录，触屏点击固定有界详情。浮层不改变页面布局，更新时关闭详情并暂停下钻。

基础主子会话计数在概况中提供；详细请求与 Token 分摊在打开委派调查时计算。筛选候选项独立读取，不通过完整用量报告获取。局部分布更新保留旧布局、暂停旧下钻，结果与当前快照及选中维度相符后替换；失败提供重试。

用量复用结构化请求事实与持久小时汇总；活动、工具和资源窄事实按不可变会话修订保存在 `overview-facts-v2.sqlite`，未变修订跨完整版本复用。日期节奏使用稀疏小时桶，完整请求成员在调查时读取。事实不包含消息正文或工具参数，原事件正文仍只在会话阅读时按身份加载。旧宽格式数据库及压缩事实文件不进入新页面查询。

七天洞察另存有界窗口事实于 `weekly-review-facts-v2.sqlite`，源索引只读。该事实包含字符数量、轮次边界和短需求预览，不保存完整正文或工具参数；每来源至多四份窗口，同一范围的详情共享聚合，跨日期复用已有覆盖。首次建立大量相关修订仍有冷算成本，缓存与首次结果的性能分别记录。 首算先校验并复用既有总览窄事实中的边界元数据和请求；同轮最后非空回复通过稀疏回复索引定位，终态标识及来源行号按消息身份从源元信息覆盖索引恢复，只有周内需求或周内回复轮次才恢复短预览。缺轮次请求按消息身份查找，歧义仍保留未归属。子 Agent 只准备独立请求与活动，不构建未使用的用户轮次；派生缓存身份区分子 Agent 与用户身份。每批最多三十二个修订共用写事务，批次之间让出执行；可选窄缓存不完整或损坏时回退只读源事实。

分区与调查结果保存在 `overview-results.sqlite`。缓存身份包含统计格式、完整版本、价格、时区、日期锚点、适用筛选、分布维度和必要仓库版本；命中前仍验证源版本有效。轻量用量的总量、趋势与分布视图使用独立缓存身份，避免复用错误结果形状。等价的快捷范围与显式日期复用同一统计缓存，响应仍绑定调用方的筛选身份。切换模型复用全局工具和压缩统计，只重算相关请求计时覆盖；总览用量摘要不传输或恢复原请求预览。

结果缓存最大 64 MiB、96 项、单项 4 MiB；事实库上限 768 MiB，文件权限为 `0600`。费用变化复用原 Token 事实，只更新依赖价格的汇总和结果。

冷回填使用单个写入通道，其他查询等待已落盘事实；用量趋势、当前分布与筛选项使用独立轻量通道，过程与资源统计不会阻塞它们，调查继续单独调度。容量不足明确失败并保留已完成修订，不将整库复制到内存或清空共享事实库。确认损坏的派生库仅由写入通道隔离为一份 `.corrupt` 文件并重建；不可写或空间不足保留旧页面并显示错误，修复本机权限或空间后再重试，不自动全量转入内存。原始历史不受影响。统计 Worker 有明确堆预算，闲置分析通道释放临时内存，结果仍由主线程和 SQLite 缓存保留；核心通道重建后继续承担唯一写入角色。

首页仅返回摘要和前几项。完整排行、资源对象分布、观察、组合、计时及月份／模型路径经服务端分页或对象级按需查询，分页改变调查表，不改变图表或统计范围。

常规 API 为 `GET /api/v1/overview/snapshot`、`GET /api/v1/overview/panel` 与 `GET /api/v1/overview/detail`；七天洞察使用 `GET /api/v1/overview/review` 与 `GET /api/v1/overview/review/detail`。原始记录继续使用 `overview/evidence`。既有 `overview/report` 保留完整统计兼容入口，其洞察也不超过五条，通常页面不请求它。

界面沿用共享筛选、日期、分页、帮助、主题与国际化规则。图表详情通过浮层显示；统计定义与覆盖依据收进区域帮助和调查详情。

## 总览界面与下钻

四组各突出一个主数值：活跃用户会话、平均轮次耗时、缓存读取占输入及用户交互集中时段。十八项指标整行可点击并保留轻量箭头。首页偏好不重复显示次数与占比，它们保留在完整排行。最长耗时和高 Token 轮次按两条重点记录展示；项目、子 Agent、工具及大输入低缓存调查入口归入对应主题。年度日历与活动分布按可用宽度并排或上下排列，日历日期格保持有界宽度。

调查固定保留主题、对象、日期、返回、帮助与关闭入口。对象标题最多两行，客户端与项目独立成行；数字正文与表头右对齐，文字左对齐。Token 使用统一紧凑单位，完整原值可按需查看，费用保留估算、小计和未知语义。费用入口显示请求费用，具体定价进入记录详情。仓库基线、版本和来源覆盖进入区域帮助，不占据记录首屏。

弹窗高度随内容收拢，达到视口上限后由正文统一负责纵横滚动，表头保持可见，分页固定在正文外。七天洞察显式请求每页二十条，与共享二十／五十／一百选项一致；分页菜单挂载到所属弹窗。新的下钻从顶部开始；返回保留对象、排序、页码、滚动及稳定行焦点，从会话返回也恢复原位置。等待或失败保留同一份标题、摘要和记录，重试成功后整体替换。

洞察与通用调查的记录表仅保留关键数值和会话定位，不再展开逐行原始字段详情。排行的“使用记录”与其他列统一对齐。
