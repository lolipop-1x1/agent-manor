# 会话库与统计口径

全局会话库与代码地图使用同一本机 SQLite 文件中的独立表。地图按登记仓库计算当前代码覆盖，会话库保留全部已配置来源中的可发现会话，包括无项目与未登记项目。新增客户端需要同时提供历史声明和会话规范化适配，不以 Web 名称判断历史格式。

来源文件只读。启动及主动刷新时检查来源，不变来源复用已完成修订；改变的来源逐记录解析写入新修订。完整版本发布前，查询继续使用上一版。失败标记过期，不发布半个版本；确认缺失的来源从新版排除并保留说明。索引只用于重建，清除后不能恢复已经删除的原始会话。

活动日志按开始检查时的固定字节前缀解析，允许来源继续追加，新增尾部留到下一次刷新；发布前重新校验该前缀。已有内容被改写或截短时，本次刷新失败并保留上版。单条超过 16 MiB 的来源记录不索引正文；未完成工具配对缓存限制为 32 MiB／1,024 个调用，并说明缺口。

## 浏览与搜索

消息、搜索结果均分页；分页不会缩小搜索的历史范围。关键词按字面内容匹配，默认包含标题与用户／AI 正文，中文同样支持。可显式添加工具参数／结果、思考、系统和压缩内容。工具结果是历史数据，不是客户端指令；页面按文本展示，不执行其中的 HTML。

搜索先选择结果页，再计算有界摘要，不把整个命中正文返回给页面。首版采用 SQLite 字面匹配；数 GB 历史的跨会话搜索仍可能需要数秒，项目、客户端和时间筛选可缩小搜索范围。

简易版使用明确的最终回答标记；缺少标记时按轮次顺序和工具结束状态推断，并标为“推断”。轮次没有完成回答时保持未完成。完整及轨迹视图展示已保存记录，不能恢复来源没有保存的思考或完整模型请求。

## 长会话阅读

桌面使用窗口内的三栏工作区：列表、对话与画像独立滚动，查看模式、搜索和轮次导航保持可见。侧栏可收起及调宽；窄屏将列表与画像放入侧边抽屉，通过按钮、遮罩或 Escape 返回对话。

Web 每页返回 10 个完整消息组，不在同一轮次中间截断。组按来源中的轮次首次出现顺序排列；初始上下文与无法归属轮次的记录单独成组，所以组位置可能与用户轮次编号不同。简易模式展开用户与最终回答，完整及轨迹模式默认折叠轮次与过程内容。消息定位自动载入所在页并展开对应记录；手动展开其他内容不会重新拉回定位消息。

用户和 AI 正文渲染 Markdown，原始 HTML 不执行，图片显示替代文字，不自动读取外部图片。长正文先显示预览，用户可以展开全部内容。代码块与工具等过程保留等宽格式；记录身份、关联文件放在可展开的详情中。

全局命中显示在左栏，会话内命中显示在搜索区下方的浮层，避免挤走正文。更换关键词或筛选时不显示旧查询的命中。清除会话内搜索后恢复搜索前的模式、页码及阅读位置。消息定位、查看模式、分页与组跳转同步到地址；父子会话切换可以返回，浏览器后退也恢复地址对应的视图。

画像分为概览、调用和用量。用量以趋势图和每页 12 条的请求表呈现，缺失值留空，真实零值保留；图表和请求编号可以定位对应事件。工具与资源名称可以定位首条证据，包含子会话时按明确关系搜索相应子记录。明细前 200 条的限制仍显式说明，汇总口径不变。

用量趋势的纵轴以零为起点，标注 Token 单位与等距刻度，三条曲线共用比例尺。悬浮或键盘聚焦显示当前请求的编号、模型、时间及输入／缓存读取／输出精确值；缺失显示“未记录”。参考线和数据点与数值同步，浮层限制在图表宽度内。键盘使用左右方向键切换请求、Home／End 到首末请求，Enter／空格定位记录。

## 会话画像

- 模型按记录展示全部名称和出现次数，不根据客户端名称猜模型。
- 请求用量与留存内容估算分开。估算基于本机保存的文本体量及公开方法，不能用于账单或断言实际请求上下文大小。
- Codex 的缓存读取属于输入子集；Claude Code 的普通输入、缓存读取及缓存写入归一化为总输入；CodeFlicker 保存的输入为总输入，缓存属于其中的子项。
- 缓存读取占输入比例只使用同时有可确认输入和缓存字段的请求。用量记录覆盖范围另列，缺少字段显示“未记录”，不当作零。
- 输入／输出的累计用量与单次用量不能重复相加。重复发射和流式快照按请求／消息身份及累计进度处理，不能仅因两个请求数字相同就丢弃其中一个。
- 推理输出若包含在总输出中，单列说明，不再额外加到总输出。最大单次输入由请求输入记录计算；上下文峰值仅接受明确保存的上下文计数，累计输入和单次输入都不冒充上下文峰值。
- Tool 计实际调用；成功、失败和未记录结果分别展示。耗时必须有记录依据。MCP 从实际工具身份解析服务器；Skill 明确调用与读取 `SKILL.md` 的证据分别展示，提及名字不计调用。
- 默认统计会话自身；包含子会话只遍历有明确关系的子记录。fork 与缺少原始身份的复制历史不根据正文相同而合并，不能承诺缺失日志下的全局去重。
- 请求步骤显示前 200 条并说明限制，统计仍包含全部用量记录。步骤携带所属会话身份；点击子步骤进入子会话的实际记录。

Web 与 CLI 查询使用版本化 REST API，保持相同索引版本。来源行与工具 call ID 支持代码地图定位所属会话；会话项目尚未登记时，先登记再进入地图。
