# 会话代码活动回放

活动回放与活动分布是代码地图下的两个同级视图，共用已登记仓库。活动分布用于覆盖统计，回放用于观看某次任务的文件活动与证据。会话库提供回放快捷入口；直接进入代码地图也能选择会话。

## 范围与身份

回放目标是一条全局会话索引身份，递归纳入索引已确认的 child 关系，每个成员独立一轨。fork 不作为 child 合并，复制历史仍归原会话。只有子会话有文件活动的主会话仍进入候选。原生调用 ID、请求记录位置和消息身份用于归组；相同时间不等于同一次调用。

一次回放冻结仓库分析 `version`、会话索引 `sessionVersion` 和成员集合。它们分别限定文件基线／活动与会话关系／消息定位；两种版本不能互相替代。分析存储及会话存储仍按各自既有规则保留版本。任一版本淘汰后明确失败，用户更新后重新载入，不静默替换正在观看的结果。

投影按目标身份点查 SQL 中的调用元数据，读取轻量会话目录及回放专用最小地图快照，不返回工具正文、源码或原始证据。原始证据按用户选中活动单独加载；所属消息使用固定会话版本定位。

## 时间与地图

- 共享原始绝对时间轴，按已记录时间对齐多轨；超过 15 秒且所有轨道均无文件活动的间隔统一压缩为 900 毫秒。最后一步保留 1200 毫秒观看停留。这些是观看节奏，不是测得的工具耗时。
- 0.25×、0.5×、1×、2×、4×、8× 倍速作用于共同播放头。拖动、前后活动、回到开头与键盘定位使用同一坐标。
- 未定时活动独立保留所属轨道和原始顺序。来源无法比较时明确顺序未知，不按邻近时间补齐；仅能精确关联同次原生请求时使用该请求已记录时间。
- 所有纳入基线的文本类别均展示，文件面积和布局固定。读取、修改、搜索用形状区分，轨道用编号与颜色区分；成功、失败、未知保持原义。过去痕迹与当前活动高亮分开，向后定位移除未来痕迹。
- 目录搜索表示范围，不推导为目录内每个文件均读取或命中。已删除、零行和基线外文件不能绘制面积时仍保留活动及证据入口。

暂停是初始和恢复状态。打开证据、切换功能、离开页面、网页隐藏及到达终点暂停，继续需手动操作。版本信息、缺失子会话和基线说明放入帮助。错误可见并可重试，加载新目标前保留旧完整画面并暂停旧数据下钻。

## 性能边界

后端的惰性只读 Worker 分别缓存分析版本的最小快照和双版本的回放准备结果，限制缓存数量而不截断活动。主线程固定双版本，同条件请求共享准备任务；Worker 再核验版本保留状态，冷查询不占用 HTTP 主线程。会话索引更新不重复读取同一分析版本的仓库分块。SQL 仅提取文件、活动、来源及路径字段；调用元数据按固定版本和目标会话复合主键点查，不遍历全版本消息。版本检查及各分块读取置于同一延迟读事务内，其他连接淘汰版本时仍返回完整旧快照或明确版本错误。断开请求会取消订阅并移除无订阅的排队任务，已执行的同步 SQLite 读取可以继续完成并复用缓存；这不等于立即中断查询。服务关闭时收束订阅并终止只读 Worker。

播放时使用预构建时间与路径索引、二分查找、增减累计状态；地图只在活动边界变化时更新。播放头最多每秒发布 20 次状态，不逐帧访问服务。长轨道用 SVG 批绘，动态叠层只绘制滚动视口可见段，全部轨道仍可访问。证据和未定时活动分批展开。

## API

`GET /api/v1/repositories/:id/replay/sessions?version=…&sessionVersion=…` 返回固定双版本与可选会话，每项含全局身份、原生身份、客户端、标题、活动与轨道数量。

`GET /api/v1/repositories/:id/replay?sessionId=…&version=…&sessionVersion=…` 返回固定双版本、基线 hash、轨道、完整步骤、轻量文件、原始时间范围与缺口。步骤包含调用身份、所属轨道、顺序、可选时间与活动数组；每条活动保留事件身份、工具、种类、状态、路径及可定位消息。

`GET /api/v1/repositories/:id/replay/evidence/:eventId?sessionId=…&version=…&sessionVersion=…` 要求固定双版本及所选根会话，校验活动属于该会话或明确子树，只读取所属分块中的单条完整事件，再校验并读取原始来源。它不会为一条证据恢复整仓工具正文；无关会话、fork、失效版本或不可读原始记录保持明确边界。

旧地图接口及会话过滤语义保持原样，回放使用独立接口和状态。URL 的 `#map?view=replay&repository=…&session=…` 定位功能、仓库与目标。
