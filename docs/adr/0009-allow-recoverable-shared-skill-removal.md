# 普通共享 Skill 按实际文件位置回收

多个客户端发现同一普通 Skill 目录或文件，不再单独构成禁止回收的理由；客户端原生启停适配也不限制已核验的普通文件操作。按实际位置生成一次可恢复回收预览，列出已发现的引用并说明未扫描引用的边界，保存文件操作身份及受影响入口；符号链接仍只移除所选链接，系统、插件、托管与未核验来源继续保护。

此决定补充 [ADR 0007](0007-persist-local-resource-management-state.md)。相较只允许逐客户端停用，需要保留完整的已知影响范围，使恢复与检索不会因文件消失或断链而丢失关联；执行前复核内容、引用和保护，恢复冲突不覆盖，文件回收不修改客户端原生开关。
