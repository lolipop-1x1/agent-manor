# 全局会话库采用可重建本地索引

会话库纳入现有客户端全部可发现历史，包括未登记仓库及无法归属项目的会话。浏览、搜索和会话画像所需的消息内容与派生数据保存在本机，原始来源只读，保留原始记录定位；清除索引后可从现有来源重建，分析不依赖上传历史或调用模型。

此前考虑过独立长期归档，使客户端已经删除的历史仍可查询。用户选择沿用原始来源的生命周期及可重建索引：来源确认消失时，从新版有效结果排除，保留缺口、变化原因和可用的上版对照；临时读取失败不当作来源删除，刷新失败保留上一版。相应接受清除索引后无法恢复已经缺失的来源，不承诺长期归档。

本决定扩展 [ADR 0002](0002-local-analysis-service.md) 中代码活动地图只保存必要历史源码片段的范围：会话浏览和搜索还需要本地消息内容索引。该索引可能包含完整对话与工具内容，仍受本地存储、来源只读及可清除重建的边界约束。结果一致性继续遵循 [ADR 0004](0004-publish-complete-analysis-versions.md)，启动检查与主动刷新沿用现有后台生命周期，不默认持续监听。

本决定不冻结消息表结构、全文搜索算法或分页实现；DSH 本次只作为轨迹交互参考，不新增其历史来源适配。
