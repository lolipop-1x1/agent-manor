# 用量统计采用结构化事实与后台增量汇总

报告查询不再反复读取全量原请求 JSON 并判断复制记录。会话修订完成时，在同一事务保存统计事实与复制排除结果；已有索引由统计 Worker 按修订补齐。事实格式独立版本化，原始来源只读，完整发布版本和旧版本失效规则继续遵循 [ADR 0004](0004-publish-complete-analysis-versions.md) 与 [ADR 0005](0005-rebuildable-global-session-index.md)。

独立派生数据库保存按会话修订、客户端、价格内容版本和时区生成的小时汇总。不变修订复用，发布新版本后组合当前会话身份和父子关系；价格或时区变化复用事实重算相应汇总。价格视图固定于查询，继续遵循 [ADR 0012](0012-versioned-usage-price-catalog.md)。

服务启动及分析、价格或本机时区变化时后台准备。先完成全局筛选项与无用量判定所需的事实身份，再按请求时间优先生成近期汇总。有限日期报告可在必要修订汇总完成后返回，其他历史继续计算；不把部分历史冒充完整报告。首次旧库回填仍有一次性成本，界面显示明确的准备状态与进度。

常规查询合并小时汇总。精确 ISO 区间及涉及费用临界值、指标或排序的查询读取精简事实并保留原精确计算顺序，避免浮点重排影响选中会话或同金额排序。报告和请求预览只补齐当前页需要的原始证据。准备和读取都在统计 Worker 中运行，不阻塞服务主线程。

结果缓存、事实源缓存及持久汇总均设置上限，相同在途查询合并；缓存命中仍验证版本可用。派生缓存损坏、格式变化或索引回收后可重建或淘汰，不影响手动价格、映射及原始会话。表结构、具体体积上限与验收方法见 [用量统计](../design/usage-statistics.md)。

请求明确记录的服务商随模型与 Token 进入精简事实，费用依据和覆盖计数进入小时汇总。事实与汇总格式升级后按原请求重建派生数据；来源解析规则指纹只失效受影响客户端。不变的原始历史和手动价格配置继续保留。
