# 知识与必要证据独立保留

知识正文、人工修改和审阅记录作为用户整理形成的持久内容保留，不归入可清除重建的会话索引。每项知识保留可用的来源定位与版本信息，以及支持其结论所必需的少量证据摘录；不因此永久复制完整会话。没有关联会话的直接写入保留提交来源，不补造历史证据。

原始会话确认消失时，知识及已保存的必要证据继续保留，来源明确标为不可回查。来源可回查性与人工审阅状态分别记录，来源消失本身不证明知识结论失效。

该边界区别于 [ADR 0005](0005-rebuildable-global-session-index.md) 的历史索引生命周期：原始历史及其可重建索引继续遵循原决定；知识是独立整理的内容。关键词与向量搜索索引属于派生数据，重建或清理索引不删除知识本身。代价是需要为知识及证据单独提供保留、删除和恢复机制，不能依赖会话缓存重建恢复人工内容。

当前整体设计见 [知识库设计方案](../design/knowledge-library.md)。
