# 产品版本检查、提醒与程序升级分离

产品默认自动检查新版本，并在 Web 和 CLI 呈现更新信息；安装由用户主动触发。默认跟随 npm 的 latest 稳定版，保留显式选择发布版本的能力。后台异步检查，默认每 24 小时最多一次；检查设置与缓存按产品安装共享。Web 负责检查提醒，实际安装在终端预览并确认，非交互安装需要显式授权。首版拒绝降级。

一份产品安装可以运行多个后台，并访问具有独立生命周期的本地数据。版本检查与提醒不取得安装授权、不停止后台、不触发数据库迁移。程序升级继续作为明确的管理动作，处理安装锁、实例身份、在途任务、数据备份和服务恢复，避免浏览或日常查询隐式改变运行环境。

CLI 对同一目标版本每 24 小时最多自动提醒一次，Web 使用紧凑标记，不主动弹窗。忽略版本的设置按产品安装共享，只影响自动提醒；主动检查仍显示结果，更高版本发布后恢复提醒。

本决定沿用 [ADR 0020](0020-independent-cli-unified-distribution.md) 的统一同版本交付边界，不引入无人值守安装。实现范围与后续决策见[产品更新设计](../design/software-updates.md)。
