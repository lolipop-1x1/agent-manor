# 会话刷新按客户端检查，默认快速检查并保留完整校验

允许一次刷新仅检查选定 Agent 客户端的来源，范围外来源与其最近成功检查状态保留，完成后仍原子发布完整全局会话库版本。该决定扩展 [ADR 0005](0005-rebuildable-global-session-index.md) 的主动刷新方式，结果一致性继续遵循 [ADR 0004](0004-publish-complete-analysis-versions.md)；全局版本发布时间不再代表所有客户端都在本次被检查。

日常刷新默认根据来源及已核验元信息依赖的变化指示判断复用，无法确认依赖或缺少检查记录时回退到内容检查。用户可对当前客户端或全部客户端执行完整校验，读取内容核对但不强制重建相同内容索引。相较每次完整读取，该选择减少重复读取，同时接受快速检查不能严格排除保留相同变化指示的内容改写；完整校验提供主动核对入口。SQLite 的 WAL 及影响会话标题、项目、模型和关系的旁路信息属于检查依赖，不能只检查主来源文件。

此决定不引入消息级追加解析或按会话局部更新，不改变原始来源只读、确认缺失后排除、失败保留上一版的边界；整体规格已确认，本决定接受。
