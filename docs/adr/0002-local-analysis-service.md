# 由本地后台服务统一提供代码活动分析

首版以一个本地后台服务维护历史分析索引，并向 Web 和 CLI 提供同一套覆盖率、活动与证据查询；Skill 指导其他 Agent 使用 CLI。解析、历史内容与当前仓库的对应、统计和增量更新集中在分析核心中，避免各入口重复分析并产生不同口径。

此前考虑过一次性 CLI 分析加静态报告的形态。用户需要网页关闭后其他 Agent 仍能查询、主动刷新并复用分析结果，因此选择可按需启动的本地后台服务；相应承担服务状态、并发刷新及停止的生命周期管理。

服务在 CLI 或 Web 需要时自动启动，启动时检查更新，关闭页面后继续运行，支持显式查询状态和停止。首版不默认配置开机启动或持续监听。本机保存可重建的分析索引与必要历史源码片段，保留原会话定位，原始历史只读；分析不依赖上传历史或调用模型。

本决定不选择语言、数据库或 UI 框架。首版在 macOS 完成真实验收，核心保持跨平台设计；与外传保护的独立边界继续遵循 [ADR 0001](0001-independent-project-boundary.md)。
