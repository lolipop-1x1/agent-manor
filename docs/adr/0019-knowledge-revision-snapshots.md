# 知识以内容修订快照保留历史

知识具有稳定条目身份，每次明确保存形成新的内容修订。以完整快照保存各修订的正文及相关属性，使旧版阅读和差异比较不依赖从最早版本重放一串补丁。字段和具体恢复交互在整体方案中细化。

人工审阅绑定具体修订，Agent 与后台提议的修改不直接覆盖当前有效修订。发布新修订时切换当前版本，旧修订继续保留；恢复旧内容形成新修订，不改写历史或继承一次旧确认冒充新审阅。比较及提交基于明确的基础修订，过时提交需要重新比较。

相较只保留差异，完整快照增加本地存储，但减少历史读取与恢复对长补丁链的依赖。知识正文与必要证据的保留继续遵循 [ADR 0018](0018-persistent-knowledge-and-evidence.md)，不为每个版本复制完整原始会话。

内容快照与审阅、发布、废弃、恢复等操作记录分别保存；普通键盘输入和索引更新不制造知识修订。当前可用性与人工审阅分别判断，已审内容被废弃或过期后仍保留历史，默认关键词及语义查询均排除。

当前整体设计见 [知识库设计方案](../design/knowledge-library.md)。
