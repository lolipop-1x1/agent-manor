# 增量复用、可见页面自动检查与分批空间回收

用户授权优化历史刷新、页面加载和存储占用，并要求保留数据正确性。未变化来源复用已有修订，检查完成但有效内容未变化时沿用原版本与创建时间，单独更新最近检查状态。地图解析缓存只写变化来源；归属与映射仍检查当前仓库基线、历史关系和解析规则，不能将客户端最近检查时间作为来源变化证明。

本决定扩展 [ADR 0005](0005-rebuildable-global-session-index.md) 和 [ADR 0006](0006-scoped-quick-session-refresh.md) 的主动刷新生命周期。会话库与代码地图分别保存周期自动刷新的开关和间隔，各自默认关闭。用户可选择 5 秒、10 秒、30 秒、1 分钟、5 分钟或 10 分钟，并与语言偏好一起持久保存。会话库开启且可见时按其间隔检查全部 Agent；代码地图开启且可见时按其独立间隔只检查当前仓库。服务端按对应页面保存的开关与间隔约束任务，旧标签页不能绕过关闭设置。服务端合并多页重复任务，全部页面隐藏时不再发起新自动检查，已开始任务完成。手动刷新范围和完整校验保持原语义。正文、画像和轨迹在同一完整版本准备完成后一起切换；通过稳定消息身份保留阅读位置，不以轮次序号充当稳定身份。

2026-10-14 根据全局历史来源与各页派生数据的关系调整 Web 生命周期：历史自动同步在五页共享，由可见网页调度，不再依赖会话库页面是否激活。历史与地图两份偏好及关闭默认值继续保持，地图仅在自身页面可见时自动分析当前仓库。自动任务只有发布版本变化才通知当前页，隐藏功能页在激活后消费新版本；手动同步保留主动重读。资源使用联动不触发管理记录或本地盘点，详情和同版证据完整准备后一起替换。这一调整替代上段会话库必须可见的触发条件，不引入服务端常驻监控。当前页读取未结束时暂缓新的自动检查，通知保留最新版本并在本次读取完成后消费，避免短间隔反复取消大报告。

来源只读和原子完整发布继续遵循 [ADR 0004](0004-publish-complete-analysis-versions.md)。无法证明完整旁路依赖或安全追加状态的格式回退到来源级内容校验、完整解析。会话用量、最终回答、分支与复制关系可能修改早先记录，因此本次不采用盲目消息追加写入，也不以多线程数量作为性能验收。先消除重复路径／Git 检查、无变化读取与缓存写入，再以固定输入对照评估收益。

空间回收扩展 [ADR 0008](0008-preserve-session-content-and-limit-map-versions.md) 的仅启动整理约定。新库启用增量页回收，运行期间在分析 Worker 空闲时分批归还完整空闲页，写锁竞争安全跳过，WAL checkpoint 不等待活跃读者。已有 NONE 库只在普通连接与 Worker 打开前受控转换，检查临时空间、生命周期排他锁、逻辑行、显式消息键及全文搜索关联；不符合条件时保留可用索引并报告原因。转换后启动不再反复执行全库整理。页内空隙与仍在使用的内容不计作可自动删除的空闲页。

Web 使用可选有界消息预览、请求分页、轨迹粒度与画像摘要；完整内容、旧完整 API、搜索和证据读取保留。跨模块长正文共享仍单独评估，本次不引入大范围正文结构迁移。完整规格、任务和验收记录见[索引刷新优化](../../.scratch/index-refresh-optimization/spec.md)。
