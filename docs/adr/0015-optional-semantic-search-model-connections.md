# 会话语义搜索接入用户配置的可选模型服务

会话语义搜索规划为可选能力，接入用户提供的本地或远端 OpenAI 兼容 embedding 服务。用户在界面配置服务地址、模型身份、可选访问凭据和调用策略；首版不负责模型下载、安装与启动，以控制本地推理运行时及平台适配的维护范围。

此决定为 [ADR 0002](0002-local-analysis-service.md) 和 [ADR 0005](0005-rebuildable-global-session-index.md) 的模型依赖边界增加明确的可选范围：已有历史浏览、统计和字面搜索继续在本地完成，语义索引构建会将用户选择范围内的对话正文发送给所配置的模型服务。模型连接及索引维护策略由界面管理，保存连接不自动开始处理历史，首次构建由用户显式开始。

模型请求由本地后台发起，浏览器向本地服务提交操作。后台在构建索引时编码所选历史正文，在收到语义查询时编码查询文本，再在本地匹配向量；使用远端模型服务时，两类编码都会将对应文本发送到该服务。关键词搜索不调用模型。

为简化本地部署，访问凭据保存在独立本地文件，目录权限为 0700、文件权限为 0600，内容不宣称加密。凭据与可重建索引分开保存，普通偏好、浏览器持久存储和日志不包含 Key。网页默认遮罩，允许用户点击显示完整值并复制、替换和清除，以便本地配置；凭据存储不使用系统钥匙串。

关键词搜索默认实时查询，语义查询通过 Enter 或搜索按钮提交。查询向量只在服务内存中有界复用，模型配置变化后失效；后台构建默认单请求并发并优先处理查询。用户可以设置每日估算费用预算，达到阈值后停止新的模型请求，已有缓存及关键词搜索继续可用；该阈值不保证与服务商实际账单完全一致。

语义文档按真实用户轮次组织提问与本轮助手对话正文，长内容切块，结果按会话分组并默认按相关性排序。首次完整构建后启用语义搜索，界面提供阶段和构建进度；不兼容的模型或编码规则变化要求显式重建，期间关键词保持可用。

这是已确认的规划决策，尚未交付功能。搜索设置位于会话库搜索入口旁的配置对话框；维护范围与搜索覆盖见 [ADR 0016](0016-semantic-index-retention-and-query-scope.md)。关闭网页不停止本地服务中的已启动任务，暂停后台构建不阻止主动查询编码；相同查询已有有效缓存时可以复用。内容 hash 复用、存储和调度的具体方案在 [规格草稿](../../.scratch/semantic-search/spec.md) 中等待整体审阅，确认过程见 [设计树](../../.scratch/semantic-search/map.md)。
