# 统一轮次规则升级整体发布

会话阅读、画像与七天复盘使用相同的真实输入分类及结束依据。旧来源缓存缺少当前轮次规则标记时，即使刷新请求指定单个客户端，也先对全部来源执行一次检查并原子发布，防止新旧轮次语义混入同一个统计版本。升级失败继续保留上一完整版本，原始历史保持只读。

全部来源完成规则升级后，恢复 [ADR 0006](0006-scoped-session-refresh-verification.md) 的客户端范围刷新，保留范围外来源和成功检查状态。固定规则标记使未变化来源继续快速复用，不因普通刷新重复重建。

后续轮次投入改为真实输入至同轮最后非空 AI 回复记录时间。此变更仅重建派生统计并升级缓存格式，通过新增回复索引读取已有完整修订，无须再次解析全部原始来源；原生终态继续保留用于请求速度及来源详情。
