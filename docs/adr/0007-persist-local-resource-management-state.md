# 本地资源管理状态独立于分析索引保留

使用排行及资源发现快照可以从现有历史和配置重新计算；收藏、用户添加的来源、管理记录、备用和回收材料无法由会话历史完整重建。用户在资源管理规格中选择保留这些管理状态，清除或重建历史索引不清除它们，也不重新执行先前的操作。

此决定补充 [ADR 0005](0005-rebuildable-global-session-index.md)，没有将会话库改为长期归档。来源消失后，派生使用记录仍遵循原有生命周期；管理操作及其恢复材料按各自生命周期保留，以支持查看影响、恢复和另行确认的永久清除。相比把全部数据都当作缓存，需要独立维护管理状态与清理流程，但不会因刷新或清除索引破坏恢复路径。

写操作先保存可用恢复材料并确认具体预览；恢复遇到原位置或配置变化时重新预览，不能静默覆盖。材料仅存本机，可能含敏感配置，必须限制访问并排除公开日志、Git 与发布包。「本地修改完成」与「客户端已生效」分别记录，缺少确认信号时保留待重新加载状态，不自动重启客户端。

本决定约束生命周期，不冻结表结构、文件布局或各客户端的配置修改方式。每种来源的能力、作用范围与恢复方式须单独核验。
