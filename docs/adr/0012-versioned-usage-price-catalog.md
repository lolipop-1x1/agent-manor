# 模型价格与历史用量分别保存并绑定版本

用量统计按历史请求事实保存 Token 和原始模型名，模型价格目录、用户单价及计价映射作为独立本地数据保存，费用查询同时绑定分析结果版本与价格版本。用户已确认自动定价采用网络优先、本地兜底，用户手动单价具有最高优先级；价格下载只读取固定公开目录，不携带会话内容、项目路径或客户端凭据。

相比把当前计算金额固定写入历史用量，这一方案支持补充未知模型价格和重新估价，也使同一历史范围可能因价格版本变化而产生不同估算，界面必须说明价格依据。目录快照不代表历史生效价格或实际账单；原始历史只读及完整分析版本规则继续遵循 [ADR 0004](0004-publish-complete-analysis-versions.md) 与 [ADR 0005](0005-rebuildable-global-session-index.md)，用户单价与映射不随索引重建丢失。

具体价格查询顺序、匹配边界和验收见 [用量统计规格](../../.scratch/usage-statistics/spec.md)。
