# 模型价格与历史用量分别保存并绑定版本

用量统计按历史请求事实保存 Token 和原始模型名，模型价格目录、用户单价及计价映射作为独立本地数据保存，费用查询同时绑定分析结果版本与价格版本。用户已确认自动定价采用网络优先、本地兜底，用户手动单价具有最高优先级；价格下载只读取固定公开目录，不携带会话内容、项目路径或客户端凭据。

相比把当前计算金额固定写入历史用量，这一方案支持补充未知模型价格和重新估价，也使同一历史范围可能因价格版本变化而产生不同估算，界面必须说明价格依据。当前目录快照不代表历史生效价格或实际账单；明确日期区间可以用于对应请求的历史价格估算，其来源及生效边界独立保存并展示；原始历史只读及完整分析版本规则继续遵循 [ADR 0004](0004-publish-complete-analysis-versions.md) 与 [ADR 0005](0005-rebuildable-global-session-index.md)，用户单价与映射不随索引重建丢失。

未记录服务商且无服务商前缀的标准 OpenAI 模型有精确原厂目录条目时，按 OpenAI API 价格估算；不因多个转售目录包含同名模型而拒绝原厂基准。此依据在界面可见，手动价格与明确映射仍优先；未知服务商和相似模型不猜测。该规则用于修复标准模型全部未定价的缺口，不表示请求实际按原厂价格结算。

价格版本还包含解析规则版本，使规则升级后旧费用汇总失效，原用量事实继续复用。具体价格查询顺序、匹配边界和验收见 [用量统计规格](../../.scratch/usage-statistics/spec.md)。

请求明确记录服务商时，按服务商与模型精确选价，未知服务商不回退到另一家同名价格。手动覆盖以服务商与模型为身份，空服务商表示全局覆盖且具有最高优先级；多个服务商覆盖可以共存，编辑及恢复只影响选中身份。

已核验的 `deepseek-official` 内置 API 渠道允许有限的 `deepseek` 精确模型估算基准，渠道自身价格及用户配置仍优先。明细保留原渠道、实际采用的价格服务商和 API 基准标记；路由可能覆盖端点，不能据此认定实际账单。`openai-codex` 属于订阅渠道，不自动映射为 API 计费；需要用户明确配置。

历史价格使用固定公开数据中的明确日期序列，以请求时间选择开始包含、结束排他的 UTC 区间。无适用历史依据时回退当前目录，并显示当前快照估算；不把获取日期或无日期当前单价当作生效时间。两个网络来源并行刷新，独立保留成功缓存；首次无历史缓存时继续使用当前价格兜底。价格内容版本包含历史区间及解析规则，变化后只重算费用汇总，不改原始 Token。
