# 模型价格与历史用量分别保存并绑定版本

用量统计按历史请求事实保存 Token 和原始模型名，模型价格目录、用户单价及计价映射作为独立本地数据保存，费用查询同时绑定分析结果版本与价格版本。用户已确认自动定价采用网络优先、本地兜底，用户手动单价具有最高优先级；价格下载只读取固定公开目录，不携带会话内容、项目路径或客户端凭据。

相比把当前计算金额固定写入历史用量，这一方案支持补充未知模型价格和重新估价，也使同一历史范围可能因价格版本变化而产生不同估算，界面必须说明价格依据。当前目录快照不代表历史生效价格或实际账单；明确日期区间可以用于对应请求的历史价格估算，其来源及生效边界独立保存并展示；原始历史只读及完整分析版本规则继续遵循 [ADR 0004](0004-publish-complete-analysis-versions.md) 与 [ADR 0005](0005-rebuildable-global-session-index.md)，用户单价与映射不随索引重建丢失。

自动选价优先采用同版本模型的原厂 API 单价，再采用同版本 OpenRouter 公开目录价格，之后保留明确服务商或前缀的精确匹配及唯一同名目录匹配。免费、订阅和 Token Plan 套餐内请求同样按 API 基准估算；不按价格高低或是否零价挑选条目。用户给原始模型设置的全局或专属手动单价以及明确映射均优先于自动规则。

通用名称识别处理渠道命名空间、大小写、分隔符、Claude 系列与版本顺序及末尾免费标记，不按某个渠道硬编码别名。公开目录的 `canonical_model_id` 作为标准模型身份保存并参与价格内容版本；只有标准身份与原条目型号签名一致时才用于自动匹配，避免目录把不同版本、pro 或视觉变体合并后串价。先确认标准身份，再选择官方或公开目录的同版本 API 基准；已有模型系列识别作为无标准身份时的补充。

模型版本、日期及功能变体不降级或删除。标准身份冲突时不按目录顺序选取；请求明确记录的服务商或目录前缀仍可唯一匹配同型号价格。界面区分身份冲突、需要服务商、缺 API 基准、未知身份及失效手动映射，展示相关候选供用户选择，不自动预填歧义候选。价格管理显示模型名的默认匹配，请求明细按实际服务商和时间取价。清除手动映射后恢复自动匹配。自动身份只定义估算基准，不表示实际路由、订阅支出或账单。

价格版本还包含解析规则版本，使规则升级后旧费用汇总失效，原用量事实继续复用。自动解析不落入手动配置、不改原始模型身份或 Token。手动覆盖以服务商与模型为身份，空服务商表示全局覆盖且具有最高优先级；多个服务商覆盖可以共存，编辑及恢复只影响选中身份。具体价格查询顺序、匹配边界和验收见 [用量统计规格](../../.scratch/usage-statistics/spec.md)。

历史价格使用固定公开数据中的明确日期序列，以请求时间选择开始包含、结束排他的 UTC 区间。该来源的普通单价对象及唯一无日期条目可以补充当前快照，不能作为历史依据；多个无日期候选及不支持的约束不猜选，只有输入单价的嵌入模型不进入当前文本计价结构。无适用历史依据时回退当前目录，并显示当前快照估算；不把获取日期或无日期当前单价当作生效时间。

两个网络来源并行刷新，独立保留成功缓存；主目录缺少的精确身份可以由备用当前快照补齐。少量已核对官方 API 的本地兜底保存来源链接与核对日期，同身份主目录网络条目优先，不覆盖套餐条目自身的价格。首次离线仍可使用本地当前快照。价格内容版本包含标准身份、历史区间及解析规则，变化后只重算费用汇总，不改原始 Token。
