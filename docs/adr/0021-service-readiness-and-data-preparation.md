# 分开表达服务就绪与启动数据准备

本地后台完成必要的数据库兼容、一致性检查并开放 HTTP 后，即可报告服务就绪；历史增量更新、搜索索引补齐、用量和默认总览准备在后台继续进行，各自保留进度、完成范围与失败信息。启动命令等待服务就绪即可返回，需要新数据的调用方可显式等待相关准备任务，首次准备中的空库不被表达为已完成检查后的空结果。

等待全部历史、缓存和可选模型任务会使服务可用时间受数据规模与外部连接影响，因此不把它们合并为启动完成的单一条件。已有完整结果在更新时继续可读，必要的不兼容迁移仍须先完成；模型任务只按已启用策略和预算执行，进程启动本身不额外安排全量生成或编码。本决定细化 [ADR 0002](0002-local-analysis-service.md) 的按需启动，保留 [ADR 0017](0017-backend-history-sync-scheduling.md) 的后台同步及完整版本发布边界。
