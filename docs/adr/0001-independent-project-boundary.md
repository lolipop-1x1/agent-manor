# 独立建设 Agent 工作环境管理项目

AgentManor 使用独立仓库，围绕配置盘点、历史分析、使用证据和可恢复管理建设本地优先的 Agent 管家。原 agent-guardian 以项目外传保护为目标；两者用户目标、系统依赖与验收要求不同，独立建设便于分别验证需求和交付。

此前考虑过继续把历史分析与代码地图放在外传保护产品中。现有保护实现仍在开发，其网络扩展、拦截、批准和外传账本会增加历史管理产品的交付负担；独立项目避免让这些机制成为历史分析的前置条件。

## 边界与后果

- AgentManor 的会话与文件活动分析保留来源和观察精度；它不能替代系统观察、代码外发确认或防泄露验收。
- 历史解析、源码匹配与地图思路可以评估复用，具体代码复用仍需接口、许可证和实际行为核查。
- 两个项目未来可通过明确的数据契约共享结果；本次没有抽离代码，也没有确认共享包或仓库依赖。
- 语言、数据库、UI、首版客户端版本和管理操作仍未选定；不从 agent-guardian 的 Rust／Swift 与 Mac 首版约束推导 AgentManor 的技术选择。

状态 accepted 对应独立项目边界，产品首版范围仍见 [候选建议](../product/vision-and-scope.md)。
