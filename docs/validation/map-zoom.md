# 连续缩放与全屏地图验收

本次只改变地图视野与展示，不修改历史解析、数据库或覆盖统计口径。

## 验收方法

- 纯函数样本覆盖一万个文件、悬殊行数、180 层目录、空文件、极小非空文件及数值边界。
- Chrome 端到端使用已登记实际仓库，连接已有服务，只查询已发布结果；不创建合成浏览器仓库、不刷新服务、不修改业务文件。
- 通过 `AGENT_MANOR_E2E_REPOSITORY` 传入本机仓库名称或路径，运行 `node scripts/e2e-map-zoom.mjs`。服务地址可用 `AGENT_MANOR_E2E_URL` 指定。
- 比较界面与独立 HTTP 摘要，以及缩放前后同版本完整覆盖响应；检查视野操作没有新增 API 查询或修改请求。
- 截图和私有诊断仅存于忽略的 `.local/map-zoom-e2e/`，公开记录不保存真实路径、文件名、结果版本或会话标识。

## 结果

- 类型检查、生产构建、17 项前端测试和完整 142 项测试通过；完整套件包括 macOS 实际安装包外的 CLI、Worker、Web、SQLite 与查询 Skill。
- 实际样本含 1,527 个非空源码文件。1 行文件定位到约为适应比例的 183.83 倍；局部保留 4 个可见几何和 4 个可读节点，名称、百分比和完整路径提示可读，文字字号不随放大变化。
- 13 组 Chrome 流程通过：按钮／键盘、定位、地图内／外滚轮、焦点、拖动、目录标题附近拖动、全屏／Esc、侧栏、指标、主题／窄屏、目录及仓库往返。另验证实际文件单击与目录入口单击。
- 界面摘要与独立 HTTP 查询一致，固定版本完整覆盖响应前后一致，视野操作不新增查询，所有请求均为 GET。页面、控制台、HTTP、网络与事件监听错误均为零。
- 单次自动化观察中，定位约 114 ms、滚轮约 13 ms、拖动约 59 ms；包含浏览器自动化排程，不是通用帧率基准。
- 按钮透明背景与 SVG 每侧半像素间隔已核对，放大后分隔清晰。截图仅留本机。

## Standards

首轮没有强制规范违规，发现一项判断性重复代码：被替代的 `mapTree` 只剩旧测试引用。已删除旧函数，生产布局测试沿用 `layoutMap`。最终复查无剩余发现。

## Spec

首轮发现目录标题遮挡、窄屏正常字号与验收覆盖不足；复查发现 84 像素定位高度不足以容纳标题和指标。已增加文字避让、保持 12 像素名称、补齐交互断言，并将定位高度统一为 128 像素，新增薄块回归。最终复查无剩余发现。

实际验收先暴露 CLI VM 缺少 `URL` 全局导致会话退出，再暴露 Esc 未退出。脚本改用明确的路径处理并记录事件异常；页面增加当前地图全屏时的 Esc 退出。修复后完整重跑通过。

## 边界

- 连续缩放使用浮点逻辑几何及屏幕裁剪，文字按可读空间显示，保持正常字号；不放大截图。
- 极小非空文件保留面积，空文件仍通过文件列表进入。缩放上限按最小文件可读尺寸留出余量，受浏览器数值精度保护，不承诺数学无限。
- 缩放和平移不改变统计范围；显式目录、仓库或筛选切换才改变相应范围。目录汇总和可排序列表不在本轮范围内。
- 浏览器记录是本机实际样本验收，不代表所有浏览器、硬件或更大仓库均达到相同性能。

- Web 类型检查、生产构建及完整 146 项回归通过，公开内容检查通过。
