# 历史更新与页面刷新验收

## 当前行为

- 全局“更新历史”始终检查全部客户端。会话库选中具体客户端后，菜单提供该客户端快速检查及完整校验，全部客户端完整校验始终可用。
- 历史更新成功后，当前页面读取完整结果；隐藏页面在再次激活时跟进。会话阅读解除旧版本固定并沿用消息锚点恢复，筛选、阅读位置和地图视野保留。
- 总览和用量的页面更新只查询报告，代码地图分析当前仓库，资源清单执行本地盘点。历史更新不会额外盘点资源、分析所有仓库或强制更新价格目录。
- 查询状态失败重试查询，历史检查发起失败重试检查，资源盘点失败重试盘点；旧结果保留。
- 地图关闭自动刷新后停止空闲状态轮询，已开始任务的进度查询继续保留。两套自动刷新设置保持独立、默认关闭。

## 紧凑控件验收

- 会话库自动刷新与最近检查时间进入全局历史菜单；菜单在任务进行中仍可查看状态，手动检查项禁用。桌面使用子菜单，窄屏直接展开间隔选项，避免侧向菜单越界。
- 会话库独立动作行移除，工作区直接接在全局页头下；总览标题、筛选与操作在桌面同排，窄屏保持无整页横向溢出。
- 外观弹层标题为 14px，选项与按钮为 12px；色盘与应用按钮均为 34px 高，保留三列预设及共享偏好保存。
- 来源与缺口维持现有入口与行为。
