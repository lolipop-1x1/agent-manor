# 历史更新与页面刷新验收

## 后台周期同步（2026-10-18）

本轮将历史自动同步的调度移到本地服务，替代后文历史记录中的网页可见时触发、隐藏时暂停及读取报告时暂缓检查。网页只读观察；代码地图维持可见页面调度。具体运行规则见 [ADR 0017](../adr/0017-backend-history-sync-scheduling.md)。

验证使用隔离合成来源与真实 HTTP／Worker。可控时钟验证完成后计时、单轮长耗时、睡眠跳跃、改间隔、关闭未提交补查、范围与检查强度合并、退避及恢复；真实最短 5 秒周期验证无页面检查、旧接口只读、重启和语义维护。受控本地 Embedding 服务确认历史无变化不新增模型输入，复制相同正文复用有效向量；这不代表真实模型效果或推理性能测量。

内置浏览器验证真实处理进度及完成后的列表替换、多页面策略一致、关闭全部测试页后继续发布、发布失败保留列表和正文、可见错误与立即重试。中文与英文、深浅主题、390px 窄屏的状态及帮助弹层、键盘关闭焦点恢复均在本机验证；实体触屏未测试。后台发布后，关键词筛选和原会话的第 2 轮阅读锚点保留。

首次全量发现三个失败：坏偏好读取意外阻止后台启动，以及两个测试在 Worker 写完数据库、主线程尚未结算完成基准时过早通过等待条件。修复后恢复原启动容错，保留偏好错误及原文件；用受控 Worker 延迟完成通知复现时序，测试等待真实完成基准和下次截止时间，再重跑全量通过。审查还修复全局失败重试继承旧局部范围，以及无变化手动任务终态被后继摘要遮盖后遗漏主动重读的问题；补读仅针对尚未确认的本页手动任务，沿用同一观察循环，不增加周期触发或常驻第二计时器。

日常历史只读测量：同一摘要接口先预热 1 次，再串行读取 20 次，计时包含本机 HTTP 与 JSON 解码。新增调度状态仅返回内存基准与任务快照，不在每次观察中遍历历史任务。

| 轻量状态读取 | 改造前 | 改造后 |
| --- | --- | --- |
| P50 | 5.73 ms | 4.83 ms |

- 地图关闭自动刷新后停止空闲状态轮询，已开始任务的进度查询继续保留。两套自动刷新设置保持独立、默认关闭。
