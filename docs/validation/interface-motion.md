# 界面动效验证

本轮使用共享样式、独立选中指示层和浏览器原生动画实现短反馈，没有引入动画依赖。开发规则见[界面动效开发规范](../agents/interface-motion.md)，根目录 AGENTS.md 要求后续同类变更先读取并复用。

## 行为与布局

- `scripts/e2e-interface-motion.mjs`：生产构建中的共享时长、连续导航、语言及尺寸变化后的指示层对齐、菜单焦点、弹层退出中切换减少动态效果、地图定位中断和快照释放、轮次定位与手动滚动中断、返回阅读位置、切换阅读模式、英文深色窄屏、系统减少动态效果，共 22 项检查。
- `scripts/e2e-workspace.mjs`：目录与文件筛选、桌面面板展开及手动调宽、选择保留、键盘、主题和窄屏。关闭外观菜单后等待其真实卸载，避免退出节点影响后续命中。
- `scripts/e2e-session-reading.mjs`：连续阅读补载、阅读锚点、失败重试、超过 300 条的单轮记录、轨迹与长正文、分栏调整、返回位置、中英文和窄屏。滚动基准在同一帧采集，等待实际滚动稳定，网络空闲不再被当作滚动完成。
- `scripts/e2e-session-code-replay.mjs`：四轨并行、未定时活动、同刻调用、363 条密集轨道、248 文件大地图样本、倍速、证据、全屏、悬浮预览与减少动态效果；播放期间不重复读取活动原文，固定观看范围的地图尺寸和比例保持稳定。
- `scripts/e2e-overview-review.mjs`：78 项总览浏览器检查，包含详情弹层、分页、日期、错误与重试、刷新保留完整结果、精确阅读返回及焦点恢复。

桌面中文浅色与英文深色窄屏成组检查了最终布局，没有引入全局横向溢出。界面保持当前紧凑布局；面板内容进入、选中指示和手动定位过渡不逐帧调整页面分栏或地图尺寸。

## 真实数据与性能边界

在现有本地已发布历史上只读验证：默认源码地图 594 个文件，整个仓库回放 1,233 个文件，所选真实会话 17 条轨道。使用同一生产前端分别启用普通动效和系统减少动态效果，检查手动聚焦与 32× 播放。

| 观测 | 普通动效 | 减少动态效果 |
| --- | --- | --- |
| 地图加载，包含网络空闲等待 | 约 2.0 秒 | 约 3.2 秒 |
| 聚焦约 0.6 秒采样，RAF 间隔 P95／最大值 | 约 8／14ms | 约 7／8ms |
| 播放约 1.8 秒采样，RAF 间隔 P95／最大值 | 约 7／8ms | 约 8／8ms |
| 两段采样内超过 50ms 的主线程长任务 | 0 | 0 |
| 固定观看范围的地图尺寸与相机变化 | 0 | 0 |

播放位置确实前进，页面异常和失败接口响应均为零；普通动效采样期间的一次请求来自既有会话状态轮询，未读取回放原始证据。手动聚焦只提交目标相机，原视口快照仅淡出并释放，避免把大地图快照放大后产生额外绘制成本。快照不接收交互，也不参与可访问树。

上述值是同一台机器的短时 RAF 与长任务观测，不能代表实际显示帧的全部呈现成本、低性能设备、长时间播放或任意仓库规模。加载数值包含当时服务缓存及系统负载，两次加载不是严格性能对照，不能据此断言某种动效模式加载更快。真实输入、身份、路径和截图仅保存在本机忽略目录；公开脚本使用隔离合成数据。

## 检查范围

类型、中英文目录、生产构建、全量 1,523 项自动化测试及公开内容检查通过。机械设计检查仅提示两像素选中底线的 1px 端部圆角未列入面板圆角尺度；这是线条端部形状，保留，不扩展面板 token。

旧 `scripts/e2e-sessions.mjs` 与 `scripts/e2e-session-usability.mjs` 分别停在初始请求版本断言和旧筛选控件断言，未计入通过项，也未为本轮动效改写这些无关断言。会话定位、中断、阅读恢复和连续阅读使用上述当前专项脚本验证。
