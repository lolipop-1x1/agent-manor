# 七个原生客户端接入验收

核对日期：2026-10-14。范围包括 Gemini CLI、Qwen Code、新版 Kimi Code CLI、Oh My Pi、Grok Build、Reasonix 和 Codewhale；版本、原生入口和不可恢复的字段见 [来源与证据](../design/native-client-sources.md)。

## 方法与能力范围

全部输入使用固定上游生产 schema 的人工匿名样本。历史、配置、仓库和管理写入位于隔离临时目录；详细日志和浏览器截图留在忽略目录。未安装、登录或运行原生客户端。

- 会话发现、搜索、正文与执行轨迹共用客户端身份，保留原生父链、分支、终态及缺口。
- 成功工具结果进入代码地图，可回读原始证据并核验内容哈希；派生投影、迁移副本和已经核验的继承前缀不重复产生活动。
- API、CLI、会话画像、总览和用量入口核对同一结果版本。逐请求用量与原生轮次／会话报告保持各自身份；缺少请求、时间或用量桶时保持未知。
- Skill 与 MCP 盘点保留加载层级、同名选择、原生状态和保护来源。管理预览、写入、重新盘点及恢复使用隔离配置，不触碰真实资源。
- 浏览器覆盖七客户端的中英文筛选、执行轨迹、Skill／MCP 本地清单，以及管理执行和恢复；窄屏、深色主题及原生累计报告单独检查。

## 两轴审查

比较基线为规格提交 `844d8c902e1fc371890b1ec613d540f033205b6e`，首轮实现提交为 `27678683065c87fd4dd99bddd5d7df168ab13b03`。规范与规格分别独立审查，所有确认项交由同一个修复任务处理。

规范轴确认五项：Oh My Pi 强制启用覆盖停用、损坏的实际配置未阻止写入、Gemini／Qwen 扩展引用缺少真实路径限制、侧文件绕过读取预算，以及 Codewhale 预算错误缺少国际化标识。

规格轴确认五项：Grok MCP 同名选择顺序与停用作用范围、Reasonix 回退版本的重复活动、Kimi 模型计时混入工具耗时，以及 Grok 多次回退的当前分支错位。

审查发现的验证使用独立人工来源或固定版本源码，不以已有测试通过替代语义核验。十项原始根因与独立复核发现的直接残留均已修复；规范轴与规格轴的最终复核分别确认限定范围内没有未解决发现。

## 支持边界

源码核对、合成回归、浏览器验收和原生运行属于不同证据层。当前交付只完成前三类；原生客户端实际权限、设置重载和运行效果未验证，当前平台边界保持 macOS。

Gemini／Qwen 转录不能证明全部网络请求；累计或晚到部分用量不进入请求数量与费用估算。插件、系统和托管本体保持保护；复杂配置、动态展开、未核验的批准链或损坏配置保持未知／只读。Kimi 与 Codewhale 普通 Skill 使用本产品的回收与恢复，不声称存在原生逐项停用开关。
