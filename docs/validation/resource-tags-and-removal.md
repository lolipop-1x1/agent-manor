# 资源标签与 Skill 文件回收验收

本轮补齐现有管理弹窗中的文件回收入口，并按最新用户要求移除总览状态列及概括统计提示。保留原列表、地图、筛选、右侧详情、默认总览、统计指标和排序；上一轮整体界面改动仍保存在本机 stash。

## 实际行为

- Skill 和 MCP 总览移除状态列。列表、详情、本地资源及地图不再显示“统计不完整”标签或概括提示，使用筛选及原始统计保留；管理时直接说明具体操作限制。
- 普通本地 Skill 文件或完整目录在实际路径旁提供一个“移入回收区”按钮。已发现客户端去重，“发现于”表示本地扫描结果，不证明实际调用或加载。
- 文件回收确认列出全部已发现引用，并说明未扫描位置的边界；文件移出原位置，恢复材料保留，客户端启停配置不修改。归档保存受影响范围，支持按相关客户端及项目检索。
- 同一路径的链接只提供一次移除操作；链接目标及其他链接保留。恢复前核验目标存在，原位置冲突时不覆盖。原生客户端停用及恢复沿用现有入口。
- 系统、插件、托管及未核验来源继续保持管理限制；无可管理本地位置时，管理弹窗直接说明，历史使用记录保留。

## 验证边界

本机服务已重新构建并重启，真实页面已核对更新。没有执行真实 Skill 或 MCP 的管理写操作，也没有验证各外部客户端重新加载后的行为；文件操作的写入和恢复结论来自隔离合成资源。历史数字没有补造或重新定义，“未发现使用”仍不等于从未使用。旧归档没有新操作范围字段时继续按原入口范围保守处理。
