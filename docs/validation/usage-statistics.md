## 统计、价格与 API

- 请求按已记录时间归属本机时区，日期区间和带偏移 ISO 半开区间分别核对；合成回归覆盖跨天、周／月、夏令时及半小时偏移时区。缺时间保留独立小计，不混入有限日期总量或伪造趋势日期；其部分 Token 与部分／缺价格覆盖也独立显示。
- 主、子会话累加各自新增请求，复用有效索引来源与明确复制排除。缓存已包含在输入时不重复累加，输出中的推理不再次相加；缺失与已确认零值分别保留。组成与总 Token 的覆盖范围分别显示。
- 客户端、项目、模型的包含与排除、主／子、会话类型、用量及价格覆盖、会话数值范围共享同一请求集合。模型映射不改原始名称；实际名称 `unknown` 和 `literal:unknown` 与缺模型／项目独立筛选，不被翻译或合并。
- 缓存比例分子、分母来自同一组可配对请求，页面直接展示覆盖数量。会话分页和请求分页只改变证据行，不改变指标、趋势、组成、排行或日历总量；较大请求集合仍可完整分页。
- 用户对任意模型设置的单价优先于网络及映射，重启保留，网络刷新不覆盖设置。明确映射同时指定服务商；自动目录逐模型保留最近成功缓存及随包兜底，不用同名服务商或客户端默认值猜价格。
- 估算费用保留实际适用单价和上下文阈值，缺必要 Token 与缺必要单价分别给出原因。音频／推理与缓存含义不足时保留部分估价，已知金额只作为可计算桶的小计。
- 查询固定完整索引及价格版本，已淘汰版本明确失败。API 拒绝未知条件、非法日期、时区、数组与数值范围；价格写入沿用本地服务的实例与来源保护。
