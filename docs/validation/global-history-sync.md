# 全局历史自动同步与刷新体验验收

验收日期：2026-10-14。本轮以五页共享的历史自动同步替代会话库页面专属调度；历史与地图仍分别保存设置，默认关闭。

本记录保留当时的网页调度行为与测量。2026-10-18 起，历史周期迁至后台，网页隐藏或报告读取不再阻止历史检查；新行为与本轮验证见[历史更新验收](refresh-workflow.md)。本记录的性能数据不代表后台周期版本已重复完成相同测量。

## 行为与迭代

- 全局自动同步覆盖全部客户端，页面切换保留同一间隔；网页隐藏时停止新检查，恢复可见补查。运行任务继续显示进度，关闭设置不丢失已提交任务。
- 无变化自动检查只更新同步状态；首次索引发布、新版本和手动同步通知页面读取。隐藏功能页在激活后消费通知。
- 大报告读取期间暂缓下一次自动检查，连续同步通知合并为一次后续读取，避免反复取消慢请求。人工延迟接口验证读取中的报告不被第二、第三次同步取消。
- 资源历史联动仅更新相关统计，不触发清单盘点或管理记录读取。详情与同版本证据一起准备，延迟、失败及重试均保留旧内容。
- 会话列表、正文、画像已有内容时使用标题旁固定进度图标，移除会推开旧内容的加载行；初次加载仍有反馈。
- 地图画布、文件表和会话选项复用稳定输入；历史进度轮询不反复构建闭合文件表。语言、筛选、选中、缩放、目录、主题及面板操作继续验证。

## 真实历史测量

使用已有本机数据目录与独立 Chrome，测量时约有 7,722 个会话、7,723 个来源。原始历史只读，正常同步更新可重建索引；测试结束回读确认语言、历史间隔、地图间隔恢复，外观不变。详细请求、版本标识、截图和日志只保留于忽略的 `.local/global-sync-real/`。

先等待当前页面完整结果就绪，再以真实来源自然增长触发自动检查；单周期提交后关闭后续调度，继续观察在途任务与页面联动。记录 RAF 空白帧、容器身份、滚动、没有近期输入的布局变化、超过 50ms 的浏览器主线程任务，以及状态弹层点击至打开并关闭的自动化响应时间。查询时间包含本机后台计算，不等同于主线程阻塞。

关键对照：

- 地图没有重新查询，但优化前历史轮询每轮产生 12–15 次长任务，峰值 93–96ms；隔离画布与文件表后，对应采样为 0 次长任务。
- 会话库加载行导致布局变化约 0.0241；改为固定位置图标后约为 0.00105。读到的新内容与计数仍按实际结果更新。
- 会话库和地图的真实静止周期沿用原版本：0 个重新解析来源，后台检查约 4.3–4.5 秒，没有重读消息、画像、地图或报告等大接口。五页无变化去重同时通过隔离浏览器验证。
- 第一次测量前的同步有 36 个来源需要解析，后台约 46 秒；后续少量自然增长的检查约 5–10 秒。大报告联动耗时仍高于来源检查：总览约 28–35 秒，资源详情约 23–27 秒，期间保留旧结果并暂缓下一次自动检查。

## 边界

这些是本机、当前数据及所选范围的观察，不覆盖所有设备和数据规模。总览完整结果替换时仍有约 100ms 的短任务，未将它表述为零卡顿；报告查询耗时也没有被消除。首次加载不计入已有内容刷新空白帧测量。真实来源在本轮工作过程中持续增长，因此有变化周期和静止周期分别列出，合成故障与受控进度不作为真实性能证据。
