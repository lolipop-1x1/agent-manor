# 资源使用分类验收

验收于 2026-10-08，开发与验证在 `main` 进行。最新规则见资源管理规格的“使用分类更新”章节；分类不改变调用次数、使用会话数、资源身份或管理保护。

## 可复现检查

```sh
npm test
npm run check
npm run build
node scripts/e2e-resources.mjs
node scripts/e2e-resource-map.mjs
node scripts/e2e-codeflicker-resources.mjs
npm run check:public
git diff --check
```

浏览器脚本使用真实 Chrome、隔离服务及人工 Skill／MCP 配置。全部历史来源和用户目录显式隔离；停用、回收、恢复和永久清除仅针对这些人工资源。脚本关闭自己创建的服务和浏览器，并清理临时夹具；报告与截图保留在忽略的 `.local/` 中。

## 分类与证据

- 本地有效资源在当前 Agent、日期和关键词范围没有使用证据时，立即进入未发现使用；不等待首次发现七天。正常查询的零记录显示零，索引未就绪、真实读取失败和身份不明分别保留错误或未知，不补造零值。
- 低频按正使用会话数判断，默认不超过两个会话；长期未用按已记录最近使用时间判断，默认至少九十天。两项可以重叠，阈值可调整；总览与本地入口共享阈值判断，覆盖九十天边界。无记录不推断闲置时长，缺时间不使用首次发现或文件修改时间替代。
- 收藏、系统、插件与只读资源正常分类，管理保护独立保留。命中整理分类不开放原先禁止的写操作，仍需选定具体入口并确认预览。
- 已记录调用缺完成结果时仍保留使用及未知结果；Skill 读取只接受成功正文读取。思考、附件和用量等无关诊断不清零分类；真正影响来源、配对、身份、去重或时间的缺口按范围保留部分记录与原始详情。
- 名称聚合统计与本地本体关联分别处理。同名不同路径不合并管理对象，缺路径的名称使用不强行归到某个本体，也不把该本体标成确定未使用。缺失日期保留数量与状态，不猜日期范围。

## 页面与兼容

- Skill／MCP 的总览、本地筛选和地图取消待检查。中英文保持调用次数与使用会话数，默认调用次数；部分记录、时间未记录、使用记录未关联及真正未知继续可见。
- 地图保留全部筛选结果，正值按线性面积绘图。零值与无法赋面积的资源在一个可折叠、独立分页的紧凑区域中展示，未知显示未知；不再另设待检查分组，不伪造面积。
- 旧 Web `candidate=review` 回到全部并清理旧分组页码，保留 Agent、关键词、指标、视图和选中项。旧 CLI／API 查询同样兼容全部，`counts.review` 保持零、`map.review` 保持空，原始字段与诊断不丢弃。
- 浏览器覆盖鼠标和键盘筛选、阈值、搜索空结果、长列表与证据分页、跳转返回、异步详情、主题、375px 窄屏和地图全屏。共享入口管理、MCP 配置恢复、冲突禁止覆盖及保护对象不能写入继续核验。

## 执行结果与审查

完整自动化回归 481 项通过；类型、翻译完整性、构建和公开内容检查通过。真实 Chrome 共 82 组通过：资源列表 47 组、地图 21 组、CodeFlicker CLI／桌面版 14 组。隔离 HTTP 与 CLI 还验证了分类计数、旧查询兼容、管理保护、完整结果及原始统计。

规格轴未发现缺失、错误实现或范围扩大。标准轴提出两处阈值重复判断的维护问题，已提取小型纯函数，并补充 HTTP 总览／本地默认值、可调整阈值及日期边界一致性回归；原有聚合与管理前置条件保持不变。

## 本机核对与边界

最终构建加载到当前本地服务后，只读比较完整 Skill／MCP 总览与地图。未发现使用、低频和长期未用均按已有记录正常计数；调用、读取、使用会话、结果、耗时等完整统计与实施前一致，历史索引版本未变化。实际数量、资源名称、路径、原始历史标识和截图只保留在本机私有材料中。

本次没有重建真实历史索引，没有操作真实 Skill 或 MCP 配置，也没有启动、重启或卸载客户端／MCP 服务。分类描述当前范围内已找到的使用证据；没有记录不证明从未使用或可以安全删除。原有逐来源管理能力和平台支持边界保持不变。
