# 共享地图绘制与资源边界验收

2026-10-11，资源使用地图同步代码地图的细边界规则，并将两张地图的填充与边界绘制抽取为 `web/shared/map/MapTileLayer.tsx`。调用方提供已裁剪的屏幕矩形和色阶，组件统一处理填充内缩、主题中性边界、时间缺失虚线与批量 SVG 绘制。

## 规则

- 共享边缘固定 1 CSS px，不随地图缩放加粗；普通边界复用 map-N-border，时间缺失保留赭金虚线。
- 任一边不超过 8px 的小块保留完整填充且不画边界，放大后恢复普通间隔与边界。
- 地图面积、统计范围、按最近使用时间着色、悬停、选择和键盘焦点保留；两张地图均按色阶批量绘制，最多十二个 SVG 路径。
- 复用要求已加入 AGENTS.md，视觉规则已更新 DESIGN.md。

## 方法

```sh
npm run check
npm run build
node --import tsx --test tests/resource-map.test.ts tests/appearance.test.ts tests/web-map-viewport.test.ts
npm test
node scripts/e2e-map-boundaries.mjs
node scripts/e2e-resource-map.mjs
npm run check:public
git diff --check
```

两套浏览器脚本使用隔离数据目录、人工历史和独立 Chrome 会话，管理操作仅作用于合成资源。资源地图基础数据来自真实解析与发布，悬殊面积场景额外截获地图响应，注入一比一万亿的人工数值以验证小块与极端缩放。截图和日志留在忽略的 `.local/`。

资源面积比例从实际 SVG 浮点几何读取，避免按钮 CSS 小数舍入影响严格比例断言。外观切换与缩放断言等待动画帧完成，避免把尚未提交的相机状态当作最终状态。

## 结果

- 颜色、资源地图和代码地图几何专项 30 项通过；全量 767 项自动测试通过，无失败、取消或跳过。
- 代码地图浏览器 34 项通过，抽取后填充内缩、共享边缘和小块行为保持一致。
- 资源地图浏览器 23 项通过，覆盖 Skill／MCP、中英文、六种预设与自定义黄色的深浅主题、固定 1px 边界与时间虚线、选中与键盘焦点、主题切换视野保留、375px 窄屏、全屏、筛选、证据回查和管理恢复。
- 悬殊面积场景三个正值均保留；两个微小块在全图中无间隔且无边界，定位后恢复细线，时间缺失块恢复虚线。
- 类型、翻译、服务端／前端构建、公开内容及空白检查通过。
- 人工检查浅色全图、深色放大、窄屏和微小块定位四张资源截图：相邻浅色块边界清楚，深色与选中状态可辨认，时间缺失虚线保留。
