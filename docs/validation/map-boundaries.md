## 方法

```sh
npm run check
npm run build
node --import tsx --test tests/appearance.test.ts tests/web-map-viewport.test.ts
npm test
node scripts/e2e-map-boundaries.mjs
npm run check:public
git diff --check
```

浏览器脚本建立隔离 Git 仓库、人工 Codex 历史、独立数据目录及 Chrome 会话。覆盖率来自真实解析和分析发布，包含未读取、20%、40%、60%、100% 五阶及微小文件。登记与外观写入仅作用于隔离服务，完成后关闭服务与浏览器并清理临时输入。详细截图及日志留在已忽略的 `.local/map-boundaries-e2e/`。
