## 性能实测

固定同一版本、日期范围、时区与价格，在约 92 万条活动事件、23 万个模型请求的本机历史上测量请求开始到完整 HTTP 正文读取结束。基础报告约 16.5 MB，以下为单机实测，不包含浏览器绘制时间。

| 场景 | 完整响应耗时 |
| --- | --- |
| 没有事实缓存，首次完整读取及计算 | 93.268 秒 |
| 服务重启后复用事实缓存，首次生成报告 | 28.149 秒 |
| 同一报告再次读取 | 0.148 秒 |
| 同一范围首次切换模型 | 7.591 秒 |
| 同一模型报告再次读取 | 0.121 秒 |
| 清除模型回到已缓存全局报告 | 0.148 秒 |

完整事实在后台线程准备，测量期间主线程状态请求仍可响应。查询缓存与事实缓存分别减少重复聚合和跨进程完整索引读取；新索引版本、未缓存范围和首次模型分析仍需计算。大历史首次加载仍存在明显等待，不能把缓存命中耗时作为所有查询的性能承诺。

## 数据与验证边界

统计使用已发布的完整索引与已登记仓库的现有快照，不更新原始会话，不自动登记或重新分析仓库。新增的本机事实缓存是可重建的派生数据，不包含消息正文和工具参数，单文件权限为 `0600`，原始上限 768 MiB、压缩上限 128 MiB。版本变化或缓存不可用时从索引重建。

真实身份、个人路径、业务内容、截图和测量原始输出只保留本机忽略目录。公开检查不替代对新图片与提交身份的人工核对。本次验收覆盖总览统计、调查与界面流程，不等于逐一重审所有客户端的原始解析，也不构成完整无障碍认证。
