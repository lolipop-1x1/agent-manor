# 资源管理验收

验收于 2026-10-07，开发与验证在主干进行。写操作只针对隔离的人工资源；真实资源仅只读观察。资源使用表示已记录活动，不能直接解释为任务效果。

## 可复现检查

```sh
npm run check
npm test
npm run build
node scripts/e2e-resources.mjs
node scripts/e2e-resource-map.mjs
node scripts/e2e-i18n.mjs
npm run check:public
git diff --check
```

浏览器脚本使用真实 Chrome 和独立临时服务，显式隔离全部历史来源及资源目录。报告与截图分别写入忽略的 `.local/resource-e2e/` 和 `.local/resource-map-e2e/`；完成后关闭测试创建的浏览器、服务并移除临时资源。

初版地图验收的类型检查、356 项自动化测试与 59 组真实 Chrome 端到端测试全部通过，其中 44 组为既有资源回归、15 组为资源地图验收。后续回归结果见页面加载性能及统一使用展示章节。

## 已验证场景

- 历史统计覆盖所有已支持 Agent；主界面显示使用会话数，显式 Skill 调用、成功正文读取在详情分列，会话数取并集，文本提及和外层脚本内容不补造调用。
- 失败与未知结果分开，成功率只用已知结果，耗时只用实际记录样本。缺失时间不进入某日；分叉复制前缀与重复消息不重复统计。
- 合成规模包含 20,001 条 MCP 调用与 205 个 Skill 身份，分页后总数、趋势、工具下钻及最后一条证据仍完整可达。
- Skill 使用排行按记录的完整名称跨 Agent、项目及路径合并，会话数取并集，Agent 筛选保持名称标识稳定，旧项目条件不限制 Skill 排行。详情保留实际来源和分布；旧来源链接仍可回查，缺失名称不依占位文案误合并。
- 本地管理中同名不同路径不合并安装本体，关联历史仍定位具体来源。共享真实本体保留全部入口；多个入口有歧义时，已确认同一本体的使用仍合并，会话数不相加，趋势与客户端／项目分布可回查。
- 收藏保护贯通历史与明确关联的本地入口；收藏或共享关系变化使旧预览失效。确定零使用、观测不足与未知状态分别展示。
- 来源盘点不暴露 MCP 注册值，不执行脚本或启动服务。未知格式、插件及系统资源保持只读；支持矩阵说明已核验来源与操作能力。
- HTTP 与真实 CLI 共用资源 API；执行需要确认具体预览。同源写入限制、参数校验和过期／内容变化检查有效。
- 原生开关、备用、回收、恢复和独立永久清除经合成文件回读验证。恢复不覆盖已占用位置；共享链接操作保留目标与其他入口。存在已发现共享引用的物理 Skill 本体不开放备用／回收，避免破坏其他入口；JSONC／TOML 保留无关字段、注释及其他注册。
- 备份失败不修改来源；写入后反馈失败保留部分完成及可用恢复材料。恢复后的材料仍可单独清除，不声称删除当前原始资源。
- 历史索引清除与重建后，收藏、手动来源、操作记录和备用／回收材料继续保留。
- 真实浏览器覆盖收藏、搜索空结果、日期清空、键盘导航、长列表分页、证据跳转返回、深浅主题与 760／375px 窄屏。嵌套弹层关闭后焦点恢复，页面不产生横向溢出。
- 人工同名 Skill 场景包含两个 Agent、两个项目和四个来源，五次读取汇总为三个使用会话；历史缺失来源显示部分未关联。旧来源收藏可继承和取消，名称收藏贯通已确认入口保护；Agent 筛选和轨迹跳转返回保持范围。
- Skill 总览合并完整历史排行与本地清单，七类快捷筛选显示当前范围计数；排序支持升降序。观测不足与未知统计留空，确定零值才显示零；收藏和系统／插件保护资源不进入整理候选。
- 总览详情的 Agent 范围包含已记录使用与本地入口，历史分布只统计真实事件。名称收藏与本体收藏独立，取消名称收藏不会取消独立本体收藏。旧项目条件不会阻止进入精确用户级或跨项目本体。
- 列表分页验证首尾页、页码、跳转、20／50／100 条容量、空结果与当前区间；使用证据固定十条，跳转及返回保留页码。筛选和容量改变重置页码，排序和容量在刷新后保留；375px 表格独立滚动且页面不溢出。
- 采集缺口按已确认来源归属影响对应 Agent；未知归属缺口继续保守处理。HTTP／CLI 覆盖总览全量、旧来源链接以及缺失时间导致的空统计，不把缺失值补为零。
- MCP 总览按完整服务器名称汇总本地注册与历史使用，默认使用会话数降序。合成同名服务跨两个历史 Agent、两个项目，29 次调用汇总为三个会话，工具分为 22／7 次，结果为 26 次成功、三次失败；同名不同注册仍分别管理。缺名且无路径的两个来源保持独立，详情和证据不串源。
- MCP 复用七类计数、表格排序及统一分页；验证鼠标／键盘排序、20／50／100 条容量、首尾和页码跳转、刷新、搜索空结果、深浅主题与 375px 独立滚动。工具证据最后一页及轨迹返回保留范围，旧精确来源仍为 27 次调用、两个会话；名称收藏与注册收藏互不取消。浏览总览前后，隔离配置逐字回读保持一致。
- 真实安装包在仓库外安装后，CLI、SQLite、Worker 和 Web 可用；停止服务不等待未读完的静态响应，实例记录和锁完成清理。

## 资源使用地图

- 完整轻量查询覆盖同一已发布版本的全部筛选结果。隔离场景中的 Skill／MCP 正值均超过二百项，不受列表页码或容量限制；复用已有总览缓存，不为绘图重解析历史。发布切换期间不会混合两个版本的统计。
- Web 面积统一使用去重会话数；一百次同会话调用只占一个会话，调用与另一会话成功读取的资源占两个会话，SVG 面积为一比二。屏幕间隔单独计算，零值和待检查不赋伪造面积。底层 API 保留调用、会话和读取指标；局部原点相机测试覆盖安全整数极限及更大差距，微小节点定位后仍可阅读、命中、缩放和平移，保持原始面积比例。
- 首次列表、地图按需查询、Agent／时间／关键词／状态和会话上限均通过。旧次数指标链接自动切到会话数并清除旧上限；新会话上限可在列表／地图之间保留。未发现使用与待检查区域可折叠，独立分页不会重新查询地图；零调用但存在读取的 Skill 直接进入正值地图并保留已使用状态。
- 悬停与键盘聚焦显示完整名称、使用会话数、占比、最近使用和保护状态；颜色采用任意使用证据的最近时间。缺失时间、部分记录、系统保护、仅历史、空结果和查询失败重试经浏览器验证。
- 滚轮缩放、拖动、适应窗口、可搜索定位、正常字号及原生全屏通过。菜单 Escape 恢复焦点且不同时退出全屏；全屏选择资源会退出全屏并打开详情。证据轨迹返回同一范围时，相机倍率及位置保持，未产生重复地图请求。
- 地图详情直接管理共享 Skill 的所选链接，目标及其他入口保持不变；独立 MCP 注册只修改所选配置，敏感值不进入地图响应，其他注册与配置内容逐字保持。收藏预览显示保护提醒，取消后未执行整理；取消收藏后回收、恢复保留真实活动统计，合成文件与链接回读正确。
- 深浅主题和 375px 窄屏通过，详情弹层受视口约束、页面无横向或纵向溢出。展开紧凑区域时画布不遮挡摘要及分页，超出主区域的内容在内部滚动。

地图验收中的管理写入只作用于人工夹具，没有启动 MCP 服务、移动真实 Skill 或修改真实客户端配置。原生全屏在前台 Chrome 中测试；焦点、筛选和分页测试等待实际状态，不用固定延时断言。

## 真实本机只读核验

只读盘点发现 941 个入口、626 个本体和 85 个来源，保留 16 项缺口及 282 个保护入口；该次扫描约 661 ms。这是单机观察值，不是跨机器性能承诺。

历史统计另用已保留的本机索引快照复制件验证：117 个会话、7 个客户端，Skill 查询约 19 ms、MCP 查询约 4 ms。快照并非当前全部历史，部分来源已缺失、资源路径无法关联，结果保留部分记录和未关联状态；它不能证明全部真实历史的关联覆盖率或性能。

随后对当前有效版本只读核验：5,897 个会话、11 个客户端，Skill 为 5,687 条使用证据，MCP 为 5,144 条。完整 HTTP 排行请求从约 14／12 秒降至约 2.6／1.0 秒，优化前后的完整统计与资源数量一致，部分记录状态继续可见。专用部分索引只纳入已标注的资源调用；结果配对仍检查全部调用，普通调用复用同一标识时不会误判成功。旧库首次创建该索引约 30 秒，后续启动复用；这些是本机观察值，不是服务响应时限承诺。

Skill 名称汇总调整后，使用排行由 1,147 行变为 387 行，其中 45 个名称记录了多个 Agent 的使用。5,687 条证据、1,639 个使用会话及全部结果／耗时统计与调整前一致；MCP 保持 60 行及完整统计不变。名称详情、Agent 筛选、旧来源回查和本地页面实际展示均只读核验通过。

Skill 总览调整后只读核验 639 个名称，覆盖 730 个本地本体；原有 387 个历史名称的完整统计逐项保持一致，252 个无历史统计的名称纳入待检查，MCP 统计未变。当前旧索引仍有无法归属的采集缺口，部分资源也尚未满足观测时间，未把它们归为未使用。首次总览 HTTP 请求约 7.1 秒，缓存后的已使用／待检查查询约 125／169 ms；这是本机观察值，不是跨机器响应时限承诺。

MCP 总览调整后只读核验 25 个名称／来源项，其中 20 个有历史使用、五个待检查；覆盖全部 17 个本地注册本体。原有 60 个精确历史来源及 5,144 条调用的完整统计保持一致，名称汇总的调用、结果和耗时样本逐项核对通过；详情工具总数与最后一页证据完整可达。Skill 的 5,687 条证据未变。内置浏览器确认六列表格、默认调用降序及快捷计数已实际显示。

地图实施前后只读逐项比较当前总览：Skill 仍为 639 项，调用指标下 190 个正值、197 个零值、252 个待检查，3,038 次显式调用及 5,687 条活动保持一致；MCP 仍为 25 项，20 个正值、五个待检查，5,144 次调用与原 60 个精确来源保持一致。名称身份、统计、具体本体关联和最近使用均未变化；切换面积指标后最近使用仍一致。内置浏览器实际显示完整 MCP 地图和对应计数。

本机路径、真实资源名称、配置值、原始会话标识和截图仅保留在私有验证材料中。没有修改真实 Skill、MCP 配置或重启客户端；客户端加载效果仍显示待重新加载或未知，不用文件修改结果代替运行反馈。

## MCP 两路审查

### Standards

统一组件、最小修改与公开内容边界通过，未发现需要重构的启发式问题。初检发现浏览器排序步骤的可访问名称与实际表头不一致，已修正并运行通过；筛选等待也改为等待更新后的行数，避免读取上一个结果。

### Spec

名称汇总、会话并集、缺名来源隔离、旧链接、独立注册和收藏保护、未知／零值、分页与 URL 状态符合补充规格；没有未解决的缺失、范围扩大或错误实现。

## 地图两路审查

Standards 与 Spec 分别检查统一组件、最小修改、公开边界及 V1–V10 的实现。已修复定位控件复用、证据返回相机丢失、极小节点定位和展开区域画布遮挡问题；最终复审没有未解决的实际问题。手势处理的局部重复仅作为非阻断启发式观察，没有为此扩大修改到代码地图。

## 支持边界

历史统计覆盖现有全部客户端。本地写入按来源逐项开放，当前主要核验普通 Codex／Claude Code 入口；其他客户端与插件没有经过写入核验的来源保持只读。具体来源、格式和原生开关范围见[资源支持矩阵](../design/resource-support.md)。安装市场、自动升级、插件本体卸载和跨客户端部署同步不属于本次范围。

## 页面加载性能验收

总览的历史统计与本地关联改为共用一次事件流，最多缓存八个统计范围。验证 Skill／MCP、分页、排序与地图复用聚合；收藏、索引发布和清单刷新正确失效，同范围并发复用，查询失败可重试。缓存复用时重新判断观测期限，避免资源满七天后仍停留在观测不足。所有统计保持单一已发布版本。

独立盘点来源最多四路并行，合并时恢复来源顺序；本机前后结果除采集时间与缺口排列外一致，共享本体及入口顺序不变。真实 Chrome 验证资源首屏没有隐藏代码地图查询，切回地图后正常加载。

本机只读测量中，首次 Skill 总览约 3.4s 降至 2.7s；缓存内后端切换约 9–17ms，实际页面切换约 110–122ms。首次读取历史仍有秒级磁盘成本。测量未重置操作系统缓存，不作为通用或稳定性能保证；详细输入与计时仅保存在本机私有材料中。

最终 403 项自动化回归、45 项资源和 15 项地图真实 Chrome 验收通过，覆盖筛选、分页、地图视野、证据返回、收藏及隔离资源管理与恢复。类型、翻译目录、构建和公开内容检查通过。没有修改真实 Skill 或 MCP 注册。

## 统一使用展示

Skill／MCP 的主列表和地图统一显示使用会话数，默认降序；主列表只保留名称、Agent、使用会话数、最近使用和状态五列。调用与成功读取次数保留在详情和证据中，API／CLI 的原指标未改动。同一资源在同一会话中的多条使用证据计一次，不因重复调用增大面积。

旧 Web 的调用／读取指标及排序链接规范化为会话数，原次数上限清除；明确的会话上限仍可保留。地图汇总只展示色块数，不把跨资源重叠的会话数加总成独立会话总数。未发现使用和待检查分开展示，已有保护与管理边界不变。

本机内置浏览器只读确认：Codex 读取型 Skill 已进入会话地图，五列表格与会话上限正确显示。没有刷新历史索引或修改真实资源，截图只存本机忽略目录。

最终 403 项自动化回归、45 项资源及 16 项地图真实 Chrome 验收通过；中英文 Web／CLI 回归验证地图相机、展开状态、详情和管理预览保持，语言切换没有增加资源请求。类型、翻译完整性、构建、公开内容与差异检查通过。管理写操作仅针对隔离人工资源。

## 客户端解析复核

重新核验十一种客户端及 CodeFlicker 的 JSONL／IDE 桌面来源，以已保存的原生字段和参考源码为依据。成功读取复用客户端实际返回证据，写入、搜索、空返回与任意 command 参数不计 Skill 使用；结构化返回路径矛盾不回退到文本猜测。命名空间 Shell、Claude 省略 is_error 的结构化 Read 及 Pi 完整原生 Skill 展开经合成回归验证，调用和结果只贡献一次统计。

DSH Bash 非零退出码判失败，中断和后台状态保留未知；OpenCode invalid 判失败，自定义工具 completed 不补造协议成功或 MCP 身份。WorkBuddy 保留原生 toolResult；CodeBuddy 当前已核验 JSONL 的工具采集能力不足直接显示缺口。支持版本、无法还原的历史字段与参考源码见 [解析边界](../design/resource-history-parsing.md)。

423 项自动化回归、45 项资源及 16 项地图真实 Chrome 验收通过。浏览器夹具增加成功写入 SKILL.md，确认不会增加读取次数；Claude 夹具省略 is_error，确认实际结构化读取仍进入跨 Agent 排行、详情及证据。类型、翻译完整性、构建、公开检查与差异检查通过。没有为缺少阳性原生样本的格式宣称完整支持，没有修改真实 Skill 或 MCP 注册。

会话索引规则和代码活动规则已升级，旧缓存在刷新时重新解析；资源部分索引 v2 支持原生展开消息，旧库首次建立有一次性扫描成本。管理数据库、收藏和恢复材料保持独立。
