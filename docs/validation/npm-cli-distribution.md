# npm 与 CLI 交付验证

本记录区分源码与模拟路由测试、实际 tarball 安装和平台矩阵。公共 npm 发布不属于本次验收，当前使用本地构建包；在线升级目标也尚未公共发布。

## 实现范围

- Commander.js 私有 workspace、统一 npm 产品包、`agent-manor`／`am`、MIT 和公共 registry 元数据。
- 页面业务能力对应的 CLI，JSON 文件／stdin 输入、查询范围、稳定 JSON、中英文、任务等待与明确管理确认。
- 默认端口顺延、实例核验、后台日志、服务就绪与数据准备、停止等待、版本兼容和程序更新边界。
- 自包含场景 Skill，两个宿主的用户／项目级与自定义路径，版本与内容校验、冲突保护、备份更新和移除。

完整设计及命令/API 对照保存在源码仓库的设计与任务文档中；这些文档不作为运行依赖。

## 实际包外验收

本机环境为 macOS arm64、Node.js 24.19.0。构建后生成 tarball，在源码目录外的新 npm prefix 分别进行全局安装与本地安装，再从另一个工作目录实际执行命令；安装目录不含 TypeScript、Vite 或未发布的 CLI workspace 依赖。

`npm run test:package -- <tarball>` 验证：

- 两个 bin、普通导入、版本与状态不启动后台或创建用户数据。
- 原生 SQLite 实际查询及 sqlite-vec 运算。
- Skill 安装、同版跳过、用户修改拒绝、明确更新前备份与安全移除。
- 默认端口冲突顺延与显式固定端口失败；后台启动和 Worker 运行、启动数据准备、真实 Web HTML／JavaScript、停止完成。

`npm run test:cli:installed -- <tarball>` 使用合成会话和隔离知识数据，验证 21 组场景：

- 状态、帮助、版本、诊断和日志的只读行为；真实服务地址、启动与准备等待。
- 会话列表、关键词／分组搜索、筛选与分页；消息、轮次、轨迹、画像、费用及来源定位。
- Markdown 完整导出和含空格的文件路径；用量、总览及面板与 HTTP API 结果相同。
- 知识 stdin 写入、幂等、默认待审、关键词搜索、正文读取、具体修订授权、伪确认拒绝。
- 修订冲突、历史快照、恢复重新待审、废弃与重新启用、偏好持久化和单次语言覆盖。
- 设置脱敏与按需查看 Key；限定输入的实际 HTTP 抽取调用、无价值结果不强行保存、完成状态和任务历史。
- 仓库登记、覆盖与回放数据、删除登记保留原始文件；资源与关闭的语义状态不隐式调用模型。
- 知识和会话向量实际构建、`--wait` 成功退出、语义检索和查询缓存。
- 停止与重新启动后知识、偏好仍在；日志不含凭据和知识正文。
- 非法启动、重启参数不改变健康实例；缺值全局参数仍返回可解析 JSON；关闭的自动刷新策略明确返回跳过。
- 知识抽取、知识索引和会话索引均在模型请求进行中暂停，`pause --wait` 成功返回暂停状态，恢复后完成。
- 4000 个快照与长正文下的默认响应有界；画像和价格分页、完整响应兼容，中英文及 emoji 正文按固定版本续读后无损拼接。

生成与向量服务使用本机合成 HTTP fixture，生成调用七次、向量调用七次，单次最大输入 5832 字节，不调用收费远端模型。大量快照的查询阶段不增加模型调用。该检查验证 CLI 到模型请求、任务、保存和查询链路，不代表模型质量评估。安装期间 npm 可以下载公开依赖；用量价格沿用已有公开目录更新行为。

## 自动化与失败边界

CLI workspace 测试逐项核验 74 条业务命令的 HTTP 方法、路径、查询和结果；额外检查完整中英文帮助、文件／stdin、成功、失败、暂停、预算停止、部分完成和超时。该层使用隔离路由 fixture，业务真实返回由上述包外验收另行核对。

生命周期测试覆盖端口顺延及固定端口冲突、并发单实例、纯读状态、旧身份／版本、数据准备失败和旧结果保留、日志轮换与更新锁。Worker 延迟创建并等待初始化握手，覆盖无任务关闭、初始化中关闭及任务失败重试，避免端口失败时中断 SQLite 原生模块初始化。

本轮源码全量测试 1646 项通过（测试并发度为 4）；CLI workspace 37 项通过。类型与中英文目录检查、构建、公开内容检查及实际安装检查通过。独立规格与规范审查发现的问题已修复并复验，最终复核无剩余行动项。

响应修复覆盖审计发现的 13 类问题：参数校验先于副作用、JSON 错误流、三类任务暂停、来源错误映射、默认摘要及完整模式、明细分页、价格目录、自动刷新无任务状态及回放参数说明。补充验证摘要与完整画像在同一版本下统计相等、状态摘要保留同步失败与关键计数、任务历史在后台 SQL 中分页后再解析、JSON 模式不等待交互。用量 Worker 初始化时关闭的真实回归通过，避免 SQLite 原生模块初始化期间被强制终止。

此前交付的知识索引成功退出、多数据目录升级保护、日志轮换与清理及中英文维护摘要继续由全量测试覆盖。Web 未改变完整 API 的默认响应，完整查询兼容由真实 HTTP 回归验证；本轮没有前端交互改动。

管理测试覆盖短期单次令牌的实例、方法、路径和请求内容绑定，拒绝重放及修改；可用性变更遇到新修订报冲突。普通调用不能因自报人工身份而发布。该设计记录明确授权，不承诺识别同一本机账号下每个进程的实际操作者。

软件更新测试使用合成 registry 元信息和安装执行器验证安装方式、公共源参数、忙状态、等待、数据备份及失败恢复边界。尚未对公共 registry 上的新版本执行真实在线升级，也不宣称已经验证任意未来数据格式的降级。

## 平台安装矩阵

CI 将同一 tarball 全局安装到 macOS arm64/x64、Linux arm64/x64 和 Windows x64，分别执行原生依赖、两个命令、后台、Web、Worker 与 Skill 验收。以对应提交的 CI 结果为准，不能用本机成功代替其余平台执行。

Linux 验收目标为 Ubuntu 24.04／glibc；不包含未经测试的其他发行版和 musl。Windows ARM64 不在本轮矩阵内。

开发及运行验证没有使用个人历史、业务源码、真实凭据或正在使用的服务。详细原始输出仅保留于本机忽略目录，公开测试代码使用合成内容。
