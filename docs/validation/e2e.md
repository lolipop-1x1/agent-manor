## 可复现的 CLI 端到端

脚本 [scripts/e2e-cli.mjs](../../scripts/e2e-cli.mjs) 创建自己的临时仓库、JSONL 和数据目录，只通过编译后的真实 CLI/HTTP 操作。它不导入解析或匹配函数、不替换 API 响应。正常结束会停止服务并清理自己的目录；`--keep` 可保留人工浏览器验收现场。

```sh
npm run build
node scripts/e2e-cli.mjs
# 对真实安装后的包执行相同验收
AGENT_MANOR_E2E_CLI=/absolute/install/node_modules/agent-manor/dist/cli.js node scripts/e2e-cli.mjs
```

## 2026-10-04 覆盖偏低与格式缺口补验

用户随后指出 AI 开发项目的读取百分比仍低，并发现数千条格式缺口。固定旧版 `historical-source-redacted` 的 2362 条 unsupported_format 全为三类非工具元数据：token_usage_record、world_state、inter_agent_communication_metadata；不含源码读写证据。解析规则 4 跳过这些已确认类型，保留真正未知类型的名称与记录行。

同时确认两项实际漏算。matching-v1 的整块候选长度差限制会丢弃大幅增长文件中仍唯一保留的代码；matching-v2 回退到有唯一内容锚点的精确子块，不扩大近似门槛。旧版同一基线、同一历史下，精确读取从 3169/6870 恢复为 3902/6870，修改从 4278/6870 恢复为 6078/6870；初始成功创建记录中 315 条唯一未变长行从全部遗漏恢复为全部对应。两个最小合成回归先失败后通过，重复边界、歧义与失败事件仍不补覆盖。

另一实际 CommandExecution 的三段固定 sed 范围返回 114 行，恰好等于 36+25+53，验证可以按次序切分；新增这一严格组合及单层 sh/bash/zsh 包装支持。返回截断、缺行或混入可变输出命令时不猜边界；外层调用与同一具体命令拆分事件不双计。合成解析回归覆盖完整、截断、行数不符、未知组合和去重，真实记录提取回读得到相同范围。

最终代码全量 96/96、类型检查、构建及包外安装通过，重启日常预览并清除派生缓存重建真实历史。版本 `historical-source-redacted` 的 Codex／全部历史／源码结果为 46 文件/7008 行，精确读取 4067 行（58.0%）/23 文件（50.0%），精确修改 6183 行（88.2%）/46 文件（100.0%），近似读取和修改各 4 行单列。此时 57 个来源包含本轮新增会话；新增实现与回归使分母增长，不能把这组实时数值当作旧版同输入差分。
