# 豆包工作接入验收

核查日期：2026-10-16。缓存样本初次核查版本为 2.25.17；验收期间检测到当前安装版本为 2.32.12。真实原生材料仅保留在本机忽略目录，本文记录方法和支持边界。

## 原生来源

使用生产 Node 读取器及历史适配器读取真实稳定副本，并对当前原始缓存只读核对；验证原生聚合响应、消息顺序、内容块、同会话投影去重、用户轮次及原始证据哈希。没有要求额外 Python 运行时，没有读取凭证或发出私有历史接口请求。

真实资源通过隔离盘点环境引用已核验本地根，确认托管与共享入口、顶层文档去重、状态未知和保护；原目录成员及元信息前后核对。该检查不等于客户端逐项加载效果，也不替代逐文件哈希检查。

经正常客户端运行专用临时目录内的合成读写任务，核对失败命令的退出码和断言输出、修改后的测试成功及缺失文件错误。缺失文件的过程卡片仍显示“已读取”，因此卡片完成与工具成功保持区分。

任务完成、重开任务、重载任务页以及正常退出重开应用后，已解析缓存均未出现该新增任务。额外原生执行日志只有部分关联输出；新发现 WebStorage 分区的数据库元数据也未提供明确的会话来源。因此只声明已发现缓存支持，不承诺完整历史或实时同步。

## 自动与产品验收

正式构建服务在隔离数据目录读取真实来源，通过 HTTP 与 CLI 核对 3 个唯一会话、7 个用户轮次和 78 个内容块；列表、三种阅读模式、搜索、对话导出、总览、用量和资源盘点均可访问。2 个正文来源完成原始证据哈希回读；没有生成缺少原生依据的模型请求或工具调用。原始缓存 10 个相关文件的前后哈希一致。真实 Skill 隔离盘点得到 176 个条目，盘点结果没有转成历史使用事件。

合成自动场景覆盖 SST／WAL、删除标记、外置 blob、损坏、未知结构、预算、并发变化、空 store、消息与投影关系、语义指纹复用、旧证据失效，以及来源替换和消失。跨接口核对会话、搜索、导出、总览、用量、代码地图和资源管理；文件卡片不产生精确覆盖，上下文占用不产生请求统计，历史清理不删除仍存在的资源盘点。

正式 dist 的独立 Chrome 浏览器通过 7 项验收：中文与英文客户端筛选、键盘操作、三种阅读与过程卡片、全局搜索、真实 Markdown 下载、普通／托管资源位置与保护、合成普通资源的回收恢复、深色主题及 390 px 窄屏。无页面错误；实际管理仅写入合成临时资源。

`npm run check`、`npm run build` 和包外安装测试通过。包外安装实际覆盖发布包、CLI、Worker、Web、SQLite 和 Skill；首次完整测试发现的新文档随包链接缺失已修正，并通过安装复验。最终完整测试及独立代码审查仍在执行。
