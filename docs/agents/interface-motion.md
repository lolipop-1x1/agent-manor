# 界面动效开发规范

应用页面采用克制动效：操作即时、过渡短、空间稳定。动效只解释反馈、状态或空间关系，保持既有紧凑布局与完整结果语义。

## 复用入口

- 共享样式与时长、缓动 token：`web/shared/styles/motion.css`。常规反馈、状态切换和面板分别使用 `--motion-feedback`、`--motion-state`、`--motion-panel`，退出使用 `--motion-exit`；会话落点使用 `--motion-focus`。以源码值为准。
- 独立选中底板／底线使用 `SelectionIndicator`，传选中值、ARIA 选择器与底线模式；保留按钮原有语义、方向键、焦点和尺寸。
- 动态短反馈使用 `animateSurface`，复用 token 与缓动，系统开启减少动态效果时跳过或中断；调用方在新操作、卸载或目标失效时取消已有动画。
- 菜单、日期、帮助与对话框继续复用现有 Radix 组件和内容类。通过 `data-state` 驱动进入和退出；居中弹窗保持原 transform，用独立 translate 表达短位移。

## 各类交互

| 对象 | 目标行为 |
| --- | --- |
| 按钮、枚举、列表和局部 Tab | 仅操作对象过渡背景、边界和文字颜色；焦点轮廓与禁用状态即时可见。主要按钮按下可极轻缩放，表格文字和地图格子保持尺寸。 |
| 主导航、代码地图主 Tab | 独立指示层移动；页面内容立即可读，语言、视口或字宽变化后指示层重新对齐。连续点击从当前视觉位置接续，最后一次选择生效。 |
| 菜单和帮助 | 按锚点方向轻移几像素；选择／操作菜单关闭即时交还焦点，帮助浮层短退出。维持 Portal、视口限制和独立滚动；嵌套选择后紧接 Escape 应能关闭外层。 |
| 图表、地图和时间轴明细 | 数据点首次悬浮快速出现，之后原位更新；位置跟随即时，不重播入场，不为查看点添加等待或请求。 |
| 弹窗、桌面侧栏、窄屏抽屉 | 弹窗与抽屉展开短过渡，桌面侧栏只过渡展开内容；分栏与地图尺寸一次确定。手动调宽即时响应，隐藏内容不参与焦点导航。 |
| 会话定位 | 近距离显式定位可平滑滚动；远距离直接定位并短暂强调落点。刷新锚点、返回书签和阅读位置恢复均即时。 |
| 地图手动聚焦 | 相机只提交最终布局，独立场景层做短合成过渡；原视口的有限快照仅淡出衔接后释放，不放大快照或扩张整仓画布。快照不可交互、不参与可访问树。拖拽、滚轮、缩放或新定位打断旧动画并释放快照。自动播放镜头在活动共同目录范围变化时定位，跨模块可回退整仓。 |
| 回放 | 播放头单独平滑，暂停／拖动／跳转即时定位；文件按真实步骤更新，当前描边只强调一次。高倍速减少装饰反馈，保留事件与累计痕迹；控件动效不随播放倍速加快。 |
| 成功与失败 | 复用原位状态反馈，只有真实完成才展示成功；错误立即可见。数值直接更新，未知、小计和估算含义保持不变。 |

## 刷新与性能

已有数据的刷新、筛选和分页保留原完整结果与布局，固定槽位显示进度，成功整体替换，失败保留并重试。内容刷新不重播菜单、面板或整页入场。

优先让独立小层通过合成动画完成过渡。分栏、地图容器、表格和长正文不逐帧插值宽高、边距或位置；密集文件格子不逐个添加持续过渡，图表不从零值重新生长。JS 只在交互、目标状态或尺寸变化时准备动画，动画帧不触发整树 React 更新。临时合成提示仅在必要期间存在，不长期给大量元素设置 will-change。

组件默认状态保持可读、可操作。新动作中断旧动作，不排队，离开或隐藏后停止无用循环。减少动态效果保留稳定的选中、完成与加载语义，空间运动直接到位；拖动和键盘反馈保持即时。

## 验收

1. 在桌面与窄屏成组检查进入／退出、连续快速切换、键盘导航、Escape 后焦点恢复、深浅主题、中英文和长名称。
2. 开启系统减少动态效果，验证 CSS 和动态动画均直接到位；运行中的过渡可被偏好变化打断。
3. 刷新和失败重试保持旧结果、滚动及布局；阅读返回保持原锚点。回放高倍速与暂停定位准确，播放期间地图宽高和比例稳定。
4. 对密集地图、长列表和真实历史记录长任务、布局漂移与交互响应；区分后台查询等待与动画成本。公开夹具使用合成数据，真实内容及截图仅留本机忽略目录。

变更新增动效时检查对应共享入口和上述适用项；不为简单反馈增加动画依赖或全局逐页入场系统。
