# 公开内容约定

公开仓库与 npm 包只包含项目实现、通用文档和人工合成样例。公开客户端及依赖名称、许可证和官方链接保留；真实个人身份、公司内部资料及用户历史不公开。

## 验证与提交

提交前执行 `npm run check:public`。它扫描已跟踪和未忽略的文本文件与路径，检查本机用户路径、内部域名、依赖 registry 和本地禁用词；输出只有文件、行号与规则，不回显命中的内容。图片、Git 提交身份、历史与外部附件仍需人工审查。

维护者可在 Git 忽略的 `.local/public-denylist.txt` 中逐行填写不应公开的个人或业务词，空行与 `#` 开头的行忽略。CI 从仓库 Secret `PUBLIC_CONTENT_DENYLIST` 读取同样的换行分隔列表，不把实际禁用词写进公开配置。通用规则不能识别所有公司项目名，未配置本地列表或 Secret 的环境不具有相同的定制检查；来自 fork 的 PR 通常不能取得仓库 Secret，仍需维护者复核。

真实会话、数据库、临时输出和真实业务截图留在 `.local/` 或仓库外；验收文档只记录可公开的方法与结论，不保存可回溯真实来源的标识。所有新图片均以人工合成数据生成，并在提交前检查可见文字和元数据。

## Git 历史与身份

新增普通提交不能删除旧提交中的信息。历史处理前盘点所有分支、标签、作者及二进制，保存私有备份，在隔离副本中验证清理结果，再列明需要覆盖的远端引用和协作者操作。强制推送前取得明确授权；旧克隆、fork 和缓存不受当前文件清理控制。

使用公开 GitHub 昵称和 noreply 邮箱提交，避免私人姓名与公司邮箱。不要为不属于自己的提交伪造作者归属。
