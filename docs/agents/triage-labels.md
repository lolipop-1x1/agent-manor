# Triage Labels

工程技能的五种标准分诊角色映射如下。

| 标准角色 | 本仓库状态字符串 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格明确，可交给 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

Skill 提到分诊角色时，使用第二列字符串。
本地 Markdown 任务用顶部附近的 `Status:` 行记录。
需要调整名称时，编辑第二列。
