# 豆包模型选择记录

规格见[任务 13](../../.scratch/doubao-work/issues/13-model-records.md)。用户希望原生 Auto 与手动选择名称进入已有模型记录。

复用共享消息的模型显示字段和画像模型记录组件；来源只接受同条 Bot 回复中的无歧义原生模型展示，不从数值类型或当前配置还原历史模型。Auto 是自动选择显示值，不证明底层实际模型版本。多模型或混合展示项不猜成一个名称；请求、Token、provider 与费用继续独立。

同时检查新增指定模型任务在本机的持久化范围。会话列表快照只能证明会话元数据，不能证明正文、模型回复或完整历史已缓存。新来源须先核验 schema、账号边界、同会话去重及失败保留旧版，再进入生产读取。

验收以合成无歧义／歧义样例和真实本机记录相互补充，沿用既有模型记录组件，无客户端专属面板；日常原端口的 API 与真实浏览器必须同步显示新结果。
