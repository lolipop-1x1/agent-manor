# 统一会话轮次与投入统计

一次真实用户需求及其后续响应过程为一轮。会话阅读、画像和固定七天复盘共享同一轮次与投入事实。输入分类排除工具结果、已知注入/后台通知和客户端取消控制记录；原始正文与依据保留。

结束状态保留 explicit/inferred/unconfirmed；只有明确结束或带原生正常结束依据的可靠推断结束纳入平均值。中断、截断、未完成工具及仅末条回复兜底不纳入。推断依据使用 SessionMessage.finalEvidence: turn_terminal / normal_stop / response_completed。持久化用量本身不是完整响应证明。

模型步骤按唯一逻辑请求计，工具调用单列，Token 为归一化输入加输出，耗时为需求起点至完整响应结束的经过时间。缺关联、缺分项和无效时间不补零。平均提示词按真实输入的非空白 Unicode 字符计算。

会话画像使用当前会话自身完整留存历史；七天复盘按本地最近七个完整日历日的结束日选择，使用完整轮次。真实用户事件节奏按事件日期统计。含可靠推断样本的数值显示约数标记，具体依据放现有帮助/详情。

所有工作直接在 main，使用现有共享目录。真实历史证据保存在 .local，不提交私人数据。验证跨客户端合成回归、画像与周复盘一致性、跨周投入、真实历史接口和页面，以及性能和公开内容检查。

## 后续口径调整

用户确认改用同轮最后非空 AI 回复记录时间，不再要求正常结束依据；当前规则与验证见 ../reply-rounds/spec.md。以上原生完成口径为历史决策，已被替代。
