# 统一轮次验证

直接在 main 实施，覆盖全部十一种已注册客户端。画像与七天复盘共享真实需求、请求关联、结束资格和完成时间，统计范围分别采用会话留存历史和本地七个完整日历日。

全量自动测试 1,031 项通过；轮次专项 33 项复测通过。类型、国际化、构建、公开内容与差异检查通过。浏览器合成端到端 60 项通过，覆盖可靠推断纳入、明细默认筛选、分页、延迟、失败重试、范围选择、返回恢复和窄屏。

真实历史回读十一客户端、31 个会话样本。三个近期活跃客户端的会话画像加权步骤与耗时均值和七天复盘逐项相同。已识别注入及取消的 CLI 样本需求数从十二修正为九，缺少正常终态的记录仍不进入结束均值；已知辅助事件和附件缺口不会抹掉请求步骤，未知事件与请求身份缺口保持保守。

真实页面验证了总览指标、客户端筛选、可统计结束详情、下钻与会话画像，未新增常驻解释。原始会话、标识、接口快照和截图保存在忽略目录，不进入公开文件。

在约 173 万条消息、18 GiB 会话索引上测量完整七天报告：改进前首次计算 47.4 秒；备份并移开复盘、总览事实和结果派生缓存后，优化后的首次接口计算为 18.7 秒，三次同版本复用为 19–42 毫秒。未清空操作系统磁盘缓存；冷算仍有约十九秒成本。缓存已有时，浏览器重新加载至七天主体可交互实测 129 毫秒，请求耗时 23 毫秒，该页面数字不是冷算耗时。

新增稀疏边界索引约 4.8 MiB，覆盖元信息的索引约 397 MiB；元信息索引本次一次性建立约 49 秒，日常启动和刷新复用。索引不含正文，活动及结束富集的查询计划和字节码确认不回读消息表正文。旧只读库缺索引时按原查询回退，报告一致。轮次规则升级一次性整体检查并原子发布，之后恢复定向快速刷新。
