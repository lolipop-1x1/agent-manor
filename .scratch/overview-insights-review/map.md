# 最近七天洞察口径讨论

## 已确认

- 重点洞察应围绕个人最近一周的会话、轮次投入、缓存、上下文、执行节奏、模型与思考程度使用，避免只挑总量变化、长期资源频次和工具失败。
- 最近固定为本机时区最近七个完整日历日，不含今天；不与前七天比较。
- 任务统计单位采用一次真实用户需求对应的会话轮次；有明确结束证据才进入已结束轮次样本，不将响应结束解释为需求满足。
- 缓存展示实际未缓存输入，并允许单列假设缓存价差；不把价差称为实际损失。
- 执行步骤采用模型请求数；工具调用数单列，不与模型请求或消息片段相加。
- 轮次耗时采用真实用户请求至明确终答的经过时间，包含本轮等待；提供平均值、中位数、P90 及最长轮次。
- 未观测到压缩会话的输入长度采用逐会话峰值，再对会话取平均；总输入包含缓存输入、不包含输出，不使用含义不一致的 contextTokens。
- 区域改为固定最近七天复盘指标与重点记录，不随页面顶部日期变化，继续跟随客户端和项目筛选，明确显示具体日期。
- 以用户会话与有独立需求的分叉轮次为核心；子 Agent 与有明确来源依据的自动执行单列，不随意分摊到父轮次。
- 单轮投入按结束日在统计期内纳入，并读取整轮步骤、Token 与耗时；活动、缓存和用户消息节奏按事件实际日期统计。
- 无压缩样本按整个可读取留存会话未见压缩判断；输入峰值只取最近七天。无压缩记录支持或有相关缺口的会话不纳入该样本。
- 采用会话与压缩、单轮投入、缓存与输入、偏好与节奏四组，固定展示核心指标；分位数、排行、来源与解释按需打开。
- 保持原始历史只读、来源可回查、未知与零分开、费用为估算的既有边界。
- 用户已整版确认，并授权全部核心指标、扩展详情、单会话三项均值及说明减噪直接在 main 实现、测试和真实页面迭代。

  - 子会话用量归属：单列，只有明确轮次关联才可合并，已确认。
- 实际未缓存输入与缓存价差：已确认。
  - 零缓存、部分缓存、缺少缓存字段：待核对并分别处理。
- 无压缩会话上下文：整个可读取留存会话未见压缩且具备观测依据，最近七天逐会话峰值输入再平均，已确认。
- 用户工作节奏：建议仅统计真实用户消息，明确自动来源、子任务、注入与复制记录排除；未知来源保留，不能按内容猜测。
- 模型与思考程度偏好：建议默认按请求数排行，来源未知与设置未采集分别保留；思考程度需补结构化支持。
- 常用 Agent：用户新增的核心指标；当前按 Agent 客户端理解，推荐按最近七天真实用户发起轮次数排行，展示名称、次数与占比。子 Agent 仍放在委派详情，术语解释待整版审阅。
- 提示词长度：建议统计真实用户输入的可见非空白字符，排除明确注入、工具结果与附件内容；不可可靠拆分的记录不假装已清洗。
- 呈现方式：四组固定核心指标与按需详情，已确认。
- 最终方案共同理解与扩展指标优先级：已确认，全部列出需求纳入实施。

## 方案讨论时的源码事实

- 现有洞察最多五条，顺序挑选用量变化、项目或模型占比迁移、资源习惯与工具失败，尚未以轮次投入组织。
- 现有近期变化采用三十个完整日期；资源和工具候选使用页面所选范围，不是统一最近七天。
- 总览已有会话、压缩、模型用量和请求计时基础；请求计时不等于轮次时长，活动时段也尚未单独限定真实用户消息。
- 轮次关联、明确或推断终答、请求身份和消息时间有基础字段；仍需新增轮次统计，不将现有请求计时当成轮次耗时。
- 子 Agent 目前只有会话级父子关系，没有可通用归属具体父轮次的字段。
- 思考程度有些来源已保存为上下文文字，尚无统一结构字段；不能据此声称模型或所有来源均已支持。
- contextTokens 的 Codex 解析会在缺少原字段时回退到 total_tokens，不能视为跨客户端统一上下文占用。
- 缓存输入已归一化，普通未缓存输入需要扣除缓存读取与缓存写入；缺少分项时不能按零扣除。价格支持按请求上下文档位和日期取价。
- 会话元信息有 child/fork 关系和特定客户端静默入口，但没有统一的自动触发分类；静默入口不能直接等同于自动任务，实施需保留来源未知。
