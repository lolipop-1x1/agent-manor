# 最近七天洞察指标与领域口径

Type: grilling
Status: resolved

## 目标

明确固定最近七天的轮次、缓存、上下文、工作节奏与使用偏好统计；形成可审阅的指标与呈现方案。讨论完成并确认共同理解后，再安排实现。

## 成功标准

- 每个指标有统计单位、样本、范围、缺失处理和可回查依据。
- 已结束轮次不等同于任务成功；缓存价差不等同于实际损失；用户消息时段不等同于工作时长。
- 平均步骤、Token、时长、上下文以及最长轮次可以解释其聚合方法。
- 明确新增有价值指标的优先级与页面呈现，避免恢复无价值的自动结论。
