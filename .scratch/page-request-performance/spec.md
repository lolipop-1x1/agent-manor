# 页面与接口性能优化

用户反馈页面卡顿、各接口响应偏慢。先测量本机现有页面及实际 API，用同一服务数据对照优化前后；保持功能、原始统计、刷新与管理边界，不处理真实资源文件。

## 已复现

资源状态接口连续三次中位耗时约 1.04 秒，响应约 3.55 MB；资源列表响应约 1.45 MB，大部分为诊断覆盖明细。并发资源状态请求时，会话列表与会话状态也由几十毫秒被拖至约一秒。详细真实输入和计时只保存在忽略目录。

## 验收目标

- 常规页面读取不反复盘点资源，不提前构造或传输当前界面用不到的诊断明细。
- 复用已有数据时，资源状态接口中位耗时低于 500ms，其他轻量请求不被拖至秒级。
- 首屏及轮询请求的内容和调用次数缩减；统计及操作结果不变，来源与缺口仍可按需查看。
- 缓存与并发复用覆盖索引发布、刷新、收藏、来源更改及管理写入的失效边界，失败可重试。
- 合成回归覆盖真实触发模式，类型／翻译／构建／公开检查通过，浏览器核对功能与测量结果。
