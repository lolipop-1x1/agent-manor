# 页面请求性能验收

日期：2026-10-09。本机实际历史的输入、完整响应、采样和截图仅保存在忽略目录；本记录只保留方法与汇总结论。

## 瓶颈与修改

- 资源状态读取每次重新装饰全盘点，重复写入发现记录、查找共享引用和管理能力。改为复用已装饰快照，扫描成功时替换，失败保留原快照；收藏仅更新标记。管理预览与执行仍重新扫描核验。
- 状态与资源总览在常规页面请求中携带数千条完整诊断。新增兼容的 `summary=true` 投影，保留筛选、统计、缺口数量及必要异常信息；原完整接口继续可用。
- 总览缓存命中和会话查询只需要当前版本，却读取完整状态。改为读取版本标量，避免反序列化诊断正文。
- 关闭的来源、资源历史和会话诊断区域仍构建大量列表节点。改为按需加载及渲染，来源缺口匹配用集合查询；会话缺口读取绑定索引版本，保留错误与重试。

## 同机测量

每个 HTTP 接口连续读取三次，记录响应完成耗时中位数；下表为缓存已建立后的常规读取。浏览器以相同资源列表路由重新加载，记录 Resource Timing。后台索引会更新实际历史，响应字节会小幅变化；指标口径的一致性另由隔离合成测试验证。

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 完整资源状态耗时 | 1,044 ms | 34 ms |
| 页面资源状态响应 | 3,552,778 B | 63,931 B |
| 页面 Skill 总览响应 | 1,447,177 B | 14,518 B |
| 页面 MCP 总览响应 | 1,447,321 B | 14,662 B |
| 页面会话状态响应 | 1,440,741 B | 8,136 B |
| 浏览器资源状态请求 | 1,181 ms | 22 ms |
| 浏览器 Skill 总览请求 | 1,159 ms | 109 ms |
| 浏览器首页状态请求 | 1,183 ms | 123 ms |

最终页面摘要接口中位数：资源状态 18 ms、Skill 总览 87 ms、MCP 总览 7 ms、会话状态 16 ms、首页状态 16 ms。完整资源状态与会话列表、会话状态并发的三轮请求，优化前均约 1.0–1.5 秒；最终中位数分别约 126、97、121 ms。

首次盘点不使用内存快照，仍涉及文件读取和管理能力计算。服务重启后的首次请求曾在后台分析同时运行时耗时约 6 秒，尚未分离系统负载与首次盘点的各自成本，不能由此认定后台分析阻塞 HTTP 主线程。后台分析已使用独立 Worker；本轮未更改启动刷新策略，未做长期或低配机器压力验收。

## 回归边界

连续及并发状态只装饰一次盘点；收藏、索引发布、刷新与范围变化更新聚合；聚合失败及盘点失败可重试，失败刷新不覆盖旧快照。完整与摘要的资源、地图及会话统计一致，诊断原文不丢失，旧索引版本仍可读取对应缺口。
