# 原生来源调查与隔离验收

Type: research
Status: resolved

## 目标

核对本机缓存生产结构和原生操作语义，为各功能定义有证据的支持范围。

## 已有证据

- 已解码 IndexedDB／LevelDB 与外置 blob 中的实际 V8 会话对象，核对消息顺序、回复关联及内容块树。
- 已确认启动页与聊天页缓存投影不同，列表分页状态不证明全部消息完整。
- 已有文字、过程、文件卡片、附件和本地 Skill 文件证据；模型用量、工具成功状态、执行身份和原生资源控制仍待核实。
- 没有确认本地缓存 TTL 或自动回收规则；本轮只接本机，云端协议不再作为接入前提。

## 验证方式

在独立临时目录准备人工源码、测试和 Skill 文档，经正常客户端创建合成任务；对照文件变化、可见客户端记录与任务后本地稳定快照。原始历史不写入，真实配置不作为操作目标。

## Comments

- 用户已允许隔离合成任务及少量模型调用；本轮范围不需要再次申请同一授权。
- 初次观察包含两个有消息的会话、14 条消息和 78 个内容块，是当次样本规模，不是固定格式契约。
- 隔离原生读写任务已完成；独立源码及测试检查通过。失败读取仍有“已读取”卡片，不能从卡片标题推断成功。
- 任务完成、离开并重开后，已解析缓存仍未包含新任务。本机可靠持久层与更新触发条件继续调查，参见 [验收记录](../validation.md)。
- 重载同一任务页仍未更新已解析缓存。候选原生日志只有部分合成输出，未发现另一份可解析的完整任务历史；本轮窄核查已结束，此缺口继续保留。

## Answer

已完成真实缓存、原生合成读写任务、正常退出重开及候选本地持久层核查。已确认的来源足以读取旧缓存；新增任务持续落盘、原生取消／重生成、Skill／MCP 执行身份与控制仍未核验，因此保留未知，不开放猜测行为。见 [验收记录](../validation.md) 和 [支持范围](../../../docs/design/doubao-work-sources.md)。
