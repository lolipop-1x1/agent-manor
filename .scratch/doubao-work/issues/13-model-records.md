# 展示豆包原生模型选择记录

Type: task
Status: resolved
Blocked by: 12

## 目标

用户要求 Auto 也进入既有模型记录，并用新建的手动指定模型任务验证。所有读取限定本机，不获取云端历史或登录凭证；直接 main 开发，真实原地址验收后提交推送。

## 规格

- 只从原生 Bot 回复的 `commerce_model_data_v1` 中读取可无歧义识别的展示值；支持对象与 JSON 字符串。Auto 保持原生值，具体名称有记录时同样保留，不根据未知数值类型、当前输入框选择或 AI 自述猜历史模型。
- 模型选择值进入共享消息及画像模型记录；仅标记思考与 AI 回复，不计入用户、普通上下文或原生操作记录。模型记录计数沿用现有消息记录口径，不等于 API 调用数。
- 单项有效模型展示可识别，空白、坏 JSON、非文本、多项歧义保持未知。不得制造请求、Token、费用、provider 或底层实际模型结论。
- 查明新任务本机落盘范围。能确认的新来源再适配；只有标题或当前配置时，不补造正文和回复模型。原生列表投影与旧聚合来源按相同身份去重、保留正文较完整来源。
- 合成回归、真实旧会话与新任务来源核对、既有模型记录组件浏览器验收；变更应在日常原端口实际生效。保留其他任务的未提交改动。

## Answer

同条 Bot 回复中的单项原生展示进入思考／回复的 `model`，沿用共享模型图表；Auto 保留原文，不推断底层路由，不增加请求、Token 或费用。模型参与规范化指纹，旧无模型修订可重新解析。

新增五种会话列表快照读取、账号分区校验、去重及原生版本择优。列表 `extra` 中的工作目录和有效时间可保留；仅摘要来源不补造消息或回复模型。实际手动选型任务有本机列表及工作区映射，但没有已缓存 Bot 正文，其选择键不转成回复模型。

最终暂存副本独立通过类型、国际化、正式构建和相关 70 项回归，Chrome 12 项覆盖共享模型图表、中英文与原有流程。首次完整 1360 项有 1359 项通过，包外安装因隔离副本未初始化 Git 失败；修正副本 Git 及依赖链接忽略后，包外安装补跑 1／1 通过。新增跨缓存版本回归包含在最终 70 项中。

真实本机生产读取与日常原端口 API／浏览器均确认 Auto、摘要项目和时间；范围外客户端会话数不变。实际服务一次性延后旧派生修订回收后发布，随即恢复原运行代码并续跑原同步；没有新增归档能力。真实输入、标识、路径、截图和运行记录仅保留在忽略目录。
