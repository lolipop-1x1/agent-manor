# 从执行轨迹估算模型步骤

Type: task
Status: resolved
Blocked by: 11

## 目标与口径

用户要求已有执行轨迹的来源可以计算平均模型步骤，所有客户端共用规则。直接在 main 开发并使用真实本机来源验证，检查通过后提交推送；不修改原始历史，不访问云端。

- 原生请求身份完整且能关联轮次时继续按唯一请求数计步，缺少 Token 不阻断。
- 某轮没有可关联原生请求时，按原始顺序将连续非空思考与 AI 回复合并为一个模型输出段；工具请求、工具结果、原生操作及新的真实用户输入划分后续输出段。上下文标题、普通注入、复制历史、空白内容不单独计步。
- 仅有思考没有非空 AI 回复的轮次不进入平均值。具备请求记录但请求边界不完整时不以轨迹覆盖已知缺口，不把未知补零。
- 轨迹估算仅描述已留存的可见过程，不制造 SessionUsage、模型请求数、Token、费用或成功状态。以独立字段记录估算来源，画像及七天复盘使用同一算法，并以约等号和已有帮助披露。
- 画像统计使用整个会话自身历史，分页、阅读模式、日期及包含子会话开关不改变该值。窄投影保留计算所需非空标记与操作边界，不读取整段工具正文。

## 验收

覆盖连续输出合并、并行操作、工具结果、普通上下文、复制／注入／空白、原生优先、混合轮次、未关联及部分请求；真实豆包 API 与轨迹逐轮核对，Codex 原生计数回归。七天原始与窄缓存投影一致，旧派生缓存自动失效。中英文、帮助、主题和窄屏浏览器验证；相关测试、类型、构建、公开检查和两轴审查通过后提交推送。

## 分工

主 Agent 负责共享算法、契约、画像投影、核心回归及真实验收；界面任务负责现有组件的估算标记、帮助与浏览器回归；七天复盘任务负责源投影、缓存升级与相关回归。保留并行 Skill／压缩历史任务的全部改动。
