# 项目、上下文占用与消息结束时间

Type: task
Status: claimed
Blocked by: 08

## 目标

补齐实际本机缓存中已核验但漏读的会话工作目录、上下文窗口快照和消息结束时间。继续仅使用本机来源；没有请求、工具执行或计费用量依据时保留未知。

## 验收

- 会话级任务参数的绝对 workspace 参与项目归属；与消息级目录冲突时不选择单一项目，不使用项目 ID 或授权目录代替。
- 上下文窗口四个占用分项与容量通过校验后独立保存和展示，包含最新、峰值及分项；不产生请求、累计用量或费用。
- 原生 finish_time_ms 与消息创建时间分别保留，轮次耗时优先使用最后非空回复的消息结束时间；不提升终答、任务成功或 TTFT 证据。
- 合成回归覆盖异常、冲突、重复投影和升级；真实缓存经生产刷新、API 与浏览器核验。
- 完成独立审查、公开检查及 main 推送。

## Answer

会话级任务 workspace 已参与归一化和冲突检查；上下文四分项及容量以独立快照保存，只有快照的会话启用用量页且不显示零请求／空费用；消息结束时间独立保留，画像与七天复盘共用有效结束时间优先的观测边界。规范化指纹覆盖新增字段，七天事实及结果缓存已升级。

真实运行服务专项刷新核对 3 个会话、78 个块、1 个项目、7 条快照及 7 条结束消息；其他客户端会话数量保持不变。实际页面验证项目、用量、明细、帮助和 390 px 横向滚动；正式合成 Chrome 11 项、全量回归 1324 项及最终相关 25 项通过。规范审查发现的领域与帮助口径差异已统一修复并独立复核；需求审查无未处理发现。

公开检查、类型检查和正式构建通过；剩余 main 提交、推送和远端回读。详细支持边界见 [来源说明](../../../docs/design/doubao-work-sources.md)，验收见 [公开记录](../../../docs/validation/doubao-work.md)。
