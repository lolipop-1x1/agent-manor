# 暂停豆包工作导入与产品入口

Type: task
Status: resolved

## 目标与约定

用户决定先从数据导入和页面屏蔽豆包工作。现有本机缓存不足以稳定还原历史，当前产品状态改为暂不支持；保留研究解析器及发现记录，原生历史、配置、资源和独立恢复材料不删除。

## 实现与验证

1. 已知身份保留，当前可用客户端集合排除豆包；来源发现、显式刷新与手动资源来源不接受豆包，自动资源盘点停用。
2. 旧会话发布索引在启动事务中切换为排除豆包的新版本，其他客户端修订保持不变；旧版本不可查询，避免历史统计缓存复用。代码地图和资源管理独立屏蔽既存豆包记录。
3. 页面共用可用客户端集合；旧筛选 URL 安全处理，旧会话深链接不再显示正文。更新当前能力说明，研究文档保留数据不完整、消息片段／摘要差异、云端历史读取与未确认边界。
4. 合成旧索引升级、禁用发现／刷新／资源入口、其他客户端统计回归、正式构建、中英文浏览器和真实原端口验证；通过后 main 提交推送。

## 结果

已完成上述停用。代码地图额外覆盖旧跟踪来源与解析缓存，避免刷新时再次读取或导入；独立审查发现的该路径已修复。原生历史、配置、资源和独立恢复材料保留，旧派生缓存即使暂留磁盘也不再通过有效版本查询。

类型、国际化、正式构建通过，完整回归 1378／1378；旧地图缓存专项 23／23、历史同步任务隐藏专项 1／1、正式 Chrome 中英文与窄屏 6／6。日常服务已在原端口更新，其他客户端会话与来源成员的身份及修订摘要前后一致。详细材料只保存在忽略目录；公开结论见 [验收记录](../../../docs/validation/doubao-work.md)。
