# 豆包工作本机来源接入

Status: claimed

## 目标与已确认边界

为豆包工作建立独立客户端身份，尽量接入 AgentManor 的全部现有功能。各功能按原始来源的实际证据开放；技术未知由本机调查与隔离验收解决，不通过猜测补齐字段。

- 只读取本机来源，不读取登录凭证，不增加云端历史接口或云端补全设置。客户端正常执行合成任务产生的模型调用属于已授权验收。
- 沿用 [ADR 0005](../../docs/adr/0005-rebuildable-global-session-index.md)：来源确认消失后从新版有效结果移除；临时读取失败保留上一完整版本；不新增永久归档。
- 允许在专用临时目录创建合成任务，核验读写、失败、取消、重生成以及 Skill／MCP 记录；真实业务目录、既有配置与外部服务不作为写入目标。
- 沿用当前 macOS 平台边界。本轮调查基线为豆包工作 2.25.17，不推定其他版本或普通豆包客户端使用相同格式。
- 现有产品规则能够覆盖已确认范围；方案已确认，直接在 main 开发，使用真实本机来源验收，检查通过后提交和推送。

## 已确认来源与读取路径

本机 Chromium IndexedDB 的 LevelDB 与外置 blob 保存账号分区下的会话缓存。启动页与聊天页可能是同一会话的不同投影，不能重复统计，也不能假定任一投影完整。

读取时先取得一致的隔离快照，再依据活动表、日志、原生记录版本和删除标记选择当前有效值；解开 IndexedDB 包装及外置值，解析已验证的 V8 对象。未知编码或不一致快照产生可见缺口或刷新失败，不作为空来源发布。

缓存包含会话聚合响应、消息及内容块。消息与块保留原生身份、原生顺序、父关系及来源定位。正文从实际内容块解析；不得使用同会话共享的 section 身份代替用户轮次，也不得将过程块数量作为模型请求数量。

已完成实际载荷解码和离线关联核对；这些事实不代表已接入产品。真实副本、正文、路径和截图仅保存在忽略的本机调查目录中。

隔离原生任务已完成文件读取、修改、成功与失败实验；但任务完成并重新打开后，已解析的聚合缓存仍未包含新任务。继续核实本机来源与更新条件；已经核验的缓存读取可以实现，开放持续同步前须明确其更新边界，不能把解码成功描述为实时历史同步已可用。结果见 [原生验收记录](validation.md)。

## 功能范围与成功标准

| 功能 | 接入目标 | 必须保留的边界 |
| --- | --- | --- |
| 发现与刷新 | 默认入口发现、来源开关、明确目录覆盖、账号分区及缓存投影去重 | 快速检查须涵盖活动文件和 blob 依赖；快照失败不发布空列表 |
| 会话库 | 列表、项目、阅读、搜索、对话导出和原始证据回读 | 搜索只覆盖已导入缓存；原生项目身份不当作本机 Git 根 |
| 过程与关系 | 解析正文、过程容器、文件卡片、附件及已确认的用户回复关联 | 分支、子会话、取消、重生成和完成状态仅按明确证据解释 |
| 用量与计时 | 接入可确认的原生请求、模型、计量与计时字段 | 上下文占用、显示金额、首网络包和消息数量不能替代请求 Token、费用、首 Token 或模型调用数 |
| 总览 | 统计有可靠时间的会话活动和满足既有口径的指标 | 缺少压缩、用量或资源身份时保留覆盖缺口，不补零 |
| 代码地图 | 将已确认的文件活动与证据送入既有分析链路 | 卡片完成不等于工具成功；失败、截断、范围未知不计精确覆盖 |
| 资源使用 | 关联明确的 Skill 调用、成功正文读取和 MCP 工具身份 | 选择技能不等于执行技能；资源名称或文本提及不证明 MCP 调用 |
| 资源盘点 | 盘点已核验本地 Skill 入口及可确认的 MCP 配置 | 本地技能文件、产品技能目录和缓存副本分别处理；嵌套说明文档不重复计资源 |
| 资源管理 | 对已核验普通入口接入预览、停用或回收及恢复 | 系统、托管、共享保护沿用现有规则；写入规则未核验时保持只读 |
| Web、CLI、API | 共用客户端声明、来源与统计结果，补齐中英文入口 | 页面筛选、已有状态、未知值及原始内容语义保持一致 |

## 生命周期与失败处理

1. 同一会话在多个本地投影中出现时，以原生身份合并，记录来源及冲突；文件时间较新本身不能裁决字段正确性。
2. 只有一次完整、有效的来源发现才能确认会话从本地缓存消失。读取失败、格式变化或缺少 blob 不能冒充用户删除。
3. 确认本地来源消失后沿用现有索引生命周期，并明确它不证明远端已删除。清除索引后无法恢复已经缺失的缓存。
4. 原始证据回读检查来源修订；内容已变更或不再存在时，返回相应状态，不制造原生历史副本作为永久来源。

## 验收

1. 隔离合成任务：读文件、修改、创建文件、成功命令和预期失败命令；再核对客户端展示与本地留存记录。
2. 按客户端实际提供的控制核验取消、重生成与分支；无法触发或缺少留存字段时记录未验证，不通过改原始库构造“真实验收”。
3. 使用隔离 Skill 与本地测试服务验证资源记录；不修改真实配置，不连接真实外部业务服务。
4. 合成容器覆盖 blob、重复身份、旧版本、删除标记、未知块、来源变化与消失、并发更新以及快照失败。
5. 通过既有会话、总览、用量、代码地图与资源接口核对同一完整结果版本；完成中英文、搜索、导出、轨迹及管理预览浏览器验收。
6. 完成相关类型、国际化、回归、公开内容与打包检查。原生运行、离线解码、合成测试和产品浏览器结果分别记录。
