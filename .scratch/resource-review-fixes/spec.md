# 资源管理证据一致性与恢复边界修复

沿用已确认的资源管理设计，修复总体 review 中的两项证据展示问题：同一资源切换历史范围或版本后，概览不得展示可跳转的旧范围证据；最近使用从当前完整历史范围按发生时间倒序选取三条，独立于使用记录分页及工具筛选。更新期间保留完整旧结果并暂停下钻，新概览与同版最近证据一起替换，失败保留错误及重试。

恢复及永久清除前核验材料位于本次操作对应的回收目录，拒绝越界或符号链接祖先；兼容既有恢复材料布局。为资源查询失败补充不含请求正文、凭据和查询参数的本地诊断信息，不推断既有运行异常的根因。

同步现有 E2E 的 CLI 完整响应、详情按需加载与视口稳定等待。回归使用匿名合成资源，真实配置只读；截图及详细日志保留在本机 `.local/`。通过相关及完整自动测试、检查、正式构建、Chrome 宽窄屏和中英文验收后，在 main 提交推送并回读远端状态。
