# 多模型速度对比

Type: task
Status: resolved
Blocked by: 05

## 范围

用户要求在同一速度图中展示多个模型，并能筛选一个或多个。延续 main 开发，不创建分支或 PR。

- 多选仍以客户端、原始模型、计时窗口、依据和方法组成的独立分组为单位，不合并不同口径。
- 增加 `speedGroups` 数组；未指定时默认选择当前筛选范围内全部可用分组。显式空数组表示暂不选模型；部分选择失效只保留仍存在的分组，全部失效回退默认。
- 兼容旧 `speedGroup` 单选地址及 API；新字段优先。响应增加 `selectedGroups` 和 `series`，每条序列有 `group` 与完整 `buckets`，旧 `selectedGroup`／`buckets` 保留首条视图。
- 复用可搜索选择控件，支持多选后菜单保持打开，提供不受搜索限制的全选、清空选择及应用；图例有界滚动，图例和浮层使用一致颜色与线型，同日期分别显示各组速度、覆盖、输出和耗时，估算独立保留 `≈`。
- 清空选择显示可重新选择的空状态；不影响普通用量指标。保留断线、单点、完整筛选范围、加载冻结、重试、地址和偏好恢复。
- 测试覆盖精确与汇总多序列对照、空选／回退、旧地址兼容、多选交互、颜色一致性、中英文、深浅主题、窄屏和触屏。完成后构建并重启本地服务供用户查看。
