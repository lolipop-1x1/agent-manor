# 模型吐字速度日期趋势

状态：单模型首版及用户追加的默认全选、多模型对比均已完成开发、测试与双轴审查。目标、入口和布局已由用户确认，实际结果见[验收记录](validation.md)。

## 产品行为

- 在用量统计页现有时间主图的指标选择中增加“吐字速度”。选择后原位显示一条或多条日期折线，纵轴为 tok/s；不新增页面或常驻图表区域。
- 沿用顶部日期、客户端、项目、模型、父子关系、会话类型、记录覆盖、定价覆盖及数值筛选，按请求发生时间 `occurredAt` 与报告时区分桶。小时、日、周、月使用已有边界。
- 速度是时间图的局部指标。原 Token／费用／请求数选择、归因维度、柱线偏好与日历视图保持各自语义，返回普通指标时恢复。速度视图只提供折线，不展示速度组成、速度占比、混合总速度或速度日历。
- 每条速度曲线对应一个独立分组：客户端、原始模型、响应／输出阶段、原生／历史估算及具体计时方法相同。默认选择当前筛选范围内全部可用分组，通过共享可搜索多选控件增减为一个或多个。菜单提供“全选”和清空选择，勾选后点击“应用”整体提交，Escape 或关闭放弃未应用选择。显式空选显示选模型入口；筛选后保留仍存在的选项，全部失效才回退默认。
- 多条曲线共用日期和 tok/s 纵轴，每条使用一致的图例、曲线和明细颜色与线型；较多图例在有限高度内独立滚动。增减选择不重新分配其他曲线颜色；同日期分别展示各组值，不合成总速度。模型与计时口径始终可识别，避免将响应区间和输出阶段误读为相同依据。
- 未知模型不能确认相同模型身份，不进入模型速度曲线；请求仍保留在用量统计与总体覆盖中。
- 模型、客户端和计时区间用清晰标签识别；估算组速度数值保留 `≈`。具体方法与算法放在区域帮助，避免常驻解释文字。
- 悬停、键盘和触屏可查看日期、速度、可计算请求数与该组请求数、合格输出总量和合格耗时。浮层不参与页面布局，Escape／关闭后恢复焦点。
- 缺样本日期为未知并断线，不补零、不跨缺口连接；只有一个有效点时仍可看见并选中。缺少合格数据提供明确空状态。
- 切换指标、分组或范围时保留上一份完整图和真实选择，固定位置显示进度；更新期间暂停旧图交互，成功整体替换，失败保留图并提供重试。
- 地址、页面隐藏再显示、语言与主题切换保持速度选择与分组；会话明细分页不改变完整曲线。所有新增文案及可访问名称提供中英文。

## 统计口径

- 复用 `requestSpeed()` 的有效请求判定：输出至少 200 Token、耗时至少 1 秒、明确或可靠推断完整结束、合法且一致的时间证据；原始用量不受该门槛影响。
- 日期点与组平均均为同一合格集合的输出 Token 总和乘 1000，除以耗时毫秒总和。使用未舍入原值，不平均单请求速度，不重复加入推理 Token。
- 同一会话请求身份去重，明确复制历史沿用现有排除结果；主子会话各统计自身新增请求。
- 缺可靠日期的请求不伪造时间桶。缺模型或缺分组依据的请求不补入某个模型；总体覆盖与分组覆盖分别说明，不能将分组内覆盖冒充全部已识别请求的覆盖。
- 组内没有合格请求时速度、合格输出和合格耗时均为 null；缺失与真实零值区分。
- 请求筛选及会话数值阈值须与现有用量报告完全一致。精确 ISO 时间范围和费用阈值继续走现有精确计算路径。

## 数据接入

- 保留 `UsageMetric` 的三种全局度量，新增可选 `UsageQuery.includeSpeed` 与 `speedGroups`，由前端速度视图请求。`UsageReport.speed` 为可选附加结果；旧 `speedGroup` 查询与地址仍可恢复单选，新数组优先。
- 速度结果含全部分组摘要、`selectedGroups` 选中分组身份、`series` 中各组完整日期桶、当前日期范围已识别请求数与可计算请求数，以及独立的无日期请求计数。旧 `selectedGroup`／`buckets` 保留首条曲线视图。分组切换在相同版本与筛选下查询，不通过逐会话画像拼接。
- 在可重建用量事实中保留足以校验速度的精简计时字段，小时汇总保存可合并的合格输出、耗时和请求计数。正常查询不反复恢复全量原请求 JSON。
- 事实和汇总格式升级使旧派生数据正常回填，不修改原始历史、价格设置或会话身份。所有结果继续绑定分析版本、价格版本与时区。
- 不请求速度时省略速度响应和额外时间序列聚合；既有用量与总览接口的度量语义保持。

## 验收

1. 合成单测覆盖加权平均、门槛、无效／部分／未知结束、计时输出覆盖、混合客户端／模型／区间／方法、缺日期和缺模型。
2. 精确事实与小时汇总对照：所有筛选、日期时区、小时／日／周／月、主子去重、费用阈值、分页及缓存重启结果一致；旧事实与汇总可回填。
3. 真实浏览器使用隔离合成资源验证指标切换、分组搜索／空结果、完整日期范围、断线和孤立点、浮层与焦点、慢请求／失败／竞态、地址恢复、中英文、主题及窄屏。
4. 执行类型与国际化检查、完整自动测试、构建、用量看板回归、公开内容与空白检查，再进行规范和规格两轴代码审查。
