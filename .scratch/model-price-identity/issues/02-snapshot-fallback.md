# 单价快照与历史日期序列

Type: task
Status: resolved

范围：备用价格源普通单价、无日期快照、日期序列及缓存重读。不伪造历史生效日期，不随意选择多个无约束价格。

## Answer

普通对象与唯一无日期条目作为当前快照；明确日期序列保持原历史区间。复杂约束、多条无日期候选和损坏缓存不猜选，对象及数组形式的仅输入计费条目不阻断文本目录。实际公开源导入及合成缓存回归通过。实现见 [价格数据导入](../../../src/usage/historical-prices.ts)，回归见 [快照测试](../../../tests/usage-snapshot-fallback.test.ts)。
