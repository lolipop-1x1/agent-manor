# 搜索零命中空状态

Type: task
Status: resolved

## Goal

全局搜索零命中时使用紧凑的列表空状态，避免重复统计；会话内零命中时使用行内提示，避免空浮层遮挡正文。

## Acceptance

- 全局空状态复用列表的布局、主题与文字层次。
- 会话内零命中不展示命中导航及空结果浮层，保留当前对话。
- 真实浏览器验证零命中、恢复命中及清空搜索，中英文、深浅主题和窄屏。

## Comments

用户反馈两处空状态的字号与占用空间不协调，本任务只修改搜索结果呈现。

后续用户要求会话内有命中与无命中使用同一浮层，[任务 07](07-local-search-popover.md) 已取代本任务的会话内行内提示方案；全局搜索空状态继续保留。

## Answer

- 全局零命中复用列表空状态，使用搜索图标与 11px 提示，移除重复的零命中汇总。
- 会话内零命中使用搜索栏下的行内提示，隐藏命中导航与空浮层，保留当前对话。
- 前端类型检查、翻译目录检查、前端构建、公开内容检查与差异空白检查通过。
- 隔离合成数据的 Chrome 验收通过 21 项检查，覆盖零命中、恢复命中与定位、清空搜索、语言切换、深浅主题以及 390px 窄屏；无运行时异常。
- 桌面及窄屏截图保存在本机忽略目录中，未使用个人历史截图。
