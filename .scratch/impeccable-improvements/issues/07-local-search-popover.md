# 会话内搜索浮层定位与状态统一

Type: task
Status: resolved

## Goal

会话内搜索的命中、零命中、加载及错误统一在搜索框下方呈现。浮层锚定搜索框，宽度及高度受视口约束，保留当前对话的阅读位置。

## Acceptance

- 复用 Radix Popover，通过 Portal 展示结果，桌面靠近搜索框，窄屏不越界。
- 零命中使用同一浮层中的紧凑空状态，不再出现在正文左侧。
- 输入保持焦点，Escape 关闭后回到搜索框，点击外部关闭，搜索命中及分页仍正常。
- 真实浏览器覆盖中英文、深浅主题、桌面及窄屏、加载、错误和空结果恢复。

## Comments

用户要求有命中与无命中保持一致，并调整浮层位置；此前行内零命中方案由本任务取代。

## Answer

- 会话内搜索使用现有 Radix Popover，浮层与搜索框右沿对齐，下方间隔 6px；桌面宽度最大 480px，窄屏与搜索框等宽，高度受视口及可用空间约束。
- 命中、零命中、等待、加载和错误共用一个浮层；搜索范围与命中导航收在浮层内。空状态使用紧凑提示，正文及轮次导航不被挤动。
- 输入时保留焦点；向下键进入命中，Escape 及关闭按钮返回搜索框；点击外部关闭，命中选择继续精确定位，清空搜索恢复阅读位置。
- 专项 Chrome 验收通过 45 项检查，覆盖桌面、390px 窄屏、中英文、深浅主题、加载、错误恢复、空结果、长结果滚动和分页，无运行时异常；截图与日志保存在本机忽略目录。
- 前端类型、翻译、构建、公开内容及差异空白检查通过，布局扫描返回零项发现。
- 会话端到端脚本加入空结果、浮层位置及 Escape 焦点回归断言。完整脚本在此前已有的“执行入口记录”定位检查处超时，尚未执行到新增断言；当前 Web 没有使用对应可访问标签，未将完整脚本计为通过。
