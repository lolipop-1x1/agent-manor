# 平均每会话轮次

在最近7天洞察的「会话与压缩」中，在「有回复轮次」下增加「平均每会话轮次」，显示一位小数与轮次单位，保留整行点击入口，不添加常驻说明。

统计为最近七个完整本地日历日内发起的真实用户轮次数，除以发起过这些轮次的用户会话数。未回复需求也计入；旧会话仅计窗口内新发起轮次；排除子 Agent、继承边界未知分叉及共享轮次规则排除的注入、复制、通知记录。无样本显示空值。

客户端与项目筛选同步生效。详情复用既有弹窗，按会话显示窗口内轮次、最近提问时间及原会话入口，默认轮次最多，可切换最近提问。紧凑摘要显示平均值、会话数、发起轮次，公式收进帮助。

复用已有窗口轮次，不新增历史扫描或事实缓存格式。验证跨周、时区、缺回复、无需求活动、子 Agent、注入、筛选、排序与分页；核对真实历史和浏览器后在 main 提交推送。
