# 总览页面设计

状态：已按确认布局完成实施与真实数据页面验收；宽屏节奏与洞察并列，1420px 及以下活动通栏。实现及验证结果见[验收文档](../../docs/validation/overview-dashboard.md)。

统计范围、计算规则及证据约束见 [spec.md](spec.md)。本文只约定页面组织、视觉层级与交互。

## 设计目标

进入总览后，先看清所选范围的规模，再理解全年使用节奏与值得调查的变化，随后进入项目、模型、资源及仓库的具体记录。

页面采用现有工作界面的字体、主题、导航和筛选控件。重点通过留白、对齐、图表比例和明确的动作形成，保持各区域易扫读。统计说明通过帮助与详情查看。

## 推荐布局

```text
总览  代码地图  会话库  资源管理  用量统计

总览                                       帮助  更新总览
近一年 ▾   客户端 ▾   项目 ▾

会话数   模型请求数   Token 总量   估算费用   活跃天数   当前连续活跃
──────────────────────────────────────────────────────────────
活动节奏                              重点洞察         查看全部
全年活动日历                          五条短句结论
星期 / 时段分布                       每条均可查看证据
──────────────────────────────────────────────────────────────
用量趋势                              使用分布
Token / 估算费用 / 请求                项目 / 客户端 / 模型 / 工具
──────────────────────────────────────────────────────────────
Skill 使用                            MCP 使用
次数、会话数与趋势                     服务器、调用数与会话数
──────────────────────────────────────────────────────────────
过程调查                              使用画像
失败 / 压缩 / 请求计时                 连续、峰值、种类与偏好
──────────────────────────────────────────────────────────────
代码活动                                         打开代码地图
仓库摘要、各自覆盖与热点入口
```

- 顶部六项指标组成一条概况带，用细分隔线区分；指标按现有统计页面的尺度呈现。
- 宽屏活动区与洞察区约为 2:1。年度日历形成主要视觉焦点，右侧五条洞察保持短句列表。
- 下方依次为用量与分布、资源、过程与画像、仓库摘要；每组围绕一个明确任务组织。
- 主内容居中，最大宽度沿用用量页的 1440px。区域以标题、留白和细边界分隔，保持平整的页面层次。
- 日历与洞察无法同时完整容纳时，活动区改为通栏，洞察接在其后。布局变化保持内容顺序、字号与操作语义。

另外两种可选布局：通栏活动之后依次展开洞察与分析的“宽幅纵向复盘”；六项指标之后先读五条结论的“洞察先行”。三种布局使用同一套内容、控件和统计规则。

## 字体与视觉尺度

总览沿用 Geist Variable，中文使用现有中文字体回退。分析页面的字阶以当前用量页为准。

| 内容 | 设计尺度 | 使用方式 |
| --- | --- | --- |
| 页标题 | 22px，650 字重 | 只显示“总览” |
| 区域标题 | 15px，650 字重 | 活动节奏、重点洞察、资源等 |
| 六项主指标 | 桌面 25px，600 字重 | 使用等宽数字特性，单位保持当前格式 |
| 中等宽度主指标 | 22px，600 字重 | 沿用现有统计页面的响应规则 |
| 窄屏主指标 | 24px，600 字重 | 通过重新排布保留可读性 |
| 次级画像数字 | 19px，600 字重 | 峰值、种类和最长连续等 |
| 列表、排行及洞察正文 | 13px | 主要分析内容，不另加常驻说明行 |
| 表头、坐标与筛选文字 | 12px | 与用量页保持一致 |
| 帮助与统计详情正文 | 12–13px | 沿用共享弹层与详情的文字尺度 |

筛选控件保持 34px 高度、6px 圆角及现有焦点反馈。桌面主体左右留白为 28px，窄屏为 14px；区域内以现有 8px、12px、20px 间距组织，分析区域之间保留约 24–32px。

浅色与深色主题均沿用当前页面、正文、次要文字、边界和强调色。强调色用于当前选择、关键数据系列和交互反馈；危险色只表达已经确认的失败及阻断错误。活动强度沿用现有数据色阶。

## 区域呈现

| 区域 | 默认呈现 | 展开后的内容与动作 |
| --- | --- | --- |
| 范围与筛选 | 日期、客户端、项目；刷新位于页头 | 自定义日期使用共享日期控件；项目支持名称及路径搜索；已选择的条件可明确清除 |
| 六项概况 | 标签、数值及必要状态图标 | 会话打开主／子拆分和会话列表；请求、Token 和费用进入相应记录；活跃及连续进入日期活动 |
| 活动节奏 | 年度日历；紧凑的星期与时段分布 | 区域内切换会话、请求、Token、工具调用；日期明细提供“查看当天”和“设为日期范围” |
| 重点洞察 | 默认五条，一条结论配一个证据入口 | 查看全部进入完整洞察列表，可按使用特征、变化、待调查记录筛选 |
| 用量趋势 | 一张趋势图，默认按周 | 切换 Token、估算费用与请求，以及日／周／月；完整用量调查进入用量统计页 |
| 使用分布 | 一组横向排行，默认项目维度 | 切换客户端、模型、工具及统计指标；完整排行使用共享分页 |
| Skill 使用 | 重点五项，列为名称、次数、会话数和趋势 | 展开完整排行；调查中分开查看显式调用和成功正文读取 |
| MCP 使用 | 重点五个服务器，列为名称、调用数、会话数和趋势 | 先进入服务器，再查看工具分布与具体调用记录 |
| 过程调查 | 失败、压缩、请求计时三个入口，当前入口显示摘要与少量记录 | 失败查看同轮次后续调用；计时按可比较分组进入分布和最长记录 |
| 使用画像 | 项目数、模型数、最长连续、单次用量峰值、资源种类 | 以紧凑的标签与数字配对呈现，点击可计算指标进入来源记录 |
| 代码活动 | 仓库摘要列表，每行保留关键活动、各自覆盖和热点入口 | 查看该仓库热点，或进入代码地图；覆盖基线及分析时间放在详情中 |

重点列表只保留对象、关键数值及动作。用轻量条形或趋势表达差异，具体日期、来源和分项按需打开。资源名称、模型名称与仓库名称保持原始内容，长名称支持查看完整值。

## 洞察与调查交互

洞察采用可扫描的短句，例如“近期请求数增加 24%”“一个项目占所选范围 Token 的 58%”“有 3 条已确认工具失败”。这些仅为合成文案示例，实际结论须满足规格中的数据条件。

每条结论默认保留必要的对象、数值与作用范围。“近期 30 天”等与当前年度范围不同的窗口须有简短标记；完整比较日期、两期原值和覆盖放入证据详情。结论可以折行，不能把关键数值截断。

调查遵循同一条路径：

```text
总览结论或排行
  → 数值与分布
  → 对应记录列表
  → 原会话事件 / 请求明细 / 仓库热点
```

- 汇总详情使用一层有界弹层，区域内通过页签或返回操作查看分布与记录。需要完整会话、用量或地图时进入现有页面，避免叠加多层弹窗。
- 资源调查的次数、会话数、分布和记录均保留同一范围；组合默认按会话，真实用户轮次作为局部切换项。
- 悬停与键盘聚焦只显示明细浮层。点击明确动作才施加筛选或进入证据，查看日期不会隐式改变整页范围。
- 全局范围只在顶部设置。模型筛选位于模型／用量区域内部，其局部范围通过区域标题及选中控件表达；六项概况继续保持全局范围。
- 返回总览恢复筛选、滚动位置、局部选择和焦点。当前报告与证据版本失配时显示重新加载入口。
- 日历通过可移动的键盘焦点访问日期；明细浮层支持键盘与触屏，Escape 关闭后恢复焦点。

## 文字与帮助

常驻文字保留页面标题、区域标题、指标名称、数据、坐标、图例及操作。标题下方不重复添加介绍句；每行记录不附加统一的解释段落。

每个分析区域合并为一个帮助入口，说明该区域的口径、公式、范围与可用操作。费用、Token、缺失和版本的具体依据进入对应详情；帮助支持鼠标、键盘与触屏。

需要区分的含义直接进入名称或状态：部分费用显示“估算费用小计”，部分 Token 显示“已记录 Token 小计”；历史范围的连续指标显示“截至区间末日连续活跃”。已知零值显示零，未知显示横线，缺口可按需查看。

## 响应布局

- 宽屏：六指标横排；活动与洞察并列；下方分析组双列。日历所需宽度与洞察可读宽度共同决定是否并列。
- 中等宽度：六指标为三列两行；年度活动通栏；重点洞察接在后面。分析组在内容可容纳时继续双列。
- 窄屏：六指标为两列三行，其余区域单列；日期独占一行，客户端与项目在下一行。局部控件自然换行。
- 全年日历在自己的容器中横向滚动，保留格子、月份和日期明细的可读尺度；首次显示包含范围末日的部分。
- 长表格在区域内滚动。触屏以点击打开明细，关键动作不依赖悬停；英文与长名称增加高度时不遮挡操作。

## 状态设计

| 状态 | 呈现与行为 |
| --- | --- |
| 首次读取 | 使用与最终区域结构一致的占位；准备信息集中在一处，不显示虚构数字或伪进度 |
| 筛选或更新中 | 保留上一份完整结果和布局，刷新位置显示进度；暂停旧数据下钻，完成后整体替换 |
| 更新失败 | 保留完整结果，在刷新附近显示明确错误及重试入口 |
| 范围内无活动 | 保留筛选与页面结构，集中显示“所选范围内暂无活动”，提供调整范围的动作；有依据的零值仍为零 |
| 某区域没有证据 | 区域内显示简短空状态及帮助入口；未知保持未知，不把缺失转成零 |
| 没有合格洞察 | 显示“当前范围暂无可生成的洞察”，仍可查看基础统计；不强制凑足五条 |
| 部分数值或无时间记录 | 名称与状态保留小计和未知语义，详细覆盖进入帮助或详情 |
| 仓库未就绪 | 仓库行显示未就绪及现有入口；不在总览自动登记或发起分析 |
| 证据版本失效 | 保留当前上下文，提供重新加载；新记录不能直接解释旧报告数字 |

## 组件与验收约束

筛选、项目搜索、日期、分页和帮助继续使用 `FilterSelect`、`ProjectPicker`、`DatePicker`、`ResourcePagination` 与 `HelpPopover`。图表、数值和显示文案沿用当前国际化及格式规则，原始对象名称保持原文。

实施验收至少覆盖：

1. 默认近一年与三项全局筛选可用，局部模型条件不改变其他分析区。
2. 首屏六项指标与活动、洞察的阅读层级清楚，字号与现有用量页一致。
3. 五条洞察及完整列表均可进入支撑记录，关闭或返回恢复范围、位置与焦点。
4. Skill 与 MCP 从次数和会话数进入分布、记录及原事件，统计对象与分母可查。
5. 深浅主题、窄屏、英文、长名称、未知值和大数值均能完整阅读与操作。
6. 鼠标、键盘和触屏均能访问筛选、日期明细、帮助和下钻入口。
7. 更新期间页面稳定，失败可重试，版本失效可重新加载。
