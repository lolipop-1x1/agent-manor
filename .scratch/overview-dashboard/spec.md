# 总览看板规格

状态：已按规格建议约定与推荐布局完成开发、测试及真实数据页面验收。实施结果见任务记录，运行证据及边界见[总览看板验收](../../docs/validation/overview-dashboard.md)。

页面布局与交互见 [design.md](design.md)，采用“节奏与洞察并列”。任务图见 [map.md](map.md) 的实施部分。后续[查询优化规格](../overview-performance/spec.md)覆盖本文的两期热点、完整洞察列表与集中读取约定；旧扩展规则保留为统计调查口径，不表示全部生成首页洞察。

## 目标

通过一个页面理解个人 Agent 工作环境的整体活动、用量投入、使用习惯与值得调查的变化，并从汇总进入具体记录。

总览同时覆盖整体复盘、个人使用画像和统计诊断。使用规模、频率和偏好描述已记录活动；任务效果与效率须有独立依据。

## 已确认事项

- 新增一级“总览”入口，保留独立的用量统计页。
- 总览提供跨模块分析；用量统计页继续承载用量、估算费用和请求明细调查。
- 洞察由本机统计规则生成，每条结论应能回查支撑记录。
- 首屏采用六项主指标：会话数、模型请求数、Token 总量、估算费用／小计、活跃天数和当前连续活跃天数。
- 首次进入默认展示近一年，即含今天的近 365 个本地日历日，强调个人使用习惯；明确地址中的时间选择优先。
- 首版覆盖整体概况、活动节奏、使用分布、工具与资源习惯、统计诊断和数据洞察。
- Skill／MCP 纳入次数、使用会话数、趋势和具体记录调查；用量变化与过程信号均纳入诊断范围。
- 展示各已登记仓库的活动摘要与热点入口，每个仓库保留自身覆盖基线。
- 将总览设为默认进入页，明确会话、地图或用量地址仍直达对应页面。
- 日期、客户端和项目控制整张总览，模型筛选仅作用于模型／用量区域；下钻和返回保留总览范围与位置。
- 会话数包含主会话与子会话，可查看拆分；一个主会话及四个子会话在范围内均有活动时计五个会话。
- 图表与个人画像均跟随所选时间范围，峰值和最长连续在该范围内计算；历史区间将连续指标标为截至区间末日连续活跃。
- 洞察与紧邻之前的同长度区间比较，并补充近期 30 天对前 30 天的变化；近期比较仅采用完整日期，缺少有效数据时不生成变化百分比。
- 资源调查从次数与会话数进入分布、使用记录和会话原事件，完整排行与记录按需展开。
- 活跃日包含有可靠事件时间的真实用户交互、子会话和自动任务活动，排除系统提示、注入正文及明确复制记录。
- 今天未结束且尚无活动时，当前连续记录可延续截至昨天的序列；历史区间严格检查末日。
- 洞察覆盖使用特征、变化及待调查记录，默认展示重点五条，完整列表按需展开。
- 慢请求先提供同类计时依据下的时长与吐字速度分布及具体记录，不自动判定性能异常。
- 首版洞察扩展为用量构成、集中度、资源习惯、委派、缓存、项目与模型变化、组合、失败过程、续用、输入走势、仓库热点和统计覆盖等十六项规则，具体目录与证据见下文。
- 新观测资源采用随后 30 个完整本地日期的后续观察窗口，未结束的窗口单列观察中，不推断安装或生涯首次使用。
- 资源组合默认按同一会话计算，可切换同一用户轮次；主子会话按自身记录计算，不自动解释为固定流程。
- 失败后的过程先调查同一会话、同一用户轮次中的后续同名工具调用，跨轮次通过原会话继续查看，不生成确定的重试率或恢复成功率。
- 采用稳健的小样本规则：次数与原事件可调查，小样本比例或偏好不进入重点；单条已确认失败或明确用量峰值仍可作为待调查记录。样本门槛按规则分别建议。
- 任务实际用时、推理强度、快速模式及成果评价列为后续数据支持项，首版聚焦可计算指标。
- 已确认按推荐的设计及统计建议约定进入实施，原始历史保持只读。

| 活跃日期与连续活跃 | 已有事件时间、请求日桶及用量活跃天数 | 按总览活动定义新增全局日期、会话与连续序列聚合 |
| Skill 与 MCP 使用 | 已有事件数、使用会话数、结果、趋势和分布 | 名称级统计与本地资源身份保留区别，不推算单个资源消耗的 Token |
| 工具使用 | 已有会话画像中的名称、调用和结果统计 | 全局聚合与工具分类口径需要补充 |
| 压缩与请求计时 | 已有压缩记录和部分请求计时证据 | 全局聚合、比较方式及合格样本范围需要补充 |
| 扩展洞察 | 请求分项、父子关系、资源事件和定位元数据可作为计算基础 | 新增跨请求、跨会话和两期聚合；已具备字段不表示已实现规则或所有历史均可计算 |
| 代码活动 | 已登记仓库各自提供活动、热点与覆盖结果 | 总览按仓库呈现摘要与热点，跨仓库不能直接平均覆盖率 |
| 任务用时与成果 | 有会话记录时间、过程事件及部分请求耗时 | 缺少统一任务起止和成果评价，记录跨度不足以表示实际任务用时 |
| 推理强度与快速模式 | 部分请求保存推理 Token，会话保留明确的执行类型 | 尚无统一可统计的强度或快速模式字段，不能从 Token 或执行类型推断 |

## 页面范围与建议层级

全部分析区域已纳入首版。以下排序已确认采用：

1. 范围与筛选：日期、客户端和项目，以及更新状态。
2. 整体概况：会话、模型请求、Token、估算费用、活跃天数和当前连续活跃六项主指标。
3. 数据洞察：重点五条，直接进入支撑数据与记录。
4. 活动节奏：日历、时间趋势及星期／小时分布。
5. 用量与使用分布：Token 组成、费用、缓存读取占输入比例，以及项目、客户端、模型和工具分布。
6. 资源习惯：常用 Skill／MCP、次数、使用会话数、趋势、分布与使用证据调查。
7. 过程调查：工具失败、压缩及有依据的请求计时。
8. 个人使用画像：项目与模型数量、最长连续活跃、单次用量峰值和资源种类，跟随所选范围。
9. 代码活动：各已登记仓库的摘要、热点与代码地图入口，覆盖率保留各自基线。

区域组织为连续分析页面，复用现有主题、共享控件和按需帮助。桌面分布与资源区域可并列，窄屏单列；密集表格在自己的区域内滚动，不为每个区域叠加独立卡片装饰或常驻解释。

## 主指标与活动口径

| 指标 | 统计对象与定义 | 缺失与下钻 |
| --- | --- | --- |
| 会话数 | 所选范围内存在自身有效活动的不同会话，主会话与子会话分别按身份计数；明确继承记录排除 | 可查看主／子拆分和会话列表；分叉会话的纳入及关系展示见建议呈现约定 |
| 模型请求数 | 沿用已识别的逻辑请求与用量事实，不从消息片段推算请求数 | 请求可能缺 Token，仍保留其请求身份；进入用量或请求记录 |
| Token 总量 | 同一请求集合的归一化总输入与总输出之和，缓存及推理不重复相加 | 分项不足时显示已记录 Token 小计，无可确认量时显示未知；进入请求明细 |
| 估算费用 | 同一请求集合按固定价格版本及现有计价规则估算 | 不全时显示估算费用小计，全部不可计算时显示未知，已知零值保留；进入费用依据和请求明细 |
| 活跃天数 | 所选范围内存在总览有效活动的不同本地日期 | 无可靠时间的活动不归日，覆盖细节进入帮助；进入日期活动记录 |
| 当前连续活跃 | 从范围末日向前计算连续总览活跃日，序列不越过范围起点；含今天的范围允许当天未活动时从昨天继续 | 历史范围显示截至区间末日连续活跃，并严格以该末日为终点；仅选择今天时的边界见建议呈现约定 |

总览有效活动包括真实用户请求、AI 回复与思考、工具请求与结果，以及明确模型请求和真实压缩过程记录。相同活动的多个来源投影不形成新活动；模型请求与消息只是不同查询投影，不能相加冒充新的交互。

系统与上下文记录、注入的指导正文、展开的 Skill 正文及已确认复制记录不单独构成活跃事件。Skill 的真实调用或读取工具仍按其实际执行事件计算活动；普通用户请求提到 Skill 时仍属于用户交互。无法判断性质的记录保留解析及覆盖边界。

日期归属使用事件发生时间及本机时区。会话摘要时间跨度、文件更新时间和索引导入时间不替代活动日期。同一会话跨日活动可分别进入多个日期，但整个范围内的会话数仍只计一次。

没有 Token 的真实会话活动仍可计入会话数与活跃日。用量页继续以已记录模型请求计算用量活跃日，两类活动指标在定义和帮助中明确区分。

最长连续活跃取所选范围内的最大连续日期序列；范围起点之前的活动不延长该序列。项目数来自范围内有效会话的已记录项目；模型数来自范围内已记录模型请求的原始模型身份；资源种类来自范围内使用证据。未知身份保留覆盖，不作为一个已知实体增加种类数。

单次用量峰值使用可确认的单个模型请求总 Token，完整总量与部分分项不混为同一峰值；同值按请求发生时间及稳定身份定位。请求自身最大输入可作为独立补充指标，不与总 Token 峰值混用。

## 时间范围与比较

- 默认起点为今天之前的第 364 个本地日历日，终点为今天。跨月、闰日和夏令时均按本地日期处理，不以固定小时数替代日历日。
- 日期、客户端、项目作用于全部历史分析；顶层六指标保持全局范围。模型局部筛选的区域与当前条件明确可见，不能静默影响活动、工具、资源或代码区域。
- 所选范围与紧邻之前的同长度日历区间比较，客户端与项目条件保持一致，局部模型比较也保持自身条件一致。
- 建议含今天的范围在变化比较中截至昨天，前期也使用相同完整日数；今天的已记录活动仍保留在当前概况和图表中。只有今天的范围不生成完整日变化结论。
- 近期变化使用截至昨天的最近 30 个完整日期及其前 30 个完整日期。建议仅在所选范围包含今天且覆盖近期窗口时补充，查看纯历史区间时不混入今天附近的数据。
- 比较保留两期实际边界、原数值与覆盖。前期为零时说明新增记录，不计算增长百分比；没有有效依据时不输出变化结论。
- 费用比较绑定相同价格内容版本，保留各请求实际适用的历史价格与计价状态。费用变化不能单独解释为用量变化或实际支出变化。
- 选择全部历史时，会话、请求、Token 和资源次数等总量可以纳入性质明确的无时间记录并单列覆盖；日期趋势、活跃、连续与日期比较仍只使用有可靠时间的部分。建议日期展示边界从最早有效活动日到今天；全部历史没有可确定的等长前期时不生成全范围环比，近期窗口仍按自己的日期范围计算。

含今天的范围在图表中可查看当天不完整数据，按需说明不完整日期；不通过常驻提示条占用页面空间。

## 资源使用调查

首版同时呈现使用次数与使用会话数，提供趋势、分布及具体使用记录调查。指标含义沿用现有资源使用口径：

- Skill 显式调用与成功正文读取分别记录；合计时称为使用次数，文字提及保留为弱证据。
- MCP 按服务器汇总工具请求，进一步查看具体工具；配置或工具声明的存在不增加使用次数。
- 使用会话数按发生使用证据的不同会话去重，同一会话内重复使用增加次数而不增加会话数。
- 成功、失败和未知结果分别保留。结果未知不默认为成功；正文读取与显式调用的结果分母保留区别。
- 名称级排行用于分析，具体本体与入口继续按现有资源身份调查，不能从排行名称直接执行管理写操作。
- 有日期筛选时只纳入具备有效事件时间的记录，缺时间和未关联记录的覆盖情况按需查看。

调查路径为次数与会话数 → 日期／客户端／项目／工具分布 → 具体使用记录 → 会话原事件。总览先呈现重点，完整排行和记录按需展开；Skill 分开展示显式调用与成功正文读取，MCP 先按服务器再进入工具。

顶层六项指标使用全局日期、客户端与项目范围。局部模型筛选的作用区域须明确，不能静默改变其他区域的分母。用量页继续按该页完整筛选计算。

## 洞察目录与证据

洞察由本机规则生成，使用稳定消息标识、参数及中英文目录；不读取正文来生成主题解释。每条保留类型、对象、指标、当前范围、对比范围、原数值、覆盖和证据入口。数据不足时不补足五条。

| 类型 | 首版内容 | 支撑记录 |
| --- | --- | --- |
| 使用特征 | 活动节奏、使用分布、资源广度与持续性、委派分布、资源组合和跨日续用 | 相同范围下的完整分布、日期桶、关系与事件集合 |
| 变化 | 会话、请求、Token、估算费用、活跃、缓存、项目／模型重心、资源后续使用、仓库热点和统计覆盖的变化 | 两期数值、有效分母、覆盖与对应列表 |
| 待调查记录 | 用量集中与峰值、已确认工具失败及其后续过程、压缩、输入量走势、响应时长及吐字速度 | 日期明细、逻辑请求、工具结果、压缩事件及计时依据 |

资源在前期未观测而当期出现时，只描述两个区间的已记录使用，不宣称用户首次安装或生涯首次使用。次数突出不表示资源有效或低效；同名资源不能自动归因到某个安装入口。

前几个项目、模型或资源的占比使用对应指标的完整已记录分母，声明未知身份、其余合计和部分量的处理方式。不同对象的会话数不可相加推算总会话数，同一会话可涉及多个对象。

重点五条优先选择近期变化明确、样本充分且可以进入具体记录的结论；稳定特征进入画像区域，失败、较大输入和热点变化进入调查列表。同一现象在不同区域的展示共享计算结果和证据，不重复凑数。类别之间的具体排序建议见呈现约定。展开完整列表后按三类查看，选择结论打开具体分布或记录，进一步定位原会话事件。详细计算依据收进帮助与详情。

### 已确认的扩展洞察规则

十六项均纳入首版规则目录，按所选范围和实际字段覆盖生成。每项分别保留统计对象、合格样本数量、缺失数量、比较范围和证据；不因目录完整而强制输出所有结论。

| 规则 | 统计口径与结论范围 | 证据与调查入口 |
| --- | --- | --- |
| 01 用量变化构成 | 在完整 Token 请求集合中拆分请求数量与平均单请求 Token 的变化；分别展示输入、输出及项目／模型构成。模型与项目归因是不同切面，不相加作为独立原因 | 两期请求数、均值、分项及相同维度的完整归因，进入新增量集中的会话和请求 |
| 02 少量会话的用量集中度 | 单个会话自身请求汇总后，统计前一个及前五个会话占已记录 Token 的比例，并查看单请求中位数和较高分位数。排名不使用父级整树总量重复计子会话 | 完整会话排行、请求分布、Token 覆盖和具体高用量请求 |
| 03 资源使用广度与频度 | 每资源的使用次数、不同会话数、每个使用会话的平均次数、活跃星期数及项目分布；广泛、集中和持续的特征分别用原数值支撑 | 资源详情、日期／项目分布和使用会话；显式 Skill 调用与成功正文读取可分别查看 |
| 04 新观测资源的后续使用 | 从所选范围内首次有时间的使用证据开始，观察随后 30 个完整本地日期是否在其他日期再次出现使用证据。已结束、位于范围内且有可用依据的窗口进入分母，观察中、范围未覆盖及覆盖不足分开 | 首条记录、窗口起止、后续记录及各状态资源数；不推断安装时间或使用效果 |
| 05 主子会话的用量分布 | 有自身活动且关系与子活动观测可判定的主会话中，统计具有范围内已确认子活动的比例；子活动不可判定的主会话单列。请求与 Token 另外按自身归属统计子会话占比 | 主子关系、各自请求与用量及会话树，保留多级委派与缺口；分叉不自动归入父或子 |
| 06 缓存与新输入变化 | 在客户端、原始模型及输入归一化口径一致、输入和缓存分项可计算的请求中，比较缓存读取占输入比例和非缓存输入量；缺失字段不作为零 | 两期合格请求、输入与缓存分项及有变化的会话，不单独裁定缓存变化原因 |
| 07 项目重心迁移 | 比较各本地月份及前后两期的项目活动会话、请求、Token 与占比；各指标独立计算，未知项目保留覆盖 | 月份与项目分布、前后期项目列表和相应会话 |
| 08 模型偏好与切换路径 | 项目内模型请求分布、同一会话按可确定请求顺序发生的相邻模型变化，以及主子模型组合分别计算；多模型分工不当作同会话切换 | 模型分布、请求顺序和原事件；未知模型或次序缺口不拼接为确定切换 |
| 09 MCP 内部工具依赖 | 每个服务器内实际观测到的工具种类、工具请求占比与使用会话数；未观测到的声明工具不虚构为零调用工具 | 服务器详情、具体工具分布与调用记录；配置声明和历史使用分开 |
| 10 常见资源组合 | 同一会话内不同资源的共现会话数，或同一真实用户轮次内的共现轮次数；一次会话或轮次对同一资源对只计一次 | 两个资源共同出现的会话／轮次及各自事件，不能从共现推断固定执行顺序 |
| 11 失败集中点与持续性 | 已确认工具失败按工具、服务器、客户端、项目与日期聚合，保留失败次数、涉及会话／日期、已知结果失败率及结果覆盖 | 可配对的失败结果、成功与未知数量，以及连续或分散的已记录失败日期 |
| 12 失败后的后续过程 | 定位同一会话、同一真实用户轮次中，失败之后出现的同名工具调用与结果；按顺序保留独立调用身份，相邻多次失败的共同后续记录只存一份 | 失败节点及该轮后续事件序列；后续成功只表示该调用成功，不证明此前任务恢复或调用为重试 |
| 13 跨日续用习惯 | 按真实活动日期计算每会话的不同活跃日期数、日期间隔，以及至少两个日期有活动的会话占有日期活动会话的比例 | 会话日期分布、跨日会话及自身用量；间隔不表示会话关闭或工作中断 |
| 14 会话内输入量走势 | 同一会话按确定请求顺序查看输入 Token 与可确认缓存分项，在客户端和模型一致的片段中标明压缩事件位置及前后已记录数值 | 请求序列、压缩原事件、输入与缓存分项；输入量不自动等同上下文占用，不认定压缩造成节省 |
| 15 仓库热点变化 | 同一仓库、同一分析结果和文件基线内，比较两个区间的读取、修改及相关失败热点；不同证据类别分别统计 | 仓库目录／文件排行、地图及原事件；反复读取不自动判为浪费，修改不表示最终 Git 改动量 |
| 16 统计覆盖变化 | 比较有时间请求的 Token、模型、工具结果和计时字段覆盖；无法归日的记录保留为本次报告整体缺口。来源移除或解析变化仅在有记录依据时说明 | 两期合格／缺失数量、来源诊断及实际版本，不把覆盖改善或来源减少直接解释为使用行为变化 |

### 扩展规则的共同计算约束

- 用量构成使用同口径的完整请求；部分或未知 Token 另列，不能把合格子集的变化宣称为全部历史变化。两期请求数均大于零时，总 Token 等于请求数乘平均单请求 Token；数量变化贡献采用数量差乘两期均值的平均，均值变化贡献采用均值差乘两期数量的平均，两项合计等于总量差。零基数只列原数值与新增量，不生成该拆分比例。
- 新输入仅在来源分项可归一化时计算，保留普通输入、缓存读取及缓存写入的关系。缓存写入不直接并入非缓存输入或重复加总；无法区分普通输入与写入时使用可确认的已记录分项名称，不补造新输入值。
- 同一资源的名称级身份沿现有规则处理，组合使用资源身份对去重，MCP 按服务器身份、Skill 按资源名称级身份组成资源对；服务器内部工具分布另行调查。同名本地入口不因此合并为一个管理对象。
- 后续观察窗口为首次观测日之后的第一个至第三十个本地日期，首次观测当天的重复使用不算后续再次使用。窗口必须完整落在所选范围内，且已到达完整日期终点；今天仍未结束时不作为已完成的第三十日。实际日期尚未结束的窗口标为观察中，已结束但超出所选历史范围的窗口标为范围未覆盖，不读取范围外记录补齐。窗口成熟只表示日期条件满足，实际采集缺口另列，不能据此断言三十天内的所有活动均被记录；已确认影响该资源后续观测的缺口阻止其进入后续比例分母，其他观测边界继续保留。
- 主子会话的活动、请求、Token 和资源只累计各自新增记录；各指标保留自己的分母。委派活动比例的分母排除分叉、关系不可判定及子活动观测不可判定的对象，不直接复用将非子会话统称主会话的筛选结果。已声明子目标却缺少子来源、可靠时间或关系依据，且没有其他已确认范围内子活动时，该主会话归未知覆盖，不当作无子活动。只要已确认至少一个范围内子活动，就可以判断其进入分子；其他缺失子来源继续单列。子用量占比按范围内可归属的请求计算，缺失子会话、关系不明及范围外活动分别保留，不借父级树汇总补入。
- 请求切换与输入走势使用可确定的来源顺序，不依赖消息上模型名称的简单计数，不从缺时间或次序歧义中补造相邻关系。主子记录不串成同一个会话序列；模型变化后的片段分别计算输入变化。
- 资源共现与失败后续调查使用会话自身的真实用户轮次，排除复制和注入正文；没有可靠轮次归属时可保留会话级调查，不能虚构轮次级组合或失败后续结论。失败后的范围内序列截断和未知结果明确保留。
- 所有规则遵守日期、客户端、项目全局范围。模型筛选仅改变模型／用量规则，不改变资源组合、委派活动比例、跨日活动、工具失败或代码区域；委派的请求／Token 占比等用量结果遵守局部模型范围，并保留与委派活动比例不同的分母。
- 代码热点前后比较绑定同一仓库当前文件基线，不将两个版本的覆盖率直接作差。稳定特征、变化和单条调查记录保留各自生成条件，不输出资源收益、任务完成率、确定重试率或实际工作时长。

### 稳健生成与建议样本门槛

小样本处理方式及以下具体数值已确认采用，不新增用户阈值配置。未达到门槛时，完整分布、次数和原事件仍可查看，不生成进入重点区的比例、变化或偏好结论。单条已确认失败与有明确依据的用量峰值继续允许进入待调查记录；数据不足不补足五条。

| 规则组 | 建议进入重点区的最低样本条件 |
| --- | --- |
| 请求用量构成、均值与分位数变化 | 两期各至少 20 个同口径合格请求；会话集中度结论至少 10 个可计算自身 Token 的会话，部分量单列 |
| 缓存变化 | 同一比较组两期各至少 20 个输入和缓存分项合格的请求；合格范围及缺失请求数保留 |
| 资源使用偏好与组合 | 偏好至少涉及 5 个使用会话；持续特征至少在 4 个不同星期有记录；资源组合至少在 3 个不同会话中共现，切到轮次层级后仍保留涉及会话数 |
| 新观测资源后续使用比例 | 至少 5 个日期窗口成熟且有可用后续观察依据的资源；观察中和覆盖不足分别列数量，不混入比例分母 |
| 委派、跨日续用和模型切换比例 | 对应统计对象至少 10 个关系、日期或请求顺序可判定的会话；两期比例变化分别满足条件 |
| MCP 工具占比与失败率变化 | 每个相关组至少 20 个可确认工具请求；失败率另要求至少 20 个已知结果且结果覆盖不低于 80%，两期变化各自满足条件 |
| 请求计时分布 | 每个客户端、模型、区间、依据与方法组至少 20 个合格样本；吐字速度继续另行满足既有输出量及计时门槛 |
| 项目、仓库及覆盖变化 | 采用对应指标的同口径合格样本，量化变化沿相应请求／会话门槛；具体文件事件、明确缺失和来源诊断允许直接调查，不用一个百分比门槛阻断原始记录 |

重点选择先检查计算依据、样本条件和证据可达性，再覆盖使用特征、变化及待调查三类。变化幅度只在相同指标和单位内排序，并保留有效样本数；同一对象的相同现象合并，不能将失败率、Token 差值和资源次数放入一个未经定义的统一分数。

## 诊断与洞察的计算边界

已核对当前事件和计时记录，以下约束沿用现有证据语义：

- 会话摘要的开始／更新时间表示记录跨度。总览的日期活动、时段分布和有活动会话数需要按实际事件时间计算，不能用会话跨度铺满中间日期，也不能用限量时间线近似全量统计。
- 用户角色记录可能承载展开的 Skill 正文。活动统计需要结合事件种类及资源、上下文和复制标记识别，不能只看角色。
- 工具结果按调用身份配对。已知结果失败率采用失败数除以成功数与失败数之和，未知结果数量和已知结果覆盖按需查看；分母为零时保留未知。
- 压缩记录按独立事件计数，不能把压缩次数自动转换成用户请求数或任务失败数。有明确模型请求与用量的压缩调用仍沿现有用量规则计算。
- 响应区间包含首字等待，输出阶段不包含；原生计时和历史估算保留各自依据。慢请求的分布不能直接复用吐字速度的样本门槛。
- 比较保留两个区间的原数值、时间、采集覆盖和价格依据。前期为零时展示新增数量或状态，不能生成无限增长；价格依据或覆盖变化对结论的影响须可查看。

慢请求按客户端、原始模型、计时区间、原生或估算依据以及具体计时方法分别提供分布及最长记录。同一客户端的不同计时方法不自动混合；方法、结束证据与样本覆盖在详情中保留。有效结束与合法时长是时长样本的基础；吐字速度继续使用其现有合格样本规则，不把低输出量请求筛选规则套给时长分布。首版不将分位数、较长时长或低速自动标为性能异常。

## 代码活动与结果一致性

会话、工具和历史资源分析绑定完整发布的会话索引；费用另外绑定价格内容版本和时区。代码区域绑定各仓库已经完成的分析结果版本及其文件基线，不把独立仓库的版本当成一份全局源码基线。

各仓库只展示对应范围的活动、热点与可回查的覆盖结果，不新增全局平均覆盖率。无登记、未分析、过期或不可匹配的项目归属保留各自状态，不能当成零覆盖，也不自动登记或分析仓库。

页面记录本次报告实际使用的版本组合。下钻使用报告的对应版本；版本失效时提供重新加载入口，不静默切到新版本解释旧数字。加载信息、来源检查时间、版本与各仓库分析时间通过帮助或已有详情查看。

## 更新、下钻与页面状态

默认入口、筛选与返回状态沿已确认方案执行。日期及排行的悬停和键盘查看只打开明细；施加筛选或进入证据使用明确动作。完整列表及明细使用有界弹层或现有专门页面，关闭或返回恢复总览范围、位置与焦点。

复用现有更新规范：保留上一份完整报告和布局，固定位置的进度图标表示读取中，暂停旧结果下钻；新报告准备完成后整体替换。失败保留旧报告并提供可重试错误。首次读取展示实际准备状态，无可用数值时不生成伪进度或空图。

| 统计更新 | 打开和“更新总览”读取最新完整结果并重算报告，不对全部仓库发起新分析；历史刷新和仓库分析继续使用既有入口。首版不新增总览自动刷新偏好 |
| 空值与覆盖 | 已知零显示零，未知显示横线；部分 Token 与费用保留小计名称，具体缺口按需查看；未分析仓库显示未就绪 |

颜色、数字、日期、Token 单位、费用格式、控件、帮助、焦点和窄屏行为复用现有设计与国际化约定。缺时间或未知值不能伪造热力图颜色；排行、微小图块和完整记录均有键盘访问路径。

## 术语与既有约束

领域术语沿用 [CONTEXT.md](../../CONTEXT.md)。统计约束沿用 [指标与证据口径](../../docs/design/metrics-and-evidence.md)、[会话统计口径](../../docs/design/session-history.md)与[全局用量与估算费用](../../docs/design/usage-statistics.md)。

- 统计描述本机可发现、可解析的历史，保留观测窗口和采集覆盖。
- 会话、会话轮次、模型请求与工具调用是不同统计对象；会话数量不直接代表完成任务数量。
- 用量与估算费用沿用现有去重及计价规则；估算费用保留小计与缺失语义。
- 父子会话的自身活动与复制历史分别识别，汇总不能重复累加继承记录。
- 活动时间、来源更新时间、响应区间与输出阶段保留区别；记录跨度不直接表示实际工作时长。
- 汇总与下钻绑定完整分析结果版本。刷新失败保留上一完整结果。
- 洞察描述统计事实及变化；因果解释、成果评价和改进效果需要额外证据。

## 后续数据支持范围

任务实际用时、推理强度、快速模式和成果评价列为后续支持项。后续需核对明确来源字段、实际覆盖及语义；首版不预留常驻不可计算指标，也不从记录跨度、推理 Token、自动任务类型或工具成功推断这些值。

历史统计保留原始来源的生命周期和可重建索引边界，不将长期使用画像扩展为永久历史归档，不新增模型解读或会话上传。

## 整体确认

核心目标、范围与统计选择已经逐轮确认。用户已确认采用完整规格的建议约定与推荐布局，并授权开发、测试及真实数据页面迭代。页面顺序、图表默认值、排序、日期边界细则、分叉纳入方式、更新入口和具体样本门槛均已纳入本轮实现；完成情况与验证证据记录于任务文件及验收文档。后续支持项不计入已实现能力。

## 验收方向

- 用户能在一个页面了解总体规模、时间变化、使用分布及值得调查的记录。
- 含义相同的指标在总览、用量页和明细中使用一致的定义和去重规则；活动集合或统计范围不同的指标明确区分。
- 每条洞察可复算、可定位对应记录，缺少比较依据时保留不可比较状态。
- 明确的零值与未知值可区分；数据缺失不补造完成率、工作时长或效率。
- 中英文、深浅主题、窄屏及键盘访问符合现有产品约定。

| 合成验收场景 | 预期结果 |
| --- | --- |
| 主会话及四个子会话都有自身活动 | 会话数为五，拆分明确，父级整树用量不再次累计 |
| 分叉只有继承历史，另一分叉有新增活动 | 前者不增加范围内活动会话数；后者仅自身新增活动参与日期与数量 |
| 某会话第一天和第五天活动，中间三天没有记录 | 活跃日期只计两天，不按摘要跨度铺满五天 |
| 缺 Token 的交互、只有自动任务或子会话运行 | 有可靠活动时间时仍计活跃，Token 保留自身缺失状态 |
| 只有系统提示或展开的 Skill 正文，或明确复制历史 | 不单独产生新的活跃日期；真实 Skill 使用证据按原口径统计 |
| 昨天连续三天有活动，所选范围包含这三天及今天，今天尚无活动 | 今天未结束时显示三，今天有活动后显示四；纯历史末日无活动时显示零 |
| 只选择今天，今天尚无活动但昨天有活动 | 按建议的范围边界显示零，不读取范围外连续记录；今天有活动后显示一 |
| 范围起点之前已有连续活动 | 当前与最长连续不越过所选范围起点 |
| 前期零使用、当期五次使用 | 展示新增五次及两期边界，不输出无限增长或生涯首次使用 |
| 同一 Skill 在一个会话调用三次、成功正文读取两次 | 显式调用三、成功读取二、合计使用五、使用会话一，弱提及不混入 |
| 工具结果为成功八、失败二、未知五 | 已知结果失败率为 20%，未知五保留，已知结果覆盖为 10/15 |
| 缺时间的用量、活动或资源记录 | 有限范围不归日；全部范围按各指标规则保留小计与覆盖，不虚构日期 |
| 含今天与纯历史两个比较范围 | 含今天的变化只比较完整日期；历史范围不混入当前近期窗口 |
| 响应区间、输出阶段、原生计时和估算，以及同客户端不同计时方法并存 | 按区间、依据及方法分组，结束证据与覆盖可查，不生成混合速度或自动异常结论 |
| 两个仓库基线不同，其中一个未分析 | 分别展示，不生成全局平均覆盖率，未分析不作为零 |
| 局部模型筛选及明细分页 | 不改变其他区域范围，分页不改变完整统计、洞察或分布分母 |
| 刷新失败或下钻时版本失效 | 保留旧报告，提供重试或重新加载，不能用新记录解释旧数字 |
| 前期 20 个完整请求各 100 Token，当期 40 个完整请求各 150 Token | 总量从 2000 到 6000；数量变化贡献 2500、均值变化贡献 1500，两项合计 4000，部分请求不混入分母 |
| 同一资源使用 200 次但仅三个会话，另一资源 50 次分布在二十五个会话 | 分别呈现频度与广度，不把调用最多自动描述为最普遍使用 |
| 新观测资源在首日多次使用，随后没有已记录使用；另一资源在第二日再次使用 | 前者首日重复不计后续再次使用，后者计入；两者窗口成熟及采集覆盖仍单独检查 |
| 十个新观测资源中六个窗口成熟、三个观察中、一个覆盖不足；成熟资源中四个再次使用 | 成熟可用分母为六，后续比例为 4/6；观察中三和覆盖不足一单列，不解释为停用比例 |
| 选择历史区间，某资源的三十日窗口在真实日期上已经结束但超出所选末日 | 标为范围未覆盖，不当作观察中，不读取所选范围外后续记录，不进入比例分母 |
| 两个资源在一个会话重复共同出现，另在其子会话也共同出现 | 会话层共现数为二，各自去重；轮次层按各自真实轮次计算，不把父子串为一个轮次 |
| 某工具本轮失败后出现新的同名调用并成功，下一轮再次调用 | 展示本轮独立失败与后续成功调用；下一轮从原会话查看，不输出确定重试或任务恢复结论 |
| 未知模型夹在两个已知模型请求之间，另有子会话使用不同模型 | 不跨未知片段生成确定切换；子会话模型作为分工单列 |
| 六个主会话中三个有子活动，其中一个分叉和一个关系未知对象另有活动 | 委派活动比例为 3/6，分叉与未知不混入分母；该小样本比例不进入重点，原数值仍可查 |
| 六个主会话中两个确认有范围内子活动、两个确认无范围内子活动、两个声明子目标但缺来源或可靠时间 | 可判定分母为四，比例为 2/4，未知覆盖二单列；不把缺失子来源当成没有子活动，小样本比例不进入重点 |
| 某工具只有一次调用且已确认失败 | 可调查该失败事件，不以 100% 失败率作为重点结论 |
| 同组前后计时分别有二十个合格样本，其中部分为输出阶段 | 不混合计时区间、依据或方法，各组独立检查门槛；单条最长记录仍可调查 |
| 两期字段覆盖不同，部分记录没有时间，来源另有明确移除诊断 | 展示两期可归日覆盖与报告整体无时间缺口，不硬分配无时间记录，不把缺失来源解释为用户减少使用 |
