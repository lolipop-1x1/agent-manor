# 总览看板需求地图

状态：核心决策、洞察扩展与调查规则已确认，完整规格及具体建议门槛待整体确认。

规格入口：[spec.md](spec.md)。页面设计草案：[design.md](design.md)，布局等待确认。

## 已作决策

1. 总览同时覆盖整体复盘、个人使用画像和统计诊断。
2. 新增一级“总览”，保留用量统计页。
3. 使用本机统计规则生成可回查的洞察。
4. 首屏采用会话数、模型请求数、Token 总量、估算费用／小计、活跃天数和当前连续活跃六项主指标。
5. 默认时间为含今天的近 365 个本地日历日。
6. 首版纳入全部分析区域，Skill／MCP 同时支持次数、使用会话数、趋势与证据调查。
7. 纳入各已登记仓库的摘要和热点，保留各仓库自身基线。
8. 总览作为默认进入页，明确地址仍直达对应功能。
9. 日期、客户端和项目全局生效，模型局部生效，下钻和返回保留范围与位置。
10. 会话数包含主会话与子会话，保留拆分，继承活动排除重复统计。
11. 图表与画像均跟随所选范围，历史连续指标明确以区间末日为终点。
12. 使用紧邻之前的同长度区间作比较，补充完整日期上的近期 30 天变化。
13. 资源按次数、会话数、分布、记录和会话原事件调查，完整排行及记录按需展开。
14. 活跃日按真实用户交互及 Agent 活动计算，包含子会话与自动任务；系统、注入及明确复制记录排除。
15. 含今天的范围允许当天未活动时延续昨天；历史区间严格以末日为终点，序列不越过范围起点。
16. 使用特征、变化及待调查记录三类洞察都保留，默认重点五条并提供完整列表。
17. 慢请求按可比较的计时依据展示分布与记录，不自动判定性能异常。
18. 缺少统一依据的画像项列为后续支持范围，首版聚焦可计算指标。
19. 将十六项扩展洞察纳入首版规则目录，按实际数据条件生成，不强制输出全部规则。
20. 新观测资源后续使用采用随后 30 个完整本地日期，成熟、观察中与覆盖不足分开。
21. 资源组合默认同一会话，可切换同一用户轮次，主子按自身记录去重。
22. 失败后的过程先调查同一会话、同一用户轮次的后续同名工具调用，不认定确定重试或任务恢复。
23. 采用稳健小样本处理，保留原数值和事件；小样本比例或偏好不进入重点，明确失败与峰值可继续调查。
