# 完善服务商和历史价格匹配

Type: task
Status: resolved

## 范围

精确服务商价格、服务商作用范围的自定义价格、按请求时间选取有效历史价格，以及当前快照回退状态。用户配置兼容，公开目录网络失败保留本地缓存。

## 验证

合成模型验证覆盖优先级、生效边界、缺少历史或时间、免费与未定价、缓存版本更新及后台统计一致性；管理操作使用隔离合成数据。

## 结果

请求服务商精确选价，全局及服务商手动覆盖按身份共存，编辑和恢复不删除其它覆盖。新增明确日期历史目录和独立成功缓存，按请求时间解析；未知约束、缺时间或缺区间回退当前快照并标记。首次升级无历史缓存仍检查网络，失败限频；历史缓存内容版本校验拒绝损坏数据。

33 项费用接口测试通过，118 项浏览器回归包含管理写操作、历史失败、API 基准证据和中英文窄屏，全部使用隔离合成数据。已核验官方原生 API 渠道支持带原渠道标记的精确模型估算基准，精确自身单价及用户设置仍优先；订阅与未知渠道不自动借用其他服务商 API 价格。当前网络历史数据仅覆盖明确日期条目，未匹配价格仍保持未知。
