# 请求用量与费用准确性修复

## 目标

修复已记录输入漏计，依据原始总量确认推理与缓存的包含关系，保留有效的空正文和压缩请求。费用按已记录服务商、模型和发生时间匹配，用户自定义价格具有最高优先级。

## 验收

- ZCode 有效输入不因缺少供应商补充元数据而丢失；分项冲突仍显示缺口。
- OpenCode 优先依据有效总量判定推理是否已包含在输出中，不重复相加。
- 复制、继承、压缩、空正文以及来源副本规则有合成回归；跨来源覆盖差异不作为计算误差。
- 明确服务商的请求精确匹配；同模型多服务商自定义价互不覆盖，无服务商的全局自定义价保持最高优先级。
- 有有效日期历史价格时按请求时间取价；缺历史或时间时明确采用当前快照估算，不伪造生效日期。
- 解析规则、用量事实和价格变化能使对应派生缓存失效；原始历史不回写。
- 公开验证记录仅保存方法、结果及支持边界，真实数据保留在本机忽略目录。
