# CLI 核心字段与完整字段

Status: resolved

## 范围

默认响应按命令用途明确列出核心字段，`--full` 保留完整字段；`--json` 只切换格式。会话列表每条保留 id、title、client、project、updatedAt，必要的生成标题描述用于中英文显示。顶层保留版本与分页。规模、上下文、模型配置、原始来源、关系和诊断通过专用详情读取。

核对知识和仓库 CRUD，同样收紧列表、单条读取及写入结果；读取单条知识保留正文，历史快照与审计通过专门命令或完整模式读取。人工授权使用完整精确预览，不受输出投影影响。

## 验证

- 用严格字段白名单断言复现当前摘要仍泄漏非核心字段，而非仅判断响应字节。
- 验证默认与完整模式、旧后台响应兼容、中英文、分页和正文读取。
- 隔离合成数据执行 CLI 测试与安装包实际调用，检查全局安装与后台版本是否一致。

## Answer

默认会话列表收紧为五个核心字段，知识、资源及仓库按查找、正文读取、写入确认和历史目录区分返回字段。知识详情保留紧凑来源锚点；本地资源按本体 ID 读取入口详情，再以入口 ID 预览管理。完整字段模式、错误、版本、分页及授权预览均保留。

源码全量 1652 项、CLI 37 项、包外实际命令 21 组、安装冒烟、类型、构建、中英文及公开检查通过。独立只读复核没有剩余功能问题。模型验证使用本机合成接口；全局安装在无在途任务时受控更新，实际核对默认五字段、默认分页和固定版本全量读取，未修改个人模型配置。
