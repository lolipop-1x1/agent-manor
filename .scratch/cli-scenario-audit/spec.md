# CLI 全命令场景与默认字段审计

Status: resolved

## 目标

覆盖当前实际注册的 126 条业务命令及根级默认动作，按查找、正文/证据读取、统计、任务跟踪、配置和管理场景逐项判断默认字段用途。区分必须保留、默认省略与显式完整读取，不以响应体积单独判断字段价值。

## 执行

1. 从 Commander 生成完整命令清单，对照后台实际返回及现有字段投影。
2. 按命令记录保留理由、冗余字段、固定版本回读路径和授权/错误边界。
3. 对剩余冗余输出补充可复现回归，再按场景精简；明确读取的正文、证据、日志及授权预览保留所需内容。
4. 验证默认与 --full、分页、状态读回、中英文和实际安装包，更新场景矩阵与配套 Skill。

已有核心字段约定见 docs/design/cli-responses.md。原始验证输出只留在本机忽略目录，公共用例使用合成数据。

## Answer

126项逐条审计已完成，详见 command-audit.md：18项调整、73项保留摘要、35项保留明确读取内容。覆盖活动正文、覆盖列表、抽取预览、用量、资源、偏好与生命周期；人工授权和原始证据路径保留。

1659项完整测试、38项 CLI 测试、24组包外命令场景、12项 Web/CLI 兼容复验，以及类型、翻译、构建、公开检查和最终包安装检查通过。模型仅使用本机合成 HTTP fixture。Web 不传 response 的请求与既有 summary=true 请求保持原契约；复核发现的双重摘要未知计数问题已修复并回归。
