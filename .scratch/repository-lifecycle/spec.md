# 仓库删除与会话项目登记候选

用户已确认完整方案，实施直接在 `main` 进行。任务依赖见 [任务图](map.md)，实现与验收结果随任务记录更新。

## 已确认

- 代码地图需要支持删除已登记仓库，并清理该仓库的全部专属数据库记录：登记、分析结果版本、来源与映射缓存、任务记录、手动来源关联及分块正文。
- 全局会话库与资源数据保留，本地 Git 目录及原始历史文件保留。删除操作不改变会话来源的生命周期。
- 登记弹窗提供来自会话库的项目选项，同时保留手动输入及修改绝对路径。选择项目后由用户点击“登记并分析”。
- 支持在分析任务排队或运行中删除仓库，取消该仓库的旧任务并阻止旧结果写回；其他仓库和全局会话任务继续执行。
- 候选取全局会话项目，支持名称与完整路径搜索，不列“无项目”。在提交时校验 Git 路径，子目录归到所属根目录，不同 worktree 独立登记。
- 已登记候选显示标记；提交时若解析到已登记仓库，直接切换到已有仓库，不重复登记或启动分析。候选列表只标记与已知登记路径对应的项目，不为候选批量扫描 Git；子目录或路径别名在提交解析后识别已有仓库。
- 仓库下拉菜单底部增加“删除当前仓库”。确认弹窗展示名称、完整路径及清理与保留范围，点击一次明确的“删除仓库”按钮，无需输入仓库名称。
- 删除当前仓库后切换到现有列表中的第一个剩余仓库；没有剩余仓库时回到登记空状态。

## 实施前的实现证据

- 仓库接口只有登记、查询、刷新、清缓存并重建，没有删除登记接口。
- 仓库专属数据保存在 `repositories`、`manual_associations`、`jobs`、`versions`、`source_cache`、`mapping_cache`、`tracked_sources` 与 `payload_parts` 中；当前外键没有自动级联删除。
- 全局会话索引与代码地图共用数据库文件，但使用独立的 `session_*` 表；资源管理状态有独立存储。
- 地图与会话刷新共用 Worker，任务没有按仓库取消的接口；同路径重登可能复用原仓库身份，因此删除与旧任务发布之间需要明确并发边界。
- 会话库摘要状态的 `projects` 字段是当前完整索引中的非空项目路径去重列表，不受页面客户端筛选限制；路径不保证当前有效或属于 Git 仓库。
- 现有登记解析会将仓库子目录归到 Git 根目录；不同 worktree 按工作区根目录及 Git 共享目录形成独立身份。
- 项目选择可复用 `ProjectPicker`，删除确认可复用代码地图已有 Radix 弹窗；当前无需新增组件体系。
- 以上是需求访谈阶段的源码与 ADR 静态证据；本次实现和运行验收结果见各任务记录。

## 取消语义与最小实现方案

“立即删除”表示不等待整个分析结束即可完成仓库注销和数据库清理。已排队的旧任务跳过执行；运行中的任务在检查点尽快退出。已进入的同步解析、映射或 SQLite 事务不能通过取消消息瞬时打断，但取消后的旧结果必须无法发布。删除后可立即重新登记同一路径，新分析按既有 Worker 队列调度。

- 删除时收集旧任务 ID，撤销该仓库旧任务，在事务内清理全部专属数据。排队、运行、取消回报和失败处理都按旧任务 ID 区分，不能仅按仓库 ID 取消，以免误伤重新登记的新任务。
- 任务 ID 每次新建，不随仓库同路径重登复用。发布事务在任何版本或缓存写入前，检查任务仍存在、属于目标仓库且仍在运行；旧任务行已删除即拒绝发布，无需另增仓库登记代次。
- 若发布事务先提交，随后的删除清掉其结果；若删除先提交，旧发布因任务不存在而退出。检查与写入须处于同一事务。
- 缺失的旧任务作为取消结果处理。Worker 队列、完成通知、失败处理与等待任务的调用者均须正常收束，不能因旧任务缺行破坏其他工作。
- 删除后的旧任务查询遵循不存在对象的行为；取消结果不永久写回已清理的任务表。重登重新分析，旧任务历史和手动来源关联不自动恢复。
- 项目候选按需读取当前会话索引，不为打开登记弹窗自动触发全量历史刷新。加载失败或列表为空时，手动路径输入仍可用，错误与重试入口直接可见。

## 实施与验收

1. 数据清理与任务取消：实现单仓库事务清理和任务有效性检查。
   - 验证全部专属表清理、其他仓库数据及全局会话／资源数据保留、删除失败回滚、删除后重登、旧任务不可发布。
2. 队列与并发：按旧任务 ID 取消排队及运行任务，安全处理完成和失败回报。
   - 用可控任务复现排队删除、运行删除、发布与删除的两种顺序、立即重登；检查其他仓库及会话任务能继续完成，等待调用者不悬挂。
3. API 与界面：增加删除接口、菜单与确认弹窗；登记复用 `ProjectPicker` 并保留路径输入，处理重复登记和过期请求。
   - 验证无效路径、子目录归根、worktree 区分、已登记复用、候选空或失败、删除后切换与空状态、另一页面持有已删除仓库时的状态恢复。
4. 完整检查与真实浏览器：使用隔离合成资源，覆盖中英文、深浅主题、键盘、名称／路径搜索、长列表及窄屏。
   - 完成类型与翻译检查、必要自动测试、构建、公开内容和空白检查。真实数据、实际截图及输入只留在本机。
