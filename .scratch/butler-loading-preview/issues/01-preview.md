# 独立管家倒茶动效

Type: prototype
Status: resolved

## 目标

让用户确认管家形象、倒茶动作和小尺寸辨识度。

## 验证

浏览器查看桌面与窄屏，检查暂停恢复、深浅主题、减少动态效果和倒茶时壶嘴到杯口的连接。

## Answer

- 已制作独立单 HTML 预览，包含放大、120px、88px 与 24px 紧凑版。
- 两条手臂分别从左右肩伸出；两侧均采用遮住机械结构的外套袖子，提壶前臂、袖口、手与茶壶同步运动。
- 浏览器抽查循环中的九个位置，肘关节持续对齐；倒茶阶段壶嘴、茶流与杯口对齐。
- 暂停、继续、重播、深浅主题、390px 窄屏及减少动态效果检查通过。
- 预览文件与浏览器截图位于 `.local/previews/butler-loading/`，未接入应用页面。

## Comments

- 后续应用接入已在 [02-integration.md](02-integration.md) 完成，本任务的独立预览保留用于造型复核。
- 右臂肩部反馈：将右袖与外套合并为连续外轮廓，移除贴在衣服表面的圆头臂段及外露肘关节，袖口与手套沿托盘姿态衔接。
- 两侧肘部一致性反馈：移除提壶侧的轴承图形，按先画外边、后填色的顺序合并两段袖子，覆盖肘部内部的重叠线；内部转动轴保留在动画变换中。
- 手部姿态反馈：简化提壶侧手套与壶把的交叠，缩短袖口；托盘侧改为四指朝前、掌心向上的托举轮廓，拇指贴近盘底。
