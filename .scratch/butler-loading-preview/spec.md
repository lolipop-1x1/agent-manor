第一阶段制作独立的 SVG 与 CSS 预览，形象和动作已确认。第二阶段按用户授权封装共享 Loading 并接入应用，沿用现有数据加载逻辑。

- 沿用 README 管家的圆角脑袋、天线、微笑和领结，补充倒茶姿态。
- 展示提壶、茶流、收壶与热气的循环，以及标准和紧凑尺寸。
- 提供深浅色、暂停与重播，遵循减少动态效果偏好。
- 验证浏览器呈现、暂停恢复、窄屏、主题与茶流落点。

预览文件放在本机忽略目录 `.local/previews/butler-loading/`。
