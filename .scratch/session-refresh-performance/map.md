# 会话刷新性能任务地图

- 当前任务：[02 刷新范围与快速检查规格](issues/02-refresh-scope-requirements.md)
- 已完成任务：[01 发布性能与一致性](issues/01-publish-performance.md)
- 边界：来源只读、完整全局版本原子发布、失败保留上一版。任务 01 采用完整来源校验；新阶段经 R2 确认改为默认快速检查并保留完整校验入口，不能把快检描述为逐字节核对。

## 已作决策

- R1：首版只做 Agent 范围选择与未变来源快速跳过，按会话更新和追加消息续读后续处理。
- R2：默认快速检查，另提供完整校验；完整校验不清缓存，内容相同仍可复用。
- R3：主按钮跟随当前客户端筛选，菜单可刷新全部；首版不独立多选 Agent。
- R4：进度和结果标明范围及方式，各 Agent 保留自己的最近成功检查时间与方式。
- R5：完整依赖可确认才快速跳过；缺记录、依赖未知或变化回退到内容检查，并说明回退情况。
- 局部刷新保留范围外来源与检查状态，任务按范围和方式区分，串行执行时基于最新已发布版本。
- 术语已补入 [CONTEXT](../../CONTEXT.md)；候选架构决定见 [ADR 0006](../../docs/adr/0006-scoped-session-refresh-verification.md)。

## 待确认

- 快检实际覆盖格式和性能提升须在实现阶段核验，不从旧版性能测量推断。

## 已完成
