# 刷新入口与状态交互

Type: task
Status: resolved
Blocked by: 02

## 目标与验证

负责 Web／CLI／API 范围及方式参数，任务按参数去重；复用 Radix 菜单，显示任务范围方式和各 Agent 最近成功检查。验证参数校验、旧调用与键盘鼠标操作。

具体行为与边界见 [规格](../spec.md)。

## Answer

- Web 主按钮跟随客户端筛选，Radix 菜单提供全部快速检查与当前／全部完整校验；任务卡固定提交范围及方式，显示复用、解析、缺失和回退原因，各客户端单独记录成功检查时间。
- HTTP 请求严格校验 `client`／`mode`，旧的无参数调用保持全部快速检查；CLI 增加 `--client`／`--mode`。清缓存仍为全局完整重建。
- 单队列只复用相同范围、方式与清缓存语义的任务；不同范围排队执行时保留最新已发布结果。
- HTTP／CLI 与队列回归通过，前后端类型检查、构建通过；真实浏览器及全局历史验收由任务 06 汇总。
