# 最近七天复盘首次计算优化

## 目标与范围

定位真实历史首次建立七天统计事实的瓶颈，保持当前指标、样本、窗口、价格、版本、详情与缺失语义，针对实测瓶颈优化。直接在 main 开发，不改变产品布局或用预热冒充首次成绩。

## 验收

- 同一真实索引版本、价格、日期、时区和筛选建立空派生库，分别记录源读取、事实落盘、聚合、计价及完整耗时。诊断脚本以首次计算低于十秒为反馈目标，最终同时报告实际数字。
- 优化前后的摘要、详情与记录集合校验一致；覆盖原始源投影与已有窄事实两条路径。
- 新增能复现实际低效路径的必要回归，相关自动检查通过。
- 以真实历史重新测 HTTP 首次／重复，以及真实页面从导航开始到复盘指标可见和页面主要分区就绪的耗时，说明索引和缓存条件。
- 原始历史只读。真实输入、标识、SQL计划和截图仅保存在本机 `.local/`，公开记录只保留方法与结论。
