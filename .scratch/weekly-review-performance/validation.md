# 七天复盘首次计算验收

## 方法

源索引采用真实留存历史。受控对照绑定相同索引版本、价格、完整七日范围、时区和筛选，各次创建空的复盘派生库。真实 HTTP 和浏览器测量分别备份并清空复盘派生库及复盘结果缓存，重新启动服务；其他总览缓存保留。这里的首次指应用层没有复盘事实与结果缓存，不表示清空操作系统文件缓存。测量时不并行运行测试。

真实历史、原始会话身份、完整响应、查询计划、CPU 采样及截图仅保存在本机，不进入公开仓库。原始会话文件未修改。

## 确认的瓶颈与修改

- 原轮次边界查询扫描整个候选会话的消息与正文，SQL 采样中该路径耗时约十三秒。复用校验通过的总览窄边界元数据，源索引仅按消息身份恢复明确结束标识与行号；仅为有关轮次恢复需求短预览。
- 缺少轮次身份的请求使用带 OR 的相关子查询，逐请求扫描整个会话。改为复合身份定位，保留多轮次关联的歧义；已有窄请求事实按需复用，缺失身份才回查原请求。
- 子 Agent 不组装核心用户指标未使用的完整轮次、正文长度和工具序列。用户与子 Agent 派生窗口隔离，身份在新版本变化时正确重建。
- 每三十二个来源共用派生写事务；本地活动日期按七个真实日界限投影，避免逐事件时区格式化。可选缓存损坏时回退原始源事实。

## 性能结果

| 场景 | 结果 |
| --- | --- |
| 同版本受控空派生库，优化前 | 30.58 秒 |
| 同版本受控空派生库，优化后 | 14.92 秒，减少约 51% |
| 同版本持久派生事实重读与聚合 | 1.89 秒 |
| 真实独立 HTTP 首算 | 20.42 秒 |
| 真实浏览器两次空复盘缓存的复盘请求 | 13.43 秒、10.79 秒 |
| 同版本 HTTP 缓存命中，三次 | 34.4、29.0、28.3 毫秒 |
| 页面导航至十八项复盘指标可用，两次 | 14.00 秒、10.96 秒 |
| 最后一轮冷复盘页面，全部总览分区就绪 | 10.97 秒，其余分区已具备缓存 |
| 最后一轮缓存命中页面，复盘／全部分区就绪 | 0.25 秒／0.51 秒 |
| 最后一轮冷复盘首次打开步骤详情 | 129 毫秒 |

首算期间二十次并行状态读取全部返回成功，最慢 37.5 毫秒。实际首算仍有磁盘和系统缓存波动，目前不能保证十秒内完成；最初的十秒诊断目标未达到。主要剩余成本是准备候选来源的边界、必要需求长度与窄请求事实，聚合计价约半秒。

## 正确性与运行检查

- 受控对照的完整摘要、十三类首屏详情以及全部记录集合的哈希一致，不只比较总量。
- 新增跨周缺轮次关联与歧义、旧正文按需预览、可选缓存 JSON 损坏、子 Agent 身份变化和夏令时活动日回归。
- 全量 981 项通过；复盘真实浏览器十八项指标与四组布局齐全，步骤分布详情可打开，无页面运行错误或失败的总览响应。
- 复盘合成浏览器 35 项通过，含筛选、窄屏、中英文和下钻。
- 类型与国际化检查、构建、公开内容检查及 diff 检查通过。
- 全量测试首次默认并发运行时，既有空闲 Worker 身份断言遇到回收时序失败；单独重跑通过，限制四文件并发的完整重跑全部通过，未修改该测试或无关生产代码。
