# Skill 使用统计补全

兼容 Codex 命令返回的已核验输出字段。Skill 使用证据与精确源码行范围分开处理：保留原生调用和来源，对可确认正文的多 Skill 读取分别记录，同一调用的相同 Skill 去重；失败、未执行、空返回、纯提及、搜索和无法确认的混合返回不补计数。

测试边界为日志解析、发布后的资源统计／证据接口、会话画像及正式页面。一次真实工具调用保持一次工具调用，新增资源证据不增加轮次、消息或工具数。兼容旧单资源消息和已保存身份。

升级解析规则并通过标准刷新回补受影响历史。真实原始日志只读，管理数据、收藏及恢复材料保留。实际页面核对目标资源的事件身份、来源行、会话数及去重；公开代码和夹具使用合成数据，真实对账留在本机忽略目录。完整检查通过后直接推送 main，保留其他任务改动。
