# 资源接口加载优化验收

2026-10-17。Skill 与 MCP 使用相同实现。对比基线为本次修改前的主干产物，使用同一本地服务、正式构建及 Chrome 实际页面。原始输入、请求明细、版本标识及截图仅保存在本机忽略目录。

## 改动

- 概览和位置读取轻量详情，不等待历史详情与证据。
- 使用记录并行读取摘要与证据，固定同一已发布版本；证据分页复用已取得的摘要。
- 详情与证据沿用只读 Worker；默认摘要不传输完整诊断，展开缺口时再读取并支持失败重试。
- 同版、同类型、同客户端及项目范围复用无正文事件元数据，日期变化重算统计。最多 4 个范围、合计 64 MiB、单范围 32 MiB 的保守估算预算；超限回退原查询，不缓存前缀。
- 版本变化清理缓存；旧来源身份与项目筛选的交集保持原语义。原完整接口继续兼容。

## 实际页面耗时

均为单次测量，不代表跨设备分位数。点击资源至概览可用，以及概览至完整使用记录可用分别计时；合计不包含人为停留和截图时间。

| 操作 | 优化前 | 优化后 | 等待减少 |
| --- | ---: | ---: | ---: |
| Skill 点击资源至概览可用 | 1,830 ms | 72 ms | 96.1% |
| MCP 点击资源至概览可用 | 2,331 ms | 31 ms | 98.7% |
| Skill 打开资源并进入使用记录，合计 | 1,866 ms | 287 ms | 84.6% |
| MCP 打开资源并进入使用记录，合计 | 2,374 ms | 237 ms | 90.0% |

旧版概览已经等待历史与证据，因此单独点击使用记录仅 36／43 ms；新版将这部分成本移到首次点击，分别为 215／206 ms。对比完整阅读路径而非只比较第二次点击。

页面点击的详情响应体：Skill 由 1,689,615 B 降为 6,328 B，历史摘要另取 10,969 B；MCP 由 1,694,212 B 降为 3,183 B，历史摘要另取 18,711 B。证据页保持原有内容。完整诊断仍可按需读取。

## 日期范围与缓存

全历史元数据已加载，首次查询此前未访问的同一日期范围；两版使用相同历史快照与日期边界。

| 请求 | 优化前 | 优化后 | 等待减少 |
| --- | ---: | ---: | ---: |
| Skill 首次范围查询 | 4,602.6 ms | 260.6 ms | 94.3% |
| MCP 首次范围查询 | 2,893.3 ms | 134.3 ms | 95.4% |
| Skill 重复范围查询 | 28.2 ms | 26.5 ms | 已有缓存保持快速 |
| MCP 重复范围查询 | 8.4 ms | 8.2 ms | 已有缓存保持快速 |

新进程实际页面首次清单等待也观察到减少（Skill 7,114 → 2,966 ms，MCP 4,350 → 817 ms），但操作系统文件缓存与初始化条件会影响该结果，不将全部差额归因于代码。

重启后直接访问使用摘要的额外探测，Skill／MCP 冷请求约 5.16／2.66 秒，暖请求约 135／118 ms；同期轻量状态请求最大约 321／7 ms。首次盘点、首次 SQL 读取与缓存构建仍有成本，本次未承诺所有冷请求低于 1 秒。

## 计数一致性

固定已发布历史快照逐项对照，而非直接比较持续增长的当前索引。

- 全历史统一清单的 750 个 Skill、27 个 MCP，及指定日期范围的 648／22 个资源，身份、每个资源统计、全局统计、筛选计数和覆盖状态与基线一致。
- 全历史事件合计 Skill 9,347、MCP 6,921，前后不变。
- 三个 Skill 与一个 MCP 的全历史和日期范围：完整分页证据集合、事件标识、会话并集、每日趋势及工具分布前后一致；事件标识无重复，证据总数等于使用次数。
- 本机实际页面复核当前 Skill 与 MCP 的次数、证据分页和加载结束状态。测试期间当前索引另有正常发布，最终对照仍显式指定基线版本；没有将新加入的历史当作优化造成的差异。
- 当前来源覆盖不足的状态继续保留。这些检查确认本次性能改动没有改变已索引证据，不代表所有外部原始历史都完整可读。
