# 地图加载与服务响应优化

Status: resolved

活动分布首次加载较慢，加载期间其他功能也受阻。先通过真实 HTTP 并发探测及线程采样确认瓶颈，再减少无用正文读取、将仓库查询移出 HTTP 主线程，并按完整版本复用元数据。紧凑缓存与完整版本同事务发布，旧版可按需补齐，版本淘汰一并清理；查询 Worker 仅为派生缓存执行写入。所有文件、活动、覆盖范围、筛选及原始证据语义保持一致；不通过截断数据提速。

验证：合成回归确认查询不执行主线程快照读取、耗时 Worker 不阻塞其他 HTTP 请求、版本淘汰和取消；逐项比较完整与投影数据的统计、文件及证据。用真实仓库重跑首次／重复地图查询、并发其他功能、浏览器加载与交互。真实输入和详细结果仅留本机忽略目录。完成检查后在 main 提交和推送。

结果见 docs/validation/map-query-performance.md。已实现查询隔离、版本紧凑缓存及活动路径索引，真实数据验证未减少统计范围。
