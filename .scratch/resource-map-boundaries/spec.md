# 资源地图边界同步

将代码地图已实现的边界规则同步到资源使用地图，并抽取两者共用的绘制组件，避免后续修复遗漏调用方。

- 复用 map-4、map-1、map-0 的中性边界色，保留按最近使用时间着色的含义。
- 边界沿共享边缘绘制，固定 1 CSS px，不随地图缩放加粗；按时间类别批量绘制，避免每个资源增加边界节点。
- 两张地图只传入屏幕矩形和色阶；共享组件统一填充内缩、边界色、时间缺失虚线与批量绘制。
- 任一边不超过 8px 的小块不留间隔、不画边界；放大后恢复正常边界。
- 时间缺失继续使用语义虚线，选中、悬停和键盘焦点保留。
- 使用隔离合成数据验证面积比例、缩放、深浅主题、中英文、窄屏和资源选择；运行资料留在 `.local/`。
