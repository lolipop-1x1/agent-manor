# 速度说明与画像指标布局

## 已作决策

- 移除阅读工具栏独立速度说明；速度表头统一解释算法，速度标记可按需查看说明。
- 用量表每行只保留速度或缺失标记，点击后查看算式、缺失原因与计时证据；不删除原有依据。
- 平均速度进入画像指标网格，覆盖数量紧随对应指标；最大单次输入作为可定位的独立指标。
- 按画像内容区实际宽度自适应：窄区两列，宽区四列。估算、部分覆盖、不同计时区间及缺失状态保持直接可见。

- [界面与验收结果](issues/01-speed-layout.md#answer)：表头帮助和请求弹层已经落地；画像内容宽度 560px 切换四列，保持不同计时区间与覆盖状态。
