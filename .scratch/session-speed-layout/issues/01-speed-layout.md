# 速度帮助入口与响应式画像指标

Type: task
Status: resolved

## Scope

调整速度说明入口、用量明细单请求详情和画像指标布局。复用统一帮助弹层、图标与主题，保留计时证据及统计口径，补齐中英文。

## Acceptance

- 阅读工具栏不再有独立速度说明；用量表和轨迹速度表头有统一算法帮助。
- 每行没有重复的请求依据折叠入口，点击速度或缺失值可查看代入算式、原因及起止证据。
- 对话速度及轮次平均可以按需查看帮助；点击不触发轮次折叠或轨迹行选择。
- 画像指标在同一窗口拖动右栏后按内容宽度切换两列／四列；覆盖状态跟随速度，最大输入仍可定位。
- 不同计时区间分别展示，零合格请求保留数据不足与覆盖数量。
- 实际浏览器验证焦点恢复、触屏、中英文、深浅主题、窄屏及现有会话交互。

## Comments

- 用户确认实施两处布局建议，包括右栏拉宽后的响应式排列。

## Answer

- 阅读工具栏移除独立速度说明；轨迹和用量表的速度表头复用统一帮助弹层。
- 单次速度或缺失值通过徽标打开详情，保留代入算式、缺失原因、时间边界和记录定位；轮次平均可以直接查看算法。
- 总输入、输出、平均速度和最大输入进入同一指标网格。画像内容宽度达到 560px 时四列，否则两列；部分覆盖紧随速度，最大输入数值旁保留定位图标。
- 不同计时区间分别显示；所有请求均缺少速度时保留表头帮助、缺失标记和可计算数量。
- 类型及中英文目录检查、公开内容检查、572 项单元测试通过。合成历史浏览器验收覆盖三来源、历史缺失、分支及统计范围、660 请求长历史、双语、深浅主题、390px 触屏、帮助焦点恢复和画像宽度切换。
- DSH、Pi 与混合计时区间验收的 54 项检查通过；会话操作和轨迹缩放回归通过。截图与详细运行日志仅保存在本机忽略目录。
