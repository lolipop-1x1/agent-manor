# 提升主要状态变化的动效存在感

Type: task
Status: resolved
Blocked by: none

用户确认增强导航、菜单、弹窗、侧栏及主动切页反馈，按钮与直接操作继续即时。复用共享 token，主动切页采用不改变定位参照的轻微透明度过渡；首屏、刷新、筛选和后台数据更新不重播。中断、减少动态效果、读取位置与密集地图性能继续验收，真实输入仅留忽略目录。

1. 调整共享时长、位移和缓动，补入只随功能页变化触发的工作区过渡。
2. 更新开发规范及专项浏览器验收，检查快速连续操作、交互中断、菜单焦点及窄屏。
3. 使用真实大仓库和多轨回放比较展示、交互与短时性能，通过后在 main 提交推送。

## Answer

导航 240ms、菜单 230ms／8px、面板 280ms／10–16px、窄屏抽屉侧滑 20px 已实现；控件仍为 110ms，主动切页采用可中断的 160ms 透明度衔接。修正抽屉淡入造成的文字透出；语言检查等待真实语言状态后再核对导航。规范同步到 AGENTS.md、DESIGN.md 与统一动效文档。

全量 1,523 项、动效专项 31 项、工作区、连续阅读、完整回放与总览 78 项浏览器检查通过，类型、构建及公开内容检查通过。真实 1,233 文件／17 轨样本验证立即交互、聚焦和 32× 回放；切页约 70ms RAF 峰值及短时观测边界保留在[验证记录](../../../docs/validation/interface-motion.md)，真实内容仅保存在忽略目录。
