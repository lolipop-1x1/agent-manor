# 状态标签收敛

Type: task
Status: resolved
Blocked by: 01

## 目标与验收

沿用当前状态列与布局，使用情况保留；统计相关缺口合并为统计不完整。关联及管理保护不堆在常驻标签中，管理时说明具体限制；真实缺口不补造零值。中英文和合成浏览器验证列表、详情、正常零值、历史独有及管理原因。

## Answer

列表和详情保留使用情况，将解析缺口、缺失时间及用量归属不确定合并为“统计不完整”。关联与保护不再作为常驻标签；管理时说明无本地位置、具体只读原因及使用记录未能对应文件的边界。未改变原始统计、默认页、指标、排序与布局。中英文契约回归通过，正常零事件不误标；真实 Chrome 已核对原状态列与关键缺口直接可见。

## Comments

最新用户要求移除状态列与“统计不完整”表述，上述标签合并方案已被替代；最终展示及验收见 [05](05-remove-status-column.md)。
