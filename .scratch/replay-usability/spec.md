# 活动回放可读性与播放器完整体验

Status: resolved

直接在 main 开发、验证、提交和推送，不创建分支或 PR。复用固定分析版本、共享多轨时钟及按需证据读取。

## 已确认范围

1. 默认展示整个会话及明确子会话涉及的基线文件；支持整仓、指定目录与面包屑。观看范围不筛除时间轴或证据。
2. 地图布局在同一观看范围内稳定。缩小时识别模块，进入目录查看文件；当前活动提供可读路径标签。可选跟随当前模块，手动地图操作暂停跟随，并行活动采用共同范围。
3. 右侧播放时按轨道跟随活动，点击暂停检查，恢复播放回到跟随；高倍速保留近期摘要。自动跟随不读取原始证据。
4. 时间轴使用单个快速、有界的自定义预览，包含轨道、时间、操作、状态及路径；支持密集 SVG 轨道、键盘和触屏。悬浮不暂停，点击暂停检查。
5. 增加 16/32/64/128 倍速与合法范围内自定义倍速、预计剩余观看时长和下一次修改。
6. 全屏覆盖地图、详情、控制与时间轴，浮层在全屏容器中正常工作；普通和窄屏保持控制可达。
7. 形状区分操作、颜色区分轨道；未知和失败使用额外状态标记。补齐图例及折叠空档说明、原始起止和时长。

## 验收

合成自动化覆盖范围、密集悬浮、暂停恢复详情、多轨、倍速输入、全屏浮层、中英文及深浅主题。真实会话检查路径与活动对应、大仓库与多轨布局和播放性能，不提交真实数据、标识或截图。运行类型与国际化检查、相关测试、完整测试、构建及公开内容检查；提交明确文件清单并回读远端 SHA。

## 结果

全部范围完成。最终完整测试 1514 项通过，类型、国际化、生产构建、合成 Chrome 和公开内容检查通过。独立 Standards／Spec 评审发现的焦点恢复、加载期目录下钻及并行摘要上限问题均修复并复核。真实数据方法与聚合结果见 docs/validation/session-code-replay.md；原始资料仅留本机忽略目录。
