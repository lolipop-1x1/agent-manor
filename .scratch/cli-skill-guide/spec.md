# CLI Skill 使用指南完善

仅在 main 完善随 npm 包分发的 Skill、参数帮助及验证，不修改 Web 或业务 API 契约。

- Skill 按任务路由，指导参数来源、类型、输入结构、输出字段解释、续读及完成条件。
- 知识只在用户明确要求沉淀时写入；写入保持待审，审批仍绑定具体修订。
- 参数帮助支持中英文；JSON 样例随 Skill 一起复制，自包含且使用合成数据。
- 隔离安装后执行样例，验证正文、ID、版本、分页、冲突、任务与错误；模型只用本地合成服务。

验收：类型与 i18n 检查、CLI 测试、Skill 校验、包外安装及指南样例实测、公开内容检查；通过后提交推送。
