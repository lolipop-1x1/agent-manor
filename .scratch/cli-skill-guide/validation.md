# CLI Skill 使用指南验收

## 范围

- 根 Skill 保持按场景路由，11 份 references 按需加载；新增5份随包复制的 JSON 样例。
- CLI 仅补帮助描述、参数约束与示例，不修改解析、命令、业务 API 或 Web 行为。
- 明确仅用户要求沉淀时写入；知识保持待审，人工审批仍按具体版本授权。

## 已完成验证

- 中英文 i18n、服务端和 Web 类型检查通过；Skill 元数据与包内相对引用检查通过。
- CLI 40项测试通过，包括全部126个命令审计、中英文帮助、授权、输入与现有输出行为。
- 23项 Web/API 返回契约回归通过。
- npm 包安装到仓库外，25组隔离合成场景通过；Skill 安装副本携带全部 JSON 样例。
- 样例实测覆盖创建、完整修订、冲突拒绝、待审检索、正文回读、单轮抽取预览、语义查询、临时连接测试（不保存）及价格设置。
- 修正测试说明：语义临时连接测试直接使用 connection 外壳；请求明细固定 priceVersion，避免与报告费用快照错配。
- 原安装包场景继续覆盖服务启停、暂停恢复、分页、4000快照大会话响应和Unicode正文续读、原始活动证据。
- 模型仅使用本地 HTTP 模拟服务：生成请求7次、向量请求10次，最大单次输入5832字节；未调用真实付费服务。

## 验证边界

- 实际包外执行环境为 macOS arm64；未重跑其他平台运行时验收。
- 本轮没有前端界面变更，没有进行浏览器视觉验收；Web保持由类型与返回契约回归验证。
- 没有发布公共 npm 版本，也没有变更用户后台或覆盖用户已安装的 Skill 副本。
