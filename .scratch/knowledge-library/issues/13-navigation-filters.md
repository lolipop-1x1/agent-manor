# 13 知识浏览菜单切换的筛选归属

Type: task
Status: resolved

## Scope

复现并修复待审队列、具体项目的筛选状态残留到其他浏览菜单。侧栏入口设定自己的视图、项目、审阅和任务范围；普通浏览恢复默认已审且有效，待审队列覆盖全部项目，具体项目仅限定该项目。显式返回审阅前的知识列表保留原筛选与阅读位置，与主动换菜单区分。保留其他用户手动筛选及实际深链语义，侧栏选中态与实际入口一致。

## Validation

隔离合成浏览器先复现两条用户路径；修复后覆盖连续菜单切换、待审返回、项目筛选、任务结果范围和中英文／窄屏。模型与实际知识数据不参与测试。

## Answer

侧栏入口统一生成完整视图查询，重设项目、审阅、可用性、任务范围和页码，保留其他手动筛选。普通视图默认已审有效，待审队列不限旧项目；具体项目和父菜单不再同时选中。显式返回恢复审阅前上下文，地址完整保存过滤字段；任务结果独立清除环境筛选。

两条用户路径在修复前均可稳定复现，修复后通过。独立复核发现相同地址残留自有导航标记、外部审阅深链复用旧返回快照两项 P2，已分别复现、修复并通过关闭复核；忽略过时 hash 事件，不将重复点击误记为新导航。
