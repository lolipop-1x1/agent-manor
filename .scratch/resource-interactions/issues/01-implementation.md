# 资源交互与收藏更新

Type: task
Status: resolved

## 范围

整行点击、收藏原位同步、加载内容保留及使用聚合缓存复用。

## Answer

- Skill、MCP 总览及本地资源的普通单元格和空白可打开详情；收藏、管理及文本选择独立处理，保留原有键盘入口。
- 收藏即时投影到列表、详情、本地本体和管理保护状态；按资源显示保存状态，失败回滚，保存按点击顺序执行。
- 普通收藏只发送一次写请求，不卸载列表、详情或证据；收藏筛选、地图及当前分页之外的详情收藏仅重新查询所需列表。
- 后台更新保留已有结果和分页，失败保留内容；收藏末页取消后同步夹紧路由页码。
- 历史聚合缓存与收藏状态分离，复用事件和关联结果；当前收藏、别名、本地本体和配置保护重新投影。

验证：`npm test` 625 项通过；资源管理 Chrome 回归 55 项、资源地图 Chrome 回归 21 项通过。延迟、失败、连续操作、末页、双语、深浅主题及窄屏均使用隔离合成资源验证。类型、翻译、构建、公开内容及 diff 检查通过。界面检测仅提示已有字号及圆角，不涉及本轮新增样式。
