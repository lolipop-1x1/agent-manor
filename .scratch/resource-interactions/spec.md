# 资源列表点击与收藏响应

## 目标

- Skill、MCP 总览及本地资源的普通单元格和行内空白可打开现有详情；收藏、管理及文本选择保持独立。
- 收藏即时反馈，保存失败回滚；保留表格、焦点、滚动位置及已打开详情，不重新请求使用证据。
- 不同资源的保存状态独立；收藏筛选正确更新成员、计数和末页页码。
- 已有结果在后台更新期间继续显示，失败保留旧内容并显示错误。
- 收藏不使历史聚合缓存失效；别名收藏、本地收藏和配置保护的语义不变。
- 使用总览删除与“全部”筛选重复的总数行及其空白占位；后台加载提示继续可见，本地资源及管理视图计数保留。

## 验证

使用隔离合成资源。自动测试验证缓存复用与收藏语义；Chrome 验证点击范围、请求数、DOM 保留、失败回滚、并发、分页、中英文、深浅主题和窄屏。完整检查通过后在 main 提交并推送。
