# 资源恢复中心与常驻导航

合并停用与回收记录为恢复中心，仅展示尚未还原且记录了恢复材料的变更；预览时检查当前材料与原位置，列表不作可还原保证，损坏材料保留记录并明确报错。左侧常驻资源清单、恢复中心、操作记录；窄屏也直接可见。筛选仅属于清单，页面各自保留搜索、选中、分页和滚动。旧路由与既有档案兼容。

记录直接表达停用配置、移除链接、回收文件、移除注册；预览和主动作明确还原对象，永久清除恢复材料收进次级菜单。成功结果只呈现一次，失败和冲突保留原因与重试。删除资源页底部常驻成功通知。链接检查沿实际目标核验 Skill 文件存在及可读取，提示限定于当前入口。

验证：恢复中心合并排序与分页、旧路由、链接目标文件边界、既有管理回归；正式页面隔离资源执行停用撤销、文件／链接／注册还原、永久清除，验证导航、筛选隔离、状态保留、中英文、主题、窄屏和地图。限制测试并发，完成检查后 main 提交推送。
