# 筛选组件与前端约定

Type: task
Status: resolved
Blocked by:

## Scope

替换五处原生下拉及四处日期输入，项目支持名称与路径搜索，复用统一控件与现有主题，在 AGENTS.md 写入后续前端复用约定，更新受影响的浏览器测试。

## Validation

类型检查、构建、人工样本真实 Chrome 端到端，覆盖鼠标、键盘、滚动、关闭焦点、主题及窄屏菜单。

## Answer

- 实现 FilterSelect、ProjectPicker、DatePicker 及共用样式，替换五处原生下拉和四处日期输入；筛选值、时间边界与统计逻辑保持原有口径。
- 项目搜索展示完整路径；中文日历提供今天与清空。鼠标点击不显示键盘外圈，键盘保留焦点标识；窄屏 Escape 先关闭顶层弹层并恢复触发器焦点，不连带关闭侧栏。
- 在 AGENTS.md 记录后续前端统一组件复用、主题、可访问性与浏览器验收要求。
- 验证：类型检查与构建通过；17 项已有前端测试通过；桌面来源和会话库两条人工样本 Chrome 端到端通过，覆盖读写统计、五个筛选、名称／路径搜索、项目键盘选择、四个日期控件、日期范围校验与清空、深色菜单、500px 窄屏和焦点恢复，浏览器异常为 0。
- 本地页面另核对 108 个项目选项的固定高度与独立滚动，以及日历深浅主题；仅记录汇总，真实项目内容与截图不进入公开资料。
