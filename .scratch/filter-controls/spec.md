# 统一筛选下拉

## 已确认方案

- 代码地图的客户端、时间和文件类别，以及会话库客户端筛选使用 Radix Select。
- 会话库项目筛选使用 Radix Popover 与 cmdk 搜索选择，支持项目名和完整路径，同名项目可区分。
- 会话库和代码地图的起止日期统一采用 Radix Popover 与 React DayPicker，提供中文日历、今天与清空入口，保持本机日期值。
- 共用现有主题变量。菜单在控件旁展开，限制高度、独立滚动，支持键盘和深浅主题；鼠标焦点与键盘焦点区分。
- 不改变筛选值与 API 语义。在 AGENTS.md 沉淀组件复用和交互验证约定。

## 验收

构建与类型检查；真实浏览器验证五处筛选、项目搜索／无命中、键盘选择／关闭与焦点恢复、菜单滚动、四处日期选择／清空、深浅主题及窄屏定位。端到端数据使用人工样本。
