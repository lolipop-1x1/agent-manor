# CLI 缓存零值恢复

核实 CodeFlicker CLI 的零缓存计数与原始持久化记录。该客户端保存规范化用量时，只写入大于零的缓存读取与写入字段；缺省可表示其保存的零值。

仅识别原生 CLI message、有效输入/输出用量以及完整 requestTokenBaseline（requestId、requestContextKey、非负整数 historyRevision）的持久化格式，恢复缺省缓存读写为零。缺格式依据、字段显式无效、其他客户端和 IDE 仍保持未知，不根据续聊间隔推测缓存命中。

修复原始解析后，以完整版本发布 CLI 规则升级；统计缓存随版本失效。核验周内原始记录、久置续聊请求、零/部分/未知分布、未缓存输入及假设价差，保留实际费用和假设估算的区别。真实输入与诊断只留本机 .local。
