# 核验与修复

原始 CLI 序列化只持久化正缓存桶。对照近期索引与原文件，周内 35,476 条请求包含 35,261 条正缓存读取及 215 条缺字段；其中 214 条正输入具有完整持久化格式依据，可按该格式恢复零值，另外一条仍无法按正输入缓存命中分类。隔一小时后继续的 29 个请求中，25 个属于省略零值；约 92、49 小时后的续聊首个请求在此范围。部分久置请求仍有正缓存读取，不能按时间间隔统一判零。

修复仅对已识别 CLI message 格式恢复缺省缓存读取和写入；缺依据、其他客户端及显式无效字段保持未知。零输入不算全部缓存命中。CLI 独立规则指纹触发一次重解析，其余客户端规则保持不变；随后以完整索引版本发布。

- 原始解析和规则升级回归先失败，修复后通过。
- 完整测试 1,035 项通过，新增解析到周复盘链路与最终定向 94 项通过；类型、国际化、构建及公开内容检查通过。
- 60 项合成浏览器交互检查通过；真实内置浏览器首屏和零缓存详情核验通过。
- 最终真实周报：零缓存 214、部分缓存 35,261、未知 1；缓存输入占比 95.8897%，普通未缓存输入 212,433,801 Token，假设价差 USD 43.0298722791。零缓存详情总数 214，前 100 条请求缓存为零且普通输入等于总输入。核心轮次仍为 1,366。
- 首次真实报告及详情完成约 19.3 秒，随后同一接口验证约 90 ms。原始文件不改写，真实定位与截图留在忽略的 .local/zero-cache-audit/。
