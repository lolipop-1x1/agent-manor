# 支持范围与验收边界

Type: grilling
Status: resolved

## 目标

明确七个原生客户端在现有产品中的支持范围、来源版本、资源管理方式和验收标准，为实现提供可执行的边界。

## 已作决策

- 覆盖全部现有能力，包含资源管理。
- 固定上游版本核对生产写入与配置加载规则，合成来源测试通过后可以交付。
- 合成验收与原生运行验收分别记录，不将源码事实或合成结果描述为客户端已生效。
- 当前正式发布版作为基线，Grok Build 固定源码提交；不额外增加旧代际历史适配。
- 资源管理沿用原生范围；无停用开关时提供现有回收与恢复，保护和未核验写入边界继续保留。

## Answer

- 规格与支持矩阵已确认，按当前正式版本与固定提交接入全部现有能力，直接在 main 开发、测试、审查和交付。

## Comments

- 已启动七个上游仓库的源码研究；完成后根据生产写入、配置加载与迁移证据继续梳理设计树。
- 七个客户端的静态核对已完成；版本与资源管理决策已确定，结果记录在来源支持矩阵。
