# 原生资源盘点与可恢复管理

Type: task
Status: ready-for-agent
Blocked by: 02

## 目标

接入七个客户端的 Skill／MCP 用户、项目、兼容及受保护来源，沿实际配置加载与控制范围提供管理。没有逐项原生开关的普通 Skill 使用既有回收与恢复，不伪造停用字段。

## 验收

- 保留同名覆盖、信任、原生启停、继承、管理规则和插件所有者语义。
- 原生全局或名字级控制在预览中呈现已发现影响范围。
- 停用、回收、恢复、共享入口、外部来源保护及配置变化冲突使用隔离资源验证。
- 配置内容不泄露到 API，管理修改与实际客户端生效分开记录。
