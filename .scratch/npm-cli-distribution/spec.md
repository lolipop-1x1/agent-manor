# npm 安装、完整 CLI 与配套 Skill

Status: resolved
Type: grilling

本文记录已确认范围及实施细化项，不构成功能已实现或立即公共发布的说明。

## 已确认范围

1. 对外统一交付 agent-manor npm 产品包，包含 CLI、本地后台、Worker、已构建 Web 和配套 Skill；一次安装后不要求用户构建前端。CLI 使用 TypeScript 与 Commander.js，在 packages/cli 建立独立内部私有 workspace、构建配置、命令模块和测试，与整体产品保持同版本交付。用户安装编译后的 JavaScript，由 Node.js 24 运行，原生依赖按平台安装；本轮不内置 Node.js 分发独立可执行包。
2. 首次正式支持 macOS arm64/x64、Linux arm64/x64、Windows x64，运行时为 Node.js 24；必须分别通过安装、命令、启停、日志、更新、网页与原生依赖验收。Windows ARM64 后续补充。
3. CLI 复用后台业务 API，按页面业务能力建立覆盖矩阵，包括总览、会话、代码活动、用量、资源、偏好和知识读写、抽取、版本及管理。业务筛选和证据含义一致，视觉交互不按按钮机械复制。
4. 默认端口 16666，占用时顺延，最多尝试 100 个候选端口，仅地址占用继续尝试；显式固定端口冲突立即报告。保存实际地址并核验实例身份，CLI 不依赖当前工作目录猜测端口。同一数据目录的实例发现、并发启动和停止继续受统一生命周期约束。
5. 后台支持脱离终端运行；普通查询及 web 按需启动，status、版本、帮助、诊断与日志读取不启动服务。start 等必要初始化和 HTTP 就绪后返回，历史更新、索引补齐和常用缓存准备在后台推进；页面与 CLI 显示实际进度，允许显式等待相关任务。已有完整结果继续可读，首次准备中明确报告，不伪装为空结果。
6. npm 包附带一个主 SKILL.md 和按业务功能拆分的 references。主 Skill 从场景选择能力，各参考文档提供最短流程、筛选、按需回读和完成条件；跨客户端会话回查是明确使用场景。复制后的 Skill 文档引用自包含，CLI 可定位并验证。
7. 通过显式 skills install 安装完整 Skill 目录，支持 Claude Code、Codex、用户级、项目级和自定义路径；npm 安装本身不写入宿主客户端目录。提供安装状态、更新和移除入口；同版跳过，保护用户修改，覆盖前展示差异并保留备份。
8. 提供显式版本检查与更新命令，识别安装方式，检测正在运行的旧后台。有在途任务时先明确处理方式，再切换服务；普通查询不静默升级或中断任务。程序更新保留本地知识、偏好和管理记录。
9. 已开启的自动策略按原开关与预算恢复；进程启动本身不额外新建全量模型任务。默认总览与基础统计可预热，其他查询按需计算，不每次全量重建。
10. 知识的已审阅状态仍表示用户核对并确认具体修订。Agent 普通写入默认待审；CLI 与 Web 均提供人工核对和确认入口。非交互审批需要用户明确授予该次操作，不能依靠调用方声明已审阅或通用 --yes 自行获得人工审阅身份。
11. npm 包名为 agent-manor，主命令为 agent-manor，同时提供 am 别名；两个入口使用相同实现、参数和数据目录。安装与发布使用 npm 官方公共 registry，发布配置明确指定公共地址，正式交付使用 MIT 许可证。
12. 设计文档只描述本产品自己的方案。当前仅梳理设计，尚不修改实现、不改变发布配置、不进行公共发布。

## 实施细化项

- 在覆盖清单中逐项固定命令参数、任务进度、JSON、退出码与管理接口字段，保留现有命令兼容并执行中英文验证。
- 按设计实现服务与数据分别就绪、实例核验、在途任务处理、数据迁移及失败恢复；日志默认每份 10MiB、保留 5 份。
- 固定 Skill 安装清单与兼容版本，验证自包含引用、用户修改保护、备份、更新和移除。
- 完成三平台五种架构组合的原生依赖和包外安装验证；MIT 在实施时应用，发布账号、包名权限及实际 npm 发布单独处理。
