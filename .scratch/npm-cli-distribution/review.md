# 双轴代码审查

固定点：`12fe846`；首轮实现：`baae902`。两个审查任务独立只读核对规范与规格，以下保留各轴结论；共享问题只在修复清单合并一次。

## Standards

1. P1：同一安装可供多个数据目录使用，更新只停止当前目录的实例，会覆盖另一后台使用的 Web／Worker 文件。需要安装级登记和互斥，其他实例活跃时拒绝覆盖。
2. P2：日志轮换的检查与改名存在跨进程竞争。缩小轮换阈值后，八进程各写一百条，七个进程因 ENOENT 退出；日志异常还可能中断关闭清理。需要并发轮换及失败隔离。
3. P2：新增生命周期、Skill 和更新命令的默认输出仍回退原始 JSON，未提供中英文人类摘要。机器 JSON 字段应保持稳定，默认摘要需本地化。

## Spec

1. P2：知识向量索引成功终态为 `ready`，通用等待只接受 `complete/completed`，成功构建后仍退出 1。已直接调用等待函数复现；需补真实构建等待验收。
2. P1：更新只保护当前数据目录而覆盖共享安装，违反升级期间避免新旧代码混用的要求。至少发现其他实例时拒绝更新。
