# 用量统计增量预计算

状态：已实现并验收，直接在 main 开发。

## 目标

统计读取结构化事实和可复用的小时、日期汇总，避免每次报告全量读取请求 JSON 并重新判断复制记录。保持既有 API、统计口径、价格优先级和完整发布版本一致性。

## 计算时机

- 新会话修订完成时写入结构化事实和确定的复制排除结果；旧索引在统计后台 Worker 中按修订补齐。
- 服务启动及新分析版本发布后，后台优先准备近 30 天，再补齐历史；原始会话保持只读。
- 汇总以会话修订、价格版本和时区为身份；不变修订复用，价格变化重算费用，新时区另建汇总。
- 报告查询检查必要数据是否准备完成；未完成时异步等待并提供准备状态，主请求线程不承担全量计算。
- 日期和身份筛选读取范围内汇总；ISO 时间边界等不能安全整桶复用的条件使用结构化事实精确计算。
- 分页、排序和指标切换共享基础结果；相同进行中请求合并，缓存有界。
- 会话预览与请求明细仅加载当前页需要的原始请求。

## 不变口径

缺失数值与零不同；无可靠时间单列；主、子及分叉复制按已有明确身份规则判断；阈值筛选作用于当前范围内会话总计；筛选选项保留全局全集；价格修改不改历史 Token 与模型；夏令时重复小时、半小时偏移及 ISO 结束排他保持不变。

## 任务依赖

01 结构化事实与索引集成、02 小时预聚合与差异验收可并行。
03 后台 Worker、持久化增量汇总及查询缓存依赖 01、02。
04 准备状态与浏览器验收依赖 03；05 真实数据性能和完整验证依赖全部任务。

## 验收

- 原实时分析函数保留为合成与真实数据的结果对照。
- 覆盖日期、时区、主子会话、缺失、价格、阈值和所有筛选；金额浮点合并误差低于显示精度。
- 检查重启、价格变化、增量刷新、旧版本、并发请求、关闭和失败。
- 真实历史只在忽略目录保留输入与测量细节；公开记录只包含合成案例、测量方法和汇总结论。
- 运行类型、国际化、自动测试、构建、公开内容检查和真实浏览器验收。
