# 可控的周期自动刷新

默认关闭。对应页面页头提供“自动刷新”下拉框，复用 FilterSelect；选项为关闭、5 秒、10 秒、30 秒、1 分钟、5 分钟、10 分钟。代码地图和会话库分别保存开关及间隔，各自默认关闭，切换页面恢复对应选择，中英文完整支持。

设置保存在独立偏好文件，与可重建索引无关；旧文件未设置间隔时视为关闭。语言和两份间隔独立合并、原子保存；保存失败提示错误，不把未保存间隔显示为生效。

关闭任一页面时取消该页面的前端周期自动检查与空闲版本轮询，另一页面设置不变。服务端每次自动请求读取对应页面保存的设置，并按所选间隔合并多标签页任务；已开始的分析继续完成，手动刷新与进度查询继续可用。服务启动时的一次性索引检查保留，开关控制网页周期刷新。

开启后仅对应页面可见时发起该页面的周期检查；隐藏暂停，恢复补查但服务端仍约束间隔；慢请求不重叠。版本发布、阅读位置、筛选和地图视野保留既有语义。

验证独立开关与不同间隔互不影响、并发保存不丢字段、默认值、旧文件兼容、全选项校验、重启保留、实际调度边界、关闭与手动刷新、多页合并、隐藏恢复、语言、键盘和窄屏。
