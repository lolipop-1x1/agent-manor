# 前端模块目录整理

将 Web 源码按应用组装、代码地图、会话库、资源管理和共享能力组织，保持页面交互、API、状态和构建产物路径不变。

## 范围

- 迁移已有模块，同步测试导入及当前工程文档。
- 分离应用组装与代码地图页面，提取共享提示、格式化、时间筛选和地图几何。
- 保持三个页面常驻挂载、跨页定位、筛选与阅读位置、地图视野和自动刷新行为。
- 继续共享服务端契约及翻译目录，不引入依赖或新的状态管理框架。

## 验收

- 迁移前后类型检查与全量测试通过，构建通过。
- 合成资源的真实浏览器回归覆盖三个页面、跨页状态、国际化、自动刷新和资源管理。
- 公开内容检查与 diff 检查通过后，显式暂存本任务文件，提交至 main 并核对远端。
