# 单会话概览增加三个平均指标

Type: task
Status: resolved

## 目标

用户可在会话库选中一个会话，在概览查看平均模型步骤、平均轮次耗时和平均提示词字数。各项沿用已确认的轮次定义，解释与缺失范围按需查看。

## Comments

- 当前工作区包含洞察讨论产生的术语与草案，实施保留这些已有改动，只新增本项所需代码、测试及说明。
- 前端复用既有概览统计行与 HelpPopover；后端位置及用户输入分块正在进行只读核对。
- 已实现画像窄字段与自身统计，单会话 HTTP/store/字符与边界回归通过；合成 Chrome 验收三项指标、空值/零值、子会话隔离、语言、窄屏与帮助焦点。最终整轮集成及真实页面验证继续由总览任务统一执行。

## Answer

概览显示平均模型步骤、平均轮次耗时和平均提示词字数。服务端同时返回各自合格样本；完整画像、summary 与用量分页的均值一致，包含子会话不会改变自身轮次均值。

最终完整检查与真实长会话 HTTP／浏览器回读已通过，详见 [验收记录](../validation.md)。
