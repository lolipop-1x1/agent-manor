# 单会话概览的轮次与提示词指标

## 范围

在会话库右侧画像的概览增加平均模型步骤、平均轮次耗时、平均提示词字数。沿用最近七天复盘已经确认的领域口径，但单会话统计覆盖当前会话的完整留存历史，不限制为最近七天。

## 统计与呈现

- 模型请求为一步，工具调用和消息片段不相加。步骤只对有明确结束证据且有已识别请求的用户轮次计算，缺少请求证据不能当作零。
- 轮次耗时为真实用户请求至明确终答的经过时间，包含模型、工具、排队和等待。起止时间缺失或倒序不计算，真实零耗时保留。
- 提示词采用真实用户输入的非空白字符数，按同轮次和来源记录行合并文本块，不把工具结果、明确上下文注入和复制的继承消息算作输入。无法可靠拆分的混合正文保留原文，帮助说明边界。
- 三项统计始终对应所选单个会话自身，包含子会话的用量开关不将子 Agent 工作分摊到用户轮次。打开子会话后计算该子会话自身记录。
- 复用概览现有数值行、字号与主题，缺少可用样本显示空值符号；样本数量和计算说明合并到区域帮助，不增加常驻解释小字。
- 服务端提供可核对的总轮次、明确结束轮次、步骤和计时有效样本、用户输入样本。原始历史只读，不新增日期筛选或改变阅读分支。
- 用户追加要求：概览与用量页的 Token 覆盖行、费用计数小字移至现有统计帮助；完整曲线下的重复请求区间行移除。部分 Token 或费用通过字段名的小计含义保留，缓存比例只基于可计算样本，部分范围标为已记录。

## 验证

- 合成数据核对多个轮次的均值、未结束和推断结束排除、请求缺失、复制及注入排除、Unicode 字符、起止缺失与零值。
- 画像接口的完整与 summary 查询返回一致统计，包含子会话时三项自身指标保持一致。
- 中英文界面、帮助样本、概览与其他页签、切换会话、窄屏和深色通过真实浏览器验收。
- 完成类型、国际化、相关回归、构建与公开内容检查。
