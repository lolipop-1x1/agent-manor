# 湖畔花园庄园
Type: task
Status: resolved

在现有体素庄园中重排树群，增加池塘小桥、玻璃温室、藤架花境与连贯游园路径。保持主楼、机器人茶会与现有产品入口的视觉主次；场景动画共用暂停与减少动态效果的控制。

## 验收

- 全景可识别水景、温室与花园，桌面构图保留文案阅读区域；近景与旋转仍完整。
- 新增模型保持细节、材质层次和明确的表面间距，不重新引入共面闪点。
- 类型、场景测试、生产构建、浏览器交互、公开内容检查通过；记录实际渲染开销。
- 直接在 main 完成提交与推送，不启用 Pages 或改动产品后台。

## Answer

- 增加不规则石岸池塘、睡莲与芦苇、逐块铺板的木拱桥、玻璃温室及可见种植台、攀援藤架、花境和长椅；树群退到外围，入口和环湖路径连接各处设施。
- 水面波光、涟漪与花穗轻摆使用同一绝对时间，保持暂停、减少动态效果与离屏停止行为；全景重新取景，原有茶庭和安装面板镜头保持。
- 只读几何审查发现桥头与温室入口高度差、池岸石块悬空，均已修复并回查。实际模型射线测试先失败、补齐台阶后通过；同时间重放确认动画无累计漂移。
- 官网类型检查、11 项场景测试、生产构建、翻译及公开内容检查通过。11 组浏览器交互回归通过，1280、1440、1920 桌面宽度无横向溢出；温室和池塘近看检查完成。
- 六个旋转角度的微小相机位移采样，高对比像素变化为 1–11 个，固定相机重复渲染为零；该采样用于排查共面闪点，不等同于全设备保证。
- 1440×1000、DPR 1 下 30 帧采样平均间隔 16.67ms、P95 16.8ms，114 次绘制调用、187890 个三角形；首屏传输约 1.29MB，无外部请求或产品 API 请求。仅记录本次设备表现。
- Impeccable 检测无发现。完整浏览器、稳定性与近景证据保存在已忽略的 .local/manor-garden/ 和 .local/manor-site-e2e/。
