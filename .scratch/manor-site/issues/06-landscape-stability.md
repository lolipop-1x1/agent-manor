# 领地环境与旋转稳定性
Type: task
Status: resolved

修复旋转庄园时的闪点，并让首页体现围墙外延伸的完整领地。

## Answer

- 暂停动画后用固定相机和微小位移分别采样，定位到花坛、树篱、铺装、树冠及翼楼屋瓦的同向共面重叠；通过缩进、接缝和高度差修复真实几何。
- 新增与庄园共享镜头的草坪、弯曲入园车道、树林、路灯和远坡，以淡雾过渡远景；首页画布铺满首屏，文案区域保留柔和遮罩，茶庭及安装近景展开完整场景。
- 5 项实际模型射线回归与原有 4 项茶会测试通过；官网类型检查、翻译检查和生产构建通过。
- 11 组浏览器回归通过，覆盖旋转缩放、近景、安装面板、暂停、键盘、语言、减少动态与 WebGL 降级。1280、1440、1920 桌面宽度无横向溢出。
- 六个旋转角度的微小相机位移采样，高对比变化像素由每角度 70–191 个降至 0–6 个；静止画面重复渲染变化为零。此采样用于确认几何修复，不代表所有设备或所有视角均无像素变化。
- 1440×1000、DPR 1 下采样 30 帧平均间隔 16.67ms、P95 17.4ms，96 次绘制调用；首屏传输约 1.28MB，无外部请求和产品 API 请求。仅记录本次设备表现。
- Impeccable 检测保留了既有官网字体与配色相关提示；本次延续官网视觉体系。浏览器诊断和截图只保存在已忽略的 .local/。
