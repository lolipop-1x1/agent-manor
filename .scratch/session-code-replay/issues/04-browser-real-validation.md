# 浏览器、真实历史与性能验收

Status: complete

Blocked by: 03

## 范围

负责 `scripts/e2e-session-code-replay.mjs` 的合成全链路验收与 `.local/` 中只读真实数据验证辅助脚本。已有模式见 `scripts/e2e-map-session-filter.mjs`，使用 `playwright-cli --headed --browser=chrome`。

## 要求

- 独立临时仓库和 data home，合成带真实父子声明的主会话和三个并行子会话；批量文件活动、失败、缺时间、长空档、同名候选和长列表。
- 验证紧凑工具栏、两个 Tab、搜索／选择、播放／暂停／倍速／拖动、累计状态、同步、证据、返回、语言／主题、窄屏及键盘。
- 监视请求与页面异常，保证动画不逐帧请求 API。保存截图与日志到 `.local/session-code-replay-e2e/`。
- 初步只写脚本，不抢先运行未完成界面；集成完成后主实现者安排执行并反馈缺陷。
- 真实历史辅助工具只读现有来源，输出真实标题、路径、标识等只能进入 `.local/`，不在公开代码硬编码真实数据。主实现者选择样本并执行。

## Comments

- 不修改生产代码及其他实现者的测试文件，不自行提交推送。脚本开发可与 01、02 并行。

## 验收结果

- `node scripts/e2e-session-code-replay.mjs` 最终完整通过。独立合成历史覆盖四轨并行、同调用批量文件、缺少时间、失败／未知、长空档、零行／已删除文件、候选搜索／同名／长列表、键盘、两个 Tab 独立状态、会话库入口、URL 与同版本播放位置／倍速恢复、深浅主题、中英文、窄屏及减少动态效果。
- 额外独立样本覆盖同一轨道、同一时间的六次调用，路径全部不在当前基线。点击重叠时间点展开全部六项，切换第四、第五项均核对同版活动身份及对应原始记录。英文候选明确断言 `1 activity` 与 `1 track`。
- 合成浏览器没有页面异常、API 失败及非取消网络失败，播放期间没有 HTTP 请求；截图与日志保存于 `.local/session-code-replay-e2e/`。脚本语法与改动空白检查通过。
- 真实历史使用只读选样、复制源文件、独立 data home 重新导入方式验证，未修改日常索引及偏好。样本包含十二份原始来源、两棵完整多轨会话树及独立会话；所有标题、路径、身份和截图只留在 `.local/`。
- 两棵真实会话树分别形成六轨／一百九十五步／六百二十四次活动、四轨／一百零八步／二百七十一次活动。逐项交叉核对源记录中的身份、状态、时间、多文件分组和外部路径排除；样本没有缺时，缺时边界由合成样本覆盖。
- 真实六轨浏览器验证会话库入口往返、同版原始证据和暂停；一百二十帧采样平均约 6.95ms、P95 约 8.3ms，播放期间没有 HTTP 请求。该结果仅代表这组本机样本，不泛化全量索引性能。
- 真实隔离服务在验收完成后已正常关闭，未终止日常服务。
