# 代码地图双视图与活动回放界面设计

状态：待审阅的设计方案。静态稿使用合成数据，不表示功能已实现。

访客模式：Operate。沿用当前工作台视觉体系，不替换品牌或全站设计语言。

需求与数据边界见 [功能规格](spec.md)。本文件集中描述界面与交互。

## 设计目标

让用户在同一个仓库工作区内，在累计活动调查和会话过程观看之间切换。观看时同时理解当前发生在哪个文件、来自哪个会话，以及此前留下了什么活动记录；需要核实时可以暂停并回到原始证据。

主视觉由仓库矩形地图与多轨时间线共同承担。播放控制使用熟悉的播放器交互，避免扩展成剪辑、配乐或视频导出工具。

## 页面层级与两个功能的切换

- 全局继续保留总览、会话库、代码地图、用量统计、资源管理。
- 全局导航下使用约 48–52px 高的单行工作区工具栏：小型代码地图标题、仓库选择、活动分布／活动回放 Tab 同行，重新分析与帮助靠右。
- 不再给标题和 Tab 各分配一整行。Tab 保留细下划线，底线落在同一工具栏下沿；正文紧接工具栏开始。
- 仓库选择从目录侧栏提升到公共工具栏，不在两个位置重复。
- 全局导航继续采用现有轻底色选中态；功能 Tab 使用底线；地图指标沿用紧凑分段按钮。三个层级在视觉上分别可辨。
- 两个 Tab 共用仓库，分别保留分析筛选与观看状态。切走回放时暂停，返回时保持暂停及原位置。
- 仓库完整路径放入选择列表和按需提示，页头只显示可识别名称；同名仓库仍能区分。

## 活动分布

保留现有调查方式。公共工具栏下方，左侧为约 190–210px 的目录导航，右侧保留筛选、覆盖指标、地图和按需文件详情。

- 左栏只负责目录范围，不重复仓库选择和页面标题。
- 筛选仍按客户端、会话、日期、文件类别、路径搜索组织。
- 覆盖指标保留现有含义；地图的面积与着色不因新增 Tab 改变。
- 指标切换仍位于地图工具区，不与功能 Tab 合并。

## 活动回放

### 从选定会话开始

- Tab 下方保留一行操作：宽而紧凑的会话选择器，右侧为查看会话。
- 初次进入时未选会话，选择器是主要动作；从会话库跳转时自动预选。
- 候选支持标题搜索，选项辅以客户端与日期。列出自身或明确子会话在当前仓库有文件活动的目标，避免漏掉只负责委派的主会话。
- 选择新目标后停在起点；恢复上次目标时停在上次位置。两个入口使用同一个播放器。
- 不显示分析页的日期、目录或文件类别筛选，也不显示覆盖率指标。默认观看该会话树在当前仓库的已纳入文本文件活动。

### 桌面工作区

- 默认收起目录侧栏，为地图与时间线提供宽度。
- 上方约三分之二用于地图，下方约三分之一用于播放控制与轨道；两者之间允许拖动分隔线。
- 没有点选证据时，地图使用完整宽度。点选后，右侧展开约 320–380px 的活动详情，时间线继续横跨整个工作区。
- 默认保持仓库全景，用户可以手动缩放与平移。多个子会话并行时不自动在不同目录间切换镜头。
- 地图逻辑布局固定；打开详情或改变视口只改变可视区域，不按当前活动重新排列文件。

### 地图的观看语言

- 未发生的活动保持中性底色，已发生的活动保留较淡累计痕迹。
- 当前活动通过短暂光点、清楚描边及小型轨道标记表达；同时发生时可以有多个高亮。
- 读取、修改、搜索分别使用圆点、方点、菱形及紧凑图例；不同轨道通过名称、编号和辅助色识别，地图标记与轨道对应。形状和文字承担活动类别含义，不依赖颜色区分。
- 同一调用的多个文件同时呈现。不同轨道操作同一个文件时，保留各自的轨道标记。
- 失败与未知保留对应状态，不变成成功读写标记。
- 不在文件块中展示分析页的覆盖百分比。历史已删除路径、零行文件等无矩形的活动继续通过时间线与详情访问。
- 保留必要的短暂反馈，不绘制永久覆盖全图的活动连线。

### 播放控制与共享时间轴

- 传输控制放在地图与轨道之间：播放／暂停、前后活动、倍速、原始时间定位；时间轴缩放位于右侧。
- 拟提供 0.25×、0.5×、1×、2×、4×、8×。地图缩放与时间轴缩放分别提供可访问名称，避免同屏加减号混淆。
- 一根播放头贯穿标尺及全部会话轨道。各轨道使用同一套时间映射，单轨不能独立压缩时间。
- 长时间无可展示文件活动记录的区间可折叠成共同的断轴列，用双斜线表达；查看时说明原始时间跨度。相邻时间标签保留原始时间，不伪装成连续等比例区间。
- 轨道以活动点为主；仅在开始／结束或时长证据可靠时绘制持续区间。
- 拖动定位同时更新全部轨道与地图累计状态。向前定位包含此前活动，向后定位移除未来痕迹。
- 结束时暂停并保留最终累计结果。首次进入与恢复页面均不自动开始播放。

### 多轨的密度与阅读

- 左侧轨道名称列固定，约 170–190px；右侧标尺及活动横向同步滚动。
- 主会话在首行，子会话按明确父子层级排列；长标题截断并按需显示完整内容。
- 每条轨道约 36–44px 高，默认可读四到五条。更多轨道在有界区域内纵向滚动，不无限推高页面。
- 缩小时密集活动可合并为视觉标记，播放数据仍完整；放大或选择后能定位具体活动。
- 无法时间对齐的活动放入所属轨道的未定时区域，暂停后按可确认顺序查看，不塞入共享时钟。
- 缺失子会话历史通过轨道关联处的紧凑状态入口说明，不补造执行片段。

### 证据交互

- 点击时间线活动：暂停并定位到该活动时间，地图同步定位，右侧显示对应证据。
- 点击地图文件：在当前时间暂停，显示该文件截至当前时刻的相关活动；不把播放位置跳到未来。
- 详情首先展示文件路径、读／改／搜、结果状态、来源轨道和记录时间，再展示历史片段或工具记录。
- 历史片段明确其来源，不将其标为完整文件版本或最终 Git diff。
- 原始证据及查看会话动作就近提供。关闭详情保留播放位置，恢复时由用户点击继续。

## 视觉规则

沿用 DESIGN.md 的白色／冷灰平面工作区、深浅主题、小圆角和细边界。标题约 22px，正文与列表约 13px，控件与标尺约 12px，时间使用等宽数字。主题色承担选中与播放头，图表类别及失败／未知保留独立含义。

当前活动的光点是本功能的轻量识别点。地图与时间轴本身是主要视觉内容，减少常驻说明、重复计数、成功通知和装饰性容器。

## 初始、更新与异常状态

| 状态 | 呈现方式 |
| --- | --- |
| 尚未选择会话 | 保留仓库上下文，以选择会话为主动作；地图轻量预览，不出现无意义的空轨道 |
| 首次加载 | 保持地图和时间线的预期区域，使用简洁占位结构 |
| 更换会话或更新 | 保留上一份完整画面，固定位置显示进度；新数据就绪后整体替换，期间暂停旧画面的证据下钻 |
| 没有文件活动 | 简洁说明当前仓库无该会话可回放活动，提供更换会话入口 |
| 部分时间缺失 | 已定时活动正常同步，未定时活动在所属轨道单独访问 |
| 证据读取失败 | 在详情内显示具体原因及重试，不将成功状态或空记录代替失败 |
| 回放版本失效 | 暂停，说明原版本不可用，提供更新到当前版本的明确动作 |

## 窄屏与可访问性

- 两个功能 Tab 保持可见；窄屏公共工具栏优先保留仓库与 Tab，重复页面标题收起，低频操作进入更多菜单；会话选择位于下一行。
- 窄屏地图保持约 280–320px 的可用高度，多轨时间线保留独立滚动；轨道名称列收窄但不消失。
- 证据使用受视口约束的底部面板，打开时暂停，关闭后恢复焦点。
- 播放控制在观看区内保持可达，不需要滚动整页寻找暂停按钮。
- 键盘可操作播放、前后活动与定位；标尺提供原始时间的可访问值。避免让大量事件成为连续 Tab 停靠点。
- Space 仅在播放器有焦点且不处于文字输入时切换播放；Escape 沿用浮层关闭与焦点恢复。
- 减少动态效果时使用明确的高亮切换，仍保留完整活动顺序与定位能力。
