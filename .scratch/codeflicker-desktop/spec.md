# CodeFlicker 桌面版历史接入

## 目标

- 现有客户端 ID `codeflicker` 保留，显示名调整为“CodeFlicker CLI”，兼容改名前后 CLI 的历史。
- 新版 MyFlicker 桌面端以独立客户端接入，显示名“CodeFlicker 桌面版”。
- 桌面版同时兼容 `~/.codeflicker/data/codeflicker/` 中旧桌面／IDE SQLite 历史，仍使用同一桌面客户端 ID。
- 代码地图与全局会话库、搜索、画像、CLI／API 客户端筛选和原始证据回查贯通。
- 只读本机已有历史；以客户端元数据确认项目与身份。记录值、估算值、缺失值以及精确／近似范围口径保持一致。
- 同一执行的缓存投影与原生轨迹不重复计算；只按实际保存的工具参数、终态及返回内容计算覆盖。

## 验收

- 使用匿名合成格式验证发现、身份隔离、读写范围、消息过程、标题／项目／模型与用量。
- 隔离后台的 CLI／HTTP／真实 Chrome 端到端贯通两个客户端，并验证现有客户端未受影响。
- 本机真实桌面历史与独立原始记录核对，确认已保存部分及采集缺口；私人资料仅留在忽略目录。
