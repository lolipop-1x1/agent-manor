# 总览派生缓存数据库名称统一

Type: task
Status: resolved

## 目标

总览和七天洞察的派生缓存使用不带版本后缀的固定数据库名称，删除本机已停用的旧版缓存。

## 验收

- 总览事实使用 `overview-facts.sqlite`，七天洞察事实使用 `weekly-review-facts.sqlite`。
- 代码、测试和设计文档使用相同名称，不增加旧文件名迁移或兼容回退。
- 现有总览、七天洞察与缓存复用回归通过。
- 本机停止后台后清理旧版缓存，复用在用缓存并以新名称重新启用；核对表结构、记录数和接口。
- 真实数据库及运行验证材料只保留在本机忽略目录。

## Answer

- 两个事实缓存统一使用无版本后缀的固定文件名；默认路径、七天洞察对总览事实的复用、测试与设计文档同步更新。
- 不增加旧文件名兼容或自动迁移代码。缓存内容的格式校验与损坏重建沿用现有机制。
- 49 项总览事实、分区统计、七天洞察和过程数据回归通过，服务端类型检查、构建及公开内容检查通过。
- 本机停止后台后删除停用旧库，将两份在用缓存改名，核对文件身份和修订记录数保持一致，避免重算；重启后验证接口与实际打开的文件名。
- 当前本机只保留六个数据库，两个事实缓存分别包含七张与四张表。具体路径、文件信息和接口验证结果保存在忽略目录。
