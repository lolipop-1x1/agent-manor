# 核验 CodeFlicker CLI／桌面版本地资源来源

Type: research
Status: resolved

## 目标

从当前发行源码及本机目录形态确认 Skill／MCP 的发现、登记、作用范围、命名迁移、插件缓存与启用状态。区分已核验只读格式、可确认的原生管理能力和未确认能力。

## 预期输出

- 每个客户端的实际来源与优先级，保留安装版本及证据定位。
- 本体与入口、共享路径与独立副本、原生登记与缓存文件的区别。
- 可支持的盘点、历史关联及管理操作，明确尚未核验的边界。
- 不运行 Skill、MCP 或客户端命令，不修改真实资源；凭证和私人样本不进入公开文档。

## Comments

- 两路只读调查分别核验 CLI 与桌面版；主 Agent 整合来源身份及产品边界。

## Answer

CLI 和桌面版发行来源均已核验，补充自定义目录与 MCP 消费格式调查已完成。新版 npm CLI 仍使用旧配置根；桌面版使用新根及复制迁移，不能按程序名称推断资源根。具体可读来源、优先级、设置字段、静态来源限制和未验证写操作见 [来源矩阵](../../../docs/design/codeflicker-resource-sources.md)。

主 Agent 只读核对了 CLI 根设置及 user-only 状态算法，桌面 MCP 注册结构只投影字段类型／数量，未回显注册值。桌面配置字面 disabled 与查到的运行时 disable 消费差异列为逐来源核验事项，未知状态不阻塞只读盘点。

调查未运行客户端、loader、Skill、插件或 MCP 服务，未修改真实资源、配置或数据库。操作效果仍须在隔离合成资源中验证；不将静态源码证据等同于运行效果。
