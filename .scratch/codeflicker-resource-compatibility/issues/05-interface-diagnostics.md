# 展示来源、原生状态与覆盖诊断

Type: task
Status: resolved
Blocked by: 03, 04

## 目标

让两种客户端的资源在本地列表、总览与地图详情可查看和管理，明确空结果、来源缺口、仅用户触发、保护、覆盖与残留副本；复用统一控件和按需说明。

## 验收

- CLI／桌面版及 Skill／MCP 四种组合的列表、筛选、分页、详情与管理面板正确。
- 桌面 MCP 只读原因及客户端管理引导清楚，不显示可执行写动作；其他来源显示真实能力。
- 用户默认及项目覆盖关系可查看，旧副本／被覆盖项不与有效入口混列。
- 关键状态直接可见，详细原因进入来源详情；不添加常驻解释小字。
- 中英文、可访问名称、键盘、触屏、深浅主题和窄屏沿用现有规范。

## Answer

- 本地列表与具体入口显示仅用户触发、托管／系统／插件保护及未知原生状态；用户默认与项目设置可按需展开，长范围列表独立滚动。
- 来源面板沿用当前 Agent、资源类型及项目范围，覆盖、残留、动态与无效引用诊断折叠展示；被覆盖来源保留当前选中路径。本地详情也可查看相关来源诊断。
- 管理预览保留各受影响范围，移除后可能重新出现的下层入口直接列出。桌面 MCP 显示只读与客户端管理帮助，不提供未核验写动作。
- 空状态区分未匹配、来源不可读与待适配；搜索未匹配保留已有简洁提示。说明复用 HelpPopover，不新增常驻解释性小字。
- 中英文翻译完整性、Web 类型检查与资源国际化 5 项回归通过。真实浏览器四种组合、管理、键盘与主题验收由任务 06 统一执行。
