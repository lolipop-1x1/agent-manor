# 适配历史关联与可恢复文件操作

Type: task
Status: ready-for-agent
Blocked by: 03

## 目标

将已盘点入口按保存路径和可核验原生身份关联历史，核验普通独立 Skill 和 CLI 配置型 MCP 的停用／回收／恢复能力，复用现有预览、确认、持久恢复与冲突机制。

## 验收

- 原始历史名称、路径和使用次数不因当前安装变化而重写；别名与插件前缀仅在原生证据可确认时用于关联，歧义／路径缺失保持未关联。
- 写操作限定已核验、非托管来源，保留其他配置项与未知字段；桌面 MCP 保持只读并给出原因。
- 名称规则、共享本体标记与项目覆盖的影响在预览可见；不能把跨入口修改描述成独立入口操作。
- 隔离合成资源验证停用、回收、恢复、冲突、来源改变及下层同名项重新可见；真实配置不执行写操作。
- 所有新能力在完整恢复测试通过后才开放，无法安全表达的来源继续只读。
