# 适配历史关联与可恢复文件操作

Type: task
Status: resolved
Blocked by: 03

## 目标

将已盘点入口按保存路径和可核验原生身份关联历史，核验普通独立 Skill 和 CLI 配置型 MCP 的停用／回收／恢复能力，复用现有预览、确认、持久恢复与冲突机制。

## 验收

- 原始历史名称、路径和使用次数不因当前安装变化而重写；别名与插件前缀仅在原生证据可确认时用于关联，歧义／路径缺失保持未关联。
- 写操作限定已核验、非托管来源，保留其他配置项与未知字段；桌面 MCP 保持只读并给出原因。
- 名称规则、共享本体标记与项目覆盖的影响在预览可见；不能把跨入口修改描述成独立入口操作。
- 隔离合成资源验证停用、回收、恢复、冲突、来源改变及下层同名项重新可见；真实配置不执行写操作。
- 所有新能力在完整恢复测试通过后才开放，无法安全表达的来源继续只读。

## Answer

- CLI Skill 名称名单停用保留 userOnly／enabled 与未知配置，恢复精确撤销本次目标成员；新建控制文件恢复原缺失状态，后续无关设置继续保留。
- 桌面独立 Skill 使用可恢复 `.disable` 标记；共享本体不开放标记停用，链接可独立回收。CLI MCP 使用单数 disable 字段局部编辑及注册回收／恢复，桌面 MCP 保持只读。
- 预览列出相关名称设置的有效作用范围及隔离后可能重新出现的下层来源，复核配置依赖和共享入口；未知跨范围设置不开放原生停用，恢复冲突不覆盖用户内容。
- 历史关联仅在明确路径、客户端和范围匹配后使用已核验原生名称别名；目录名与声明名不同的读取可以关联，原始名称、身份与使用统计保持不变。
- 被覆盖的托管引用继续保护相同真实本体；隔离回归验证桌面共享入口所有管理能力关闭，停用及回收预览被拒绝，普通独立同名目录不受误保护。
- 验证：50 项管理与历史使用测试通过，包含 12 项新增兼容／隔离场景；服务端类型检查通过。实际浏览器及全量验收由后续票据完成，真实配置没有写操作。
