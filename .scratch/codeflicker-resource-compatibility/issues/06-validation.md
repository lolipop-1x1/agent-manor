# 资源兼容回归与端到端验收

Type: task
Status: resolved
Blocked by: 03, 04, 05

## 验收

- 对来源、优先级、同名覆盖、共享引用、设置状态、注册敏感值边界和未知消费者建立合成回归。
- 隔离验证所有新文件操作的预览、确认、冲突、恢复与其他配置项保留，测试失败不得开放对应写能力。
- 真实本机只读检查两个客户端的 Skill／MCP 入口与历史关联；原始输入和截图留本机私有目录。
- 浏览器端到端验证四种组合、列表／地图、Agent 筛选、分页、覆盖诊断、管理／只读状态、刷新、中英文和窄屏。
- 运行相关回归、类型、翻译完整性、构建、公开检查；核对历史统计及其他客户端行为不回归。
- 正式验收记录只保留方法、结论和支持边界，未实际验证的客户端生效不得标为成功。

## Answer

- 两种客户端的 Skill／MCP 盘点、作用范围、配置状态、覆盖诊断、历史路径关联和管理边界已通过合成回归。管理写操作全部限定在隔离资源，未执行真实客户端、插件或 MCP 服务。
- 最终全量测试 469 项通过，类型检查、中英文目录及参数完整性检查、构建、公开内容检查、差异检查和发布包内容检查通过。包清单包含来源能力矩阵。
- 新兼容浏览器端到端 14 组在最终构建上通过；原有资源管理 47 组及资源地图 20 组回归通过。覆盖两种客户端与两类资源、分页跳转、筛选及空结果、列表／地图详情、来源诊断、操作预览／恢复、保护状态、只读帮助、中英文、窄屏主题与 Escape 焦点恢复。
- 真实本机只读验证确认四类本地资源均可发现；仅刷新桌面历史以补齐原生 Skill 目录证据，历史会话数及使用统计不变，其他客户端检查时间未改变。详细输入、结果和截图留在忽略的本机目录。
- Standards 与 Spec review 的五项行动均已修复并复核通过：插件 JSON 真实路径边界、新旧路径合并、默认触发状态、被覆盖托管本体保护及 tracker 格式。新增测试证明共享托管本体拒绝写操作，独立同名目录不受误保护。
- 本地服务已加载新构建，保留原数据库与索引。桌面 MCP 首版保持只读；动态插件来源、未持久化临时配置及客户端实际重新加载结果不在本次验证范围。
