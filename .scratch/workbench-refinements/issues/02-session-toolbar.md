# 会话页头与阅读工具栏收敛

Type: task
Status: resolved

## 目标

将会话信息与阅读操作分成两组：标题、元信息、按需来源和会话级动作组成信息头；模式、搜索和轮次组成同一条阅读工具栏。消除整行空白和重复分隔线。

## 交互

- 来源入口内联到元信息，点击浮层查看，Escape 恢复焦点。
- 轮次触发器显示当前轮和总数，展开后输入回车跳转；首轮、末轮位于同一浮层。
- 前后轮和问题目录保持直达，当前轮仍随阅读和执行轨迹定位更新。
- 以中心面板宽度响应换行，长标题与中英文均保留完整可访问名称。

## 验收

桌面、中心面板拖窄和手机宽度下检查层次、分组与溢出；验证输入范围、首末/前后轮、问题目录、来源焦点、语言及阅读位置保留。

## Answer

- 信息头与阅读工具栏已分组：来源详情改为元信息行内浮层，代码地图与导出集中到标题右侧；模式、搜索和轮次共用一行，移除独立导航行及相邻重复边界。
- 当前轮次按钮打开跳转输入与首末轮；前后轮、问题目录直达。输入范围沿用总轮数，回车提交，Escape 与关闭后恢复焦点。
- 110 轮合成历史的可用性浏览器回归通过，包括越界输入、首末／前后轮、目录摘要、搜索、导出和焦点恢复。
- 1720px、1280px、390px、375px，以及双侧栏拖宽后的窄中心面板完成视觉检查；中英文、深浅主题和窄屏浮层无横向溢出，来源浮层不改变页头高度。截图和运行记录保留在本机忽略目录。
- 同步旧浏览器脚本中的轮次控件定位；这四个脚本仅完成语法检查，未重复运行整套场景。
