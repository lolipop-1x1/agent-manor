# 只展示有数据的 Agent 客户端

各功能的客户端筛选依据完整功能数据生成，保留全部入口，不使用固定支持名单，也不只看当前分页。候选集不受自身客户端、日期、搜索和项目筛选缩小，保证可以切换及查询历史；代码地图按当前仓库完整版本计算，资源按 Skill/MCP 及使用、本地、停用、回收、操作视图区分。

会话库及总览依据完整已发布会话索引；用量沿用完整统计数据候选，包括有记录的缺用量会话。代码地图仅纳入命中仓库基线文件的事件客户端，失败与未知活动保留，纯来源或无文件事件排除。资源使用总览纳入实际使用和本地资源的客户端；本地视图按资源入口，管理视图按完整对应记录并包含共享本体的受影响入口。

加载时不回退到全部支持名单，更新保留上一份候选。成功取得候选后将已失效选中客户端恢复为全部，旧深链接与包含／排除选择也同步清理；错误不触发清理。添加来源属于配置目标选择，继续提供所有支持客户端。

用只读元信息及既有索引计算候选，复用版本缓存，不新增原始历史扫描。验证分页外、空数据、版本变化、复制排除、文件匹配、共享资源、旧链接、筛选切换与中英文及窄屏，真实页面通过后在 main 提交推送。
