# 会话库易用性优化规格

Status: resolved

## 本轮范围

用户确认实施优化项1–7：解析与展示正确性、界面减噪、会话级搜索、查找状态恢复、长会话跳读、统计到证据定位、复制与Markdown导出。收藏、本地别名、隐藏管理与原生继续不纳入本轮。

## 已确认体验规则

- 默认布局暂不修改：保留现有三栏结构、默认开合及宽度；可以精简各区内容和控件，不将右侧信息默认收起。面板持久化暂不作为布局优化实施。
- 默认对话优先显示明确或可靠推断的最终回答；没有可确认终答时显示本轮末条已保存AI正文，并标为未确认结束。展示兜底不修改来源终态，不把它写成推断终答，也不补造正文。
- 有可靠原生标记的技术注入退出用户问题与轮次；原始记录在过程查看和检索中仍可回查。
- 空的可选指标、图例、列和模块不渲染；真实零值与缺失分开。缓存覆盖不足时隐藏比例，展示部分累计值时明确其记录范围。
- 常驻技术说明、成功刷新内部计数、重复角色和重复摘要退出默认界面；右侧保留原有统计分区，真正影响当前阅读或操作的错误与数据缺失保留提示。
- 用户反馈后恢复左侧全部常驻筛选，查看模式和导出直接可见；右侧恢复模型条形统计、概览用量、会话内容、子会话及用量明细。定位入口融入对应统计；右侧向右收起、向左展开。
- Web全局搜索按会话分页，一项包含记录命中数和代表片段，展开可分页查看全部命中并定位原记录。不提供按消息查看的额外界面切换；现有CLI和记录级搜索契约保持兼容。
- 会话内搜索按消息定位，不重复当前会话标题、项目及客户端信息；过程检索选项靠近对应搜索入口。
- 筛选或搜索变化后保留当前阅读现场；当前会话不在结果范围时显示简短状态和清除筛选入口。
- 当前查找条件随地址恢复，阅读位置随会话恢复；旧地址继续可访问，语言切换不改变条件或位置。

## 长会话跳读与证据定位

- 轮次导航提供按问题跳转按钮，点击才展开目录；目录取用户问题短摘要，跟随当前分支，不新增常驻面板。
- 首批证据入口仅为失败调用、压缩记录和最大单次输入，支持查看对应记录并定位原消息。不新增分析图或自定义高用量阈值。
- 失败与压缩列表在对应右侧统计入口旁按需弹出，不挤占阅读区；名称与时间分行，统一字号与间距，长列表内部滚动。选择后关闭并定位，支持关闭按钮、点击外部与Escape；窄屏受视口约束。

## 复制与导出

- 支持AI回复、代码块和本轮问答复制；复制完整内容，不以屏幕预览长度截断。
- 导出Markdown，明确为当前分支对话；跨页读取该分支全部轮次，不将当前页视为全量。
- 内容与默认对话一致：用户问题及最终回答；无可确认终答时包含标明未确认结束的末条已保存AI正文。
- 不包含思考、工具原始记录或子会话，不新增导出范围配置。
- 固定所读索引版本，失败或版本不可用时不保存半份导出。

## 验收方向

- 没有空指标卡、不完整缓存占比或重复角色。
- 已保存AI正文不会因终态缺失而静默消失；未确认结束与真正终答不混淆。
- 一个长会话不会占满搜索首页；展开全部命中和跨页定位准确，现有CLI与直接链接兼容。
- 页面刷新、前进后退及会话切换恢复明确范围的查找和阅读状态。
- 真实错误可见，生效筛选可辨，来源只读；语言、主题、窄屏和键盘操作通过真实浏览器验收。
- 复制与导出取完整已确认范围，消息和轮次数量跨页准确，未确认结束标识保留，过程记录及子会话不混入。

## 实现与验收

已完成本轮全部范围，默认三栏布局保留。结果与验证方法见[任务地图](map.md)和[验收记录](issues/05-validation.md)。解析规则通过受影响客户端的指纹后缀更新，下一次正常刷新纠正存量缓存，无须清空索引。
