# 会话库易用性优化

## 目标

围绕找到会话、读懂对话和复用内容优化，整体做减法。沿用本地分析、来源只读和可重建索引的边界。

## 设计树

1. 本轮范围：已确认优化项1–7；收藏、别名、隐藏管理和原生继续后置。
2. 默认布局：已确认暂不修改现有布局，保留三栏及当前默认开合和宽度。
3. 默认对话：已确认终答优先；无可确认终答时显示本轮末条已保存AI正文，标明未确认结束。
4. 搜索组织：已确认Web全局搜索仅按会话组织，展开全部记录命中；会话内搜索继续按消息定位，保留CLI已有契约。
5. 筛选与阅读：已确认筛选变化保留阅读现场，仅在当前会话不属于结果范围时提示差异并提供清除筛选入口。
6. 长会话跳读：已确认轮次导航按钮展开问题目录，使用用户问题短摘要，跟随当前分支，不新增常驻面板。
7. 证据定位：已确认失败调用、压缩记录和最大单次输入三个入口，不新增分析图或告警阈值。
8. 复制与导出：已确认回复、代码块及本轮问答复制；Markdown导出当前分支全部轮次，范围与默认对话一致，不含思考、工具和子会话，不增加范围配置。
