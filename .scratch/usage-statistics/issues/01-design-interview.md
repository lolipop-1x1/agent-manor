# 用量统计需求与口径访谈

Type: grilling
Status: resolved

## 目标

确认跨客户端模型用量、估算费用、筛选和图表的产品闭环，形成能够审阅的规格后再实施。

## 已确认

- 独立顶部入口，首版同时包含 Token 和估算费用。
- 请求按已记录的发生时间统计，缺可靠时间的用量单独保留。
- 默认纳入主、子会话的自身新增用量，沿现有身份与去重规则每条请求只计一次。
- 文档直接记录本产品的定义与决策，不记录外部实现的来源说明。

## 验收

- [规格](../spec.md) 区分用户已确认选择、当前源码事实与待确认方案。
- Token 分项和费用公式不重复计算缓存或推理，不把缺失值默认为零。
- 需求包括筛选、图表、明细下钻、数据覆盖和验证方法。
- 更新已明确的领域术语；只有符合长期取舍条件的新决策才新增 ADR。
- 规格达到共同理解后结束访谈，应用代码实施另行记录。

## Comments

- 已完成当前用量数据、统计和界面能力的只读调查；未修改应用代码或读取真实历史正文。
- Q1–Q4 已确认；Q6 完整筛选与图表组合已确认。
- Q5 经讨论确认为网络优先、本地兜底、用户任意模型价格及映射；手动价格最高优先，网络更新不覆盖。
- 完整规格已补充 Token 与费用公式、价格获取、缺失边界、筛选和视觉方案，等待最终共同理解确认。

## Answer

- 完整方案已确认并获实施授权，独立用量入口、完整筛选图表、请求时间归属、主子默认纳入和手动价格最高优先级均保持。
- 价格与用量分开版本化的 ADR 已接受；用户要求直接 main 开发，覆盖分支与 PR 流程。
