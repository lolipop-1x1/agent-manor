# 会话概览显示估算费用

Type: task
Status: resolved

## 范围

- 在会话画像的请求用量区域展示估算费用与 USD 币种，沿用全局用量统计的定价规则。
- 自身与包含子会话分别按完整范围计算，不受请求分页影响，不重复纳入复制用量。
- 完整、部分及未定价状态明确展示；未知费用不显示为零。
- 复用统计 Worker、固定索引及价格版本，定价变化不写入纯画像缓存。
- 补充中英文、说明文档及 API／真实浏览器验证，真实数据细节仅保存在本机忽略目录。

## 验证

沿用既有 HTTP API 与浏览器公开测试边界，验证金额、范围、缺失、手动价格更新、分页独立性及窄屏主题。

## Answer

- 概览及用量标签的请求用量区新增金额行，显示估算费用与 USD。部分记录显示已知费用小计和覆盖计数；全部无法估价显示横线，明确零值保留零。
- 单会话接口沿用画像范围，在现有统计 Worker 中复用价格解析与汇总，递归子会话且排除复制用量；索引与价格版本、范围共同隔离缓存。
- 费用加载、结果、错误均绑定会话、版本和当前选中范围，快速切换时取消旧请求并隐藏旧金额；失败独立重试，返回页面和重新展开刷新最新价格。
- 751 项自动测试、国际化及类型、构建、公开内容和空白检查通过。费用专项及当前会话可用性 Chrome 回归通过，覆盖中英文、快速切换、价格更新、零／未知／部分、错误重试、帮助、明细分页、窄屏深色和原阅读交互。
- 8 类客户端的 8 个真实会话、1,297 条请求汇总与全部逐请求费用及覆盖计数一致；含子会话小计与各成员自身小计一致。详细数据仅留在本机忽略目录。验证边界见 [验收记录](../../../docs/validation/usage-statistics.md)。
