# 显示自动映射并允许用户调整

Type: task
Status: resolved

## 范围

- 在请求价格依据和价格管理中直接显示官方或公开目录 API 基准，以及自动目标服务商和模型。
- 已记录模型提供修改映射入口，预填自动目标；用户手动映射和价格覆盖自动规则，删除手动映射后恢复自动结果。修改源模型身份时移除旧映射，避免残留。
- 复用既有价格表、映射编辑器和通用控件，补齐中英文文案。

## 共享接口

- ModelPrice.matchBasis: official | catalog；RequestCost.priceMatchBasis 与 priceModel。
- createPriceResolver 返回的价格附带自动匹配依据，原始模型名保留。

## 验证

沿用价格管理与用量 API 的既有测试边界；隔离合成数据验证目标显示、调整映射、最高优先级手动单价、恢复自动、中英文及窄屏。

## Answer

- 价格管理保留原始模型，直接显示自动或手动映射目标；已记录模型可打开既有映射编辑器，预填手动目标或自动解析目标。搜索包含解析后的计价模型。
- 请求价格依据显示采用模型、官方或公开目录 API 基准；说明订阅、Token Plan 和免费渠道同样按 API 基准估算。用户单价及手动映射保持优先，删除手动映射恢复自动匹配。
- 控件、表格、主题及弹层继续复用既有实现，补齐中英文文案。
- 检查通过：中英文目录完整性、Web 类型检查、7 项用量 Web 自动测试、公开内容检查及改动空白检查。隔离数据的真实浏览器整体验证由集成任务执行，本项不将静态检查当作浏览器验收。

- 集成补充：147 项隔离 Chrome 检查已通过，包含中英文自动目标预填、手动目标调整与恢复、任意原始模型单价、映射更名、窄屏目标选择及焦点恢复。最终规范与需求审查已整合。
