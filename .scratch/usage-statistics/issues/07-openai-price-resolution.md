# 修复标准 OpenAI 模型未定价

Type: task
Status: resolved

## 范围

标准模型在多个服务商目录中同名时，现有唯一名称规则拒绝原厂条目，导致有完整 Token 的请求仍无法估价。

- 对无服务商前缀的标准 OpenAI 系列使用精确原厂 API 价格基准，手动价格与映射保持优先。
- 带服务商前缀按精确服务商匹配；其它多服务商同名、未知模型与未知前缀不猜。
- 价格版本包含解析规则版本，旧费用汇总失效，Token 事实复用。
- 价格管理区分记录模型的有效价格与服务商目录价格，展示和编辑保持一致。

## 验证

合成回归先复现未定价，再验证原厂基准、缓存分项、优先级与匹配边界。类型、国际化、公开内容检查与隔离浏览器验收通过；真实历史只用于本机前后对照，详细输入与报告留在忽略目录。


## Answer

共享价格解析器已新增无前缀标准 OpenAI 名称的精确原厂基准，保留用户手动覆盖、明确映射与服务商限定名称的优先级。未知前缀不剥离，完整带斜杠模型 ID 的唯一精确匹配保留。价格版本包含解析规则版本，升级后不复用旧费用汇总。

价格管理显示已记录模型的有效计价依据，目录条目使用服务商限定身份及自身价格；编辑目录条目不把另一服务商价格写入同名模型。主页面与价格管理直接说明 API 估价基准，帮助说明金额只含可计算部分。

验证：新增回归先复现旧规则未定价，修复后 19 项价格测试通过；完整 713 项自动测试、类型、国际化、构建、公开内容与 diff 检查通过。隔离 Chrome 共 70 项检查通过，覆盖目录多服务商显示、编辑、保存、恢复及原有筛选、分页、证据、主题、窄屏、中英文、错误重试。真实历史绑定相同分析版本，Token 与请求总量保持不变；新汇总与精确计算及独立分项/档位公式复算一致。用户本地价格与映射未改，原始历史只读。
