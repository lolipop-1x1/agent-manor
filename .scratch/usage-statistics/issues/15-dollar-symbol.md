# 费用展示统一使用美元符号

Type: task
Status: resolved

## 范围

- 用量指标、费用图表与提示、归因、日历、会话和请求明细、会话概览使用美元符号前缀，金额保留两位小数。
- 费用筛选与模型单价单位使用美元符号；模型单价保留原精度。
- 计算、存储、接口币种和筛选含义不变；未知金额继续显示缺失值。

## Answer

- 金额通过现有本地化数字格式使用美元窄符号，例如 `$1,234.56`；移除金额之后的重复单位。
- 图表轴、逐区间提示、排行和热力图金额沿用同一格式；价格说明及编辑单位使用 `$ / 百万 Token`。
- Web 类型、国际化、7 项用量前端测试、前端构建、公开内容与空白检查通过。
- 中英文隔离会话费用浏览器验证通过，覆盖自身与子会话范围、完整费用、部分费用、零价、未定价、重试、价格更新及窄屏深色。
- 真实统计页确认指标、会话表、费用坐标轴、区间提示、排行、日历和模型单价单位使用美元符号；没有修改真实价格或配置。
