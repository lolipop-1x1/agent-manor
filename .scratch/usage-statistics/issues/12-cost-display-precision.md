# 费用金额统一显示两位小数

Type: task
Status: resolved

## 范围

- 用量指标、无时间小计、会话及请求明细、趋势与提示、排行、热力图和会话画像的费用金额统一保留两位小数。
- 保留已确认零值、未知值及部分估价状态；计算、存储、筛选与模型单价使用原精度。
- 调整既有浏览器验收的显示值，验证中英文及图表，不新增格式镜像测试。

- 仅调整展示精度，后端金额与单价不舍入，未知值及部分状态保持原语义。
- 中英文与类型检查、构建、9 项相关自动测试、147 项用量 Chrome 检查及会话费用专项的中英文／窄屏回归通过；公开内容和空白检查通过。
