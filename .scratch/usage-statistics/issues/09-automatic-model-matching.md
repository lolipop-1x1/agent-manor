# 通用模型识别与官方 API 优先估价

Type: task
Status: resolved

## 范围

- 使用通用名称结构识别模型，不绑定某个客户端或命名空间；完整名称、大小写、分隔符和 Claude 系列顺序参与候选识别，版本及功能变体保留。
- 用户原始模型手动价格与明确映射最高；自动估价优先同模型官方 API 目录，其次同版本公开聚合目录，再保留现有可确认的目录匹配。
- 免费、订阅和 token plan 渠道不影响官方 API 基准优先级；仅移除名称中明确的免费计费标记，不删除日期、thinking、flash、pro 等模型变体。
- 以 matchBasis 和 priceMatchBasis / priceModel 保留自动映射依据与目标；更新价格解析版本，只重估费用，不改变 Token、来源身份或筛选值。
- 自动结果不写入手动配置。无法唯一识别目标版本时保留未定价。

## 验证边界

沿用已确认的公开估价接口 PricingService.estimate / createPricingEstimator，采用合成目录和已知手算结果验证官方优先、任意命名空间、手动覆盖、历史价、变体、歧义与缺失分项。

## Comments

- 2026-10-11：用户确认自动匹配、允许手动调整，并明确免费及 token plan 套餐均按 API 单价估算。直接在 main 实施，真实记录仅在本机忽略目录核验。


## Answer

- 共享模型解析器建立名称签名及候选缓存，识别通用命名空间、大小写、分隔符、Claude 名称顺序及免费标记。版本、日期和功能后缀继续参与匹配；歧义不猜目标。原厂 API 基准优先于渠道免费及套餐单价，缺同版本原厂条目时采用同版本公开聚合目录基准。
- 手动原始模型价格与明确映射优先，不将自动结果写入用户配置。请求及精简汇总保留采用模型与官方／公开目录基准，解析规则版本升级只失效费用汇总；原始模型、来源及 Token 继续复用。
- 750 项自动测试、147 项隔离 Chrome 检查、国际化、类型、生产构建及公开内容检查通过。红绿回归验证名称顺序与日期后缀、免费目录重名及映射更名不残留旧身份，最终规范与需求审查已整合。
- 20 组固定真实索引及价格目录的 API 前后对照中，Token、请求、会话和原始模型分组保持一致。目标来源 148,463 条请求中匹配 148,400 条，独立分桶金额求和与实际 API 一致；137,671 条仍保留部分估价，未将缺失分项补零。
- 同步领域术语、定价决策、规格、使用设计及验收边界。真实数据与运行报告仅保存在本机忽略目录。
