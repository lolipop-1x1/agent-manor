# 用量统计界面与下钻交互整理

Type: task
Status: resolved

## Scope

- 减少常驻来源、版本与重复状态文案，保留估算及缺失语义。
- 请求明细使用宽对话框，保留九列表格，关闭后恢复会话列表位置和焦点。
- 时间趋势与日历在同一区域切换，保留完整范围、键盘选择与下钻。
- 模型价格列表与编辑在同一工作区切换，默认显示已记录及已配置模型。
- 提高正文与控件字号，费用使用美元符号并保留两位小数。

## Acceptance

类型、翻译、公开内容检查通过；隔离合成数据验证查看与返回、筛选、价格覆盖及映射、异常重试、语言和深浅主题。真实页面检查长标题、年度趋势、窄屏与滚动定位，详细截图保留本机忽略目录。

## Resolution

已实现宽请求对话框及列表位置恢复、价格列表／编辑工作区、已记录与配置的默认目录范围、趋势／日历切换、可见缺口状态和按需详情。正文与表格 13px，控件与辅助文字 12px；美元金额使用 `$` 与两位小数。真实页面迭代修正重复计价说明及首次目录菜单拦截。

766 项自动测试与 364 项隔离浏览器检查通过，另通过会话费用专项；类型、翻译和 Web 构建通过。真实桌面与窄屏核验保留截图在本机忽略目录，未修改个人价格或原始历史。详细结果见 [验收记录](../../../docs/validation/usage-statistics.md#用量界面与下钻交互回归)。
