1. 错误、未就绪和本地校验状态保存 Error 或 descriptor，渲染时翻译；切换语言不重发统计查询。

## Answer

已列问题均已修复。错误与本地校验保存 Error 及稳定描述标识，语言切换按当前语言渲染；统计重试序号参与读取依赖，相同索引和价格版本仍重新查询并结束加载。缺失模型和项目使用独立查询身份，真实 `unknown` 编码为 `literal:unknown`，真实 `literal:` 前缀再编码一层，展示恢复原名。

数量提示补齐英语单复数与中文格式；缓存比例新增 `cacheReadRatioRequests` 并直接显示相同可计算请求集合的覆盖。缺 Token 与缺必要单价分别返回 `tokens_missing` 与 `price_missing`。服务与管理页共享精确模型价格解析，映射行显示目标有效单价，用户覆盖仍最高优先。请求依据可展开实际适用单价和 `appliedContextThreshold`，基础档位为 0；目录依据可展开全部输入阈值和对应单价。另修复趋势从无桶变为有桶时重新观察宽度，保证图表文本比例。

验证：`npm run check` 通过；用量聚合、价格、输入、HTTP、前端模型与国际化共 47 项专项测试通过；`git diff --check` 通过。新增回归覆盖真实 `unknown`、缺失和真实 `literal:unknown` 各自包含/排除，缓存覆盖计数，缺单价/缺 Token 的不同原因，共享映射与覆盖优先级，已选上下文阈值及数量复数。真实浏览器的错误语言、失败重试、映射、覆盖和档位展示由集成任务继续验收。

独立复核又确认并修复两处展示遗漏：筛选标签的读屏名称复用可见原名／缺失标签；未定日小计用自身覆盖数量直接标出部分 Token、部分估价与未定价。合成浏览器覆盖三条未定日请求、部分 Token，以及定价从全部缺失变为一条部分估价、两条未定价的状态，不改变有限日期总量。最终 Chrome 60 项检查通过，浏览器没有运行错误。
