## 设计阶段只读核查

- 当前画像查询聚合单会话自身或已明确关联的子会话树，尚无跨会话按请求时间、模型汇总的查询接口。会话列表的日期条件使用会话时间，不能直接充当用量事件日期筛选。
- 模型用量保存可选的请求时间、模型、输入、输出、缓存读取、缓存写入及推理输出。可选字段缺失不代表零，模型及时间缺失需要独立保留。
- 已有缓存归一化与累计快照去重规则可复用。全局统计不能把每个父会话的整树画像相加，否则会重复计入子会话。
- 现有请求趋势使用请求序号；全局趋势需要按明确时间归属重新聚合。表格分页与图表范围已经分离，应继续保持。
- 输出与推理的包含关系受历史格式影响，不能统一相加；计价必须在分项含义明确后进行。
- 上述结论记录设计阶段的只读核查；实施后的功能测试和浏览器结果见验收记录。
- 已确认独立保留手动配置并保障其最高优先级，自动目录与覆盖分别持久化。
- 公开价格接口已实际收到完整 JSON 并解析成功；缓存与上下文档位字段存在。新方案保留这些含义，不仅保留四个平面单价。
