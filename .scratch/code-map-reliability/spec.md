# 代码地图可靠性修复

本轮范围为已确认的三项问题：关联历史分析内存溢出、Worker 失败后周期重提任务、筛选等待与失败时清除上一完整结果。

- 原始输入输出及历史片段不截断、不删除；降低整轮同时驻留的正文，不调大 Worker 堆上限。首次与增量分析均保留完整证据、对应范围及完整版本发布语义。
- Worker 崩溃后停止受影响仓库自动重提；显式刷新允许恢复，成功后恢复自动周期。其他仓库不因旧失败永久停用。
- 筛选请求与展示快照分离。等待和失败期间保留地图、统计、详情与布局，暂停旧结果下钻；成功后同版整体替换。快速切换不能让旧请求回流。
- 验证包含受限堆合成回归、故障恢复、筛选延迟与失败、中英文及窄屏、全量测试、真实仓库和 Chrome 验收。
- 检查公开内容、显式提交清单和 Git 身份后提交并推送 main，回读远端 SHA 与工作区状态。
