# 新增 Code Agent 历史来源

Status: resolved

## 已确认范围

- 新增 DeepSeek Harness、Pi、WorkBuddy、OpenCode、ZCode、CodeBuddy、Qoder；界面使用正式展示名 DeepSeek Harness。
- 贯通代码地图、全局会话库、搜索、简易／完整／轨迹视图、会话画像和 Web／CLI／API。
- 本机现存历史全部纳入验收，并支持可由官方源码或真实样本核验的格式版本；未知版本保留明确采集缺口，不承诺未经核验的全部旧版本。
- 沿用只读来源、可重建本地索引、完整版本原子发布、失败保留上一版及来源缺失规则。
- 沿用记录值、估算值和未记录分开；缺失模型、用量、缓存或关联字段不补造，不按客户端统一假定支持程度。
- 沿用内置适配器注册；客户端身份与历史格式分别保留，多个客户端可以复用格式规范化。
- 简易视图默认展示当前有效分支；完整／轨迹默认展示全部已记录过程，明确分支并可切换定位。当前分支遵循客户端持久化规则，不能声称还原尚未写入日志的实时切换状态。
- 会话画像、Token 和代码活动默认统计全部已记录的实际活动，包括后来未采用的分支；对有依据的分叉继承前缀去重。分支阅读切换不改变默认统计范围；若提供分支统计，必须明确标注范围。
- 按上述七个产品身份接入。ZCode 作为桌面客户端，任务索引与关联消息库合并，不新增 ZCode CLI。CodeBuddy／Qoder 先保留产品名及来源说明，不凭内部引擎猜测或拆分客户端形态。
- 原生记录明确证明为委派子会话时，显示子 Agent 标签；父记录缺失另标注父会话未记录。默认列表隐藏，现有显示子 Agent 开关可展示，搜索与直接链接始终可访问。无项目或任务式提示词不是隐藏依据。
- 简易视图保留所选分支中已保存的真实用户消息及最终回答；压缩摘要、注入上下文及自动续轮作为完整／轨迹的过程记录，不构成新用户轮次。历史对话与模型实际接收的压缩后上下文分别处理；来源已经丢弃的正文不补造。
- 研究优先使用真实来源的结构及字段；存在歧义时核对官方源码或本机安装包。已存在参考仓库优先复用，需要时才克隆公开项目。
- 公开文档和回归样本使用匿名合成数据；真实输入、会话身份、项目路径和详细诊断仅保存在本机忽略目录。

## 来源身份与副本规则

- 按客户端身份与原生会话身份归属记录，格式相同不等于同一客户端。标题、路径、时间或正文相似不足以自动合并不同会话。
- 同一原生会话的格式代际、投影和元信息不独立计数。优先可核验的完整原生事件来源，元信息按明确原生身份补充；存在差异时保留来源、冲突和选取依据，不直接拼接正文。
- DeepSeek Harness 的 V3／V4 副本及投影缓存分别识别；只读解码，不调用客户端触发迁移。ZCode 任务索引与消息库按原生身份关联，不把两库数量相加。
- 子委派、独立分叉及会话内分支分别建模。父会话关联与父工具调用关联是不同精度；无调用身份时只展示可证实的父会话关系。
- 分叉继承前缀按原生标记或可核验的复制关系去重。无法确定继承边界时标注统计限制，不凭相似内容删除实际活动。

## 适配与展示边界

- 复用现有内置适配器注册，来源发现、读取、格式规范化及来源指纹由适配器负责；代码地图与会话库共用来源和事件语义。只改为新增来源所需的现有客户端特例，不进行无关重构。
- JSONL、SQLite 和压缩事件流分别采用有界读取；SQLite 只读一致快照应包含已提交 WAL 内容。文件追加、格式代际变化、数据库变化和补充元信息变化都应参与增量刷新判断。
- 规范化保留原生角色与实际语义、事件／调用身份、分支关系、继承边界、模型和用量字段、原始来源定位及缺失状态；未知事件保留过程记录和解析缺口。
- 标题优先明确标题元信息，缺失时沿用现有可解释的标题推断；项目优先原生目录与元信息，无法确认时保留无项目，不按首条正文猜测。注入上下文、工具结果与自动续轮不按原生 user 角色直接计为用户发言。
- 最终回答沿用明确标记优先、顺序推断带标注、中断轮次不补造的规则。失败／重试的模型尝试保留在轨迹中，不能自动当作已完成回答。
- 工具请求与结果按调用身份关联；失败、缺失结果和无法配对分别展示。Skill／MCP 的调用、读取证据和提及沿用现有口径。
- Token 每个来源独立核验口径后归一化。缓存读写与未缓存输入是否互斥、reasoning 是否属于 output 子集均须明确；请求用量与会话累计用量不得相加，工具专用用量不得直接并入模型用量。来源写入的默认零值也需说明记录范围。
- 会话画像默认自身，沿用包含子会话切换；该聚合须处理继承前缀与父子记录去重。记录／估算／缺失分别标注；缓存读取比例只在同一可核验输入范围内计算。
- Web 使用已有统一筛选组件，增加七个客户端选项；保持简易／完整／轨迹、会话搜索、子 Agent 筛选及直接链接入口一致。分支导航只改变阅读视野，完整／轨迹保留全部过程入口。
- 模型上下文只有在原生日志足以重建时展示，明确其完整性；没有保存的系统提示、工具声明或实际请求正文不能宣称已还原。

## 来源能力矩阵

详细字段、格式和公开源码证据见 [来源与源码核验](issues/02-source-research.md)。以下为已核验能力，不保证每条会话都保留全部字段。

| 客户端 | 来源 | 已确认的重点能力／限制 |
| --- | --- | --- |
| DeepSeek Harness | V3／V4 压缩事件流 | 工具配对、模型／用量、reasoning、失败尝试、压缩、分叉继承及委派类别；缓存字段可缺失，父工具调用关联并非总有记录 |
| Pi | JSONL 事件树 | 当前／全部分支、工具配对、模型／用量、压缩及分支摘要；父文件来源不等于委派子 Agent |
| WorkBuddy | SQLite 元信息＋JSONL 正文 | 标题／项目、工具配对、reasoning、模型／用量和上下文标记；缓存原始字段存在，多种用量口径须分别核验 |
| OpenCode | SQLite 会话／消息／part | 工具、模型／用量及原生 Task 父子关系；fork 的关联规则与子委派不同 |
| ZCode | 桌面任务索引＋关联消息库 | 标题／项目、工具、模型请求／尝试、轮次汇总、缓存及耗时；避免将消息用量与请求／轮次汇总重复相加 |
| CodeBuddy | JSONL 转录 | 本机已有用户消息与目录／会话身份；当前样本缺少助手、工具和用量，按缺失展示 |
| Qoder | JSONL 转录与 workspace 元信息 | 标题／目录、消息、工具配对及部分用量；agent／parent 字段不能直接断言本机样本是子 Agent |

## 验收标准

1. **发现与身份**：对本机所有已确认来源做只读清单，与索引逐会话核对。副本、投影、关联元信息不得重复增加会话；未归属、无法解码或缺失来源必须能解释，不得静默丢弃。
2. **原始证据核对**：每个客户端抽查标题、项目、消息角色、实际用户轮次、最终回答、工具参数／结果及原始位置；用原生字段核对模型、用量和缓存。只有来源真的留存对应证据时，才验收该指标。
3. **关系与过程回归**：覆盖当前分支与全部分支、独立分叉、继承前缀、明确子 Agent、缺父记录、注入上下文、压缩、失败／重试和中断。匿名合成样本补足本机未出现但源码已核验的结构；未知能力验收为明确缺失。
4. **数据正确性**：同一次调用的请求、结果和副本不重复计数；分支阅读切换不改变默认画像／代码活动；缓存分母不重复计算，reasoning 子集不重复加总；模型请求和会话累计量不重复累计。
5. **代码地图**：各新增客户端的真实工具证据可贯通读取／修改／活动及证据回查；无返回内容、工具失败或无法定位范围不得虚增精确覆盖。沿用当前文件和行覆盖口径。
6. **查询入口端到端**：七个新增客户端及现有客户端在 Web／CLI／API 的筛选结果、会话身份和统计一致。浏览器验证标题／正文搜索、过程搜索、简易／完整／轨迹、时间线定位、分支导航、子 Agent 隐藏与筛选、直接链接和画像切换。
7. **刷新与性能**：检验首次、无变化及增量刷新，追加事件、SQLite WAL、元信息改动、来源删除和损坏输入；失败不发布部分新版本。记录本机真实语料的耗时与峰值内存，验证搜索和详情保持分页／按需读取，不增加全量正文加载。
8. **开源与回归**：公共样本仅用匿名合成数据，真实路径、身份和诊断留在忽略目录。运行与改动相关的解析、统计、索引及浏览器回归，保持现有客户端及 Quiet 模式等已确认行为，并通过公开内容检查。

## 实现任务

实现及核验已完成，任务关系见 [任务地图](map.md)，验收结果见 [公开验收记录](../../docs/validation/additional-agent-history.md)。尚未确认的原生字段语义按上述缺失／限制规则处理，不补造统计。

## 已有决定

ADR 0005 中 DSH 仅作为交互参考是原会话库首版范围；本需求明确将 DeepSeek Harness 增加为历史来源，不改变该 ADR 的可重建索引与来源生命周期决定。明确委派但缺少父记录时的默认隐藏规则扩展既有列表行为，不能仅按通用父字段把分叉误判成子 Agent。
