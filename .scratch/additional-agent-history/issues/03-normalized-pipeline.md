# 共享规范化与来源注册

Type: task
Status: ready-for-agent
Blocked by: 01, 02

## Scope

扩展客户端注册及内置适配接口，新增来源共用规范化事件供代码地图与会话库消费，复用现有事件身份、工具提取和证据回查。不把七个客户端特例散落到各入口。

## Acceptance

- 原生快照保留来源选择器、哈希、原始记录行及原始正文引用；增量指纹包含相关旁路元信息与 SQLite WAL 的有效数据。
- 共享事件能表达消息语义、调用配对、用量、分支成员／当前分支、继承副本及独立委派身份。
- 既有客户端行为回归通过，未知记录／超预算保留缺口；来源读取有界。

## Comments

实现文件为共享 contracts、registry、规范化 helper、parser／refresh 集成。具体原生解码由 04–06 负责。
