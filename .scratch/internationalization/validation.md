# 国际化验收记录

本次在 main 上实现简体中文与英文，使用固定设计规格和工作树独立评审。测试的仓库、历史、数据目录和管理资源均为隔离合成样本；详细日志和截图留在忽略的 `.local/` 中。

## 验证结果

- `npm run check`：目录完整性、字面量标识引用、参数／复数、服务端和 Web 类型检查通过。
- `npm test`：399 项通过，无失败或跳过；覆盖偏好生命周期与权限、CLI 优先级／自动模式／覆盖不保存／JSON 稳定性、消息来源及描述持久化、资源统计与管理等。
- 服务端与 Web 构建通过；`check:public` 和 `git diff --check` 通过。构建产物包含公开的本地翻译目录，不依赖远程翻译服务。
- `node scripts/e2e-i18n.mjs`：真实 Chrome 共 88 项断言通过。共用控件／代码地图 31 项、资源管理 30 项、会话 27 项；另验证真实 CLI 子进程与 Web 共享偏好、显式覆盖、数据目录隔离及 pretty／紧凑 JSON 逐字节相同。
- 原有代码地图工作区浏览器回归通过；原有全局会话 CLI／HTTP／Chrome 回归通过，覆盖完整 210 条合成用量请求、轨迹定位及标题更新。
- 语言切换保留代码地图和资源地图相机、筛选／日期、分页、资源详情／预览、阅读模式、分支、轨迹选择／折叠、原始正文入口、代码搜索和用量请求。语言切换额外历史／地图／资源查询及管理操作为零。
- 深浅主题与窄屏验证通过；菜单可用键盘操作，Escape 恢复焦点；日期选择及清空保留原筛选边界。资源实际执行备用／恢复、停用／恢复、回收／恢复，组合部分失败使用合成响应验证。
- 旧或未知描述键与外部诊断保留原文和原始详情语境；产品提示按明确标识翻译。真实同名标题／资源名不按中文文本猜测替换；原始消息、路径、工具及模型名不翻译。

## 独立评审与修复

两次独立视角分别核对规格和仓库标准。修复并复查了缺失资源名称来源、父标题来源、趋势双数量复数、未知描述原文回退，以及刷新错误／阶段描述跨字段误配。新增可选描述经消息、画像、资源事件、总览和地图透传，原身份与分组不因语言改变；无法确认来源的旧记录保留原文。

窄屏真实浏览器发现顶栏存在少量横向溢出，已允许窄屏换行。用量图语言菜单失焦曾使请求选择回到首条，现保留最后聚焦请求而保持 Tooltip 的原可见条件；复跑通过。

## 支持边界

只启用经过验收的简体中文与英文；更多语言须按开发文档补齐目录、日历、格式和测试。没有为翻译重建或回填已有历史索引。浏览器写操作使用合成资源，未测试或修改真实客户端配置；没有执行永久清除。

其他页面的共享同步通过浏览器焦点事件验证；偏好保存／读取失败和部分管理结果通过隔离响应注入验证。自动测试与浏览器结果不代表尚未接入语言或客户端原生界面的行为。
