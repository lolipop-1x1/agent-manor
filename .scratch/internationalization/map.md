# 中英文界面与语言扩展设计树

## 已作决策

- 08 已完成跨模块双语、共享偏好与原有功能回归；399 项自动测试及 88 项 Chrome 双语断言通过，独立评审问题全部闭环，详见 [验收记录](validation.md)。

- 05 已完成会话库、消息／轨迹／时间线与画像／用量双语迁移，来源描述保留生成正文与原文边界；81 项定向测试与隔离 Chrome 27 项状态／原文／诊断／窄屏断言通过，详见 [05 结果](issues/05-session-interface.md)。

- 04 已完成全局 Web 语言 Provider／菜单、公共控件、代码地图与代码查看器迁移；23 项针对性测试和隔离 Chrome 双语状态／焦点／错误／窄屏验收通过，详见 [04 结果](issues/04-web-common-and-map.md)。

- 03 已完成服务端产品诊断的稳定描述、418 项双语目录和持久化／DTO 透传；保留原始诊断且不回填旧索引，组合原因使用可选完整详情列表，详见 [03 结果](issues/03-product-diagnostics.md)。

- 02 已实现本地共享翻译基础、语言检测／格式工具与独立原子偏好文件；类型、构建、公开检查及 10 项合成测试通过，详见 [02 结果](issues/02-language-foundation.md)。

- 用户要求支持中英文切换，后续可以扩展更多语言。
- 沿用主干开发、统一组件、原始证据与公开内容边界。
- I1：首版同时覆盖全部 Web 界面与 CLI 人类可读输出；稳定接口字段与标识保持一致。
- I2：Web 首次跟随浏览器语言，手动选择优先并记住；立即切换，保留当前筛选、选中项及地图视野。
- I3：会话标题／消息、Skill 正文、MCP／工具名称、路径与配置值保持原文；只改变产品显示语言及日期／数字展示。
- I4：顶栏提供全局语言菜单，并可选择自动模式。
- I5：首批为简体中文和英文；自动检测中的中文系列用简体中文，英文系列用英文，未支持语言回退英文。
- I6：CLI 默认跟随 Web 手动语言偏好；不采用两者独立的默认偏好方案。
- I7：共享手动偏好按本地数据目录保存；CLI 参数 → 专用环境变量 → 共享偏好 → 自动检测 → 英文，单次覆盖不修改共享值。自动模式下 Web 跟浏览器，CLI 跟系统。
- I8：数字、百分比、日期、日历与数量复数本地化；统计时区、日期筛选边界、原始排序及 JSON 数值／时间戳保持不变。
- I9：产品生成的提示使用稳定消息标识与参数进行翻译；外部错误和无法识别的旧诊断保留原文，以本地化标题说明原始详情。现有接口字段与原始诊断保留，语言切换不重建索引。
- I10：共享本地翻译目录、稳定文案标识、参数和复数规则；中英文完整覆盖，新语言补齐翻译及日历／格式并验收后才启用。运行时缺失回退英文，开发检查发现缺失或参数不匹配失败；规则记录到 AGENTS.md。
- I11：当前 Web 立即切换，其他已打开页面重获焦点同步；CLI 每次启动读取最新偏好，一次执行中语言保持稳定。
- I12：确认机器输出稳定、偏好在重启／清索引后保留、无效参数报错与保存失败反馈，以及完整双语验收和隔离资源管理测试。

## 当前前沿

I1–I12 已全部确认，01–08 均已完成；实现、独立评审修复、完整回归与双语端到端验收已收口。CLI 独立偏好推荐被用户修改为共享手动偏好。

## 设计树

- 覆盖范围 → 页面／控件／错误／帮助／可访问名称 → CLI 边界。
- 语言偏好 → 初次选择／手动覆盖 → 入口／持久化／跟随模式／未支持语言。
- 内容边界 → 原始证据 → 日期／数字／时区／搜索与排序。
- 扩展能力 → 语言目录／缺失文案 → 添加语言／质量检查／验收。
