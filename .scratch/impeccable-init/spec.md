# Impeccable 产品上下文初始化

## 目标

为后续界面设计建立根目录 `PRODUCT.md`，记录目标用户、产品定位、实际工作流、能力边界和长期约束。

## 范围

- 读取现有产品、领域、架构、使用文档及前端实现，区分当前能力与早期设想。
- 通过一次产品访谈确认主要用户及长期定位，再写入产品记录。
- 独立询问未来落地页和展示页的制作流程，仅保存用户明确选择。
- 检查可运行 Web 的 live 配置所需入口和 CSP；已有配置保持不变。

## 验收

- `PRODUCT.md` 包含 `impeccable:product-schema 1` 和 `## Platform`，平台值为 `web`。
- 产品记录以当前实现和确认答案为依据；未确定的许可证、平台及发布状态保留边界。
- 工作流偏好只存于 `.impeccable/config.json`，不混入产品事实。
- live 配置指向实际 HTML 入口；配置检查不修改页面或服务端 CSP。
- 公开内容检查与改动空白检查通过。

## 已确认

- 主要用户是使用一个或多个 AI 编程客户端的个人开发者。
- 长期定位是统一的 Agent 工作环境管家，会话库、代码地图和资源管理共同服务这一目标。
- 后续规划使用历史会话抽取知识或记忆；具体方案尚未确定。
- 未来官网落地页和展示页采用效果图优先；应用页面与文档采用代码优先。
