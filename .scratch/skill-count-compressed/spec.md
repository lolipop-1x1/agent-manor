# 压缩历史与原生 Skill 使用补全

支持 Codex `.jsonl.zst`，修复由客户端原生展开形成的 Skill 使用证据，并通过标准刷新回补历史。

- 原始历史只读，解压流不落明文副本；指纹使用压缩字节，证据使用解压行号。
- 完整逐帧校验，限制解压总量和单条记录；损坏来源不能用成功前缀替换已发布版本。
- 使用来自原生元数据、完整正文及已核验关联；纯提及、目录清单、复制历史不计数。
- 同一次展开的触发、元数据与正文只贡献一次；独立真实读取继续按既有口径计数。
- 测试发现、导入、索引、排行、画像和证据；真实页面核对目标资源，再次刷新确认幂等。
- 对其他客户端和 Skill 做格式审计，公开材料只保留人工合成样例与聚合结论。
- 同线程分段存储须按原生边界补齐前缀，保留真实来源定位；不能用较长后段覆盖前缀中的使用证据。
