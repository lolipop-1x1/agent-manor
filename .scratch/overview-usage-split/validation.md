# 总览用量查询验收

## 实现结果

趋势和组成使用轻量日期统计，默认分布只生成项目维度，筛选项独立读取。客户端、模型及完整排行只查询当前维度；详细委派分摊在打开调查时读取。轻量查询不构建完整报告、会话行、请求预览、价格管理数据或逐日分组。原完整报告和独立用量页继续兼容。

用量、分布和筛选项独立调度，过程统计不再阻塞这些结果。加载中改选会立即取消废弃维度并补读当前维度，批次只等待当前必需结果。已有完整结果仍保留到下一完整批次成功，过期内容暂停下钻。

## 测量方法与结果

固定同一完整索引、价格版本、本机时区、日期锚点和年度范围，逐项对照优化前已保存结果。范围内约 22.7 万模型请求。费用比较允许不超过 `1e-6` 的浮点顺序差异；总量、日期、组成、三种分布、筛选项、基础主子身份及详细委派分摊全部等价。

首次生成测量复用已有事实和小时汇总，私下绕过报告结果缓存读写，不清空数据库。重启测量恢复正常缓存路径。以下为接口响应时间，不代表整页渲染时间，也不代表完全没有派生事实的首次回填。

| 测量项 | 结果 |
| --- | --- |
| 原用量分区首次报告 | 约 15.91 秒 |
| 轻量趋势首次报告 | 5.81 秒 |
| 当前项目分布首次报告 | 5.83 秒 |
| 独立筛选项首次报告 | 5.78 秒 |
| 重启后的趋势／项目分布 | 29／94 毫秒 |
| 同进程趋势／项目分布缓存 | 14／14 毫秒 |
| 趋势、当前分布及筛选项响应 | 约 231 KB，原用量响应约 909 KB |
| 整张默认总览分区响应 | 约 370 KB，原六分区约 1.06 MB |

首次全部分区仍约 18 秒，主要剩余等待来自过程统计和洞察；不宣称整页首次查询已消除等待。独立执行增加一个有界 Worker，本次隔离测量进程峰值约 1.14 GiB，完整回归与真实数据测量串行执行。冷准备仍保存原用量报告需要的有界预览，不将查询时跳过预览构建说成消除全部准备成本。

## 验证

- 完整套件以并发 2 运行，928 项全部通过；类型、双语目录、构建及公开内容检查通过。
- 统计专项对照两种数据路径，覆盖阈值、无日期、时区、模型未知与字面身份、复制排除、覆盖和原接口兼容。预览 getter guard 与调用隔离证明轻量路径不读取完整报告所需内容。
- 通道隔离测试在过程 gate 未释放时返回趋势、分布及筛选项，事实准备仍只经过核心通道。四项首次／刷新切换回归在旧项目请求未返回时也能完成当前模型或工具视图。
- 内置浏览器使用真实数据验证指标／粒度零请求、首次单维请求、回选缓存、快速改选工具、模型局部范围、日期／客户端／项目组合筛选、排行分页、委派按需及分页复用、原会话回查与返回。
- 视觉验收覆盖桌面、实际用户尺寸及 390 像素窄屏，中英文与深浅主题；恢复原语言、主题与浏览器尺寸。界面字体、字号、布局与共享组件保持。规范与规格独立评审通过，发现的废弃维度阻塞已修复并复核；独立视觉审查为 ship。

真实输入、运行日志、查询条件与截图仅保存在本机忽略目录，不进入公开提交。

测试期间还观测到独立代码覆盖请求伴随主线程堆显著增长，触发私下测试进程的内存保护。请求日志不足以判断发起时页面是否隐藏；源码已具备地图活动状态门槛与取消。本轮不据此修改地图路径。测试服务退出后，复用正常服务确认轻量接口和总览页面可用。该独立路径的内存观测与上表的用量测量分开记录，不宣称本轮已经降低所有页面的内存峰值。
