# Skill 与 MCP 统计及本地管理

Status: resolved

## 目标与确认范围

将已索引历史中的资源使用证据与本机资源清单关联，查看使用排行、检查整理候选并管理本地资源。S1–S13 已逐项确认，实现及隔离端到端验收已完成；开发写入仅针对人工资源，真实本机资源只读核验。方法与支持边界见[验收记录](../../docs/validation/resource-management.md)。

新增与代码地图、会话库并列的「资源管理」入口，内部切换 Skill／MCP。首版包含使用排行、本地资源、备用、回收及操作记录；安装市场、自动更新、跨客户端部署同步与插件本体安装／卸载作为后续独立范围。

## 使用排行与证据

- 默认全部已索引历史，可选择近 7／30／90 天、自定义日期、客户端与项目。统计覆盖现有全部 Agent，采集能力、时间或资源归属缺失时保留未知或部分记录状态。
- Skill 默认按使用会话数排序。同一会话内显式调用与成功读取合并计一个使用会话；显式调用次数、成功读取次数及最近使用分别展示，可切换排序。
- Skill 使用排行按记录的完整 Skill 名称汇总，每个名称一行；跨 Agent、项目和路径合并使用，会话数取并集。Agent 为筛选条件，项目与具体路径在详情及证据中查看；不将名称汇总视作已确认的同一安装本体。本地管理继续保留真实本体和各入口身份。
- MCP 默认按服务展示调用次数、使用会话数及最近使用，可下钻到工具；客户端／项目分布、使用趋势和有可靠记录的成功率、耗时均可回查证据。
- 调用失败也属于已发生的使用活动；失败、成功、未知分别计数。成功率仅使用结果可确认的调用作为分母，同时展示未知结果数；它不表示任务效果。
- 耗时只统计来源实际记录的执行耗时，附有效样本数。缺失不记为零，不从相邻消息时间推造执行耗时。
- 资源声明、显式调用、正文读取和文本提及分开；文本提及不计调用。外层脚本含 MCP／Skill 名称不能证明嵌套动作已执行，仅可定位有独立记录的实际事件。
- 稳定事件身份和已证明的副本、分叉复制前缀用于去重。统计全部已记录实际活动，阅读视图或分支切换不抹去实际发生的活动。
- 日期筛选依据事件时间；无法确认时间的记录不硬塞入某日，保留时间缺失数量。使用会话数、趋势及总数不被前端分页或固定明细上限截断。
- Token 属于请求级用量；不把整次请求的用量或费用归因于某个 Skill／MCP，也不把字节大小解释成实际节省的 Token。
- 收藏表示用户认为重要，保护整理操作；它不改变使用证据，也不把使用频率解释为效果或删除价值。

## 本地发现与资源身份

- 扫描已核验的用户级来源、已登记仓库和历史中可确认的项目目录，支持手动添加路径，不全盘扫描。读取现有来源，不执行 Skill 脚本或启动 MCP 服务来完成盘点。
- 来源清单记录客户端、作用范围、原位置、来源类型、发现时间、读取状态及已核验的操作能力。首次发现和文件修改时间不冒充安装时间。
- 配置格式、作用范围和恢复方式已核验的来源才开放写操作；其他来源显示只读或待适配。会话历史目录不能直接当作资源配置目录。
- 区分资源本体与客户端入口。多个入口指向已确认的同一目标时合并总览，保留客户端／项目分布；同名但路径、来源或可确认版本不同的项分别展示。
- 内容指纹用于识别内容相同的副本及检测变化，不仅凭相同名称或指纹合并管理身份。符号链接保留入口与真实目标，断链单独展示。
- 历史与本地清单分别保留：已删除或尚未发现安装位置的资源仍可出现在历史排行；本机安装但没有使用证据的资源仍可出现在本地清单。
- 历史名称不能直接证明属于当前同名安装实例。依据已记录路径、客户端、项目范围及来源关联；有歧义时保留未关联历史，展示未关联状态，不把它计成某个实例的零使用或确定使用。
- 当前本机只读检查确认了 Codex／Claude Code 的用户级 Skill、共享链接、MCP 配置与插件来源形态；其他客户端的配置支持仍需逐项核验。每个适配来源分别声明盘点、统计关联、停用、隔离、恢复、删除能力。

## 整理候选

提供未发现使用、低频、长期未用及断链／缺失筛选。低频和长期未用条件显示所采用的次数及时间阈值，用户可调整，不生成不透明的「有用分数」。

Skill 有显式调用或成功读取证据，就不属于该统计范围中的未发现使用。未发现只描述当前索引、观测窗口和已声明采集能力，不表示从未使用；对应能力缺失、历史归属不明、新发现而观测不足的项显示待检查。

收藏、系统默认及受管理资源默认保护；受管理来源没有已核验写入能力时只读。保护项不因排行靠后或筛选命中被自动处理；用户决定操作前必须查看影响。所有整理建议保持人工选择，不自动执行删除。

## 本地管理

### 操作范围

- 停用：优先使用已核验的客户端原生开关；没有原生开关时明确展示可用的隔离操作，不把文件改名或配置审批状态冒充原生停用。
- 备用：移出指定作用范围的发现位置，保留文件或注册材料及原位置，以便重新启用。
- 删除：先移入本机回收区，保留恢复材料；永久删除单独确认，不自动清空回收区。备用用于以后重新启用，回收区用于待清除，分别展示。
- MCP 管理对象是所选客户端注册，不卸载服务、终止共享服务或删除远端资源；备用／删除按注册保存恢复材料。
- 操作默认针对选中的入口。移走一个符号链接不能移动或删除其他入口共用的目标；操作共享本体时列出全部已发现入口及作用范围。盘点范围不足时标明引用范围待确认，不宣称发现了全盘所有引用，不开放未经核验的本体操作。
- 插件资源可盘点、统计和定位来源。有已核验的客户端原生开关时允许单独停用，否则只读并提供所属插件入口。首版不直接改插件缓存、移动其中单个资源或卸载整个插件。

### 预览与执行反馈

每次写操作先生成可审阅预览：具体资源、入口／本体、客户端、项目／用户范围、原位置、目标位置、共享引用、保护状态和恢复方式。删除及永久清除分别明确确认；确认适用于该次具体预览。

执行前重新检查来源和依赖，来源变化或预览过期时重新预览；先可靠保存恢复材料，再应用修改。配置只修改目标项，保留其他注册、未知字段及当前用户改动，敏感配置值不进入页面、公开日志或导出。

执行结果区分成功、失败、冲突及必要的部分完成，按实际反馈记录，不将忽略的文件错误当成功。恢复遇到原路径被占用、共享关系变化或配置已改动时显示冲突并重新预览，不静默覆盖。

「本地修改完成」与「客户端已生效」分开。没有可确认的客户端信号时显示待重新加载；不自动退出、重启客户端或探测远端服务。

### 数据生命周期

使用聚合与可重建本地发现快照属于派生索引；收藏、管理记录、手动来源配置、备用及回收材料属于需独立保留的管理状态。清除或重建历史索引不清除管理状态，也不恢复或再次执行操作。

恢复与操作记录保存在本机；包含敏感配置的恢复材料使用受限权限，不进入 Git、发布包或普通诊断输出。永久清除的预览说明哪些材料将失去恢复路径，不把仍有副本的状态称为已彻底清除。

## 界面与现有功能整合

- 顶部新增资源管理入口，Skill／MCP 使用同一套布局与筛选；列表支持名称搜索、排序、分页、收藏和资源状态筛选。
- 使用排行主要展示使用指标；本地视图主要展示客户端、范围、来源及管理状态；备用、回收和操作记录分别提供恢复或回查入口。
- 详情展示来源入口、使用趋势、客户端／项目分布、调用结果及可用操作。MCP 服务可展开工具统计，使用证据跳到会话轨迹对应事件并保留返回位置。
- 页面与详情采用受视口约束的独立滚动，避免大量资源、调用明细或操作记录无限拉长整页；所有已记录数据可通过分页、筛选和下钻访问。
- 复用 FilterSelect、ProjectPicker、DatePicker、HelpPopover、现有主题和 Radix 弹层规范。短定义按需展示，每个区域合并帮助入口，不添加常驻解释性小字。
- 未关联、部分记录、未知、只读、受保护、冲突和待重新加载等影响解读或操作的状态直接可见。
- 统计与管理流程通过现有 Web／CLI／API 服务边界贯通；写入入口沿用具体预览、确认和反馈语义，不提供根据零使用自动清理的捷径。

## 实施约束与验收

实施顺序：历史聚合与身份模型 → 只读盘点与支持矩阵 → 可恢复管理 → 页面联动 → 端到端验收。开发前逐项核验来源适配，不沿用参考项目未经验证的目录或字段。

1. 合成历史覆盖显式 Skill 调用、成功读取、仅提及、嵌套代码文本、失败／缺失结果、缺失时间及复制前缀；验证计数、分列、去重、筛选与未知状态。
2. 构造同名不同来源、同内容不同实例、共享链接、断链及仅历史资源；验证关联不会混淆本体与入口，未关联记录不会丢失或误判零使用。
3. 在隔离的人工资源目录及配置中通过真实浏览器执行预览、停用、备用、回收、恢复、永久清除；验证其他入口和无关配置保持正确，源文件变化使旧预览失效，恢复冲突不会覆盖新内容。
4. 清除并重建测试历史索引，验证收藏、手动来源、操作记录和全部恢复材料保留；执行失败不得虚报成功，不保存可用恢复材料时不得继续破坏原来源。
5. 验证统一组件的鼠标与键盘操作、日期清空、长列表、空结果、深浅主题及窄屏；验证 MCP 下钻和证据跳转定位，关键状态与客户端生效反馈符合事实。
6. 真实本机历史和资源只读核验来源覆盖、统计关联及规模性能；写操作使用明确选中的合成资源，不把开发测试授权扩大为清理用户资源。未核验来源维持只读／待适配，记录验收缺口。
7. 提交前执行公开内容检查及 diff 检查；真实资源名称、配置值、用户路径、原始会话标识和截图仅保留于私有本机验证材料。
