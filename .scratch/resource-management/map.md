# Skill 与 MCP 资源管理设计树

## 已作决策

- S1：使用排行与收藏；频率不直接判定效果或删除价值。
- S2：可恢复管理与明确确认后的删除；MCP 管理注册配置。
- S3：默认全部已索引历史，可切换预设与自定义窗口；采集缺失归未知。
- S4：新增资源管理入口，内部切换 Skill／MCP，并与会话轨迹联动。
- S5：全部 Agent 纳入历史统计；管理操作按来源逐项核验开放。
- S6：按真实来源与引用关系归并共享资源，区分资源本体与客户端入口。
- S7：整理候选同时考虑证据与保护条件；读取证据算使用，观测不足不判零使用。
- S8：Skill 默认按使用会话数排序，显式调用与成功读取分列，允许切换排序。
- S9：删除先进入回收区，永久清除另行确认；备用与回收区分开，不自动清空。
- S10：扫描用户级来源、已登记仓库及可确认的历史项目，支持手动路径，不全盘扫描。
- S11：插件资源按核验后的单资源能力开放操作，插件本体另行管理；共享操作展示受影响入口。
- S12：首版补充使用趋势、客户端／项目分布、MCP 工具统计及重复／断链诊断，安装与部署同步另行推进。
- S13：管理状态独立保留；恢复冲突重新预览；本地修改与客户端生效分开，不自动重启。
- 任务 01 已实现[全量使用聚合与证据分页](../../src/resources/usage.ts)，历史身份保留路径与客户端／项目范围，缺失时间和未关联继续可见；合成回归通过，真实历史性能留待任务 05。[结果](issues/01-usage-and-identity.md#answer)。
- 任务 03 已实现[独立管理状态与可恢复操作](../../src/resources/management.ts)，预览／确认、备份与依赖复核、局部配置编辑及恢复冲突通过隔离合成和 HTTP／CLI 验证；客户端加载仍待确认。[结果](issues/03-recoverable-management.md#answer)。
- 任务 02 已完成[逐来源能力矩阵](../../docs/design/resource-support.md)，未知格式、系统与插件保持只读；手动来源保留独立登记身份。[结果](issues/02-local-inventory.md#answer)。
- 任务 04 已完成资源顶层入口、共享本体分析及统一管理交互；任务 05 的 22 组真实 Chrome 验收通过。两路审查问题已修复；真实资源仅只读，写操作使用人工夹具。[验收记录](../../docs/validation/resource-management.md)。
- 任务 06 将 Skill 使用排行调整为完整名称维度，跨 Agent／项目／路径汇总，会话取并集；实际来源与本地操作仍精确关联。325 项回归及 25 组真实 Chrome 通过，现有索引的排行由 1,147 行合并为 387 行，完整统计保持一致。[结果](issues/06-skill-name-ranking.md#answer)。

## 设计树状态

- 使用价值 → S1 指标／收藏 → S3 窗口 → S8 排序 → S7 整理候选。
- 产品入口 → S4 资源管理 → S12 首版统计与诊断。
- 来源 → S5 逐项适配 → S10 扫描范围 → S6 本体／入口 → S11 插件与共享边界。
- 操作 → S2 可恢复管理 → S9 回收／永久清除 → S13 生命周期、恢复冲突与生效反馈。
- 当前需求问题已逐项确认，前沿为空；事实核验和端到端验收列为实施任务，不转换成对未知格式的兼容承诺。

## 资源使用地图设计

用户希望 Skill／MCP 调用越多面积越大，并可点击低频资源进行管理。由 [13 设计澄清](issues/13-resource-usage-map-design.md) 记录讨论，完整查询、线性布局、地图交互及具体入口管理已实现，端到端验收已完成。

- V1 已确认：面积默认使用调用次数，可切换使用会话数；Skill 另提供成功读取次数，各指标不混计。
- V2 已确认：总览增加地图／列表切换，首次默认列表并记住选择，保留 Agent、时间、关键词和状态筛选。
- V3 已确认：点击色块打开右侧详情，保留统计、证据及具体入口管理；同名多本体／注册先选择入口再预览，沿用保护与恢复流程。
- V4 已确认：零指标与未知／观测不足分别展示，保留可点击管理入口；零调用不表示未使用。
- V5 已确认：面积严格线性比例，低频小块通过缩放、搜索定位及筛选访问。
- V6 已确认：颜色表达最近使用时间，保护与收藏用图标，时间缺失保留明确状态。
- V7 已确认：完整筛选结果参与地图，缩放只改变视野；零值与待检查使用独立分页。
- V8 已确认：颜色使用当前范围内任何调用／成功读取的最近时间，不随面积指标改变。
- V9 已确认：保留少会话规则，增加所选面积指标的数值上限；未知与保护状态继续分别处理。
- V10 已确认：缩放／拖动／全屏／适应窗口／定位、约一像素屏幕间隔、正常字号与渐进信息；颜色三段时间、缺失标记；零值与待检查有界布局和独立分页。数值上限默认关闭，切换指标清空。

设计前沿为空，十项已共同确认，规格收口。统计查询和交互能力的两项只读调查已完成；新增资源使用地图术语，没有改变安装身份与资源管理生命周期，也没有新增难以逆转的决策。实施任务为 [14 数据与布局](issues/14-resource-map-data.md)、[15 交互与管理入口](issues/15-resource-map-ui.md)、[16 端到端验收](issues/16-resource-map-validation.md)。

三项实施任务均已完成，356 项自动化测试与 59 组真实 Chrome 验收通过。本机完整统计前后保持一致；两路审查发现的问题已修复，写操作仅在人工隔离资源中验证。方法与支持边界见 [验收记录](../../docs/validation/resource-management.md)。

## 持久目录与管理简化

设计由 [21 目录与管理讨论](issues/21-persistent-resource-storage.md) 跟踪，用户确认后开始实施。

- D1 已确认：正常服务的索引、管理数据库、语言偏好和恢复材料整体迁到默认持久目录，保留索引；测试仍隔离。
- D2 已确认：采用应用内回收区，恢复材料区分 backups 与 trash；去掉备用入口，旧记录保留恢复能力并纳入回收区，不使用系统废纸篓、不自动清空。
- 管理入口按具体本体／注册直接展示，操作仍需预览确认；原生停用的恢复备份位置与真实回收位置分开命名。
- 迁移校验包含 SQLite 完整性、管理路径与恢复关联，不自动删除原数据副本。详细设计见规格的最新补充。

任务 21 的设计讨论已完成。只读核查确认原生停用目标是恢复备份，归档 storedPath 需随数据目录迁移；外部原位置保持不变，旧预览作废，不替换材料正文。该设计继续遵循 ADR 0007 的管理状态保留边界。

实施分为 [22 恢复目录及兼容](issues/22-resource-vault-layout.md)、[23 总览管理](issues/23-overview-management.md)、[24 持久目录迁移](issues/24-persistent-data-migration.md)、[25 综合验收](issues/25-management-storage-validation.md)。目录按资源名称、原入口身份及操作 ID 区分同名材料；Agent 保留在元信息中。列表每行与地图详情顶部提供同一个具体入口管理面板。

任务 22–25 已完成：438 项自动化回归与 67 项真实 Chrome 验收通过，两路审查问题已修复并补回归。当前服务迁入默认持久目录，索引版本、登记、偏好及管理记录核验一致，原副本保留；内置浏览器确认持久预览路径与直接管理入口。真实客户端资源没有执行管理写操作。[验收记录](../../docs/validation/resource-management.md)。

## 使用分类更新

用户要求取消独立“待检查”，未发现使用结合本地资源及已有历史判断，低频和长期未用正常展示。由 [26 分类设计](issues/26-usage-classification-design.md) 跟踪，替代原先用采集完整性和整理保护统一阻断分类的界面规则。

- 已明确：未发现使用描述本地存在且当前统计范围未找到使用证据，不表示从未使用或安全可删；该术语已记入领域词汇表。
- T1 已确认：保护资源照常分类，管理动作独立保留保护。
- T2 已确认：低频默认不超过两个使用会话，阈值可调整；主界面默认调用次数不变。
- T3 已确认：正常分类和统计，相关缺口保留部分记录状态及详情，无关缺口不阻断分类。
- T4 已确认：长期未用默认至少九十天，阈值可调，无记录和缺失日期不推断闲置时长。
- T5 已确认：全部资源界面取消待检查分类和地图分组，旧筛选回到全部，正常零使用记录进入零指标区。
- T6 已确认：名称统计独立保留，具体路径不猜，未关联记录在详情标明。
- T7 已确认：新发现立即分类，读取失败与零记录区分，旧参数与 API 结构兼容；真实本机只读，端到端验证中英文、列表／地图及关键边界。
- 只读事实调查完成：名称级使用统计与具体路径关联分开；首次发现不是安装或使用时间，不能代替最后使用时间。
- [任务 26](issues/26-usage-classification-design.md) 已完成：T1–T7 全部确认，领域词汇和指标设计已更新，规格最新分类章节替代旧待检查与统一阻断规则。设计前沿为空；实现进度见下方任务摘要。
