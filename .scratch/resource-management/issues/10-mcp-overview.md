# MCP 总览与名称聚合

Type: task
Status: resolved
Blocked by: 09

## 目标与验收

- MCP 总览按完整服务器名称合并全量历史及本地注册，会话取并集；未知名称保留来源身份。
- 保留原始注册与证据身份，不按名称合并管理对象，旧来源链接仍精确可达。
- 七类计数、空统计、来源缺口与保护边界沿用 Skill；名称和独立本体收藏分开。
- API／CLI 支持 MCP 总览及详情，保留工具统计、结果、耗时、分布和证据定位。
- 合成回归覆盖同名跨 Agent／项目、共享注册、未知名称、零值／未知、保护及旧链接。

## Answer

- 共用总览聚合与七类筛选，MCP 默认按调用次数降序；历史会话取并集，本地注册不累加历史统计。不同 Agent／项目的同名服务器保留独立注册与精确管理入口。
- 已知 MCP 名称使用独立总览标识；缺名记录按可确认的来源标识分开。既有 MCP 来源排行、旧历史标识与关联规则不变，新总览标识可回查全部同名事件、工具结果、耗时和分布。
- 名称收藏与注册收藏分开，保护、未知／观测不足、来源缺口和零值规则复用 Skill。取消名称收藏清除继承的历史别名收藏，保留本地注册收藏。
- 相关合成回归 40 项通过（总览与使用 32 项，真实 HTTP／CLI 8 项），服务端类型检查通过。覆盖同名跨 Agent／项目／路径、缺名不串源、结果与工具统计、未知／零值、旧链接与具体注册保护；完整构建和浏览器验收由任务 12 统一完成。
