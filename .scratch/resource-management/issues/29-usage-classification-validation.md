# 使用分类回归与端到端验收

Type: task
Status: claimed
Blocked by: 27, 28

## 验收

- 合成测试证明本地零记录立即进入未发现使用，低频及长期未用按证据正常计数，收藏及受保护资源照常分类，缺口不会全局阻断。
- 比较实施前后历史调用次数和使用会话数保持不变；正常零记录、缺日期、未关联证据和查询失败分别验证，不以文件修改时间或首次发现时间推造使用时间。
- 真实本机只读核对现有 Skill／MCP 分类，结果按记录自然计数；筛选范围无符合项时可以为零，不为满足非零展示补造数据。私人输入及截图留忽略目录。
- 真实浏览器验证 Skill／MCP 中英文列表、地图零值区、筛选计数、阈值、旧链接归一、详情关键状态、主题、窄屏及键盘焦点。
- 隔离资源验证保护对象仍无未授权写能力，现有停用、回收、恢复和预览流程不回归；不清理真实资源或启动真实客户端。
- 运行相关及全量测试、类型、翻译完整性、构建、公开检查和 review；在 Answer 中记录方法、结果及未验证边界，更新地图摘要。
