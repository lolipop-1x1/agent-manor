# 持久目录与管理操作简化讨论

Type: grilling
Status: resolved
Blocked by: none

## 已确认

- 默认持久目录沿用 `~/.agent-manor/`，迁移当前服务的索引、管理库、偏好及恢复材料；测试临时目录与正常运行分开。
- 应用内回收区区别于系统废纸篓；恢复材料区分停用备份与待删除资源，不自动清空。
- 去掉备用页与新备用操作，旧备用记录保留恢复能力并纳入回收区。
- 管理按钮按具体入口直接展示；原生停用预览标明恢复备份位置，不能误导为移动 Skill 本体。
- 迁移时停止写入、校验并保留原数据副本，过期预览不能跨迁移执行。

## 待实施验收

- 隔离数据库迁移验证管理档案、恢复关联、索引及语言偏好保留；失败保留原数据。
- 合成 Skill 原生停用、链接回收、MCP 注册回收、恢复冲突与永久清除验证。
- 旧备用记录、旧链接、API 与 CLI 兼容，原生配置和共享入口保持正确。
- 真实浏览器验证管理按钮可见、只读原因、预览位置标签、恢复与永久清除确认，中英文、深浅主题和窄屏。

## Answer

- 用户确认 D1、D2，目录与回收区设计前沿为空；规格已记录最新决定。功能和真实数据迁移尚未实施。
- 已核对服务目录选择及资源管理实现：原生停用的目标字段实际表示恢复备份；数据目录迁移必须处理归档 storedPath，不能只搬文件。
- 迁移仅改写指向原数据目录的管理路径；外部客户端配置、原资源位置和材料正文不做字符串替换。旧预览在迁移时失效，重新核验来源与恢复材料后生成。
- 可重建索引与持久管理状态继续遵循 ADR 0007 的独立生命周期，没有改变历史保留策略。
- 当前只读核查只查看管理库结构、聚合状态及材料数量，没有读取恢复材料正文或原始会话；真实详细结果留在本机。
