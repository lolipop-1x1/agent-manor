# 可恢复管理与独立生命周期

Type: task
Status: resolved

## 目标

实现收藏、具体预览与确认、停用、备用、回收、恢复和单独确认的永久清除，保存操作结果与恢复材料。

## 范围

负责各已核验来源的写适配、入口／本体影响边界、执行前检查、恢复冲突、敏感材料保护及管理状态持久化。MCP 仅操作选中注册；插件按核验能力操作。管理状态独立于历史索引，实施遵循 ADR 0007。

## 验收

仅用人工资源和隔离配置执行写测试；移除共享链接不动共用目标，其他配置正确保留。旧预览失效、备份失败、恢复冲突和部分失败均有正确反馈。索引重建保留收藏、来源配置、记录和恢复材料；本地修改完成不虚报客户端生效。

## Comments

规格：[spec.md](../spec.md)。开发授权不等于清理真实用户资源。

## Answer

- 整合审查修复共享物理 Skill 本体的隔离风险：存在其他已发现引用时不开放备用／回收；新引用与断链引用使旧预览失效。仅移动链接入口的操作和已核验原生开关继续可用。新增隔离扫描回归及浏览器验证通过。

- 新增[管理契约](../../../src/resource-management-contracts.ts)与[ResourceManager](../../../src/resources/management.ts)。收藏、手动来源、首次观察时间、具体预览、管理记录及恢复档案独立保存到 `resources.sqlite`；恢复材料放入独立受限目录，不依赖 `index.sqlite`，清理历史缓存不会清除或重放操作。
- 预览使用随机 ID，15 分钟有效，明确列出入口、客户端／范围、原位置、目标位置、已发现共享引用、收藏保护及恢复方式。执行必须明确确认本次预览，并复核来源内容、共享关系、保护状态及恢复材料；过期、来源变化或重复执行均不应用旧计划。
- 执行顺序为保存备份、校验备份、限制材料权限、保存恢复档案、再次检查依赖、应用修改。共享符号链接仅隔离入口，保留真实目标和其他入口；普通目录完整备份后隔离，恢复不覆盖已占用原路径，恢复原文件权限并校验内容。
- [配置保留编辑](../../../src/resources/config-editor.ts)支持已核验 Codex 用户 Skill 的 canonical `SKILL.md` 原生停用、Codex 用户 MCP 的表内 `enabled=false`，及核心 JSON／JSONC／简单 TOML 注册的所选项备用／回收。全文使用正确 parser 验证，局部编辑保留其他注册、注释、未知字段和 TOML 原数字写法；恢复允许其他项继续编辑，但所选项变化时冲突。
- 插件、系统、未核验来源、共享配置链接、复杂或未经保留编辑适配的 TOML 写法保持只读，能力直接标明；未适配原生开关不伪装为停用。已停用项重复停用被拒绝，不能凭空生成还原档案。
- 成功、失败、冲突与部分完成按实际反馈记录；写入后反馈失败保留有效恢复材料并返回部分完成。恢复后剩余材料继续保留，永久清除必须另次预览和确认；仅清材料不暗示客户端行为已改变。原生修改成功只记录本地完成／待重新加载，不运行资源、连接 MCP 或重启客户端。
- 公开预览、盘点、档案和操作记录不包含注册值、命令或凭证；私有配置与恢复材料限制权限。管理记录支持完整总数、筛选与分页，恢复档案供服务层统一筛选分页。
- [管理测试](../../../tests/resource-management.test.ts)11 项、盘点 7 项及 HTTP／CLI 4 项整合测试通过，覆盖旧预览／过期、共享链接、备份失败、恢复冲突、其他项编辑、未知字段／秘密边界、部分完成、重启／索引清理和单独永久清除。服务器类型检查、公开内容检查与 diff 空白检查通过。
- 所有写验证均使用隔离的人工资源与配置；未修改真实用户资源。当前客户端是否加载外部配置修改仍未做运行验收，保留待重新加载／未知状态。任务 02 已完成，盘点到管理及服务入口已整合验证。
