Type: task
Status: resolved

## 目标与验收

- Skill／MCP 地图面积与总览默认排序统一使用会话数，同一名称在同一会话中的调用与成功读取只计一个会话。
- 主列表、排序和地图不再区分调用／读取次数，原始分类、次数与证据在详情保留，API／CLI 契约不变。
- 旧 Web 链接的调用／读取指标及排序兼容为会话数；原指标上限清除，明确会话指标的上限继续保留。
- 验证只读取 Skill 的会话也能显示色块、同会话多证据去重、Skill／MCP 切换、列表与详情、中英文及旧链接。
- 类型、双语目录、构建及公开检查通过，真实浏览器截图只存忽略目录，管理写操作使用隔离合成资源。

## Answer

- Skill／MCP 主列表统一为五列，默认按使用会话数降序；地图按会话数线性分配面积，移除调用／读取指标切换，保留会话数上限。
- 原始分类、次数与证据仍在详情，API／CLI 不变。只读取 Skill 的会话直接进入地图，同会话重复调用不增大面积。地图不展示跨资源重叠会话数的总和。
- 旧指标及排序链接自动兼容，清除旧次数上限；会话上限、Agent、日期、关键词、所选资源及证据返回范围继续保留。
- 403 项自动化回归、45 项资源及 16 项地图真实 Chrome 验收通过；中英文 Web／CLI 回归、类型、翻译目录、构建、公开内容及差异检查通过。本机只读确认 Codex 读取型资源及五列表格，管理写操作仅作用于隔离合成资源。
