# 资源地图端到端验收

Type: task
Status: resolved
Blocked by: 14, 15

## 目标与验收

- 类型检查、构建、相关统计与布局回归通过；既有资源表格、分页、收藏、工具及管理测试通过。
- 隔离真实 Chrome 验证完整 Skill／MCP 地图、超过二百个资源、正确比例与占比、指标／上限／筛选、零值与待检查分页、主题和窄屏。
- 验证缩放／拖动／全屏／适应窗口／定位、正常字号、屏幕间隔、悬停及键盘信息、地图／列表状态和证据跳转返回。
- 合成写操作覆盖具体入口管理、共享与独立注册、收藏／系统／插件保护、只读／仅历史、冲突及恢复；确认其他入口和敏感配置不泄露或误改，历史活动不丢失。
- 真实本机历史与资源仅只读检查，原始名称、路径和截图留私有目录；完成规范／需求两路审查、公开内容与差异检查，更新正式验收文档。

## Answer

类型检查、构建、356 项自动化测试及 59 组隔离真实 Chrome 端到端测试全部通过：44 组既有资源回归、15 组地图验收。完整数据、一比十真实面积、超过二百项、指标／上限／筛选、独立分页、悬停／键盘、颜色／缺失、缩放／拖动／全屏、相机返回、主题和窄屏均已核验。

合成写入贯通共享链接备用／恢复、独立 MCP 停用／恢复、名称收藏预览、回收／恢复与仅历史只读。回读确认其他入口、目标与配置保留，历史活动不受管理操作影响。收藏遵循既有保护提醒与明确确认规则，没有额外禁止用户操作。

真实本机只读比较前后完整统计、名称身份、本体关联及最近使用，Skill 的 639 项／5,687 条活动和 MCP 的 25 项／5,144 次调用保持一致；内置浏览器显示完整地图。原始输入、配置值与截图留在忽略的本地材料中。

Standards 与 Spec 两路审查完成，定位组件、证据返回相机、极小色块和展开区域遮挡问题已修复，最终没有未解决的实际问题。正式方法、结果和支持边界见 [资源管理验收](../../../docs/validation/resource-management.md)。公开内容与差异检查通过，未新增依赖或公开图片。
