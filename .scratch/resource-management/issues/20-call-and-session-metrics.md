## 目标与验收

- Skill 调用次数包含显式调用与成功正文读取；MCP 按工具请求计数；同一会话的多次使用不增加使用会话数。
- 原始显式调用、成功读取及工具明细保留；旧 API 指标语义不变，统一计数采用新增 uses 指标和排序。

- 隔离合成样本验证中英文、真实浏览器鼠标／键盘选择、重载、双列排序、地图面积与原始明细。

- 旧指标链接迁移，指标上限按口径清除；中英文数量、帮助、零值标题、悬停和键盘提示同步所选指标。
- 424 项自动化回归、45 项资源及 20 项地图真实 Chrome 验收通过；类型、翻译完整性、构建、公开内容与差异检查通过。所有管理写操作只使用隔离人工资源。
