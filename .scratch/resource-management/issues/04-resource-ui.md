# 资源管理页面与会话证据联动

Type: task
Status: ready-for-agent
Blocked by: 01, 02, 03

## 目标

新增顶层资源管理入口，Skill／MCP 共用布局，贯通使用排行、本地清单、备用、回收和操作记录，支持详情与会话轨迹跳转。

## 范围

负责统一筛选、列表与分页、收藏、来源及能力状态、趋势／分布／工具下钻、管理预览与确认、恢复冲突交互。复用现有 Radix 组件、主题及帮助入口；列表和详情受视口约束，不无限拉长整页。

## 验收

真实浏览器验证鼠标、键盘、长列表、空结果、日期清空、主题、窄屏、筛选保持和跳转返回。未知、未关联、只读、保护、冲突及待重新加载直接可见；无常驻解释性小字。
