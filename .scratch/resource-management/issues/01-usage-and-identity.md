# 资源使用聚合与身份关联

Type: task
Status: resolved

## 目标

基于现有稳定事件和使用证据，提供跨会话 Skill／MCP 使用排行、趋势、客户端／项目分布及证据分页。Skill 调用与成功读取分列，按使用会话数排序；MCP 服务可下钻工具。历史资源与当前实例的关联保留歧义。

## 范围

负责资源身份、使用聚合、查询契约及 Web／CLI／API 的共同统计语义。全部数据通过查询与分页访问；不采用前端明细上限作为统计范围，不将请求 Token 归因于资源。

## 验收

合成样本验证时间／客户端／项目筛选、去重、失败与未知、仅提及、嵌套代码文本、同名不同来源及无安装实例历史。排行和趋势总数与证据一致，时间缺失及未关联状态可见。

## Comments

规格：[spec.md](../spec.md)。开始实施时先核验现有解析能力，缺失记为未知。

## Answer

- 资源事件专用部分索引避免遍历普通工具调用的 JSON；配对仍覆盖全部实际调用，同标识的普通调用歧义有独立回归。当前完整索引的查询及统计一致性已核验，性能与首次建索引成本见验收记录。

- 新增[资源契约](../../../src/resource-contracts.ts)与[聚合查询](../../../src/resources/usage.ts)：Skill 显式调用／成功读取分列，同会话去重计使用会话数；MCP 按服务器排行、按工具下钻；提供日期、客户端、项目、名称及排序筛选，全量趋势／分布与证据分页。
- [会话索引](../../../src/sessions/store.ts)新增 `resourceEvents`，只访问完整发布版本中非 copied 的实际工具请求元信息；可唯一配对结果通过调用标识索引定位，不加载消息正文，不推造执行耗时。统计和分页均无全量明细条数上限。
- 历史身份保留客户端、项目与已记录路径，同名不同路径／范围不自动合并当前安装实例。`associateResourceHistory` 提供只读入口关联，缺失路径或多个候选保留未关联／歧义；历史记录继续可见。
- 日期筛选使用事件时间。无时间或无效时间在未筛日期时保留使用活动，在日期窗口下单列 `missingTimeEvents`，不将其计成已确认窗口内的使用；成功率仅使用成功／失败调用，未知结果和有效耗时样本数直接返回。
- [合成测试](../../../tests/resource-usage.test.ts)覆盖全部现有客户端、复制前缀／来源副本、失败／未知、文本提及／外层脚本、同名范围、读取解析器到索引、证据末页和 20,001 调用规模。资源／会话索引／解析器共 57 项回归通过；服务器类型检查、公开内容检查及 diff 空白检查通过。
- 当前历史未记录资源安装版本及 MCP 注册路径时，不补造安装身份。未读取真实历史，真实来源覆盖与规模性能留待任务 05 验收；Web／CLI／API 复用上述共同契约与查询接口。
- 整合审查补齐共享本体分析：入口仍可有歧义，但已确认同一本体时合并活动、会话并集、趋势及客户端／项目分布；无项目筛选使用空项目语义。观测充分且零使用返回明确零计数，未知成功率／耗时继续为空值。
