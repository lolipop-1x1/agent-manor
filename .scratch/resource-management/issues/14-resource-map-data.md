## 目标与验收

- 复用现有名称总览和缓存，提供完整同版本的轻量地图查询，保留 Agent／时间／关键词／状态、未知／保护和实际本体关联；既有列表接口继续分页。
- 面积指标支持 Skill 显式调用、成功读取和使用会话，MCP 工具调用及使用会话。数值上限只比较已知非负数值，未知保留待检查；与原低频会话规则分开。
- 正值按原始数值线性布局，零值和未知不赋伪造面积。百分比分母使用过滤后的全部正值资源，保持稳定身份与微小正值。
- 查询不为地图重解析原始历史，不暴露 MCP 注册值；现有统计、来源与管理身份不变。
- 合成测试覆盖超过二百个资源、同名跨 Agent、会话去重、一比十及巨大差距、零调用但存在读取、未知／缺失时间、上限和同版本完整性。

平面二叉 treemap 使用原数值和零逻辑间隔；屏幕间隔单独投影。巨大差距下通过真实面积恢复几何宽高，不加入最小统计权重，微小正值保留稳定身份与定位几何。
