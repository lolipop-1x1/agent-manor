# 本地盘点与来源能力矩阵

Type: task
Status: ready-for-agent
Blocked by: 01

## 目标

发现已核验用户级来源、已登记仓库、可确认历史项目及手动路径中的 Skill／MCP 注册，记录来源、作用范围、入口、共享目标、状态和操作能力。

## 范围

负责来源适配、只读盘点、真实目标与链接身份、历史关联及支持矩阵。逐客户端验证配置格式；会话目录不当作配置目录。插件和受管理来源保持来源归属，不直接修改缓存。

## 验收

人工目录覆盖普通 Skill、共享链接、断链、同名／同内容不同实例、项目配置、插件来源及不可读／已消失项目。真实本机盘点只读验证；未核验来源明确只读／待适配，首次发现时间不标成安装时间。
