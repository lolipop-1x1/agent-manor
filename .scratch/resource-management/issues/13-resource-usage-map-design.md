# 资源使用地图设计澄清

Type: grilling
Status: resolved
Blocked by: none

## 用户目标

在 Skill／MCP 总览提供类似代码地图的面积视图，调用越多面积越大；点击低频资源可查看统计与执行已有本地管理操作。

## 已确认

- V1：默认调用次数，允许切换使用会话数；Skill 另可按成功读取次数展示。读取与显式调用不合并冒充调用量。
- V2：总览内地图／列表切换，首次默认列表，保留选择；两种视图共享 Agent、时间、关键词及状态范围。
- V3：点击打开右侧详情与实际本地入口管理，保留使用证据；同名多个本体或注册需选择具体入口，沿用预览、保护与恢复。
- V4：指标为零的资源在独立零值列表展示，未知／观测不足放入待检查；均可点击管理。零调用不等同于未使用。
- V5：面积保持所选指标的线性比例；低频小块通过缩放、定位及筛选访问，不用非线性变换压缩差距。
- V6：颜色表达最近使用时间，收藏与保护通过图标表达，缺失时间明确标记。
- V7：地图覆盖当前筛选的全部同版本结果，不受列表分页限制；缩放、拖动和定位只改变视野。零值与待检查使用独立分页。
- V8：最近使用按当前统计范围内任何显式调用或成功读取的最近时间判断，不随面积指标切换；缺失时间与部分记录保留直接可见状态。
- V9：保留现有以会话数判断的低频规则，另增加所选面积指标的数值上限，单位随指标明确展示。未知值不补成零，保护状态继续可见。
- V10：共同确认默认交互。支持缩放／拖动／全屏／适应窗口／定位，屏幕间隔约一像素、正常字号及逐步展开信息；悬停与键盘聚焦显示完整信息。颜色按近三十天／三十一至九十天／超过九十天分段，缺失时间单列；零值与待检查可折叠、独立分页，页面高度受约束。数值上限默认关闭，切换指标清空；关键词改变结果集，定位只改变视野。

## 设计树

- 使用指标 → V1 分列 → V5 线性面积 → V4 零值／未知可达 → V9 数值上限。
- 入口与范围 → V2 地图／列表 → V7 完整结果与视野 → V10 默认交互和有界布局。
- 颜色 → V6 最近使用 → V8 任意使用证据 → V10 时间分段及缺失标记。
- 管理 → V3 具体入口和既有保护／恢复边界，统计名称不合并管理身份。
- 前沿为空，十项决定均得到共同确认；格式兼容、完整数据和浏览器效果作为实施验收，不转换成未验证承诺。

## 已核验事实

- 名称总览已经提供显式调用、成功读取、会话并集、最近使用、零值／未知及本地本体标识；Agent 和时间范围可复用，具体管理继续定位真实入口。
- 总览内部全量聚合后再分页，HTTP 列表上限为 200 行，现有接口不一次返回全部地图节点；实施时需要补齐完整同版本数据查询，不能以当前页代替全量。
- 名称统计与安装身份分开、管理状态独立保留及保护规则沿用现有规格，不引入批量清理或真实资源写操作验收。
- 代码地图相机支持缩放、拖动、定位、全屏及按屏幕尺寸逐步显示信息；资源地图需要用资源名称与使用量布局，不能沿用文件目录树及行数权重。
- 现有低频默认按使用会话数不超过两个判断，和调用次数的面积量不同。仅历史资源无当前入口可管理；其他入口按已核验能力及保护规则开放操作。

## Answer

十项决定均已确认，规格已收口。两个只读子任务核验当前统计、分页、代码地图相机与实际入口管理能力，并完成整合。新增领域术语资源使用地图，扩展地图视野定义；界面方案可逆，未新增 ADR。

实施任务拆为 14 数据与布局、15 交互与管理入口、16 端到端验收。此阶段只写需求和术语文档，未修改产品代码、原始历史或本地资源配置；公开内容及差异空白检查通过。
