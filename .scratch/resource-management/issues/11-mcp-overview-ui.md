# MCP 总览表格与统一交互

Type: task
Status: resolved
Blocked by: 09

## 目标与验收

- MCP 首入口改为总览，按 Agent 筛选；具体项目、注册和路径在详情查看。
- 六列表格展示服务、Agent、使用会话、调用、最近使用和状态，默认按调用降序。
- 复用 Skill 快捷计数、统一分页与排序，刷新与返回保留路由范围。
- MCP 详情保留工具下钻、精确本体、证据、趋势和分布；无历史资源也可查看本地注册。
- 复用现有主题、帮助及筛选组件，无新增常驻说明小字，窄屏与键盘可操作。

## Answer

MCP 与 Skill 共用总览请求、紧凑表格、七类带计数筛选和统一分页。MCP 显示服务器、Agent、会话、调用、最近使用及状态，默认调用降序；无读取列。总览只按 Agent／时间筛选，旧隐藏项目不参与总览或证据范围，精确本地跳转清除项目限制。

详情使用总览 Agent 范围，保留真实历史的工具、趋势、Agent／项目分布、来源、证据与具体本地注册。无历史注册可查看本地入口；名称收藏与本体收藏、精确管理入口保持独立。旧历史链接通过后端兼容详情返回的实际历史 ID 查询证据。

复用现有统一筛选、分页、帮助、弹层和主题，MCP 六列表格使用较窄的滚动区域。`npm run check:web` 与负责文件的差异空白检查通过；真实 Chrome 端到端由整体验收任务覆盖。
