Type: task

## 目标

按完整 Skill 名称合并本地清单与历史使用，Agent 为筛选；历史事件和会话取原聚合结果，不重复相加本地实例统计。未知名称保留原来源身份。

## 验收

- 全部、已使用、未发现使用、低频、长期未用、待检查、已收藏提供计数；计数在当前 Agent、日期和搜索范围内计算，先于状态筛选。
- 未发现使用仅限观测充分且无证据的本地资源。采集缺口按已确认的来源客户端影响对应资源；无法归属的缺口保守影响全部。
- 未知及新发现观测不足不补成零。收藏及系统／插件保护资源不进入整理候选。
- 历史独有与本地独有资源均保留。详情展示具体本体与入口，写操作身份不按名称合并。
- API 与 CLI 提供 overview；同名多实例与共享链接不重复历史统计。
