# 取消待检查入口并统一使用分类呈现

Type: task
Status: ready-for-agent
Blocked by: 27

## 目标

Skill／MCP 总览、本地筛选、地图同时取消待检查，并沿用统一控件、双指标和管理入口。

## 验收

- 取消待检查快捷筛选、本地筛选选项、地图分组及相关独立分页；保留全部、已使用、未发现使用、低频、长期未用及收藏等现有适用入口。
- 地图按当前范围完整结果及所选调用／会话指标绘图，正值保持真实线性面积；正常零记录本地资源在统一零调用／零会话区域可查看和管理，不生成零值面积。
- 沿用中英文、调用次数默认显示、会话数切换、现有低频与闲置阈值编辑；修改筛选、排序或视图不改变底层证据。
- 真正相关的部分记录、时间未记录、使用记录未关联及不可读／缺失状态直接可见，详细说明在现有来源详情及帮助入口，不添加常驻解释小字。
- 旧 candidate=review 链接回到全部，移除或忽略旧 reviewPage／reviewSize 视图状态；不丢失其他筛选、所选资源或视图。CLI 帮助同步取消旧分类展示，旧参数遵循共享查询兼容。
- 具体本体／注册管理仍先选择入口及生成预览，系统／插件／共享保护和回收恢复冲突不回归。
