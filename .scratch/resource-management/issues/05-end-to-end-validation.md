# 资源管理端到端验收

Type: task
Status: resolved
Blocked by: 01, 02, 03, 04

## 目标

从排行与盘点到具体管理操作、恢复和证据回查，完成真实浏览器验收及支持边界记录。

## 范围

负责隔离的合成资源端到端用例、真实本机来源的只读覆盖验证、规模性能、Web／CLI／API 语义一致性，以及最终公开内容审查。未知来源或客户端生效无法核验时明确记录缺口，不宣称支持成功。

## 验收

覆盖规格全部场景，尤其共享入口、插件只读、源变化、恢复冲突、回收与永久清除、索引清除后的恢复材料保留。写入不接触未经明确选择的真实资源。必要类型检查、相关测试和公开检查通过，真实验证材料留在私有本机位置。

## Comments

规格：[spec.md](../spec.md)。使用可访问角色与名称定位统一组件。

## Answer

- 新增[真实 Chrome 验收脚本](../../../scripts/e2e-resources.mjs)及[人工资源夹具](../../../scripts/resource-fixture.mjs)，22 组通过。覆盖统一筛选、收藏、日期清空、空结果、工具下钻、轨迹跳转返回、独立滚动、主题和窄屏；包含原生停用、备用、回收、恢复、永久确认、旧预览失效与恢复冲突。
- 写操作严格隔离；回读确认共享链接目标、其他入口、无关配置、注释和敏感恢复材料保持正确。共享物理本体无备用／回收入口；确定零使用显示零值，共享本体的跨客户端／项目趋势显示完整。
- HTTP／真实 CLI 验证共用服务、具体确认、同源限制及管理状态独立于历史索引。失败保留真实反馈和恢复材料；客户端加载效果维持待重新加载／未知，不把本地文件修改当成生效证明。
- 两路审查发现的共享本体隔离、合并分析及零使用展示问题已修复并复测。未关联历史收藏保护和手动来源精确身份也加入回归。
- 真实本机盘点及历史快照查询只读核验；公开文档仅记录方法、匿名数量和能力边界，原路径／配置／截图留在忽略的本地验证目录。详细结论见[验收记录](../../../docs/validation/resource-management.md)。
- 最终类型检查、323 项自动化测试及 22 组真实 Chrome 端到端测试通过。当前有效索引的 5,897 个会话只读核验，完整统计在专用索引优化前后一致；Skill／MCP HTTP 查询约 2.6／1.0 秒，首次索引创建约 30 秒。现有本地服务已加载最终版本，资源管理页面实际显示数据。
