# Skill／MCP 页面加载性能

Type: task
Status: resolved

## 目标与验收

- 测量资源总览的首次加载、切换与重复访问，区分盘点、历史查询和浏览器初始化。
- 消除同一总览请求的重复历史读取；按统计范围复用结果，收藏、索引更新、资源刷新及时失效。
- 资源页不触发隐藏代码地图的重量查询；保持统计、证据配对、分页与管理保护语义。
- 合成回归验证查询次数及缓存失效；真实浏览器验证 Skill／MCP、地图／列表、筛选和管理入口。
- 类型、双语目录、构建及公开检查通过。真实数据与详细计时仅留在忽略目录。

## Answer

- 总览的名称统计与本地本体关联共用一次事件流；保持固定发布版本、会话并集、证据配对与缺失口径。
- 最多缓存八个统计范围，Skill／MCP、Agent 和日期范围可分别复用；分页、排序、关键词和地图只改变视野。收藏、索引发布和资源刷新使缓存失效，失败可重试。复用时重新判断随时间变化的观测状态。
- 独立来源最多四路并行盘点，合并恢复来源顺序；共享本体命名及保护不变。资源首屏不查询隐藏代码地图，切回地图正常按需加载。
- 本机只读对照：串行盘点约 460–600ms，并行约 220ms；首次 Skill 总览约 3.4s 降至 2.7s，反复切换后端约 9–17ms。真实 Chrome 缓存内页面切换约 110–122ms，HTTP 约 10–16ms。首次历史读取仍有秒级成本，没有重置操作系统缓存，不作为稳定基准承诺。
- 403 项自动化回归、45 项资源浏览器验收和 15 项地图浏览器验收通过；类型、翻译目录、构建、公开检查与差异检查通过。本地预览已重启加载最终代码。真实资源只读，写操作仅作用于隔离合成资源。
