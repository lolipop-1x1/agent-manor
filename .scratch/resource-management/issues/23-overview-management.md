# 总览列表与地图的直接管理入口

Type: task
Status: resolved
Blocked by: 21

## 目标

- 列表每行管理按钮，地图及列表的详情顶部管理按钮，打开同一个具体入口管理区，不切换统计视图。
- 多本体、注册及 Agent 入口显示实际路径；只读及保护原因直接可见。
- 去掉备用页与新备用按钮，旧备用路由及档案归到回收区。
- 停用显示恢复备份位置，回收及恢复使用对应标签；中英文与主题统一。
- 隔离浏览器验证管理可见、入口选择、旧链接、回收恢复及操作保护。

## Answer

已完成前端实现：

- 总览表格新增管理列，每行及列表／地图详情顶部打开同一 Radix 具体入口管理面板；按本体列出真实路径、Agent、项目／用户范围和 MCP 注册定位。
- 管理面板复用具体入口动作，选择后先关闭面板再打开原确认预览；关闭及 Escape 返回原管理按钮，窄屏详情与管理面板不叠加。
- 仅历史、系统、插件、缺失／不可读、其他只读限制直接可见；收藏及已有后端保护仍在预览中执行。
- 去掉备用页与新备用按钮；旧 standby 路由转回收区，旧档案在回收区继续提供恢复与永久删除；操作记录保留原动作但恢复入口归回收区。
- 停用、回收、恢复预览分别标注恢复备份位置、回收位置、恢复位置，中英文一致。
- 管理后总览筛选及选择保持；同面积布局的地图刷新保持相机与挂载状态。
- 已通过 Web 类型检查、中英文目录检查、4 项资源国际化测试、两份 E2E 脚本语法检查与差异检查。隔离真实浏览器验收脚本已增加总览／地图管理、焦点恢复、只读及仅历史原因、旧链接及窄屏覆盖，隔离真实 Chrome 已通过列表 47 项与地图 20 项，共 67 项；相关管理、焦点与视野断言保留。

## Comments

- 综合验收发现窄屏预览会卸载详情中的原操作按钮，已用稳定入口与动作定位重新挂载的按钮恢复焦点；优先恢复窄屏详情内的对应管理入口。
- 地图管理成功提示原先占据布局高度，导致画布缩小并触发相机调整；改为不占画布布局的浮动状态反馈。管理刷新保持原相机倍率及全部色块坐标。
- 浏览器排序与键盘回归改为等待实际异步数据发布和 Radix 初始选中项聚焦，避免在表头更新但旧数据尚在、或菜单焦点尚未初始化时继续断言。排序升降结果与键盘指标选择的断言保留。
