# 总览表格与可跳转分页

Type: task
Status: resolved
Blocked by: 06

## 目标

Skill 总览改为紧凑可排序表格及带计数的快速筛选，资源分页增加页码、首尾页、跳转和每页条数。

## 验收

- 表格展示 Skill、Agent、使用会话、调用、读取、最近使用及状态；排序支持升降序，未知数值独立显示。
- 列表每页 20／50／100 条，分页提供当前区间、页码和跳转；筛选、排序及修改每页条数重置页码。
- 路径和管理动作放详情，保留来源身份及旧历史链接兼容；无历史资源详情可直接查看本地入口。
- 复用统一组件、帮助与主题，无常驻说明小字；键盘和窄屏可操作。

## Answer

总览改为七列表格，快捷筛选显示计数，支持表头和统一筛选组件切换排序方向；详情展示真实本体与入口，不在列表重复路径。

新增统一 `ResourcePagination`，资源列表提供首尾页、页码、跳转、区间及 20／50／100 条容量；使用证据固定十条并保留跳转。筛选与容量修改重置页码，路由保存排序和容量。复用现有主题、帮助及统一筛选组件，分页复用约定已记录到 `AGENTS.md`。整体验收见任务 09。
