# 桌面镜像请求速度

Type: task
Status: resolved
Blocked by: 10

规格：[来源与区间](../spec.md)。用户已授权全部可计算来源接入。

## Scope

按 UUID 和唯一父子关系关联镜像计时，排除累计时长、用量冲突和歧义。

## Validation

合成数据覆盖完整结束、取消、缺失、重复、门槛和消息关联；原始历史只读，公开内容不保留真实输入。

## Answer

桌面原生镜像保存有界请求元信息，通过助手 UUID 或前置输入的唯一后继关联缓存。缓存累计时长不参与计算；用量冲突作为请求级持续状态，后续思考或匹配快照不能恢复速度。五项桌面回归通过，两轴复核关闭冲突发现。桌面专用计时规则 v3 在正常刷新时重算旧缓存。
