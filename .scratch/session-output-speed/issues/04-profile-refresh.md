# 吐字速度汇总、存储与刷新回填

Type: task
Status: ready-for-agent
Blocked by: 02, 07

## 范围

按[规格](../spec.md)复用用量 JSON 存储与 Profile，计算同范围合格子集的平均速度和可计算数量。负责请求查询、覆盖数量、分支／子会话范围和客户端计时解析规则指纹升级。

## 验收

- 全部请求明细与平均值使用同一索引版本，长历史不截断参与汇总的请求。
- 平均值由合格子集输出总量除以同一子集耗时总量，不平均已格式化速度，不把未知值当零。
- 覆盖分母按已识别并去重的请求计算，排除复制和重置，缺失／不合格请求保留在分母中。
- 轮级范围与当前会话／分支一致，右侧沿用当前会话／包含子会话范围。
- 旧 JSON 对象无字段时可继续查询；正常刷新回填受影响来源，不强制重建无关客户端。
- 失败保留上一版，完成后原子发布；查询不扫描原始历史。
