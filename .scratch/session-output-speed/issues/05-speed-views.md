# 统一速度展示、算法帮助与执行轨迹命名

Type: task
Status: ready-for-agent
Blocked by: 02, 03, 04

## 范围

按[规格](../spec.md)在会话页构建统一请求／消息／轮次映射，接入对话、全部记录、执行轨迹和右侧用量。负责统一速度标记、区域帮助图标、请求详情算式以及共享中英文文案。

## 验收

- 同请求跨视图数值一致，多模型片段共享速度但汇总不重复。
- 轮次折叠保留平均值，部分覆盖与缺失状态清楚可见。
- 执行轨迹速度列位于输出／结果与时间／耗时之间，保留固定行高和虚拟滚动。
- 用量明细保留请求定位与分页；无可计算记录时显示数据不足。
- HelpPopover 增加可选纯图标方式，保留可访问名称和现有调用默认外观；帮助按区域合并。
- 详情显示该请求代入算式、用量、耗时与计时依据，缺失不造算式。
- 中文可见名称统一为执行轨迹，英文使用 Execution trace；稳定 `trace` 模式值不变。
- 中英文目录完整，沿用主题、数值格式与现有统一组件。
