# 请求计时、结束依据与模型消息关联

Type: task
Status: ready-for-agent
Blocked by: 02

## 范围

按[规格](../spec.md)扩展单次请求用量的可选计时、结束依据、缺失原因及模型消息组关联。负责 SessionUsage 契约、请求归组和 Codex／Claude Code／CodeFlicker CLI 来源解析，保留原始用量记录的定位身份。

## 验收

- 多消息片段与重复快照归为一个请求，不因输出数相同合并不同请求。
- 可靠识别起止边界，排除工具执行等待，明确结束与推断结束保留依据。
- 工具调用响应结束不要求整轮最终回答；轮次中断不整体剔除之前已经完成的请求。
- 部分响应、未知结束、无效时间、缺失用量、短请求分别保留原因。
- 输出 200 Token 与耗时 1 秒的等号合格；上下边界有合成测试。
- 复制历史、压缩重置与来源投影不新增请求或速度。
- 原始历史只读；桌面镜像和新运行时采集不在本任务范围。
