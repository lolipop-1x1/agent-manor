# 资源管理操作性能

将资源管理的历史统计与当前盘点分开缓存，本地文件和配置变更不重新读取未变化的历史事件。首次重计算在只读后台 Worker 执行，服务主线程继续响应。执行前仍核验真实引用、保护和依赖内容，不以提速跳过冲突保护；减少盘点中的重复计算和操作后的无关状态、证据重载。

链接预览显示解析后的实际目标位置，继续区分链接已还原与目标 Skill 文件可读取。保留三栏、地图、恢复中心、主题和中英文。

验收使用相同来源、统计范围和测量路径，对比预览、执行前核验、操作执行、后续读取、页面切换及并发轻量接口响应。真实来源只读，移除、还原、清除使用隔离人工资源；原位置占用、材料变化、共享引用、系统和插件保护继续有效。测试限制并发，详细输入与截图仅留本机。
