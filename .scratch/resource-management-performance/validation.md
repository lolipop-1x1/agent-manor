## 真实规模只读测量

盘点使用相同的 119 个项目、9,415 个来源、3,473 个入口及 1,028 个本体。扫描与管理装饰分别计时，归一化差分只忽略观测时间和首次发现时间；来源、入口、本体、缺口、诊断及管理能力全部一致。

| 阶段 | 修改前 | 修改后 | 耗时减少 |
| --- | ---: | ---: | ---: |
| 扫描 | 3,052 ms | 2,080 ms | 31.8% |
| 管理能力计算 | 2,504 ms | 88 ms | 96.5% |
| 两阶段合计 | 5,556 ms | 2,168 ms | 61.0% |

| 冷总览期间轻量接口响应 | 10,708 ms | 30 ms | 99.7% |

后两项为本机服务的单次前后 HTTP 探针：同一统计范围、相同 Skill 事件量，刷新后再请求总览，并在总览启动 10 毫秒后请求会话摘要。新版后台首次 Skill 总览 1,378 毫秒，缓存总览 12 毫秒；首次 MCP 聚合仍可能需要数秒，但已在独立只读线程执行。磁盘缓存、调度和元信息变化会影响单次时间，不将这些数值解释为所有机器的保证。

服务重启可能导入新增会话元信息，因此统计正确性另在同一个 SQLite 只读事务中固定历史版本、复用同一盘点，直接比较旧、新完整聚合结果。361 个 Skill 历史名称、7,465 个事件，以及 16 个 MCP 历史名称、4,127 个事件的统计、覆盖信息、来源和本地关联逐字段一致。另有合成差分测试覆盖日期缺失、客户端／项目筛选、同名多来源和关联歧义。
