# 拆分历史缓存并优化管理链路

Type: task
Status: resolved

## 验收

- 本地变更后不重读历史，关联与保护仍随新盘点更新。
- 后台首次聚合不阻塞服务，失败可重试，关闭能回收 Worker。
- 执行前保护和冲突校验保留，操作后的无关读取减少。
- 真实规模和真实页面的前后测量、隔离管理全流程与自动化回归通过。
- 公开检查通过后直接提交推送 main，保留其他任务的修改。

## Answer

已拆分压缩历史统计与本地投影缓存，正式服务使用只读 Worker；盘点复用物理 Skill 的解析和指纹，管理装饰使用引用及来源索引。执行前的完整盘点、引用和内容保护保留。前端区分管理刷新，不重载无关状态及同版使用证据，离开预览时取消读取；相对链接展示实际目标位置。

完整测试 1,260 项、Chrome 工作区 45 项及地图 23 项通过，类型／翻译、构建与公开检查通过。相同资源独立复测中，移除／还原／清除及后续清单读取分别减少 56.4%／59.1%／58.6%；真实冷统计不再占用 HTTP 主线程。方法、全部测量项及边界见 [验收记录](../validation.md)。
