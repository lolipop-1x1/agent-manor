# 执行轨迹缩放

## 目标

长会话的轨迹总览可以放大查看节点，并保持与记录表、选中详情的联动。

## 已作决策

- 横向缩放改变节点间距，标记尺寸、轨道高度和左侧标签保持固定。
- 沿用地图的缩放、适应窗口和定位所选项控件；放大后通过横向滚动或触屏滑动浏览。
- 保留事件顺序、轮次和记录时间三种投影及原有节点键盘选择；缩放围绕当前可见中心或滚轮指针位置。
- 只绘制当前可见区的标记，合并同一像素内的节点；原始记录、节点总数和时间缺失口径保持。
