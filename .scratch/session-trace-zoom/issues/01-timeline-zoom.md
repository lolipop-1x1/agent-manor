# 轨迹总览缩放与定位

Type: task
Status: resolved

## Scope

给执行轨迹总览增加缩放控件、可横向滚动的绘图区和所选节点定位。复用已有图标按钮、提示组件与帮助入口，补齐中英文。

## Acceptance

- 放大后节点间距增加，缩小和适应窗口可恢复完整总览；缩放不放大文字或轨道高度。
- 三种排列方式的点击、悬停、选中标记和键盘选择保持一致；跨可见区选择会自动显示目标节点。
- 缩放围绕可见中心或指针位置，横向滚动、窗口尺寸变化和触屏浏览没有页面级水平溢出。
- 长会话绘制数量受可见区限制，端点和成对工具结果仍能定位。
- 合成数据自动化、中英文及深浅主题、实际长会话浏览器验收通过。

## Comments

- 用户请求轨迹图支持缩放，改善大量对话节点挤在一起的阅读体验。

## Answer

总览支持 100%–6,400% 横向缩放。标题右侧复用地图的减号、倍率、加号、适应窗口和定位图标，以及统一 Tooltip。普通横向滚动和触屏滑动浏览放大后的图，Ctrl / ⌘ 加滚轮围绕指针缩放；键盘加减与 0 控制缩放，原有方向键和首末节点选择继续联动详情。

绘制与命中共享坐标，标记保持 5px × 9px，轨道保持 66px 高。只绘制可见窗口及少量边缘标记，在实际像素内合并并优先保留选中节点。缩放、窗口尺寸变化和三种投影保持正确定位，原始记录与缺失时间口径不变。操作说明合并到现有执行轨迹帮助，中英文齐备。

验收通过：轨迹模型 7 项测试，包括 10,000 节点窗口、锚点和端点边界；3,281 节点人工会话的实际 Chrome 30 项检查，覆盖点击、悬停、键盘、工具结果关联、轮次／时间投影、缺失时间、滚轮锚点、原生横向滚动、窗口变化、触屏、中英文、深浅主题和 390px 窄屏。现有会话可用性 Chrome 回归通过，包括搜索、证据入口、视图切换与 110 轮导出。实际长会话页面已加载新前端并验证缩放控件；截图留在本机忽略目录。
