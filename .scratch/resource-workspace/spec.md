# 资源管理正式页面重设计

Status: resolved

## 已确认范围

- Skill 与 MCP 统一为名称清单，合并历史使用与当前本地位置，删除使用总览／本地资源双入口。
- 三栏工作区：左侧精简筛选，中间列表／地图，右侧详情。复用统一可调宽工作区、筛选、分页、弹层和主题。
- 支持本地存在／未发现／尚未确认，全局／项目级位置；历史筛选不被当前配置位置反推。
- 详情分概览、文件／配置位置、使用记录。具体文件／链接／注册承担操作，不用聚合名称的泛化管理按钮。
- 管理先呈现具体文件、精确配置项或路径的前后变化、已知影响与恢复方式。沿用真实管理协议、并发校验和恢复冲突保护。
- 来源设置和管理工具收进更多，默认来源缺失及适配器诊断不干扰日常页面，实际可处理问题按位置归并。
- 保留地图、未知与零的区别、收藏、分页、历史证据跳转，以及更新期间旧结果与布局。

## 执行与验收

1. 调整统一资源查询、路由兼容与本地筛选 → 单元检查历史口径、位置过滤、未知及旧链接。
2. 改造三栏、详情与管理预览 → 类型／国际化检查、相关自动测试及构建。
3. 使用正式页面与真实 Chrome 验证 → Skill／MCP、地图、三栏缩放、宽窄屏、深浅主题、键盘及错误／恢复。所有管理写操作使用隔离合成资源。
4. 测量真实本机只读性能和隔离页面交互 → 检查请求次数、响应体、收藏与筛选更新；修复实际问题后跑完整检查，提交并推送 main，回读远端 SHA。

## 交付边界

本次已获正式实施与推送授权；独立原型保持原样。真实配置仅只读观察，不用于管理写验收。公开代码、文档、测试和截图使用合成内容，不包含个人路径或真实历史。
