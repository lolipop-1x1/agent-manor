# 发布操作指南

Type: task
Status: resolved

## 范围与验收

- 记录维护者从版本准备、打包和验收到手动发布及结果确认的完整步骤。
- 复用现有 prepack、包外安装及 CLI 验收，不另建打包或自动发布脚本。
- 说明 CI 同一提交、同一 tarball 的验收边界，以及失败后的处理方法。
- 文档使用通用路径和人工示例；检查链接与命令，实际验证打包和包外验收，不执行 npm 发布。

## 计划

1. 对照当前脚本与 CI 编写发布指南，在交付设计文档加入入口。
2. 检查 Markdown 链接和示例命令，执行打包、包外验收及公开内容检查。
3. 记录验证结果，提交并推送 main。

- 复用现有构建、许可检查与包外测试脚本，未增加重复的打包逻辑或自动发布行为。
- 在隔离 manifest／锁文件副本中验证两条版本更新命令，五处版本记录均正确更新，源码版本未变。
- 13 个相对链接、13 个 shell 代码块语法、公开内容及 diff 检查通过。

- 未执行 npm 登录、发布或发布后的线上包回装；这些步骤在文档中保留为正式发版时的人工操作。
