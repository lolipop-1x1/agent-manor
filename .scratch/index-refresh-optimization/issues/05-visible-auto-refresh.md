Type: task

## 目标与责任

负责 web/ 以及本任务新增中英文文案、前端测试。可见页面自动检查全部 Agent，服务端合并；隐藏暂停，恢复补查。新版消息、画像和轨迹一致切换，保留稳定锚点和地图视野。使用 03 的有界查询契约，完整内容仍可访问。

## 验收

数据与完整处理一致；性能收益以固定输入对照验证，不牺牲原始内容、搜索或完整版本语义。

## Answer

- 可见网页每 60 秒触发全部 Agent 快速检查；隐藏暂停新检查，返回可见按截止时间补查。正在进行的请求不重复或因隐藏而取消。当前地图单独检查当前仓库；多页合并交由服务器处理。
- 每 5 秒读取轻量状态；同版不重取消息、画像或轨迹。新版将有界消息、完整画像摘要与轨迹元信息准备完毕后一起切换，失败保留旧版整套结果。按稳定消息身份保留阅读锚点，末尾阅读接续新内容，定位失效直接提示。
- 每次阅读最多 300 条消息、每条预览 6000 字符；长轮提供记录分页。长正文展开、原始详情、回复／代码块／本轮复制按稳定身份读取完整内容。轮平均使用完整去重请求集合，不取当前正文分页作为统计分母。
- 画像首屏只读摘要，进入用量时每页 12 个请求，趋势标明真实请求范围。地图首屏只读摘要，诊断按当前版本展开读取；新版保留地图实例、缩放、中心文件与筛选。
- 轨迹总览默认最多 1800 个代表，缩放后最高 5000 个，所选身份优先保留。聚合直接显示记录总量，代表不推断工具配对；完整阅读表格依全分支确认唯一配对，跨页伙伴仅取有界预览。所有显式有界总览在聚合前后沿用完整原始记录的事件、轮次、时间坐标，旧未传粒度的调用保持原契约。
- 审查修复覆盖：分支切换清除正文偏移；新页到达后重试虚拟列表定位；工具跨页伙伴与全范围歧义；未知轮身份归一；聚合代表替换、跨聚合阈值、工具结果时间极值、空会话零计数；共享完整轮复制及语言订阅。

验证：`npm run check`、`npm run build`、`git diff --check` 通过。定向 store／轨迹／有界查询／调度与复制测试 61 项通过（后补空会话专项单独验证）。`node scripts/e2e-visible-auto-refresh.mjs` 使用人工 3239 条记录、1010 条请求与 Pi 双分支、隔离服务、真实 Chrome，9 组全部通过：可见／隐藏恢复与无变化不重载、新版锚点、失败保留和重试、末尾接续与完整正文复制、短分支偏移、跨页定位、英文窄屏、地图摘要自动检查、地图换版缩放与筛选。详细人工结果和截图留在 `.local/visible-auto-refresh-e2e/`。

边界：高密度长会话缩放继续使用有界代表，不新增局部原始轨迹区间接口；完整原始记录仍由分页、搜索与稳定身份访问。本次不增加独立速度曲线、CPU 分片或自定义刷新设置。
