# 总览用量趋势自适应修复

状态：已实现并验收，结果见[验收记录](validation.md)。

## 行为

- 图表按实际绘图区宽度绘制完整日期范围，避免每日柱形越过右侧区域。
- 每日点间距不足 4px 时显示折线；较疏的每日数据及周、月数据保留柱形。仅改变展示，不聚合或丢弃每日事实。
- 纵轴从零开始，使用整齐刻度；请求数刻度为整数。零值不补造最小高度，缺失值保留空缺。
- 横轴按宽度显示月份或日期刻度，保留首尾日期及跨年辨识。
- 统一悬停、键盘与触屏详情，通过一个键盘入口选择区间，点击或 Enter 下钻原范围；刷新时关闭浮层并暂停下钻。
- 沿用现有字体、字号、主题和 Radix 浮层，不添加常驻解释文字。

## 验收

1. 定向测试覆盖日期聚合、轴刻度、首尾定位、零值和缺失断线。
2. 合成浏览器回归覆盖全年每日、短期日、周月、窄屏、键盘及刷新暂停下钻。
3. 内置浏览器检查真实数据的一年每日、主题、悬停及请求下钻。
4. 通过类型、国际化、构建及公开内容检查。
