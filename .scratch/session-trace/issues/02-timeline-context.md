## Answer

- 参考 DSH `TrajectoryTimeline.tsx` 与 `timeline.ts` 的输入／模型／工具三轨道，自行实现全会话轻量总览。支持事件顺序、轮次与已记录时间排列、悬停、鼠标点击、键盘定位；时间缺失不补造。标记按像素聚合，正文继续分页及可见行渲染。
- 初始上下文按位置 0 单独展示，分页只计算真实轮次；导航改为首轮／末轮／第几轮，重复跳转仍重新定位并高亮轮次，清除旧记录详情。
- 详情使用与事件表一致的边框、背景、元信息和正文；短内容自适应，长内容限制高度并独立滚动；参数／结果与预览／原始正文分别切换。
- Codex `content_item_kinds` 明确分类优先，`user.text`、未知或无效分类保持用户身份；缺少分类时才从完整独立注入包推断。保留原文和原角色线索，识别依据明确展示，规则版本更新可重建索引。
- 全量 215 项测试通过；类型检查、构建与公开内容检查通过；Chrome 端到端验证悬停点击、明确／推断注入、重复轮次与跨页定位、工具关联、深浅主题及窄屏。验收截图均为合成数据，仅存 `.local/session-e2e/`。
