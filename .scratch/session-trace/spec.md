# 会话执行轨迹

参考 DSH 的事件账本与局部记录检查器，让轨迹与全文阅读有明确区别。按轮次展示紧凑记录，工具调用与响应仅按明确身份关联；选择记录后查看正文、参数、结果、原始定位与已记录用量。

保留搜索、用量图、地址定位、父子会话、分页、代码地图入口。长轮次只渲染可见行；缺失信息不补造请求上下文、模型步骤或耗时。

验收：关联规则测试；浏览器验证轨迹表、结果定位、轮次折叠、键盘、长列表、深浅主题及窄屏；完整和简易模式不变。

总览采用输入、模型、工具三行时间线，覆盖整段会话，只加载定位元信息。事件顺序、轮次和已记录时间改变横向排列，点击与键盘定位对应页。导航以真实用户轮次计数，初始上下文单独显示，不占轮次；每次跳转都明确定位，清除上一条节点详情。

Codex 注入优先采用客户端内容分类，缺少分类的旧日志才从完整独立包格式推断；详情说明依据。注入保留原文与搜索入口，但排除简易对话与用户轮次。明确用户文本、未知分类及混合请求保持用户消息。
