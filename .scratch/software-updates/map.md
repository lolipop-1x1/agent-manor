## 已核对事实

- `am update --check` 从 npm 官方公共 registry 读取目标版本，不安装；`am update` 当前直接安装，没有二次确认。
- `--to` 支持明确版本号；当前有更新的判断仅为版本字符串不相等。
- 当前没有自动检查、CLI 新版本提示或 Web 更新入口。
- 一个产品安装可供多个数据目录运行后台。现有更新会拒绝覆盖仍有其他数据目录实例运行的同一安装。
- 共享偏好属于数据目录，现有安装运行登记属于规范化安装路径；更新偏好与缓存的作用范围需要单独明确。
- npm 全局与本地安装支持现有升级流程；源码和临时运行环境不允许自覆盖。
- 更新已有安装锁、服务身份核验、在途任务处理、数据备份及原运行服务重启。失败保留恢复材料，不自动回退数据库。
