# 产品更新方案规格

本轮按已确认方案在 main 实现产品版本检查、Web／CLI 提醒及显式程序升级，完成测试、截图留存、代码审查与推送。npm 尚未发布，安装与 registry 场景使用隔离 mock，不发布包、不升级用户现有程序。

## 已确认范围

- 自动检查提醒，用户主动安装；默认 latest 稳定版及显式指定版本，首版拒绝降级。
- 默认每 24 小时最多自动检查一次，手动检查立即执行；多个数据目录共用安装级设置和缓存。
- Web 检查、提醒并复制命令，终端负责安装；安装前预览并确认，脚本显式 `--yes`。
- CLI 同一目标版本每 24 小时最多提醒一次，Web 不主动弹窗；忽略版本的设置两端共享，更高版本重新提醒。

## 验收

1. 对照现有源码，区分当前行为与新增目标，避免将设计写成已经实现的功能。
2. 完整设计覆盖版本比较、缓存和并发、安装范围、提醒控制、服务与任务、备份恢复、CLI／Web 入口、中英文与测试边界。
3. 领域术语与长期决策分别记录于 CONTEXT.md 和 ADR，原分发方案能够定位本轮设计。
4. 新增文档链接、公开内容与 diff 格式检查通过，不出现外部方案来源叙述。
5. 验证通过后提交并推送 main，核对远端结果。

详细方案见[产品更新设计](../../docs/design/software-updates.md)，访谈结论见[地图](map.md)。
