# 会话范围与地图入口

Type: task
Status: resolved

## 目标

在代码地图搜索、切换和清除会话筛选；从会话库跳转携带当前会话。筛选保持整个仓库的基线分母，各处活动证据一致。

## 验收

- 不同会话及不同客户端的同名原生 ID 相互隔离，复制历史不计入子会话自身。
- 覆盖、热点、未观察文件、文件详情、活动、来源和证据接口使用统一会话范围。
- 浏览器验证自动跳转、独立搜索切换、清除、空活动、键盘焦点、中英文、主题和窄屏。
- 类型、翻译完整性、单元与 HTTP 测试、构建及公开内容检查通过。

## Answer

- 已提供可搜索会话选择器与清除入口，会话库按钮及消息文件跳转携带当前会话身份。
- 活动使用客户端与原生会话 ID 的组合筛选，各地图查询沿用相同分析版本；文件与行分母保持当前基线。
- 会话列表来自该版本的来源与规范事件，标题仅查询已发布会话元信息；子会话可独立选择，复制历史不扩大自身范围。
- 来源定位增加原生会话身份核对，避免分叉副本来源覆盖规范事件归属。
- 574 项单元及 HTTP 测试通过，类型与中英文检查、构建、公开内容检查及 diff 空白检查通过。
- 专用浏览器脚本验证自动跳转、消息文件跳转、切换、清除、空活动、同名搜索、长列表、键盘、焦点恢复、中英文、主题与窄屏；真实本机历史确认分母不变，返回事件及来源均属于所选会话。详细记录与截图仅存本机忽略目录。
- 旧的会话综合浏览器脚本在已失效的“执行入口记录”可访问标签处中止；当前基线已经将该内容放在来源详情中，本任务未修改该旧脚本，也未把它计入通过项。
