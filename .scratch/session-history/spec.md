# 全局会话库、消息轨迹与会话画像

Status: resolved

用户于产品概念图后确认逻辑并授权实现及端到端测试。沿用主分支开发的既有要求。

## 已确认范围

- 本机全部可发现 Codex、Claude Code、CodeFlicker 会话，包含未登记项目及无项目会话。DSH 仅作为轨迹交互参考。
- 顶部“代码地图／会话库”切换；地图状态保留。会话库左侧筛选列表，中间简易／完整／轨迹，右侧画像。两侧可折叠、调宽。
- 列表默认收起父关系已确认且父记录可访问的子 Agent 会话，可切换显示全部；搜索及直接链接始终保留子记录，标识所属父会话，画像／轨迹提供父子导航。正式标题及首条有效请求优先，缺失时按原生任务路径、昵称或编号生成后备并标注来源。孤立、冲突及分叉记录保留独立入口。
- 简易版展示用户和最终回答；明确标记优先，推断必须标记，未完成不补造。完整过程保留正文、思考、工具调用与结果、系统及压缩；按用户轮次折叠并联动事件定位。
- 全局及会话内关键词搜索，默认标题和用户／AI 正文；可加入工具、思考与系统。检索全部有效索引，分页不限制搜索范围；命中隐藏过程可展开定位。
- 模型、消息／轮次、请求用量与缓存、逐步用量、工具状态与已记录耗时、Skill 明确调用／读取证据、MCP 服务器及工具、压缩和子关系可视化。缺失值显示未记录，不能补 0。
- 缓存读取比例为可确认缓存读取与同批总输入之比。输入按客户端归一化，避免缓存写入与 reasoning 重复相加。请求身份及累积进度去重，复制历史仅在有明确证据时排除。
- Token 估算仅针对留存内容，按类型拆分，明确方法；与请求计费用量分开。画像默认自身，可汇总明确关联子会话；分叉共享记录不能重复累计。
- SQLite 可重建索引，来源只读。启动检查＋主动刷新；来源未变复用，改变重新流式解析。完整版本原子发布，失败保留上版并标过期，来源消失排除且显示缺口。
- Web／CLI／REST 同一查询契约。地图事件可定位所属会话消息，会话文件活动可回到地图。

## 工程与验收

- 消息逐记录写入数据库，不在内存保留全部会话正文；消息和搜索均分页。无额外后台监听。
- 合成样本核对三客户端、中文搜索、推断／未完成、用量去重／缓存口径、子会话、来源消失、刷新失败及重建。
- API 和 CLI 共用结果；浏览器验收切换、筛选、模式、过程搜索定位、统计、侧栏和主题，回归现有地图。
- 真实历史仅在本机核验；资料、截图与敏感路径不进入公共仓库。公共材料使用匿名样例。
