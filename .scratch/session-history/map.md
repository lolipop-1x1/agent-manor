# 历史会话浏览、搜索与消息轨迹

## 用户诉求

- 参考 agentsview，浏览全部历史会话并搜索。
- 支持完整过程与简易对话两种查看方式；简易对话显示用户消息和 AI 最终回答。
- 参考 DeepSeek Harness 的消息轨迹交互。
- 会话详情挖掘并可视化相关属性与用量：模型、Token、缓存、Skill／MCP／Tool 活动等；各项证据与口径需逐项明确。
- 沿用本项目独立开发、本地优先、适配器可扩展及公开内容边界。

## 设计树

1. 历史范围与客户端：全局或已登记仓库；DSH 是交互参考还是新增来源。
2. 展示语义：完整过程的可取得证据边界；简易对话的轮次、最终回答、缺失与未完成处理。
3. 搜索：会话列表与会话内定位；用户／AI 正文、工具及其他事件的检索范围。
4. 轨迹：事件顺序与关系；模型请求、上下文变更和子会话仅在来源提供证据时显示。
5. 采集与查询：新消息更新、来源消失、索引重建、分页与原始记录回查。
6. 产品入口与验收：独立会话入口、代码地图关联、CLI／API、真实历史与大消息场景。
7. 会话画像：模型变化、用量与缓存口径、工具与资源使用证据、子会话汇总、估算与缺失、统计图和轨迹联动。

## 已确认

- 用户明确要求历史列表、搜索、完整／简易切换和消息轨迹，并在认可产品概念图后授权实现及端到端测试。
- H1：本机现有三个客户端的全部可发现历史，按客户端／项目／时间筛选；未登记仓库和无项目会话均保留。
- H2：本次只参考 DSH 轨迹交互，不新增 DSH 来源适配。
- H3：记录值、估算值和缺失分开；无记录指标不显示为零，Skill 读取／明确调用／提及不混算。
- H4：简易对话优先使用明确最终回答标记；无标记时可按消息顺序与工具过程推断并标注，未完成轮次不补造回答。
- H5：轨迹按用户轮次组织可折叠过程，并与事件时间线联动；仅展示已记录的过程、请求上下文及时间证据。
- H6：全局与会话内关键词搜索；默认覆盖会话标题及用户／AI 正文，工具参数／结果、思考与系统内容可选，过程命中可跳转展开。
- H7：缓存读取占输入 Token 比例；先归一化总输入及缓存计数，避免重复计算，缓存写入另列，缺少分母时不计算并保留用量覆盖说明。
- H8：会话画像默认统计当前会话自身，可切换包含有明确关系的子会话；父调用、子执行与复制历史不得重复统计，子记录缺失保留缺口。
- H9：会话库采用可重建本地索引，包含浏览和搜索所需消息；来源只读，来源消失按已有规则从新版有效结果排除，清除后可重建。
- H10：启动检查与 Web／CLI 主动增量刷新全局会话索引；统一发布完整结果版本，失败保留上一版，不默认持续监听。
- H11–H13 随整体方案确认：按类型拆分留存估算、画像及逐步用量联动轨迹、独立会话库入口与地图关联，Web／CLI／API 共用查询。
- 长会话易用性方案经用户确认实施：三栏独立滚动，操作区固定；消息按整轮分页，过程按需展开；画像用标签和趋势／分页表组织；搜索定位可清除恢复，地址与父子返回一致。设计与验收链接见任务 08。
- 用量图增加零起点 Token 纵轴及悬浮／聚焦精确值，保留点击定位；仅调整展示与交互，统计解析沿用现有口径。结果见任务 10。
- 子 Agent 展示方案经用户确认：默认收起已确认且父记录可访问的子会话，提供显示开关；搜索保留子记录，父画像与轨迹提供入口。缺少标题时按明确任务路径／昵称／编号后备，标注来源；分叉、孤立及冲突记录保留独立入口。结果见任务 13。
- CodeFlicker 无 cwd 的会话优先用正式 `data.json` 项目映射与来源目录唯一对应，保留来源说明；Bash 目录和跨仓库读取不替代正式归属，编码冲突保持未知。修复与验收见 [任务 14](issues/14-codeflicker-project-metadata.md)。
- [15 筛选下拉框对齐](issues/15-filter-alignment.md)：统一图标与边距，实测垂直居中；前端检查、构建及真实 Chrome 筛选端到端通过。

## 参考核对

- [01 研究](issues/01-reference-research.md) 已完成。agentsview 可借鉴列表／消息分页、过程折叠、搜索跳转和步骤用量；其 Focused 最终回答为启发式，缓存指标存在不同分母。
- DSH 轨迹依赖其保存的步骤与 Session 事件，可借鉴执行时间线与详情联动；不等于其他客户端都保存了完整模型请求。
- 当前项目只索引仓库工具活动，完整对话、模型与用量尚需独立索引设计。上述结论来自本地代码，未运行参考应用或核对真实私有历史。
- 补充用量核对发现 Codex 累计／单次记录与重复发射风险、Claude 流式快照合并及缓存输入分母差异；CodeFlicker 用量字段仍需真实历史核验。不能照搬参考 parser 的 payload 去重或跨客户端直接累加字段。
- H9 的保留边界已记录为 [ADR 0005](../../docs/adr/0005-rebuildable-global-session-index.md)：扩展本地索引以支持会话正文浏览及搜索，继续采用来源只读与可重建索引。
