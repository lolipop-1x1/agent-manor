# 请求用量图的悬浮数值与纵轴
Type: task
Status: resolved
Blocked by: 08

## 用户诉求

鼠标放在请求用量趋势图上时显示数值，并增加纵坐标，让不同请求的用量更容易比较。

## 验收目标

- 请求图显示带 Token 单位的纵轴刻度，零起点与曲线使用同一比例尺。
- 悬浮与键盘聚焦显示请求编号、模型、时间、输入／缓存读取／输出数值；缺失与零值保留区别。
- 提供当前请求的参考线与点标记，点击或键盘激活继续定位消息。
- 浮层在侧栏范围内显示，不遮挡交互；在浅色、深色及窄屏下检查。
- 验证刻度算法及真实 Chrome 交互，真实截图仅留本机。

## Comments

本任务调整图表交互与刻度。任务 09 的压缩用量重置解析问题独立跟进。

## Answer

已增加零起点 Token 纵轴与网格，悬浮／聚焦数值面板显示请求编号、模型、时间和三项精确用量，保留未记录与零值的区别。参考线与点标记随请求更新；左右方向键、Home／End 切换，Enter／空格继续定位消息。图表两端留出命中空间，避免末请求难以操作，浮层不接管鼠标。

前端类型检查与构建通过，针对前端数据行为的 10 项测试通过，真实 Chrome 端到端通过；首末数值、键盘导航、定位、移出隐藏、窄屏边界与浅深色均已验证。真实本机会话的纵轴、数值浮层与请求表核对一致。

设计见 [会话历史](../../../docs/design/session-history.md)，验证见 [验收记录](../../../docs/validation/session-history.md)。截图仅保存在忽略的本机目录。
