# Codex 会话标题
Type: task
Status: resolved
Blocked by:

## 问题

Codex 会话列表及详情把自动注入的 AGENTS.md 或浏览器上下文作为标题，不能正确呈现任务名称。

## 验收目标

- 标题优先采用客户端明确保存的会话名称，来源只读。
- 未记录标题时，从实际用户请求提取后备标题，跳过自动注入的上下文，原始消息保持完整。
- 客户端改名后，即使会话正文不变，主动刷新也能更新标题。
- 合成数据回归覆盖解析、索引、搜索与更新；本机真实会话通过接口及页面核对。
- 公开材料不保存真实历史正文、路径或会话标识。

## Comments

本机页面和接口均已复现标题被自动注入上下文替代的问题。

## Answer

参考 agentsview 按线程 ID 读取 `session_index.jsonl`、以实际用户请求生成后备标题、将名称变化纳入增量刷新。另兼容 Codex 状态库中独立保存的 `threads.name`，以只读方式查询标题列；默认名称优先于旧索引，原始消息不改写。

186 项完整回归、服务类型检查、公开内容检查及真实 Chrome 端到端通过。端到端覆盖列表与详情标题、标题搜索，以及正文不变时通过页面刷新更新名称并与 CLI 核对。本机服务已更新；接口复核 1,355 个 Codex 会话，其中 996 个采用元数据中保存的名称，没有剩余的 AGENTS.md 或浏览器注入标题，当前详情页也显示正确名称。

真实核验记录及截图仅保存在忽略的本机目录。设计见 [会话历史](../../../docs/design/session-history.md)。
