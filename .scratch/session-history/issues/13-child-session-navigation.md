# 子 Agent 会话组织与标题

Type: task
Status: resolved
Blocked by:

## Scope

- 默认列表隐藏当前结果版本中父关系已确认的子会话，提供显示开关；分叉、缺失父来源及关系不明确的记录保留独立入口。
- 子会话标题优先沿用正式标题及首条有效请求，其次任务路径名称、Agent 名称，最后子会话编号；标明标题来源。
- 列表与全局搜索显示子会话身份和父会话标题。全局搜索保留子记录，直接链接仍可访问。
- 父会话画像及轨迹提供子会话入口，子会话可返回父会话，不改变统计及来源保留规则。

## Validation

- 合成样本验证默认列表、全部列表、分页计数、搜索、孤立子会话、分叉与父子定位。
- 验证标题优先级、已有索引刷新和公开内容边界。
- 浏览器验证开关、搜索命中、父子跳转及真实记录。

## Comments

用户已确认上一轮提出的展示方案，沿用主分支开发；真实输入及截图只保留在本机忽略目录。

## Answer

默认列表在数据库分页前排除当前版本中已确认父关系的子会话，Web 开关、CLI `--include-subagents` 和 API `includeSubagents=true` 可恢复全部列表。全局搜索继续包含子记录，列表及命中标识所属父会话；父画像与轨迹提供子入口，子详情可返回父记录。分叉、孤立子会话及关联冲突不会被隐藏，直接链接保持可访问。

Codex 读取原生 Agent 路径及昵称作为子标题后备，保留正式标题及有效用户请求的优先级。标题来源在详情标明，新增规则仅失效对应 Codex 子来源缓存；回归确认未改变的长主会话继续复用原修订。

190 项完整回归、类型检查、构建、公开内容检查及真实 Chrome 端到端通过。覆盖列表与分页计数、搜索保留、父来源消失、分叉、冲突、标题优先级和旧索引升级；浏览器覆盖开关、搜索命中、画像及轨迹中的父子跳转，并继续通过既有长会话、用量和改名测试。本机服务已更新，实际曾显示未命名的子任务现在显示原生任务名称，真实历史与截图不进入公开材料。

验收见 [会话历史验收](../../../docs/validation/session-history.md#子-agent-会话组织与标题)。
