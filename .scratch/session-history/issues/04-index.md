# 全局索引与查询
Type: task

实现 SQLite 分来源修订、版本发布、状态任务、分页列表／正文／搜索及画像。来源未变复用、变更流式重建，失败和缺失边界测试。责任目录 src/sessions/store*、refresh*、tests/session-store*。

## 完成记录

- 独立 `session_*` 表沿用同一本机 SQLite／WAL，不改变代码地图的迁移版本。消息逐记录、有界批量写入，正文不重复编码入元数据。
- 来源内容指纹未变复用；追加或清缓存时重新流式解析。完整版本事务发布，失败保留上一完整版本并标过期。来源删除排除新版，保留前版对照；修订和版本回收只保留当前及前版所需数据。
- 分页列表、正文定位、中文／字面特殊字符关键词检索、画像和地图来源定位均使用同一版本。搜索仅从 SQLite 返回有界摘要。`kinds` 控制列表检索及搜索范围，正文入口保留简易／完整上下文。
- 用量缺失保持空值，缓存比例使用同时记录输入与缓存的请求子集；内容估算与实际用量分开。画像只聚合确认子关系；显式目标须精准匹配会话身份，多父冲突和循环不扩大统计。关系随版本发布，不回写共享来源修订。
- 重复来源采用消息更完整、时间较新的副本，并公开择主缺口；逐步用量默认显示前 200 条，汇总包含全部记录且说明展示范围。
- 留存体量估算由 SQLite 按 Unicode 字符数分组汇总，画像元数据读取不搬运完整正文。地图定位优先来源身份，原始会话身份只能在唯一匹配时回退。
- `node --import tsx --test tests/session-store.test.ts`：10 项通过，覆盖原子失败、稳定前缀、增量／重建、缺失、千条之外的中文搜索、消息更新、缓存口径、父子冲突及版本稳定性，以及 Unicode 估算与子会话来源定位。服务端类型检查通过。

## 支持边界

- 来源按固定前缀解析并校验；允许尾部追加，已有前缀被改写或截短则刷新失败并保留上一版。没有后台持续监听。
- 关键词采用 SQLite 字面匹配，不提供语义搜索。模型记录数量是带模型字段的消息观察数；实际用量请求数只来自有依据的用量记录。
- 未记录的子目标不能推断为完整子会话集合。单条正文及配对缓存限制由规范化层提供，并保留采集缺口。
