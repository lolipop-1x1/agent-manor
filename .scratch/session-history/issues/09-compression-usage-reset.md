# Codex 压缩后的用量重置事件
Type: task
Status: ready-for-agent
Blocked by: 08

## 问题

只读复核发现：Codex 的明确压缩事件之后可能紧接一条 `token_count`。其中 `last_token_usage` 的输入、输出及缓存读取全部为零，但 `total_tokens` 非零，没有独立请求身份。当前实现把这一用量状态当作请求纳入明细，趋势图因此出现跌到零的点，请求数也包含这类重置事件。

随后实际模型请求的输入下降是有原始记录支持的；零点不能解释为真实请求的上下文变成零。不能通过删除所有零值解决问题，真实零用量请求仍需保留。

## 验收目标

- 用人工合成样例复现明确压缩事件、零值重置及后续真实请求。
- 按事件关联和请求身份区分重置与真实请求，不只按数值判断。
- 重置不进入请求计数与曲线；图表以独立压缩标记表达上下文切换。
- 验证压缩前后请求、真实零值、重复投影、明细与汇总口径，并更新解析规则使旧索引重建。
