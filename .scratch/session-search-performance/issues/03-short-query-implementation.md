# 短词索引与查询隔离

Type: task
Status: resolved

## 目标

按已确认设计优化单字和双字字面搜索，保留精确计数、分页、排序、范围及旧版本行为。

## 验收

- 先对比查询与空间基线，记录字符候选结构的选择依据。
- 补建、增删改、级联删除及完整性检查覆盖新索引，索引未完成时保留原查询。
- 计数与分页复用一次候选匹配。
- 搜索 Worker 不阻塞主线程，过期查询可取消，队列有界，同条件请求可复用执行。
- 存在性检查只取首条；筛选和分页不发无用请求。
- 字面特殊字符、单字、双字、混合文字、零结果、高频词、分页和旧版测试通过。
- 相关类型检查、浏览器验收及公开内容检查通过，真实验证材料只留本机。


## Answer

- 实现单字与相邻双字精确词项、类型候选交集、共享匹配、页内摘要及首条存在性查询。短词遵循 ASCII 大小写与 NUL 终止规则；长词保留 trigram 加 LIKE。
- 新索引在刷新线程可续建，所有写连接注册词项函数，触发器和维护检查覆盖增删改、旧版本与回收。首次类型索引建设也移入刷新线程。
- HTTP 搜索使用单独只读线程、固定版本和读快照，有界排队、共享订阅、过期取消及故障恢复通过验证。
- 前端翻页不重查范围，条件变更直接请求第一页；回到之前的关键词也不恢复旧页。连续输入、零结果、焦点、阅读保留及请求数通过真实 Chrome 验证。
- 全量测试曾通过 1221 项；最后查询调整后的 74 项相关回归、类型检查、构建及公开检查通过。固定种子的 Unicode 和特殊字符组合直接验证精确词项与 LIKE 的文档键相等。
- 真实数据在隔离实验中比较完整响应，保留精确总数与排序；查询、索引体积、取消与事件循环结果只存本机忽略目录。已在本机切换新后台，首次索引补建与历史同步完成；HTTP 搜索和原有消息定位通过运行验证。
