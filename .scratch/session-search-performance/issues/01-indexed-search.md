# 索引化会话搜索

Type: task
Status: resolved

## 目标

消除长历史的逐正文扫描，保持搜索结果和历史版本一致，并以真实历史和浏览器验证。

## 验收

- 分批索引迁移及增删改与消息事务保持一致。
- 三字符及以上查询使用候选索引；短词兼容原行为。
- 标题、默认消息、过程内容、筛选、分页及历史版本结果保持一致。
- 搜索视图不发起无用普通列表查询。
- 类型检查、相关测试、端到端测试、公开内容检查通过。

## Comments

原查询计划按会话逐正文扫描，计数和分页重复执行；真实历史反馈环确认延迟远超目标。详细样本只保留在忽略目录。

## Answer

- 新增无正文副本的 FTS5 trigram 候选索引；查询按候选 rowid 先读消息，再关联版本并核验原字面内容。标题匹配、短词扫描和原排序保留。
- 旧库在刷新 Worker 分批补建，游标与索引同事务提交。批次先取写锁，避免服务登记任务时读事务升级冲突；触发器维护增删改。
- 搜索已有选中会话时跳过隐藏列表请求，真实 Chrome 验证只发一个搜索请求、命中跳转和清空恢复。
- 真实历史固定同一版本，5 条命中及 2 个会话的完整响应与原查询逐字段一致；搜索由约 21.7 秒降到首次 148 毫秒，重复 8–9 毫秒；会话筛选由约 14 秒降至 13–19 毫秒。
- 类型检查、218 项测试、真实 Chrome 端到端及公开内容检查通过。短于三个 Unicode 字符继续兼容扫描，首次补建会随历史量增加。详细真实样本仅存本机忽略目录。
