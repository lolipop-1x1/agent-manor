# 会话搜索性能

保持标题与消息的字面子串匹配、默认内容范围、筛选、分页、排序、子会话和历史版本语义。为消息建立不重复保存正文的 SQLite FTS5 trigram 候选索引，最终沿用字面匹配验证。少于三个 Unicode 字符的查询保留兼容扫描。

已有数据库在刷新 Worker 中分批补索引；记录进度并允许中断续建。索引就绪后自动启用，正常写入、修改和删除同步维护。索引建设不要求原始历史重新解析，不改变已发布会话版本。

搜索界面仅请求实际展示的命中结果，结束搜索后恢复普通列表。

验收：真实历史同一版本、同一关键词的结果与原查询完全一致，搜索延迟目标低于 750 ms；合成测试覆盖索引迁移、增删改、字面特殊字符、短词、筛选、分页及旧版本；真实浏览器验证搜索、跳转与清空恢复。真实输入、响应和截图仅存忽略的本机目录。
