# 会话语义搜索规格草稿

Status: needs-info

本规格只整理已确认需求及待决项。功能尚未实现，设计访谈见 [map.md](map.md)，能力边界见 [ADR 0015](../../docs/adr/0015-optional-semantic-search-model-connections.md)，维护窗口与搜索覆盖见 [ADR 0016](../../docs/adr/0016-semantic-index-retention-and-query-scope.md)。

## 目标

为会话库增加可选的语义搜索，支持按大意找回历史对话并跳转原始记录，兼顾构建成本、本机资源和查询体验。关键词搜索继续可用。

## 已确认的用户闭环

1. 在会话库搜索入口旁打开搜索设置。
2. 通过界面配置模型服务地址、模型身份、可选 Key 及调用策略。
3. 明确选择首次构建及后续维护范围，开始前查看入选规模及预估成本。
4. 用户显式开始首次构建，查看进度，按需暂停或继续。
5. 构建后自动维护已选范围内的历史变化，窗口外已生成的有效向量按保留策略继续使用。
6. 使用关键词或语义模式搜索，查看会话分组和原文片段，跳转对应消息。
7. 查看用量和预算状态，修改连接或范围时明确影响。

## 模型连接和凭据

- 接入用户提供的本地或远端 OpenAI 兼容 embedding 服务，首版不负责模型下载、安装和启动。
- 日常配置在界面完成，保存连接不开始处理历史。
- 模型请求由本地后台发起：构建阶段编码正文，语义查询阶段编码查询文本，向量匹配在本地完成。
- Key 可选，保存在独立本地凭据文件；目录权限 0700、文件权限 0600，内容为明文，不宣称加密。
- 凭据独立于可重建索引；普通偏好、浏览器持久存储及日志不包含 Key。
- Key 默认遮罩，用户可点击显示完整值，并支持复制、替换、清除；普通设置读取返回是否已设置，完整值按用户操作读取，不写入地址栏。
- 连接字段、能力测试、维度及编码参数的具体设计待完善。

## 文档内容、维护范围和搜索覆盖

- 默认为用户消息和助手对话正文建立语义索引；思考、工具输入输出、系统注入不默认进入语义索引。
- 原有字面搜索保留已有内容范围。
- 维护范围支持全历史／最近 N 天、项目、客户端及会话关系、执行模式等已记录属性；提供已记录模型等可靠维度，更多筛选可含标题关键词及已记录消息数／轮次数量区间。
- 项目和客户端各自多选；同组任一匹配、跨组同时满足；不限制的维度表示全部。
- 时间按会话区间与窗口是否相交判断，入选后纳入会话的对话正文；估算规模按实际选中的正文计算。
- 子 Agent、普通分叉和 Quiet 不能混成一个互斥类型；未知属性不假装已确认。
- 默认排除已确认子 Agent 和已确认 Quiet，普通分叉及未识别属性保留，用户可调整。
- 语义文档按真实用户轮次组织提问和本轮助手对话正文，长轮次切块；归属不明时保留单条，不跨会话或分支拼接。
- 纳入全部已保存分支的独有正文；对能够确认的继承副本避免重复编码，保留各自的原文定位，不能因去重丢掉唯一可用的正文。
- 维护范围与已覆盖历史分别定义；时间窗口滚动，或主动取消项目、客户端、会话关系等维护条件，均默认保留已有有效向量，继续可搜索。
- 提供独立的“清理窗口外向量”策略，默认关闭，清理对象只包含语义向量及对应派生数据。
- 查询筛选与维护范围分开设置，不自动以维护条件隐藏保留的历史；来源确认删除或正文变化后，对应旧内容的位置映射失效。共享向量仍有其他有效位置引用时继续使用，不延长已经失效来源的生命周期。

## 相同内容的计算复用

- 用户提出按字符串内容计算 hash，复用复制会话等重复正文的编码结果；本方案纳入精确内容复用，具体键结构为待审阅的技术设计。
- 建议在真实用户轮次整理及切块后，对实际发送给模型的完整输入计算 SHA-256；不能只按整份会话文件去重，避免会话标识变化或尾部追加让全部正文重新编码。
- 复用键同时包含完整输入内容的摘要、向量空间身份及影响编码结果的规则。向量空间身份包含模型身份、实际维度及必要的服务身份；文档／查询编码用途、指令前缀和相关参数也须参与兼容性判断。相同文本但编码条件不同不能直接共用。
- 仅用于定位的会话、消息和分支身份保留在来源映射中；不为区分来源而额外加入模型输入。不同有效位置可以引用同一个编码结果，仍分别支持项目、客户端、时间、会话和分支筛选，以及原文跳转。
- 已有完整有效结果直接复用；同一构建中重复输入合并待执行项，执行中的相同请求共享结果；失败或未完整落盘的结果不算可复用。
- 不按语义近似合并正文，不擅自删除代码缩进、折叠空白或改写原文。只复用编码条件相同且实际模型输入一致的内容。
- 内容或切块边界变化后，只处理受影响的输入；保持完整相同的其他块继续复用。不能保证追加任意文字都只产生一个新块。
- 某来源删除或变化时只撤销相应位置映射，不能连带删除仍被其他有效位置使用的向量。清理窗口外数据时同样按位置和引用关系处理，仍有保留位置的共享向量不能删除。
- 开始前分别展示入选来源规模、唯一待编码输入和已有结果复用量，预估调用费用按唯一待编码输入计算；重试等实际调用另行记账，不把复用收益当作已实测金额。

## 查询交互

- 默认关键词实时查询，关键词搜索不调用模型。
- 语义模式由 Enter 或搜索按钮提交，不沿用逐次输入防抖来触发模型请求。
- 查询向量在服务内存中有界复用，相同查询仅修改筛选时可复用；模型配置变化后失效。
- 没有兼容缓存的新语义查询需要先由模型编码查询文本，再在本地匹配正文向量；命中有效查询缓存时不必再次调用模型。正文编码复用和查询缓存分别管理，不假定两种编码用途相同。
- 语义请求失败明确展示错误及重试，不静默切换为关键词结果。
- 复用会话分组、命中片段及原文跳转，默认按相关性排序并允许切换最近更新；每组以最佳片段为代表，可展开更多命中，不显示正确率百分比。
- 候选数量、分页及未覆盖范围的展示行为待完善。

## 可用性与重建

- 首次选定范围完整构建后启用语义搜索，期间关键词可用。
- 后续更新保留上次可用版本，及时排除已删除或失效内容，不混入未完成的新批次。
- 模型、维度或编码规则变化时停用不兼容旧向量，明确提示重建和预估成本，由用户显式开始，期间关键词可用。
- 仅调整 Key、超时、限流等不改变向量空间的设置，不因此要求重建。

## 性能、用量与预算

- 默认后台构建请求并发 1，前台查询优先；用户可通过高级设置调整批次、token 预算、速率、超时和重试限制。
- 首次构建显式开始，后续按范围内变化延迟增量维护；支持暂停与继续。
- 暂停构建只停止正文构建及维护的新任务，不中止主动语义查询编码；已有有效查询缓存继续复用，所有新增模型请求仍受每日预算约束。
- 本地服务运行期间，关闭网页不停止已经启动的构建，以及对已发现历史版本的后续维护；重新打开页面可以继续查看状态。不因此新增持续检查历史来源的机制，后续新历史发现仍遵循既有历史更新策略。
- 开始前展示入选规模和估算费用；未配置单价时费用显示未知，不能当作免费。
- 实际用量与估算分开；提供方未返回实际 token 时不把估算标为实测。
- 可设置本功能的每日估算费用预算，默认不填写。达到阈值后停止新的模型请求，保留缓存查询及关键词搜索。
- 预算只统计本功能发起的调用，不保证服务商账单封顶，也不涵盖其他工具消费。
- 不把请求成功、相似度或候选数量当作检索质量的证明。

## 界面组织

- 搜索设置对话框分模型连接、索引范围与构建、调用策略与用量。
- 普通筛选、项目选择、日期、帮助、状态和弹层复用既有共享组件、主题及中英文目录。
- 设置对话框有独立构建状态区域，搜索入口旁可打开状态，关闭对话框后仍能找到构建进度。
- 进度区展示当前阶段、已完成／总文本块、已用时间及暂停／继续／重试；扫描阶段尚无确定分母时显示阶段，不编造百分比。
- 进度详情区分来源文本块、新编码输入和复用输入，不把复用次数显示成模型调用次数。
- 吞吐、预估剩余时间、用量、费用及失败明细按需展开，估算保留明确标识。
- 覆盖范围和费用依据按需展开；错误和阻断状态可见，不增加常驻说明条。
- 保留已有结果和布局；进行新查询时在固定位置表示运行状态，暂停旧结果下钻，完成后整体替换。

## 具体技术方案草案

以下为根据已确认需求提出的完整方案，尚待整体审阅；数值为建议初值，不是已实现行为或性能实测。

### 连接和切块

- 首版管理一套活动模型连接，界面提供服务地址、模型名、可选 Key；高级项提供模型输入长度限制、编码指令和请求参数。界面展示最终请求地址，避免服务地址与完整接口地址混淆。
- “测试连接”由用户点击后用合成文本发起少量编码，不读取真实历史；检查可达性、返回向量数量、维度及数值是否合法。能力测试不证明不同服务的向量空间等价，也不证明检索质量。
- 向量空间指纹记录模型、实际维度、影响输出的参数及必要的服务身份；仅改 Key、超时或限流不改变该指纹。无法证明兼容的模型／服务切换，按不兼容变化处理。
- 在用户轮次内按段落和明确的代码块边界组织输入；建议每块目标上限为 1200 个 Unicode 字符，相邻块重叠最多 120 个字符，均可通过高级设置调整，不能跨会话或分支拼块。
- 字符长度不等于 token 数。模型输入限制和批次 token 预算使用明确的估算依据；接口返回输入过长时按错误类型缩小受影响输入并更新该轮构建计划，不原样反复重试。
- 实际序列化后的角色分隔、指令及上下文均参与内容摘要；仅用于筛选和定位的来源元数据独立保存。只有完整实际输入相同且编码身份兼容时才能复用。

### 持久化与发布

- 语义数据保存在独立、可重建的本地 SQLite 数据库，不把凭据、手动偏好或原始会话迁入其中，也不额外运行独立数据库服务。
- 逻辑上区分编码结果、内容位置和构建任务：编码结果按复用键保存向量；内容位置保存会话、消息、分支、原文范围及内容版本；构建任务保存计划、检查点、用量和失败状态。一个编码结果可以有多个有效内容位置。
- 向量计算和数据库扫描放在专用 Worker，避免长时间同步工作阻塞本地服务。具体向量检索扩展及索引结构先通过目标规模的性能验证再确定，不将尚未验证的依赖性能写为承诺。
- 每个构建记录输入范围、历史版本和编码配置指纹。首次计划完整完成后发布；增量以完整计划为发布单元，不能逐批把半成品混入活动版本。原始历史索引正常发布不等待模型完成。
- 已发布历史确认变更或删除时，旧位置先失效；未改变的有效位置及其向量继续使用。候选检索和原文跳转都按已发布历史版本校验位置有效性，不在每次查询时重新扫描原始文件，构建失败不能让过时正文重新出现。
- 服务退出后通过已提交的检查点恢复任务状态；未完整保存的模型响应不算完成。不能保证异常中断后的远端调用恰好发生一次，重试费用保留估算或未知状态。

### 调度与动作

- 建议后台并发 1，每批最多 8 个不同输入，并同时受批次 token 预算约束。查询在等待队列中优先，不为抢占而取消已经发出的正文请求。
- 建议内容变化后静默 5 分钟再维护，持续变化最多延后 30 分钟；高级设置可调整，手动“立即更新”跳过静默等待。
- 请求超时建议 60 秒；限流、暂时性网络错误及服务端错误最多重试 2 次，采用退避并遵循服务端重试提示。鉴权、输入格式和向量形状错误不盲目重试。
- 调整范围时预览新增处理量、已有复用量和预估费用，再应用范围。缩小范围不自动删除；扩大范围的历史补建由用户明确开始，后续范围内变化按自动维护规则处理。
- “暂停后台构建”停止发出新的正文编码请求，已发出的请求可收尾并保存；查询照常。恢复时复用检查点，不重新处理已经完成的输入。
- 建议“关闭语义搜索”同时停用语义查询和后台构建，保留连接与索引；“清除语义索引”是单独确认的派生数据删除动作，保留模型连接，之后需重新开始构建。两项动作的具体名称和边界随完整方案确认。
- 清理窗口外内容时撤销对应位置；只有不再被任何保留位置引用的编码结果才可删除。不会因一个会话超出窗口而连带删除其他会话仍在使用的共享向量。

### 查询和结果

- 主动提交后，先检查查询编码缓存；建议内存缓存最多 256 个条目、有效期 30 分钟，按编码身份及完整查询输入区分，执行中的相同查询合并。该缓存与持久化正文编码复用分别管理。
- 缓存未命中时先编码查询，再在本地进行向量匹配。只改时间、项目或客户端筛选可以复用查询向量；筛选条件仍按本次请求重新执行。
- 先确定满足查询筛选的有效位置集合，再检索对应内容；不能先取全库少量候选再过滤，导致窄范围内明明存在结果却漏掉。
- 使用兼容的向量及统一相似度度量，按最佳有效片段的相关性排序并按会话分组；切换最近更新时保留本次候选集合，不能宣称搜索到了所有语义相关会话。
- 建议一次查询保留最多 200 个候选会话，以查询快照进行后续分页。界面表达当前候选和覆盖范围，不将候选数量当成全历史精确总命中数；达到上限时可通过筛选缩小范围。
- 多个会话引用同一向量时仍保留各自结果及定位，按本次筛选决定哪些位置可见，不把去重编码误作合并原始会话。

### 规模、预算与资源

- 预览分开统计会话数、来源文本块数、唯一输入数、已有编码复用数及待编码的估算 token；费用由待编码估算 token 与用户配置单价计算，未配置单价时显示未知。
- 用量按实际发出的请求记录，区分构建、主动查询、连接测试及重试。服务仅返回整批 usage 时按请求保存实际用量，不伪造逐块实际 token；无实际 usage 的请求保留估算标记。
- 每次请求前预留估算预算，结束后按已知用量结算，异常请求保守保留未核实的估算消费。并发预算检查必须避免多个请求各自通过后一起超过调度阈值；复用编码不计作新增模型消费。
- 若唯一向量数为 U、维度为 D，采用 float32 时，原始向量载荷约为 U × D × 4 字节。例如 10 万个唯一向量、1024 维时约 391 MiB；这只是算术估计，不包括位置映射、文本、数据库索引、日志和构建临时空间。
- 精确内容复用减少模型输入和重复向量载荷，但位置映射随来源数量增长，不能承诺整体存储按同一比例下降。内存峰值和查询耗时取决于最终检索实现，须单独测量，不能用磁盘载荷直接推算常驻内存。

### 页面状态和验收

- 首次未配置时关键词搜索保持原体验，由搜索设置引导配置；保存后可预览，显式开始后显示构建状态。首次完成前语义模式显示尚未就绪及进度入口。
- 搜索设置维持三组：模型连接、索引范围与构建、调用策略与用量。常用项直接展示，编码参数及估算依据放在高级设置和按需帮助中，复用既有主题与中英文文案目录。
- 构建状态包含扫描、准备输入、编码、发布、完成、暂停、预算停止和失败；详情区分来源处理进度、新编码和复用。错误及阻断原因可见，关闭对话框后可从搜索旁重新打开。
