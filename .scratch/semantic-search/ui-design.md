# 会话语义搜索界面设计

Status: resolved
Mode: Operate

本稿记录界面与交互方案，用户已授权进入应用实现；未单独制作原型。功能边界沿用 [规格](spec.md)，视觉沿用 [DESIGN.md](../../DESIGN.md)。用户已确认首次配置与日常维护共用一个搜索设置对话框。

## 设计目标与方向

使用者在会话库中回找对话，主要任务是输入想找的内容、判断命中、打开原文。模型配置与索引维护是低频操作，不占据日常阅读空间。

延续现有开发者工作台：平面布局、清晰边界、小圆角、主题色选择态。精致感来自对齐、信息顺序、文字节奏和状态稳定性。主界面只呈现搜索、筛选、结果与必要状态；解释、计价依据、去重明细进入按需帮助或详情。

界面只增加三个接触点：搜索模式、搜索设置、索引状态。左侧搜索与结果、中间阅读、右侧画像的关系保持一致；单会话内搜索继续承担当前会话的关键词定位。

## 画面一：会话库日常搜索

### 左侧的结构

| 位置 | 内容 | 作用 |
| --- | --- | --- |
| 现有面板标题 | 会话库、收起入口 | 保留现有导航关系 |
| 模式行 | 关键词／语义；右侧索引状态与设置图标 | 切换检索方式，查看维护状态 |
| 搜索行 | 搜索输入；语义模式有明确搜索按钮 | 保留完整输入宽度 |
| 常用筛选 | 客户端、项目 | 两列排列，多选显示名称与附加数量 |
| 扩展筛选 | 更多筛选 | 日期、会话关系、执行模式、历史模型等 |
| 结果栏 | 当前结果类型与数量；语义结果排序 | 区分关键词结果和语义结果 |
| 结果列表 | 会话标题、原始片段、展开更多 | 阅读、比较、定位原文 |

模式使用紧凑分段控件，文本为“关键词”“语义”；选中底和文字沿用现有主题。设置使用现有齿轮图标风格，并提供“搜索设置”的可访问名称。

关键词占位符为“搜索标题或消息”，沿用实时查询；语义占位符为“描述你想找的对话”，通过 Enter 或搜索按钮提交。按钮直接写“搜索”，不加入模型名称、技术术语或每次查询费用标签。

模式切换保留输入和共同筛选，不自动发起模型请求。已有结果继续保留实际类型，例如“关键词结果”；用户编辑输入但尚未提交时，不把旧结果标成新查询的语义结果。进行新查询时保留完整旧结果，在搜索按钮固定位置显示进度，并暂停旧结果下钻；完成后整体替换。

首次未配置时，点击“语义”打开设置的模型连接页；首次正在构建时，点击打开构建进度。关闭设置后保留原搜索上下文；首次就绪前不出现可以提交却注定失败的语义搜索框。

### 查询筛选

客户端和项目使用可搜索多选；同组选项任一匹配、不同组同时满足。日期、会话关系、执行模式、历史模型、标题条件和消息／轮次数量等收进“更多筛选”，不铺满侧栏。

会话关系与执行模式分别设置，默认值直接写“排除子 Agent”“排除 Quiet”，不把未识别记录命名为已确认常规。允许选择全部、指定关系或指定模式，未识别属性的含义放进区域帮助。

查询筛选只作用于本次搜索，与设置中的维护范围分别保存。维护范围收窄后，保留的有效旧索引仍能被搜索。有效查询上下文存在时，只改筛选直接更新结果；上下文过期时给出“重新搜索”动作，不在后台悄悄重复编码。

关键词的“包含过程消息”按原能力保留；语义模式不显示不能执行的过程正文选项，切回关键词恢复此前选择。

### 结果的阅读顺序

- 每组先看会话标题，再看一个最佳原始片段，最后看客户端、项目与更新时间。元信息保持一行，过长时截断并可查看完整值。
- 标题最多两行，片段默认三至四行，依靠分隔和留白区分会话，不再套一层独立卡片。选中组沿用主题浅底和细边界反馈。
- 语义默认“相关性”，可切“最近更新”。结果数量表达本次返回的候选集合，不宣称是全历史精确命中总数；候选上限等定义进入结果区域帮助。
- 语义片段保留原文，不为了展示命中强行高亮并不存在的查询词，不增加正确率百分比、星级或生成式命中解释。关键词继续按字面高亮。
- “更多片段”在该组内展开；标题打开会话，片段直接打开对应分支并定位消息。去重计算不合并原始会话，不丢失各自位置。
- 分页采用现有紧凑分页。打开原文及返回后，保留查询、筛选、页码、展开组及滚动位置。

## 画面二：搜索设置对话框

### 固定框架

建议桌面宽度约 820px，最大高度受视口约束。固定标题“搜索设置”、一个区域帮助入口和关闭按钮；下方三个等权页签为“模型连接”“范围与构建”“调用策略”。选中页签采用现有底线样式，正文独立滚动，主要动作固定在底部。

不加入新的全局设置页、首次向导或模型管理中心。首次使用与再次进入使用同一位置和相同字段；页签切换保留未保存草稿，关闭时若确有未保存内容，在同一对话框内确认放弃，不叠加第二个弹窗。

从齿轮进入时恢复上次页签；从索引状态进入时直接定位“范围与构建”的进度区。打开对话框前关闭筛选浮层，关闭后恢复触发入口焦点和阅读位置。

### 模型连接

正文只放三项主要字段：

| 字段 | 展示与操作 |
| --- | --- |
| 服务地址 | 单行输入，支持粘贴和完整查看；最终请求地址进入按需详情 |
| 模型 | 直接输入模型标识，不擅自默认特定模型，不自动安装或下载 |
| API Key（可选） | 默认遮罩；眼睛显示／隐藏，复制与清除收在同一输入尾部 |

控件与标签纵向对齐，服务地址与模型名留足宽度。较长技术值使用等宽字体；完整 Key 可在输入区横向查看，不挤压对话框。切换页签或重新打开时恢复遮罩。

底部保留次按钮“测试连接”和主按钮“保存连接”。反馈只在一个固定位置显示“连接可用”或具体失败原因；不为每个字段增加绿色说明行。首次保存后进入范围页，保存本身不开始构建。

模型连接只显示服务地址、Embedding 模型和可选 API Key，不提供高级连接设置。编码格式按明确支持的模型名称自动适配，用户无需配置指令前缀；实际向量维度只出现在测试成功结果中。测试使用合成文本，具体请求与用量可在帮助和调用记录查看。已有连接继续使用保存的编码规则，避免升级后静默改变已有索引。

更换不兼容模型时，在保存前直接显示“更换模型后需要重建索引”，并提供明确的继续与取消动作；只改 Key、超时、限流不显示重建提示。影响确认仍在当前对话框内完成。

## 画面三：范围、预览与构建

### 选择维护范围

首次进入时完整展示范围表单；已经有索引时先显示当前维护范围和构建状态，范围表单通过“编辑范围”展开。

时间范围首次不预选。用户明确选择“全部历史”或“最近 N 天”，选择后显示对应输入；客户端与项目均可多选。“会话关系”“执行模式”使用各自的筛选控件，默认排除已确认子 Agent 与 Quiet。历史模型、标题条件和数量区间收进“更多条件”。

“保留范围外索引”无需用户重新打开开关，默认规则直接生效。“清理窗口外索引”作为独立选项，默认关闭，放在折叠的保留策略中；其影响为关键操作说明，展开时用正常正文字号表达，不作为常驻脚注。

字段称为“维护范围”，弹层标题和筛选始终称为“搜索范围”，避免用一个“范围”同时代表两件事。正文内容与去重属于既定规则，不额外增加一组难懂的开关。

### 构建预览

表单下方只有一个主要动作“预览构建”。预览只分析本地计划，不开始模型批量调用；结果在同一页内替换为可确认的构建摘要，保留“修改范围”入口。

摘要按一张平面清单展示，第一层只保留待处理会话、待编码文本块和预估费用，费用在右侧对齐。复用块数、估算 token、覆盖来源及存储依据通过“查看明细”展开，不放成多张统计卡片。

预估费用使用“预估”字段名和近似标记；未设置单价时显示“未知”，旁边提供“设置单价”，进入调用策略后可返回当前预览。极小的非零费用不能直接舍入成看似免费的零值。预览状态过期或配置变化时，将主要动作恢复为“重新预览”，不沿用旧费用开始新计划。

底部主要动作变为“开始构建”。此摘要就是开始前的规模与费用确认，不再叠加重复确认页。第一次构建结束前，关键词持续可用，语义状态显示“首次构建中”。

### 运行中的进度

构建开始后，同一区域展示一个进度条，重点为当前阶段、已处理／总文本块和已用时间；阶段名称用“扫描历史”“构建索引”“发布索引”等任务用语。未确定总量时显示阶段，不制造百分比或倒计时。

主要动作随状态变化：构建中为“暂停构建”，已暂停为“继续构建”，失败为“重试”；初次完成后提供“前往搜索”，仅切换模式并聚焦输入，不替用户提交查询。日常就绪后提供“立即更新”。

“查看明细”集中展开新编码、复用、失败、调用用量、预估剩余时间和费用。复用量不冒充模型调用次数，初次处理进度不冒充已经可搜索的覆盖比例。

关闭对话框不停止任务。左侧模式行保留索引状态入口，例如“构建 64%”“已暂停”“已就绪”；点击回到同一进度位置。状态有固定宽度和等宽数字，更新百分比不推挤输入或结果列表。

暂停构建后仍允许主动语义查询；说明放在暂停动作的按需帮助中，按钮名称不使用含糊的“暂停所有”。预算停止、失败和用户暂停使用不同文字与图标。

## 画面四：调用策略

默认展开的内容只有单价、每日预算与维护延迟。日预算未填写表示未设置限制，不能以 0 代表该状态。输入单位就近作为字段组成部分，沿用产品费用显示规则。

今日用量采用一张紧凑清单：构建、查询、测试及合计费用；实际值与估算值通过字段及必要标记区分。请求列表、复用情况和计价依据进入“查看明细”，不在每次搜索后弹出消费通知。

“高级调用参数”集中收纳并发、批次、token 预算、请求与 token 速率、超时和重试；普通状态保持折叠。底部主要动作为“保存策略”，不在每个参数旁重复放帮助问号。

“更多操作”容纳“关闭语义搜索”和“清除语义索引”。关闭保留模型连接与索引；清除展示将移除的派生数据及原始会话保留事实，使用明确的危险操作确认。危险入口不与保存、构建、暂停并排竞争。

## 状态与用户下一步

| 状态 | 用户能直接看到的内容 | 主要下一步 |
| --- | --- | --- |
| 未配置 | 关键词正常；语义可发现并进入设置 | 配置模型连接 |
| 首次构建 | 首次构建中、进度入口 | 查看进度；继续关键词搜索 |
| 已就绪 | 语义可以选择和提交 | 搜索 |
| 更新中 | 已有完整有效结果继续可用 | 搜索或查看进度 |
| 后台已暂停 | 已暂停；查询仍可用 | 继续构建或主动搜索 |
| 预算停止 | 索引状态显示预算停止 | 查看用量／调整预算 |
| 主动查询被预算阻止 | 查询位置显示具体原因，旧结果保留 | 调整预算或明确切换关键词 |
| 连接失败 | 当前操作处显示失败与重试 | 重试／修改连接 |
| 当前筛选下无可检索内容 | 一条空状态与操作入口 | 调整筛选 |
| 已确认范围尚未覆盖 | 明确为尚未建立索引 | 查看维护范围／开始构建 |
| 不兼容模型已保存 | 需要重建；关键词可用 | 预览重建 |

只有有数据依据时才区分“尚未覆盖”与普通空结果；不能把候选不足推断成全历史没有相关内容。错误、预算阻断及必须重建的提示直接可见，详细诊断通过展开查看，不静默切换搜索模式。

## 视觉、响应式与可访问性

- 采用现有字体、主题变量和图标体系。对话框标题建议 18px，区域标题与输入正文 13px，控件及字段标签 12px；原会话阅读字号保持不变。字号为本界面建议，沿用当前工作台的相邻层级，不另建字体系统。
- 普通区域使用细分隔与留白；只有选中、主要动作及必要状态使用主题色。只给浮层现有强度的阴影，深色主题使用同名变量，不增加高亮光晕或渐变装饰。
- 组件间距优先沿用现有 8／12／16px 节奏。表单标签和输入边线对齐，金额及进度数字右对齐。每个当前任务区域只有一个主按钮。
- 桌面沿用约 300px 的默认会话侧栏。模式行和筛选按侧栏自身宽度适配；拖窄时先压缩状态入口为有可访问名称的图标，再让控件换行、筛选单列，不强制扩大整页最小宽度。状态变化不触发新的换行。
- 1023px 以下沿用现有会话列表抽屉；打开设置临时停用底层交互，关闭后恢复抽屉、位置与焦点。小屏设置使用接近全屏的同一对话框，页签和动作保持可达，正文单列滚动；软件键盘出现时避免底部按钮遮挡输入。
- 关键图标有可访问名称，触屏命中区满足舒适点击，不通过缩小文字适配窄屏。页签支持方向键，筛选支持搜索与键盘选择，Escape 按浮层层级关闭并恢复焦点；中文输入法确认不触发搜索提交。
- 构建进度以合适频率播报，不对每次百分比变化抢焦点。动效仅用于必要进度与状态反馈，遵循 reduced-motion；不对旧结果整体淡出。
- 中英文使用相同布局与状态语义，保留长模型名、路径、项目重名、未知费用、超长错误和大规模数量的展示空间。帮助支持点击、键盘和触屏，不将含义只藏在 hover。

## 组件复用与审阅边界

筛选复用 [FilterSelect](../../web/shared/ui/FilterSelect.tsx)、[ProjectPicker](../../web/shared/ui/ProjectPicker.tsx)、[MultiFilterPicker](../../web/shared/ui/MultiFilterPicker.tsx)、[DatePicker](../../web/shared/ui/DatePicker.tsx)；帮助复用 [HelpPopover](../../web/shared/ui/HelpPopover.tsx)，分页复用 [ResourcePagination](../../web/shared/ui/ResourcePagination.tsx)。对话框沿用项目既有 Radix Dialog 结构，现有用法见 [PricingManager](../../web/features/usage/PricingManager.tsx)；不把目前不存在的通用搜索设置组件当成已交付能力。

布局依据会话库界面与源码；应用实现和验证见 [任务](issues/) 及 [验证记录](../../docs/validation/semantic-search.md)。验收重点为模式切换不误发模型请求、配置不自动构建、预览费用可理解、进度始终可找到、筛选与维护范围独立、返回原文上下文保留，以及深浅主题、中英文和窄屏操作。

## 确认点

用户已明确要求开始开发。控件像素与技术参数由实现决定；源码完成、自动化检查、真实浏览器及模型验证分别记录。

## 搜索范围统一

关键词与语义模式共享 SessionScopeFields，客户端、项目、模型均支持多选，并提供相同的关系、执行模式、日期、标题、消息数和轮次数筛选。切换模式保持条件。关键词保留过程记录开关；语义保留排序与覆盖信息。未选择时显示全部，移除搜索中的手动添加模型行。

子菜单和父筛选使用一致弹层层级，子菜单后挂载并通过 Portal 展开；父浮层固定标题、条件独立滚动。搜索按钮内部居中显示语义加载图标，关键词在输入框图标槽显示更新；不增加进度行或清空旧结果。
