# 搜索设置参数与模型连接说明

Status: resolved
Type: task
Blocked by:

## 范围

在搜索设置的连接字段与调用策略参数旁增加帮助图标，按需解释用途、调大调小的影响、零值／留空规则和切块变化的重建影响。连接说明明确要求 Embedding 模型，提供本地 Ollama 的安装命令、地址和模型示例，说明本机无鉴权服务可留空 Key。

## 验收

帮助复用统一组件，支持点击、键盘、触屏、Escape 和焦点恢复；不在表单中堆叠常驻小字，不改参数默认值与调用行为。核对实际实现与官方模型服务文档，完成中英文目录／类型检查、构建与浏览器桌面／窄屏及主题验证。

## Answer

连接页的 3 个字段和调用策略的 13 个参数均增加按需帮助，沿用统一 HelpPopover。参数帮助说明含义、作用范围、调大／调小的影响及特殊值；切块参数明确提示重新预览和构建。预算零值说明与实际估算判断保持一致。

模型帮助明确使用 Embedding 模型，提供本地 Ollama 下载命令、地址、模型名称与无鉴权时 Key 留空示例，并链接官方安装页。已核对官方接口兼容说明和模型页。

中英文目录和完整类型检查、构建、公开内容与构建产物检查通过。浏览器逐项验证 13 个参数帮助的可见性、内容、边界及 Escape 焦点恢复，并覆盖 3 个连接帮助、英文键盘打开、深浅主题、390px 窄屏和长指南滚动。配置测试在隔离合成环境中进行，没有改变日常模型连接或发起新的日常模型调用。
