# 新安装、端到端与空间验收

Type: task
Status: claimed
Blocked by: 01, 02, 03

## 目标

对照[规格](../spec.md)验证新结构全部现有功能、新用户安装与后续启动，确认减少重复存储没有造成历史、搜索或统计丢失。

## 验收

- 空数据目录与自定义目录初始化新结构，无 `.bak`、旧库迁移或无意义整理等待；按启动配置发现会话，空仓库登记正常显示，添加仓库后生成地图。
- 第二次启动复用新索引，整理不额外触发清空、全量解析或结果发布，正常增量刷新沿用既有生命周期；资源状态和语言偏好保留。
- HTTP／CLI 与真实浏览器验证代码地图、会话库和资源管理，中英文、筛选、分页、全文中文搜索、简易／完整／轨迹、画像、用量、资源列表／地图、调用与会话数、证据下钻及错误提示。
- 合成数据覆盖分支、复制前缀、工具配对、原始诊断、缺口、缺失来源及读取失败。管理写操作只使用隔离合成资源；真实客户端历史和配置只读。
- 同一组合成输入比较紧凑格式与重复存储基线，记录正文与元数据占用、保留版数量、空闲页及实际文件大小；多次刷新验证增长有界。
- 启动整理在失败与中断后的恢复行为、FTS 候选与最终结果正确，检查阈值边界和服务运行期间不整理。
- 必要全套测试、类型检查、构建及 `npm run check:public` 通过。详细真实输入与截图仅保留在私有验收材料中。

## Comments

- 2026-10-08：不把源格式兼容测试、组件测试或完整性校验单独等同于端到端验收；不承诺固定压缩比例。
