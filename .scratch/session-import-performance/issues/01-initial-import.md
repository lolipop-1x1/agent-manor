# 首次导入优化与性能对照

Type: task
Status: resolved

## 目标

减少首次导入的重复读取和索引写入成本，验证有界解析并发，保留完整版本和数据正确性。

## 验收

- 固定输入、原实现、空库基线和完整功能准备边界。
- 对照解析并发一、二、四线程的实际耗时与资源占用。
- 读取前缀校验、追加、截断、改写、错误恢复与来源检查点回归通过。
- 消息、会话、用量、搜索计数及结果与基线相同。
- 增量刷新、旧版本、失败保留上一版与维护验证通过。
- 类型、构建和公开内容检查通过；详细真实材料只保存在忽略目录。

## Answer

- 首次 JSONL 主解析合并哈希读取；固定前缀复核、活动追加与改写拒绝保持原语义。
- 默认两解析线程、单写入者；批次确认限制积压，字符词项在线程内预计算。
- 首次大批次写入，辅助索引后建；唯一约束、外键、两类全文索引及完整发布保留。
- 完成来源保存检查点，失败／重启核验复用；局部范围、来源删除、重复发现与孤儿修订清理有回归覆盖。
- 固定 74 文件约 122 MiB，四种方案各三轮；原实现中位 22.06 秒，默认方案 17.73 秒，耗时下降 19.6%。12 轮正文、元信息、用量、指纹与搜索结果摘要一致。
- 完整方法、资源占用和结论边界见 [性能对照](../../../docs/design/session-import-performance.md)。详细来源与原实现冻结快照留在本机忽略目录。
- 相关回归、类型／翻译检查、构建、公开内容检查与编译后隔离服务验收已通过。完整测试集 1,231 项通过；最后的检查点修复由 26 项定向回归再次验证。编译后服务与实际增量检查均通过。
