# 全局历史自动同步与真实数据性能验收

Type: task
Status: resolved

## 目标与决策

- 全局顶栏在五页显示同一份“自动同步”，网页可见时按间隔检查全部历史，隐藏时暂停；地图分析频率继续独立。
- 统一同步进度、错误与原操作重试；无变化的自动检查只更新同步状态，手动同步保持主动读取语义。
- 修复资源详情在历史变化时清空的问题，保持已有完整内容与阅读位置。
- 真实历史测试覆盖无变化与真实新增记录的同步周期、五页交互、空白帧、布局变化和主线程长任务，详细内容仅保存在 `.local/`。

## 计划

见 [实施计划](../../../docs/plans/2026-10-14-global-history-sync.md)。

## 结果与验证

- 已实现五页全局自动同步、无变化去重、首次发布通知、统一错误重试及在途进度保留。
- 真实测量后迭代了慢报告合并与自动检查等待、会话加载行跳动、地图与文件表被历史进度带动重绘。
- 全量 1,197 项与最终前端 121 项测试通过；15 组同步、12 组长会话与地图、55 组资源及地图工作区 Chrome 验收通过。
- 五页真实历史均观测到 0 空白帧、旧容器保留和 0px 滚动差值；地图长任务从每轮 12–15 次降至 0 次。
- 大报告耗时和总览约 100ms 的结果替换短任务如实记录，真实记录与截图保存在忽略目录；测试偏好已恢复。
- 详细方法与边界见 [全局同步验收](../../../docs/validation/global-history-sync.md)。
