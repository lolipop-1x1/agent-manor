# 刷新入口、任务联动与失败恢复

Type: task
Status: resolved
Blocked by: 01

## Answer

- 全局历史任务统一管理全部客户端检查、局部检查、完整校验、任务轮询与失败重试。
- 会话库原手动入口合并到全局菜单；客户端筛选、阅读锚点及版本一致性保留。
- 总览、用量与资源接入完成通知；当前页面更新，隐藏页面再次激活时读取。
- 页面动作统一复用刷新控件，语言与外观固定右端，地图及会话自动刷新位于各自操作区。
- 资源盘点失败再次执行盘点，任务状态读取失败只重试读取。
- 修正地图关闭自动刷新后仍继续空闲状态轮询的不一致，保留手动任务进度查询。
- [验收记录](../../../docs/validation/refresh-workflow.md)列出通过的单元测试、浏览器专项及回归。
