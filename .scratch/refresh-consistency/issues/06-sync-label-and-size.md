# 历史同步命名与按钮尺寸

Type: task
Status: resolved

## 目标与决策

- 全局按钮改为“同步历史”，状态与自动同步文案保持一致，英文使用 Sync history。会话库的可见标签直接使用“自动同步”，可访问名称保留会话库作用范围。
- 移除按钮 146px 固定宽度，复用普通按钮的字号、高度和内容宽度；保留阶段、百分比及原位细进度条。

- 语言、主题和 GitHub 作为同组控件换行，避免同步文案变化后右侧图标被拆开。

## 验收计划

- 检查中英文文案与可访问名称，回归状态、进度和两个自动设置。
- 检查桌面与窄屏的普通按钮尺寸、运行阶段文案及弹层定位，运行类型、构建与公开内容检查。

- 中文顶栏显示“自动同步”和“同步历史”，英文为 Auto sync 和 Sync history；状态、进度、时间、筛选帮助及可访问名称已同步，稳定消息标识和接口参数保持。
- 已取消 146px 固定按钮宽度，沿用普通控件的内容宽度、字号与高度；运行百分比与细进度条保留。右侧语言、外观及 GitHub 整组换行。
- 11 组历史同步 Chrome 验收及 12 组独立自动同步回归通过，已核对中文桌面明亮和英文窄屏深色的常态与运行截图。翻译、Web 类型、构建、公开内容和差异检查通过。
