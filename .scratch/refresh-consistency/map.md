# 刷新入口与状态一致性

## 已作决策

- 统一布局和状态反馈，修复资源盘点重试，提供全局历史更新并联动当前页面。
- 会话库与代码地图自动刷新继续独立，常驻后台历史同步留待后续。
- 采用“历史更新”和“页面更新”区分来源检查与报告读取。
- 全局历史更新始终覆盖全部客户端；日常 Web 移除范围选择和内容重新检查，CLI 保留局部检查与完整检查能力。

## 决策树

- 全局历史更新已确认
  - 默认客户端范围：全部客户端快速检查。
  - 会话库原刷新入口：合并到全局入口。
- 各领域独立更新范围已确认
  - 总览与用量读取报告。
  - 代码地图分析当前仓库。
  - 资源盘点更新本地清单。
- 自动刷新生命周期已确认沿用现有约定。会话库设置在顶栏直接显示，地图设置保留独立操作区；按钮直接呈现进度，最近更新时间与详细进度收进状态弹层。
