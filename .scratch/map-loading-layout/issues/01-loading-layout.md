# 地图加载提示不应挤占结果区域

Type: task
Status: resolved

## 工作

修复地图会话加载与保留结果重新查询时的空白和布局跳动，保留首次无结果时的加载占位。

## 验收

- 延迟地图会话和覆盖请求，统计卡片与地图在加载结束前后位移不超过 1px。
- 覆盖中英文、桌面与窄屏；加载状态可访问，错误提示继续直接可见。
- 类型、构建、相关回归和公开内容检查通过。

## Answer

会话加载与保留结果重新查询误用了最小高度 460px 的首屏占位样式，导致统计与地图整体跳动。两种状态改用筛选栏已有底部空间内的 12px 状态行，首次无结果占位及错误提示保留。

延迟请求浏览器脚本先复现 460px 位移；修复后中英文、1440px 和 390px、会话与覆盖查询共 8 组均为 0px 位移。现有地图会话筛选浏览器回归、类型与翻译检查、606 项测试、前端构建和公开内容检查通过。跨页视野断言等待缩放渲染帧完成后再记录倍率。
