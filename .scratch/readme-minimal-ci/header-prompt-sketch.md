# 简笔画头图提示词

模式：使用简洁版头图作为内容参考，重新绘制为稀疏的二维线稿。
产物：`docs/assets/readme/agent-manor-banner-sketch.png`，2172×724。
原始版与简洁版均保留，本轮只在本地替换中英文README的头图引用。

```text
Create a NEW style variant of this README hero banner, using the reference ONLY for the subject and broad left/right arrangement. Transform it completely into a true minimalist hand-drawn line illustration.

Wide 3:1 banner. Warm white background. On the left, a friendly robot butler drawn in just a few simple dark ink strokes: rounded rectangular head, two small dot eyes, a tiny smile, simple body and arms, and a small cobalt blue bow tie shaped like two rounded triangular wings with a short rectangular knot, recalling the AgentManor app icon. The robot should feel like a charming pen doodle, not a rendered toy. On the right and farther behind, a small manor house suggested with a handful of thin outline strokes: a modest roof, door, and a few windows. A single loose curved path connects the robot to the manor. At most one or two simple shrub outlines. Abundant empty space, calm composition.

STYLE IS THE PRIORITY: flat 2D simple line drawing, slightly imperfect human pen contours, very sparse marks, consistent thin charcoal stroke, predominantly unfilled shapes. No 3D volume, no modeling, no gradients, no glossy surfaces, no cinematic lighting, no watercolor, no hatching, no detailed garden, no elaborate decoration, no floating interface panels. The only color accent is the small blue bow tie. No text, no letters, no typography, no watermark. Elegant and light, suitable for a clean open-source project README header.
```
