# 大仓库地图的连续缩放与全屏浏览

Type: grilling
Status: resolved

## Scope

- 用户已认可地图全屏、内部缩放、拖动平移、信息随缩放展开和一键适应窗口。
- 用户进一步要求文件很多时能持续放大查看局部，文件名和百分比在放大后保持清晰。
- 保留当前读取、修改、活动指标及精确／近似证据口径，真实业务输入不进入公开文档和测试。
- 目录汇总和可排序文件列表作为后续增强；本轮先确认连续缩放体验。

## 设计树

1. 核心目标：已确认。全屏增加可用空间，连续缩放和平移定位局部，标签按可读空间显示。
2. 缩放与统计范围：Z1 已确认。缩放只改变地图视野，显式目录选择改变统计范围。
3. 滚轮交互：Z2 已确认。地图内普通滚轮缩放，地图外滚动页面；同时保留按钮入口。
4. 缩放能力与渲染边界：只读核查已完成。当前像素取整和固定层级间距可能令极小文件变为零面积；单纯 CSS transform 不能恢复。建议保留逻辑几何精度，视野变换独立于目录筛选，按投影尺寸显示标签。
5. 文字缩放：Z3 已确认。文件几何连续缩放，文字保持正常阅读字号，按可读空间展开文件名、百分比和行数；完整路径可悬停或聚焦查看。
6. 返回与状态：建议适应窗口恢复完整视野；进出全屏、开关侧栏及切换着色指标保留局部位置与选择，显式切换仓库、目录或文件集合时适应新范围。
7. 验收：建议使用大量合成文件、极小文件、深目录和长文件名，验证局部标签、定位、平移、全屏及统计一致性。

## 交互设计

- 缩放以鼠标所在位置为中心，地图内普通滚轮直接缩放；提供放大、缩小和适应窗口按钮，地图外保留页面滚动。
- 单击文件沿用选择和详情查询；拖动地图平移，拖动结束不能误触文件选择。
- 全屏内容包含地图、当前目录面包屑、着色指标和图例。支持退出按钮和 Esc，退出后保留目录与文件选择。
- 切换着色指标不重置视野；进出全屏和开关侧栏后维持正在查看的局部。切换仓库、目录或改变文件集合时适应新范围，避免留在已经不存在的区域。
- 小矩形显示指标颜色；屏幕投影达到可读空间时，依次出现文件名、百分比或活动次数、行数及近似提示。文字使用正常阅读字号，不随几何无限增大。
- 标签受地图视口裁剪；极大矩形的可见部分仍应能读到信息。超长路径通过悬停、键盘聚焦和文件详情查看。
- 色块之间采用总计 1 CSS 像素的视觉间隔，不随缩放变粗；极小色块不足以留缝时保留可见面积，放大后出现间隔。间隔仅作用于屏幕绘制，文件按钮不能覆盖它。
- 空文件仍为零行，沿用文件列表入口，不为地图虚构面积；极小非空文件需要保留正面积逻辑几何。
- 采用当前全量覆盖查询结果，缩放和平移不新增统计 API，不重新计算分母或对应范围，不触发后台分析。
- 目录汇总和可排序列表延后，不阻塞本轮连续缩放功能。

## Acceptance

- 纯函数测试使用一万个合成文件、大小悬殊行数和深目录；浏览器端到端按用户最新要求使用已登记实际仓库，不另建合成仓库。
- 每个非空文件保留有效几何，能通过持续缩放或定位进入可读局部；不以固定 8 倍、16 倍上限作为可读能力保证。
- 小文件放大后显示名称和对应指标；文字保持清晰、正常字号，标签不被缩放前阈值永久隐藏。
- 连续缩放以鼠标焦点稳定定位，拖动不会选择文件，适应窗口可随时恢复完整视野。
- 全屏进出、窗口尺寸与侧栏变化、着色指标切换、目录切换均符合视野和选择的约定。
- 缩放和平移前后，结果版本、筛选参数、统计摘要和文件覆盖数据一致；只有显式范围切换才改变统计范围。
- 验证明暗主题、按钮与键盘入口、窄屏布局和浏览器错误；记录密集样本的交互性能，必要时只渲染可见几何与标签。
- 几何测试使用合成数据；实际仓库的浏览器输入和截图仅留在忽略目录，公开材料只记录方法、匿名计数和结果。
