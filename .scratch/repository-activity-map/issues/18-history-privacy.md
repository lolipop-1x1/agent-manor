# Git 历史隐私清理

Type: task
Status: resolved

## Scope

用户明确要求清理旧 Git 历史中的个人身份、真实业务项目及公司内部信息。保留公开客户端、开源依赖名称及代码开发历史，覆盖远端分支和标签，并同步清理本地可达引用。

## Acceptance

- 仓库外私有备份覆盖改写前引用和当前未提交的任务记录。
- 在隔离副本中扫描历史文件内容、路径、提交消息、身份及二进制资料；清理后独立复扫无已知禁用词、用户目录及内部域名。
- 当前实现内容保留，依赖版本及 integrity 不变；需要覆盖的远端引用逐一使用旧 SHA 校验，避免覆盖并发提交。
- 推送后从 GitHub 新检出核查历史与当前公开检查，核对分支 SHA 和 CI。
- 明确区分已清理的 Git 引用与 GitHub PR 缓存、其他克隆等无法通过普通 Git 更新消除的副本。

## Comments

- 2026-10-05：开始执行；历史改写会改变受影响提交及后续提交 SHA。私有备份和清理规则保存在仓库外，不写入公开文件。
- 2026-10-05：三个远端分支已使用逐引用旧 SHA 校验原子更新，本地分支、Codex 树快照和四个工作副本同步；保留未提交的任务记录。GitHub 的旧 PR 引用仍可访问，普通 Git 操作无法移除。
- 2026-10-05：维护者明确要求暂不处理旧 PR 与缓存，不提交 Support 工单，申请草稿已从本机删除。分支与本地历史清理已完成，本任务 resolved；未清理的服务端副本边界保留说明。

## Answer

已在仓库外保存原始 Git 目录、全部本地引用的 bundle、GitHub 原始镜像及待提交记录，并使用固定官方提交的 git-filter-repo 2.47.0 在隔离副本中改写。82 个提交中 79 个发生改写；清理两份含真实业务信息的旧文档、个人路径、内部依赖地址和历史来源标识，包括一条现存任务记录中的真实本机标识。

独立复扫覆盖提交内容、路径、身份、消息和本地树快照；三个历史图片均为人工合成样例，未发现真实姓名或公司资料。全新从 GitHub 检出的三个普通分支，以及本地可达历史均未命中已知禁用词、个人目录、内部域名或待移除来源标识。锁文件仅改变来源地址，版本、integrity 及其他依赖元信息一致；当前实现代码逐文件一致。

本地旧 reflog 已过期并清理不可达对象，旧敏感提交不再存在于本地对象库；原始副本只留在仓库外私有备份中。既有 CI 日志检查没有发现私人或公司词，公共 runner 的标准目录不属于个人身份。

未处理的部分是 GitHub 只读 PR 引用、旧提交缓存及其服务端回收。旧 PR 虽已关闭，仍保留旧引用；仓库归档只能设为只读，不能隐藏敏感历史。这些副本需要由 GitHub Support 处理；维护者明确决定暂不处理，不提交工单，本机申请草稿已删除。不能宣称全部 GitHub 副本已经清除，也不能控制其他已有克隆。
