# 左右面板拖动宽度

Type: task
Status: resolved

## Scope

- 仓库导航与文件详情通过面向地图的分隔线独立调整宽度。
- 保留收起、展开、目录与文件选择；展开恢复本次页面中调整过的宽度。
- 导航范围 160–480 CSS px，详情范围 260–640 CSS px，地图至少保留 360 CSS px。
- 窗口变窄时约束实际宽度，不覆盖偏好；上下堆叠的面板不显示横向拖动入口。
- 支持指针捕获、触摸拖动与键盘左右键，统计范围和结果版本不变。

## Acceptance

- 验证左右拖动方向与上下限、指针移出分隔线后继续拖动及释放清理。
- 调宽后收起、展开和窗口切换恢复宽度；地图缩放倍率与局部视野保持。
- 实际仓库浏览器验收只读；真实名称、路径及截图留在忽略目录。
- 类型检查、布局测试、公开内容检查及构建通过后普通推送。

## Comments

- 用户要求左右面板都可拖动宽度，完成后推送。

## Answer

- 使用独立布局组件和现有 CSS Grid；9 CSS 像素命中区域不占额外布局宽度，悬停、聚焦与拖动高亮分隔线。指针捕获保证离开边界后继续调整，释放清理光标与文本选择状态。
- 上下限同时保护相邻面板和地图；收起时保留偏好，窗口变窄暂时分摊压缩，恢复窗口还原偏好。支持左右键、Shift 加速及 Home／End。
- 实际仓库 14 组 Chrome 只读验收通过，包含新增左右拖动与边界检查；地图倍率、局部中心、选择和结果版本保持，完整覆盖响应一致，无额外 API 查询或浏览器错误。
- Web 类型检查、生产构建、20 项相关测试及完整 146 项回归通过，含 4 项新增布局边界测试。公开内容检查通过，真实资料未进入交付文件。
- 只读复查发现压缩时调整一侧会覆盖另一侧偏好，以及旧临时宽度可能在面板／窗口恢复时重新生效；已将临时显示约束与偏好分离，并在面板状态或窗口宽度变化时清除。补充实际浏览器场景并重跑全部 14 组验收通过，最终复查无剩余问题。
