# 连续缩放的逻辑几何与视野计算

Type: task
Status: resolved

## Scope

- 规格见 [连续缩放设计](20-map-zoom-design.md)。
- 新增 web/map-viewport.ts 和对应纯函数测试，保持每个非空文件的正面积，不取整，不用固定层级间距挤掉小文件。
- 逻辑布局独立于屏幕尺寸；提供适应窗口、焦点缩放、平移、文件定位、投影及可视区域筛选。
- 缩放上限按最小文件的可读尺寸动态计算，允许高倍缩放，保留有限数值保护。
- 不改覆盖统计、历史解析或 API。

## Acceptance

- 一万个合成文件、大小悬殊行数、深目录的所有非空叶子保持有效几何。
- 焦点缩放、重新适应尺寸、极小文件定位、裁剪及数值边界有实际行为测试。

## Answer

- 已新增浮点逻辑布局及适应窗口、焦点缩放、平移、定位、投影和裁剪函数，逻辑布局独立于视口尺寸。
- 10 项地图行为测试通过，覆盖一万个文件、悬殊行数、180 层目录、空文件、极小文件定位、标题避让、焦点稳定和数值保护；完整套件 142 项通过。
- 定位的最小可读高度统一为 128 像素；横向薄块回归验证目录标题下仍能显示名称、指标和行数。
- 缩放上限取可读需求的 16 倍余量，基础至少 1024 倍逻辑缩放，最终受浏览器数值精度保护；不承诺数学无限。
