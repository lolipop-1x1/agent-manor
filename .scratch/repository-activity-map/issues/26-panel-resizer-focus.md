# 分隔线拖动出现多条线

Type: task
Status: resolved

## Scope

- 用户发现拖动时分隔线旁出现多条绿色长线。
- 将分隔线的键盘焦点与拖动状态统一为单条细线提示，保留键盘调整与命中区域。

## Acceptance

- 复现键盘焦点后拖动造成的全局 outline 与分隔线叠加。
- 在左右分隔线键盘焦点和拖动状态断言没有额外外框，仍有清晰单条提示。
- 实际仓库只读浏览器流程通过；真实截图和诊断仍只保存在本机忽略目录。

## Comments

- 已在修复前通过 Chrome 建立键盘焦点并复现回归断言失败：全局 2 CSS 像素 outline 绘制命中区左右边，叠加中间的高亮线，形成三条线。
- 仅对分隔线取消外框，继续通过现有单条高亮线显示键盘焦点与拖动状态；其他控件的焦点外框不变。

- 实际仓库 14 组只读 Chrome 验收重跑通过，覆盖拖动、键盘、宽度恢复、窄屏、地图缩放及统计不变量，浏览器错误为零。
