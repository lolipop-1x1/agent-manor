# 目录展开与地图面板收起

Type: task
Status: resolved

## Scope

- 保留现有主题、地图指标、API 与统计口径。
- 目录按层级逐级展开或折叠，展开箭头与目录选择独立。
- 左侧仓库导航和右侧文件详情可独立收起、恢复，保留当前目录和文件选择。
- 收起面板释放地图宽度，大屏使用完整可用空间；窄屏仍可访问所有操作。

## Acceptance

- 默认只显示顶层目录；展开、折叠不改变统计筛选，选择目录更新地图。
- 从地图或面包屑进入深层目录时展开其祖先；切换仓库重置目录展开状态。
- 左右面板四种组合均可恢复，收起后所选文件与目录保持，地图重新布局。
- 验证桌面、窄屏、明暗主题、键盘操作与浏览器错误；测试仅使用合成示例。

## Comments

- 2026-10-05：用户要求逐级目录操作和左右独立面板收起。按保留式交互改造实施，使用现有 React、Phosphor 与 CSS。

## Answer

- 新增目录树组件，默认折叠子目录，展开箭头与统计目录选择独立；支持保留子层展开状态、地图下钻展开祖先、切换仓库重置和含空格的目录标识。
- 左右面板独立收起至 44 px 边栏并保留选择；恢复按钮保留键盘焦点。选择地图或列表文件自动展开详情。移除桌面最大宽度，现有 ResizeObserver 按可用空间重排地图。
- `npm run check`、`npm run build:web`、7 项前端测试及 `git diff --check` 通过；新增代码没有依赖变更。构建沿用既有 CodeViewer 大于 500 kB 的提示。
- `node scripts/e2e-workspace.mjs` 使用真实后台、隔离历史目录和合成仓库，在 Chrome 中验证目录层级、筛选独立、四种面板组合、选择保留、重新布局、键盘焦点、明暗主题、切换仓库及响应式。1440 px 视口的地图宽度为 864 → 1020 → 1296 px；1920、900、390 px 视口无页面横向溢出，浏览器运行异常为 0。
- 新面板按钮的明暗对比度分别为 4.87:1、7.66:1。合成验收截图仅保存在忽略的 `.local/workspace-e2e/`，不包含真实仓库、历史或个人身份。
