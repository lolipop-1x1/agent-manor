## 问题

知识未变化时仍周期性读取、切块全库，HTTP 主线程出现与正文规模相关的停顿。

## 实施范围

- 以修订身份和编码配置指纹记录待维护范围，知识状态变化及重启后正确补齐。
- 暖无变化检查快速结束；切块、批量扫描与索引计算移入可停止的后台 Worker。
- 与任务 03 共用单执行者和取消规则，保留已有预览、同意、预算与知识可用性语义。

## 验收标准

- [x] 本地真实知识库无变化时不再周期性执行全库正文计算，状态与会话查询可并发响应。
- [x] 创建、修改、审阅、发布、废弃及恢复后的检索结果遵循当前修订和可用性。
- [x] 配置变化、暂停、停止和重启不遗漏待维护修订，不删除知识正文或必要证据。
- [x] 固定数据报告冷/暖维护耗时、主线程响应与内存；不将模型复用计为新增调用。

## 测试与数据

复用知识语义服务及索引测试入口和本地可控模型；直接观察真实数据只读查询及无变化维护，在隔离副本执行状态变化和构建。

真实数据使用范围沿用总规格：直接读取实际数据进行核对；写入与故障场景使用隔离副本。具体样本与截图只留本机。

## 协作与范围约束

实施前与任务 03 对齐任务身份、Worker 状态和取消契约，避免重复实现另一套调度机制。
