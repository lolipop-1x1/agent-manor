# 资源盘点与来源配置版本一致

Type: task
Status: resolved
Priority: P2
Review: R08
Spec: [总规格](../spec.md)

## 问题

新增/移除来源时复用已开始的旧扫描，来源配置已保存但盘点仍对应旧输入。

## 实施范围

- 扫描绑定来源配置和项目范围等实际输入版本。
- 变化期间安排覆盖最新输入的续扫，变更请求等待相应扫描结果。
- 同输入正常读取仍合并；缓存发布校验输入身份，失败保留上一完整快照。

## 验收标准

- [x] 扫描中新增来源后，操作成功返回与后续缓存均包含该来源。
- [x] 移除来源、连续变更及项目范围变化不会被旧扫描重新覆盖。
- [x] 相同输入的并发读取不创建重复全量扫描。
- [x] 失败可重试，收藏、操作记录及恢复材料保持独立。

## 测试与数据

复用 ResourceService 实际服务与临时资源来源；复制真实资源元数据到隔离目录进行变更，实际配置入口只读核对。

真实数据使用范围沿用总规格：直接读取实际数据进行核对；写入与故障场景使用隔离副本。具体样本与截图只留本机。

## 协作与范围约束

协调管理操作之后的盘点失效路径，保持现有预览、执行前校验和恢复机制。
