Type: task

## 问题

页面失活取消搜索后 loading 未复位，重新进入页面时按钮仍禁用、结果仍不可操作。

## 实施范围

- 取消、失败、成功和页面失活结束对应请求的忙状态。
- 通过请求身份控制 loading、错误和结果写入，防止旧请求清理新请求。
- 保留页面挂载、输入、筛选及上一份完整结果，恢复可操作性遵循当前范围。

## 验收标准

- [ ] 慢搜索后切页再返回，搜索按钮和结果按实际状态恢复，无需切换模式或重载。
- [ ] 旧请求取消/完成不覆盖较新的查询结果、错误或忙状态。
- [ ] 连续搜索、空查询、失败重试及筛选变化不留下遗留状态。
- [ ] 浏览器中英文、主题、窄屏和键盘操作通过。

## 测试与数据

复用现有语义搜索 API 和隔离浏览器测试；真实数据只读查询，受控延迟稳定触发切页及连续请求时序。

真实数据使用范围沿用总规格：直接读取实际数据进行核对；写入与故障场景使用隔离副本。具体样本与截图只留本机。
