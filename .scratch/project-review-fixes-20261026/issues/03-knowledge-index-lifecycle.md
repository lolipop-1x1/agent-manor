## 问题

多个请求可在异步配置读取期间同时通过忙碌检查，重复编码并覆盖控制器、进度和清理状态。

## 实施范围

- 构建、恢复、暂停与自动维护的状态检查、转换和启动使用同一串行边界。
- 进度、取消、失败和清理绑定具体任务身份；复用已有忙碌诊断。
- 协调 Worker 内外任务归属，旧执行者失去身份后不能发布向量或终态。

## 验收标准

- [x] 同一块的同一预览并发启动三次，仅一个任务被接受且仅新增一次必要模型请求。
- [x] 进度始终满足 completed 不超过 total，重复恢复和自动维护不新增并行执行者。
- [x] 暂停/恢复交错时取消覆盖当前全部执行；旧任务结束不清空新任务控制状态。
- [x] 停止后不发布成功结果，失败后可按现有入口重新构建。
